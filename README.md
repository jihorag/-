> **이 폴더는 무엇인가요?**
> 감정평가사 시험의 **문제 데이터**를 모으고·정리하고·앱에서 볼 수 있게 만드는 작업 공간입니다.
> 이 안내서는 **비전공자도** 각 폴더가 뭔지 한눈에 알 수 있게 정리한 지도입니다.

## ⭐ 제일 중요한 것 — 문제 데이터 (최상위에 있어야 함)

| 파일 | 내용 | 주의 |
|---|---|---|
| `questions_db.json` | **기출문제 원본** (실제 시험에 나온 문제) | 🔒 **절대 직접 수정 금지** |
| `questions_db_civil.json` | 민법 **연습문제** | 민법 담당만 수정 |
| `questions_db_econ.json` | 경제학원론 연습문제 | 경제학 담당만 수정 |
| `questions_db_re.json` | 부동산학원론 연습문제 | 부동산 담당만 수정 |
| `questions_db_law.json` | 감정평가관계법규 연습문제 | 법규 담당만 수정 |
| `questions_db_accounting.json` | 회계학 연습문제 | 회계 담당만 수정 |
| `taxonomy.json` · `taxonomy_v4.json` | 과목·단원 **분류 체계** | 여러 스크립트가 참조 |

> 🔒 **이 파일들은 반드시 최상위에 둡니다.** `viewer/scripts/sync-data.mjs` 가 저장소 루트를
> 직접 계산해 읽습니다. 하위 폴더로 옮기면 동기화가 **조용히** 깨집니다(파일이 없으면
> 경고만 내고 기존 데이터를 그대로 두기 때문에 눈치채기 어렵습니다).

문제를 추가한 뒤에는 반드시:
```bash
cd viewer && npm run sync-data
```

### 🔒 이름을 바꾸면 안 되는 것

- **`images/`** — 문항 본문에 `[IMAGE: ./images/…]` 로 박혀 있고, 117개 파일이 경로로 참조
- **`viewer/`** — Vercel 배포(`vercel.json`)와 GitHub Actions가 이 경로로 동작
- **최상위 `questions_db*.json` · `taxonomy*.json`** — 위 경고 참조
