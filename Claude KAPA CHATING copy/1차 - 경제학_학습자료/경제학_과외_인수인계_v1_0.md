## 📖 입력 자료 — 윤지훈 경제학 마인드

### 파일 정보

| 파일 | 크기 | 분량 |
|---|---|---|
| `거시경제학_마인드.md` | ~500 KB | 9개 Chapter, ~5,900줄 |
| `미시경제학_마인드.md` | ~450 KB | 8개 Chapter, ~5,300줄 |
| `거시경제학_마인드_OCR_.pdf` (원본) | 72 MB | 164p |
| `미시경제학_마인드_OCR_.pdf` (원본) | 70 MB | 160p |

### 변환 방식
원본 PDF는 ABBYY FineReader로 OCR된 PDF. `pdftotext -layout`으로 추출 후 Python 스크립트로 페이지 단위로 챕터 경계 인식하고 노이즈 제거.

### 변환 품질

#### ✅ 양호한 부분
- **챕터 구조**: 거시 9개, 미시 8개 모두 정확히 추출됨
- **수동 정리된 목차 인덱스**: 모든 절·항목을 깨끗한 한글로 정리해서 마크다운 상단에 배치 (OCR 노이즈 없음)
- **본문 텍스트**: 한글은 대체로 잘 읽힘. 학습에 충분.
- **명제 번호 (①②③)**: 시험 선지의 핵심. 깨끗하게 추출됨

#### ⚠️ 한계 (학습 시 참고)
- **2단 레이아웃이 그대로 흘러내림**: 본문 줄 사이사이에 사이드바(인접 박스, 추가 설명)가 끼어 있어 가독성이 떨어짐. 한 번에 죽 읽기는 어렵고, 토픽 키워드로 검색해서 읽는 게 효과적.
- **수식 깨짐**: 한자·그리스 문자·특수기호가 OCR에서 깨져 있음 (예: `G%`, `GZ가`, `刀F`, `匕` 같은 노이즈). 수식이 의심스러우면 **원본 PDF의 해당 페이지를 시각 확인**.
- **그래프**: 마크다운에는 들어가 있지 않음. 그래프 설명이 필요하면 원본 PDF에서 직접 확인. (마인드 교재는 그래프가 강점이라 강사가 강조한 부분)
- **표**: 일부 표는 텍스트 흐름 속에서 좌우 칼럼이 섞여 있음. 표가 핵심인 부분 (예: 학파별 비교 표)은 원본 PDF에서 확인.

## 🎯 출제 포인트 분석

### 현황
- **기출문제집 미수령** (수강생이 추가 업로드 예정)
- 윤지훈 교재 머리말에 따르면 **감정평가사 시험의 거시는 미시보다 난이도가 높음**
- 거시는 학파별 비교가 전반적 흐름이라 학파별 정리가 필수

### 알려진 시험 구조
- 감정평가사 **1차** 시험 5과목 중 하나 (부동산학원론, 민법, **경제학원론**, 부동산관계법규, 회계학)
- 경제학원론은 거시 + 미시 통합 (40문항 / 100분)
- 객관식 5지선다
- 절대평가 — 과목별 40점 이상, 전 과목 평균 60점 이상이면 합격

### 출제 다발 영역 (경제학 일반 기준 — 기출 자료 받으면 보완)

**미시**
1. **수요·공급 + 탄력성** (Ch.02): 매년 출제. 계산 문제 빈출.
2. **소비자이론 — 대체효과·소득효과** (Ch.03 §08): 슬러츠키·힉스 분해, 기펜재.
3. **시장이론 — 독점·과점** (Ch.05 §03~05): 가격차별, 게임이론.
4. **외부성·공공재** (Ch.08 §02~03): 코즈정리, 피구세.

**거시**
1. **국민소득 계산** (Ch.01 §02): GDP 측정, 3면 등가.
2. **IS-LM, AD-AS 모형** (Ch.04): 학파별 정책 효과 비교 필수.
3. **필립스곡선 + 스태그플레이션** (Ch.05 §03): 기대 부가.
4. **솔로우 모형** (Ch.07 §07): 균제상태 계산.
5. **환율 결정이론** (Ch.09 §02): 구매력평가설, 이자율평가설.

## 🧭 경제학 특유의 학습 포인트 (Claude용 가이드)

### 거시경제학의 핵심: **학파별 흐름**
- 고전학파 → 케인즈 → 신고전학파 종합 → 통화론자 → 새고전학파 → 새케인즈학파
- 각 학파의 **(1) 시장관 (2) 정책 효과 (3) 주요 명제**를 비교하는 표가 핵심
- Ch.06 「학파별 비교」가 사실상 전 챕터의 종합 표
- 회차마다 다루는 내용을 학파별로 정리하면서 진행하면 좋음

### 미시경제학의 핵심: **그래프와 수식**
- 무차별곡선 / 등량곡선 / 비용곡선 / 시장균형 / 게임이론 등 그래프가 본질
- 마크다운에 그래프가 없으므로, 그래프 설명이 필요한 회차는 원본 PDF의 해당 페이지를 시각 확인하면서 진행
- 수식 풀이가 많으므로 (효용극대화, 비용극소화 등) 단계별로 천천히

### 회차 진행 사이클 (참고)
```
1. 개념 — 핵심 정의·명제 + 일상 비유로 살 붙이기
2. 그래프 — (미시) 그래프 그리기 / (거시) 학파별 정책 효과 시각화
3. 암기 카드 — 시험 선지로 변환 가능한 명제 3~5개
4. 연습 문제 — 객관식 5지선다 1~2문제 + 풀이
```
