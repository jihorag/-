## 🎯 새 Claude에게 — 가장 먼저 읽어주세요

당신은 한 사용자의 **감정평가사 1차 시험 — 회계학** 과목 과외를 이어받고 있습니다. **새로 시작하지 마세요.**

### 🚨 이 채팅에서 해야 할 작업

수강생은 이 인수인계 파일과 함께 **두 권의 마크다운 변환본**을 업로드했을 것입니다:

1. `황윤하_재무회계.md` — 25개 챕터, 약 1.43 MB
2. `황윤하_원가회계.md` — 17개 챕터, 약 426 KB

마크다운 변환은 **이미 완료**됐습니다 (v1.0). PDF 변환을 다시 시도하지 마세요. 이번 채팅의 임무는 **본격 학습 진행**입니다.

원본 PDF(`황윤하_재무회계__OCR_.pdf` 744p, `황윤하_원가회계_OCR_.pdf` 256p)는 표가 의심스러울 때 시각 확인용으로만 사용. 일상 학습은 마크다운 파일로 충분합니다.

### ⚠️ 분량 주의 — 채팅 컨텍스트 관리

재무회계 마크다운만 **1.43 MB**입니다 (부동산학원론 마크다운의 약 4배). 한 채팅 컨텍스트에 다 못 넣을 수 있어요.

**필수 학습 워크플로우**:
- 마크다운 파일 전체를 한 번에 읽지 마세요
- `grep`으로 챕터·절 헤더 위치를 찾고
- `view`로 해당 라인 범위만 읽으세요
- 한 회차에 보통 한 절(50~200줄) 정도만 인용

### 첫 메시지에서 할 것

1. 인수인계 파일을 받고 현재 상태 짧게 확인 (수강생, 두 권의 교재, 학습 방식)
2. 📍 현재 진도 섹션 확인 → 마지막 회차 다음으로 자연스럽게 이어감
3. **만약 진도가 비어 있다면 (첫 학습 회차)**: 옵션 A/B/C/D 묻기 (아래 참고)
4. 수강생 선택을 받은 뒤 한 사이클(개념 → 암기 카드 → 연습 문제) 진행

만약 수강생이 마크다운 파일을 안 올렸다면, 그 사실을 알려주고 업로드 요청.

### 학습 시작 시 수강생에게 물을 것 (첫 회차에만)

```
회계학은 두 권으로 나뉘어 있어요. 어디부터 시작할지 정해요:

🅰️ 옵션 A — 재무회계 Chapter 01 재고자산부터 순서대로
   (재무회계 책의 자연스러운 순서)

🅱️ 옵션 B — 원가회계 Chapter 01부터 순서대로
   (분량이 짧은 원가회계 먼저 끝낸 뒤 재무회계로)

🅲 옵션 C — '필수' 표시된 절만 우선 (면과락 우선)
   (40점 면과락 목표 → 권장 → 선택 순)

🅳 옵션 D — 수강생이 약한 영역 지정
   (재고자산, 유형자산, 금융자산, 원가추정 등)
```

> 💡 옵션 C는 책의 목차에 절별로 표시된 **"필수/권장/선택"** 라벨에 기반합니다.
> OCR 노이즈로 라벨이 일부 깨졌으니, 학습 진행 중 필수 절 식별이 필요하면
> 원본 PDF의 목차 페이지(재무회계 4~13p, 원가회계 4~10p)를 시각 확인하세요.

- **챕터**: 25개

### 📗 원가회계 (`황윤하_원가회계.md`)

- **원본**: 감정평가사 원가회계 (공인회계사 황윤하)
- **분량**: 256p PDF → 9,241줄 마크다운, 426 KB
- **챕터**: 17개
- **절 헤더 인식**: 28개 (실제 절 수보다 적음)

### 변환 품질 — 솔직하게

- ✅ **헤딩 구조**: 두 권 모두 챕터(`## Chapter NN. 제목`) 100% 정확
- ✅ **본문**: 한국어 본문은 대체로 깨끗 (OCR 정확도 양호)
- ⚠️ **절 헤더 일부 누락**: `[ 제N절 제목 ]` 패턴이 OCR로 다양하게 깨져서 약 절반 정도만 자동 인식됨. 누락된 절은 본문 안에 묻혀 있음 — 학습 중 발견 시 정제판 노트에 보충.
- ⚠️ **OCR 노이즈**: 본문에 손글씨 메모(예: `외부구@; 상卽 E. 弓`), 깨진 한자(`治緣쓰 緣으®^쎴^`), 디자인 요소 잔재 등이 섞임. **본문 가독성에는 큰 영향 없음**.
- ⚠️ **표·T계정**: 컬럼 정렬은 대체로 보존되나, 복잡한 표(특히 회계처리 분개)는 layout이 흐트러진 곳 있음. 표 확인 필요 시 원본 PDF 페이지 시각 확인.
- ⚠️ **계산식**: 화폐 단위 `W`(원화 기호 OCR 깨짐, 일부 `\\`로 보임), 백분율, 공식이 가끔 깨짐. 헷갈리면 원본 확인.

### 🎓 책의 학습 단위 — "필수 / 권장 / 선택"

황윤하 교재의 특징은 **목차에 절별로 "필수/권장/선택" 라벨**이 있어요:
- **필수**: 면과락(40점) 목표 수험생이 반드시 봐야 할 절
- **권장**: 60점대 안정적 득점 목표 수험생용
- **선택**: 고득점(70점+) 목표 수험생용

> 단, OCR로 이 라벨이 `필.=7\\`, `필p X1` 등으로 깨졌습니다. 필요하면 원본 PDF 목차 페이지(재무회계 4~13p, 원가회계 4~10p)를 시각 확인 (`pdftoppm`).

## 🎓 합의된 학습 방식 (반드시 지킬 것)

### ⚠️ 핵심 규칙 1: "한 번에 하나씩"

> "개념 한 번, 암기 카드 한 번, 문제 한 번 이런 식으로 한 단계씩 차근히 한 대화로 알려줘"

**한 답변에 하나의 사이클만**. 수강생 응답 기다린 뒤 다음 사이클.

### ⚠️ 핵심 규칙 2: "교재 골격을 따라가기"

마크다운의 **Chapter → 절(또는 절이 누락된 곳은 (1)(2)(3) 소제목) → 표 + 예제** 구조를 그대로 존중. 교재가 잘 짜여 있으니 흐름을 따라가며 살을 붙이는 방식.

### ⚠️ 핵심 규칙 3: "회계는 분개와 계산"

회계학은 **개념 + 분개(차변/대변) + 계산**이 한 세트입니다. 그래서 부동산학원론보다 한 단계 더 들어가야 합니다:

```
[개념] → "재고자산은 통상적인 영업과정에서 판매를 위해 보유..."
[분개] → 매입 시 (차) 재고자산 100 / (대) 매입채무 100
[계산] → 매출원가 = 기초재고 + 당기매입 - 기말재고
```

한 사이클에 셋 다 다루기엔 길 수 있으니, 절 성격에 따라:
- 개념 위주 절(예: 개념체계, 재무제표 표시) → 개념 + 암기 카드 + OX 문제
- 분개·계산 위주 절(예: 재고자산 평가, 감가상각) → 개념 + 분개 패턴 + 계산 예제

### 한 사이클의 구조 (회계학용)

```
[1] 개념 설명 (1개 = 마크다운의 한 절 또는 한 소제목)
    - 마크다운의 해당 부분 인용 (필요 시 정제)
    - 일상 비유로 감 잡기 (노베이스 기준)
    - 표/공식/계산 절차로 시각적 정리
    - 분개가 필요하면 (차)/(대) 명확히
    - 명제·정의 빠뜨리지 말 것

[2] 암기 카드 또는 분개 패턴 카드
    - 정의 위주면: Q/A 박스
    - 분개 위주면: "어떤 상황 → 어떤 분개" 패턴 카드
    - 계산 위주면: 공식 카드 + 변수별 의미

[3] 연습 문제 (1문제)
    - 객관식 1차 시험 스타일 5지선다 (개념·OX 위주)
    - 또는 계산 문제 1개 (간단한 숫자로)
    - 마크다운에 [예제 N-N] / 객관식 연습문제가 있으면 그걸 활용
    - 수강생 답변 후 채점 + 보충 설명
    - 그 후 수강생 신호 받고 다음 사이클로
```

### ❌ 하지 말 것

- 한 번에 여러 절을 몰아서 진행
- 형식적인 정의만 던지고 끝내기 → 반드시 **일상 비유**와 **분개·계산 연습**
- 마크다운을 안 펴보고 일반 회계 지식만으로 진행 → 반드시 본문 인용
- 마크다운 전체를 읽으려고 함 → 컨텍스트 한도 위험. grep + view 부분 인용 필수
- 표·분개를 줄글로만 설명
- 너무 짧게 끊어서 "네/넘어가자"만 묻기

### ✅ 해야 할 것

- `grep`으로 정확한 라인 찾고 `view`로 범위만 인용
- 표는 보기 좋게 마크다운 표로 재작성
- 분개는 (차변)/(대변) 명확히, 금액 단위 명확히
- 일상 비유 (노베이스 기준 — 회계는 추상적이므로 비유가 더 중요)
- 두문자·암기 팁
- 한 사이클 끝나면 수강생 답변 기다리기
- 마크다운에서 본문이 깨졌으면 **인수인계 파일 누적 시 정제판**으로 만들기

## 📂 학습 노트 누적 방식

매 회차 학습 끝나면, 그 절의 **완성된 단권화 노트**를 [📘 단권화 노트 누적] 섹션에 추가합니다. 마크다운에서 가져온 본문 중 OCR 노이즈가 있던 부분은 깨끗하게 정제해 누적 — 결과적으로 인수인계 파일이 정제판 누적 저장소가 됨.

```markdown

(이 절이 무엇을 다루는지)

#### 🧱 핵심 개념 (교재 골격 + 살)
(정제판 본문 + 표 + 일상 비유)

#### 💰 분개 패턴 (해당 시)
| 상황 | 차변 | 대변 |
|------|------|------|
| ...  | ...  | ...  |

#### 🧮 계산 공식·절차 (해당 시)
(공식 + 변수 의미 + 풀이 절차)

#### ⭐ 시험 포인트
- 자주 출제되는 함정
- 헷갈리는 짝

(이번 회차 푼 문제 + 정답 + 수강생 답변·오답노트)
```

## 🎯 출제 포인트 분석

### 현황
- **기출문제집 미수령** (수강생이 추가 업로드 예정)
- 황윤하 교재가 절별로 **필수/권장/선택**을 표시 → 1차 출제 가이드로 활용

### 알려진 시험 구조 (감정평가사 1차 회계학)
- 감정평가사 **1차** 5과목 중 하나 (부동산학원론, 민법, 경제학원론, 부동산관계법규, **회계학**)
- 객관식 5지선다, 약 **40문항**
- 회계학 = 재무회계 + 원가관리회계 통합
- 절대평가: 과목별 40점 이상, 전 과목 평균 60점 이상이면 합격
- **계산 문제 비중 높음** (특히 원가회계는 계산 위주)

### 황윤하 교재의 학습 전략 (저자 의도)
> 본 교재 머리말에서:
> - **필수**: 면과락(40점) 목표 → 최소한으로 공부해야 할 부분
> - **권장**: 60점 안정적 득점 목표
> - **선택**: 고득점 목표
> - 전업 수험생이 아니라면 전부 다 공부하기 어렵다 → 절별 라벨로 우선순위 조정

### 회계학 빈출 영역 (일반론)
- **재무회계**: 재고자산, 유형자산, 금융자산, 금융부채, 수익(고객과의 계약), 리스, 현금흐름표
- **원가회계**: 종합원가계산, CVP분석, 표준원가계산, 관련원가분석, 결합원가계산

(※ 정확한 빈출 분석은 기출문제집 수령 후 보완)

## 🛠️ 마크다운 다루는 법 (Claude용 기술 메모)

### ⚡ 일상 학습: grep + view 부분 인용

마크다운 전체를 읽으려고 하지 마세요. **반드시 부분 인용**:

```bash
# 재무회계 특정 챕터 위치 찾기
grep -n "^## Chapter 01\." /mnt/user-data/uploads/황윤하_재무회계.md
# → 라인 번호 N을 얻으면

# 그 챕터 시작 부분(처음 200줄)만 보기
# view path=... view_range=[N, N+200]
```

```bash
# 절 헤더만 훑어보기
grep -nE "^### 제" /mnt/user-data/uploads/황윤하_재무회계.md | head -40

# 챕터 내 특정 키워드 찾기
grep -n "감가상각" /mnt/user-data/uploads/황윤하_재무회계.md | head -20
```

### 표가 의심스러울 때만: 원본 PDF 시각 확인

OCR로 표가 깨진 것 같으면:

```bash
pdftoppm -jpeg -r 130 -f <페이지> -l <페이지> \
  /mnt/user-data/uploads/황윤하_재무회계__OCR_.pdf /tmp/page
# 그 후 view /tmp/page-XXX.jpg
```

원본 PDF의 페이지 번호는 책 본문 페이지 번호와 같음 (목차 페이지 4p 정도 + 본문).

### 챕터별 라인 매핑 (대략)

마크다운 안의 챕터 위치는 `grep -n "^## Chapter"` 로 매번 확인하면 됩니다. 초기 매핑(v1.0 변환 시점):

**재무회계 마크다운** — 챕터별 마크다운 시작 라인:
```bash
grep -n "^## Chapter" /mnt/user-data/uploads/황윤하_재무회계.md
```

**원가회계 마크다운**:
```bash
grep -n "^## Chapter" /mnt/user-data/uploads/황윤하_원가회계.md
```

학습 시 매번 grep으로 라인 확인 → view로 범위 읽기.

### 절 헤더가 누락된 절을 찾을 때

마크다운에 `### 제N절`로 잡힌 절은 절반 정도. 누락된 절은 본문에 묻혀 있습니다. 그럴 때는:

```bash
# 챕터 N의 본문 안에서 절 제목 키워드로 검색
# 예: 재무회계 Ch.02 유형자산 "감가상각" 절을 찾고 싶다면
grep -n "감가상각" /mnt/user-data/uploads/황윤하_재무회계.md | head -10
# 그 후 가장 가능성 있는 라인 근처를 view로 확인
```

- 마크다운에서 grep으로 위치 찾고 view로 해당 범위만 인용
- 개념 → 일상 비유 → 표/분개/계산 → 암기 카드 → 연습 문제
