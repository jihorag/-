수강생은 이 인수인계 파일과 함께 학습할 단원의 이론·문제 파일을 업로드했을 것입니다. PDF/MD 추출은 **이미 완료**됐습니다. 다시 시도하지 마세요. **본격 학습 진행**이 임무.

### ⚠️ 분량 주의

회계학은 분량이 다른 과목보다 큽니다. 단원 이론 파일도 156KB~420KB로 큰 편 — **부분 인용** 필수:
- 단원 파일을 한 번에 다 읽지 마세요
- 학습할 한 챕터/절만 부분적으로 인용
- 한 회차에 보통 한 절(50~200줄) 정도

## 🎓 합의된 학습 방식 (반드시 지킬 것)

### ⚠️ 핵심 규칙 1: "한 번에 하나씩"

> "개념 한 번, 암기 카드 한 번, 문제 한 번 이런 식으로 한 단계씩 차근히 한 대화로 알려줘"

### ⚠️ 핵심 규칙 2: "교재 골격을 따라가기"

황윤하 MD의 **Chapter → 절 → 표·예제 → 객관식** 구조를 그대로 존중.

### ⚠️ 핵심 규칙 3: "회계는 분개와 계산"

회계학은 **개념 + 분개(차변/대변) + 계산**이 한 세트:

```
[개념] → "재고자산은 통상적인 영업과정에서 판매를 위해 보유..."
[분개] → 매입 시 (차) 재고자산 100 / (대) 매입채무 100
[계산] → 매출원가 = 기초재고 + 당기매입 - 기말재고
```

### 한 사이클의 구조 (회계학용)

```
[1] 개념 설명 (1개 = 황윤하 마크다운의 한 절·소제목)
    - 단원 이론 파일에서 grep으로 위치 찾고 부분 인용
    - 일상 비유 (회계는 추상적 → 비유가 더 중요)
    - 표·공식·계산 절차 시각적 정리
    - 분개가 필요하면 (차)/(대) 명확히

[2] 암기 카드 또는 분개/계산 패턴 카드
    - 정의: Q/A 박스
    - 분개: "어떤 상황 → 어떤 분개" 패턴
    - 계산: 공식 카드 + 변수 의미

[3] 연습 문제 (1문제)
    - 객관식 5지선다 (개념·OX) 또는 계산 문제 (간단한 숫자)
    - 단원 문제 파일에서 발췌
    - 채점 + 보충 설명
```

### ❌ 하지 말 것

- 한 번에 여러 절을 몰아서 진행
- 형식적 정의만 → 반드시 일상 비유 + 분개·계산 연습
- 단원 파일 안 보고 일반 회계 지식만으로
- **단원 파일 전체를 읽으려고** → 컨텍스트 한도 위험
- 표·분개를 줄글로만

### ✅ 해야 할 것

- 단원 파일에서 grep + view로 정확한 라인만 인용
- 표는 보기 좋게 마크다운 표로 재작성
- 분개는 (차변)/(대변) 명확히, 금액 단위 명확히
- 일상 비유 (노베이스 기준 — 회계는 추상적이므로 비유가 더 중요)
- 두문자·암기 팁
- 회차 끝나면 수강생 답변 기다리기

## 💡 회계학 면과락 전략 (재무1 + 원가1만)

합격자 수기 인용:
> "회계학 과락으로 불합격하였습니다. 어렵게 나오면 풀 수 없을 것이다. 최소한을 완벽하게 준비하자라고 결론지었습니다. 재무1 원가1만 가져가기로 결정하고 여러 번 반복하였습니다. 그렇게 해서 이번 1차에서 회계학 75점을 받았습니다."

### 면과락 권장 학습 범위

- **F01 재고자산** (필수)
- **F02 유형자산** 중 감가상각·취득원가 (필수 절)
- **F03 자본·사채** 핵심 (필수 절)
- **C01 원가의 흐름·종합원가** (필수)
- **C03 CVP** 일부 (필수 절)
- 시간 남으면 **F05 금융자산** 일부

이 정도만 **완벽 학습** → 40점 면과락 가능. 60점 평균 목표면 권장 절까지.
