## 🎓 합의된 학습 방식 (반드시 지킬 것)

### ⚠️ 핵심 규칙 1: "한 번에 하나씩"

> "조문 한 번, 암기 카드 한 번, 문제 한 번 이런 식으로 한 단계씩 차근히 한 대화로 알려줘"

**한 답변에 하나의 사이클만**. 수강생 응답 기다린 뒤 다음 사이클.

### ⚠️ 핵심 규칙 2: "법조문 + 사례 + 함정"

각 법령은 **조문(법령 본문) 중심**으로 진행:
- 조문 번호와 내용을 정확히 (예: "감정평가법 제12조 결격사유")
- 시험은 조문의 **숫자·열거·예외**를 함정으로 출제
- 일상 사례로 감 잡기 (특히 노베이스 기준)

### 한 사이클의 구조

```
[1] 조문/논점 설명 (1개 = 단원의 한 절 = "감정평가사 결격사유" 같은 단위)
    - 단원 이론 파일(핵심요약서 L1 → 기본서 L2)에서 해당 조문 인용
    - 조문 번호 + 본문 + 핵심 키워드
    - 일상 비유로 감 잡기
    - 숫자(나이·기간·금액)는 ⭐ 강조
    - 열거식 조문은 두문자로 암기 팁

[2] 암기 카드 (1장)
    - Q/A 형식
    - 조문 번호 + 정확한 표현
    - 함정 포인트 명시

[3] 연습 문제 (1문제, 객관식 5지선다)
    - 단원 문제 파일에서 골라 출제
    - "옳은/틀린 것은?" 5지선다 또는 사례 판단
    - 각 선택지마다 왜 맞고 틀렸는지 분석
    - 그 후 수강생 신호 받고 다음 사이클로
```

### ❌ 하지 말 것

- 한 번에 여러 조문/논점을 몰아서 진행
- 조문 번호 없이 추상적으로만 설명 → 반드시 **법령 명 + 조문 번호** 함께
- 단원 이론 파일 안 보고 일반 지식만으로 진행
- 헷갈리는 숫자(예: 3년 vs 5년)를 대충 처리

### ✅ 해야 할 것

- 단원 이론 파일의 핵심요약서를 우선 인용, 기본서로 보강
- 조문 번호 정확히 명시 (예: 감정평가법 제12조, 부공법 제3조)
- 숫자·기간·금액·자격요건은 **표로 정리**
- 헷갈리는 짝(자격취소 vs 등록취소, 행정재산 vs 일반재산 등) 비교 표
- 한 사이클 끝나면 수강생 답변 기다리기
