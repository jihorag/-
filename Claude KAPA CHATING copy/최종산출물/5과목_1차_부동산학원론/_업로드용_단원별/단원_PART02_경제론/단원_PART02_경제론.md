#### 05. 수요의 증가⋅감소 / 공급의 증가⋅감소

(1) 수요의 변화 요인

```
               수요의 증가 요인              수요의 감소 요인
```

∙ 인구 증가 ∙ 시장이자율⋅대출금리 하락 ∙ LTV⋅DTI 상승 ∙ 소득의 증가(정상재) ∙ 대체부동산의 가격 상승 ∙ 보완부동산의 가격 하락 ∙ 주택거래규제의 완화 ∙ 미래가격 상승에 대한 기대

① 소비자의 실질소득이 증가하면, 주택의 수요는 증가한다.
② 아파트와 대체관계에 있는 오피스텔의 가격이 상승하면, 아파트의 수요곡선은 우측으로 이동 하게 된다.

③ 대부비율(LTV)이 하락하면, 아파트의 수요는 감소한다.
④ 주택의 거래세가 인상되면, 주택의 수요곡선은 좌측으로 이동하게 된다.

```
⑤ 대부비율(LTV)이 상승하면, (       ), 아파트의 가격은 상승한다.
```

(2) 공급의 변화 요인

```
               공급의 증가 요인              공급의 감소 요인
```

∙ 주택건설업자 수의 증가 ∙ 건축(건설)기술의 진보 ∙ 생산요소 가격의 하락 ∙ 건축원자재 가격의 하락 ∙ 건축허가 요건의 완화

① 건설기술의 진보로 인한 생산성이 향상되면, 주택의 공급을 증가시킨다.
② 건설 노동자의 임금이 하락하면, 주택의 공급곡선은 우측으로 이동하게 된다.

```
③ 건축 원자재 가격이 상승하면, (        ), 주택의 가격은 상승할 수 있다.
```

#### 06. 균형을 변화시키는 4가지 규칙

```
                        구분    균형 가격   균형 거래량

                       수요증가    상승      증가

      가격 이외            수요감소    하락      감소
                   ⇨
      요인의 변화           공급증가    하락      증가

                       공급감소    상승      감소
```

(1) 수요와 공급이 동시에 변화하는 경우(힘의 크기가 주어지지 않은 경우)

① 수요가 증가하면서 동시에 공급이 증가하면, 균형 가격의 변화는 알 수 없고 균형 거래량은 증가한다.

② 수요가 증가하면서 동시에 공급이 감소하면, 균형 가격은 상승하고 균형 거래량의 변화는 알 수 없다.

③ 수요가 감소하면서 동시에 공급이 증가하면, 균형 가격은 하락하고 균형 거래량의 변화는 알 수 없다.

④ 수요가 감소하면서 동시에 공급이 감소하면, 균형 가격의 변화는 알 수 없고 균형 거래량은 감소한다.

주의(정답을 찾는 요령)

① 문제가 되는 것이 가격인지? 거래량인지? 확인한다.
② 문제가 되는 논점 : ‘알 수 없다’ 또는 ‘수요와 공급의 변화 폭에 의해 결정된다’

(2) 알 수 없다(= 수요와 공급의 힘의 크기로 결정된다).

⑤ 수요가 증가하면서 동시에 공급이 증가하였다면, 균형 가격의 변화는 수요와 공급의 변화 폭에 의해 결정된다. (=균형 가격의 변화는 알 수 없다.)

⑥ 수요가 증가하면서 동시에 공급이 감소하였다면, 균형 거래량의 변화는 수요와 공급의 변화 폭에 의해 결정된다. (=균형 거래량의 변화는 알 수 없다.)

(3) 수요와 공급이 동시에 변화하는 경우(힘의 크기가 주어진 경우)

⑦ 수요의 증가가 공급의 증가보다 크다면, 균형 가격은 상승하고 균형 거래량은 증가한다.
⑧ 공급의 증가가 수요의 증가보다 크다면, 균형 가격은 하락하고 균형 거래량은 증가한다.

⑨ 수요의 증가 폭과 공급의 증가 폭이 동일하다면, 균형 가격은 불변이다.

### Chapter 06. 수요와 공급의 탄력성

#### 01. 탄력성의 이해

```
                   의미      양의 변화 정도(%)를 측정하는 지표
         탄력성               ∙ 수요의 탄력성 : 수요량의 변화 정도(%)를 측정하는 지표
```

구분 ∙ 공급의 탄력성 : 공급량의 변화 정도(%)를 측정하는 지표

```
                   탄력적     ‘양’의 변화 정도가 많다.
         해석
                   비탄력적    ‘양’의 변화 정도가 적다.
```

```
① 수요의 가격탄력성이            탄력적이라면, 가격의 변화율보다 수요량의 변화율이 보다 크다.
```

② 수요의 가격탄력성이 비탄력적이라면, 가격의 변화율보다 수요량의 변화율이 보다 적다.

```
③ 수요의 가격탄력성이 완전           탄력적이라면, 가격 변화에 수요량이 무한대( ∞ )로 변화한다.
```

④ 수요의 가격탄력성이 완전 비탄력적이라면, 가격이 변화하더라도 수요량은 고정된다.

#### 02. 수요의 탄력성

수요량 변화율(%)
```
                     의미     수요의 가격 탄력성 =
                                                 가격 변화율(%)

                            완전비탄력적       단위탄력적                   완전탄력적

 수요의 가격 탄력성                       비탄력적                     탄력적

                     구분                                                  ∞
                              0            1           2
```

∙ 수요의 가격탄력성은 0 또는 양수(+)의 값으로 측정된다. ∙ 1을 기준으로, 1보다 크면 탄력, 1보다 작으면 비탄력

수요량 변화율(%)
```
                     의미     수요의 소득 탄력성 =
```

소득 변화율(%) 수요의 소득 탄력성 ∙ 양수(+) 값 : 정상재 특징 ∙ 음수(-) 값 : 열등재

수요량 변화율(%)
```
                   의미      수요의 교차 탄력성 =
```

다른 재화의 가격 변화율(%) 수요의 교차 탄력성 ∙ 양수(+) 값 : 대체관계 특징 ∙ 음수(-) 값 : 보완관계

#### 03. 공급의 탄력성

공급량 변화율(%)
```
                   의미      공급의 가격 탄력성 =
```

가격 변화율(%) 공급의 가격 탄력성 ∙ 공급의 가격탄력성은 0 또는 양수(+)의 값으로 측정된다. 구분 ∙ 1을 기준으로, 1보다 크면 탄력, 1보다 작으면 비탄력

#### 04. 탄력성을 결정하는 요인

```
          수요가 보다 탄력적인 경우                    공급이 보다 탄력적인 경우

∙ 대체재가 많을수록                         ∙ 생산에 유리한 상황일수록
 ㉠ 부동산 시장을 세분할수록                     ㉠ 생산에 소요되는 기간이 짧을수록
 ㉡ 부동산의 분류 범위가 좁을수록                  ㉡ 생산비가 감소할수록
 ㉢ 용도변경이 용이할수록                       ㉢ 용도변경이 용이할수록

∙ 측정 기간이 장기일수록                      ∙ 측정 기간이 장기일수록
```

#### 05. 탄력성과 기울기

```
     원칙      보다 탄력적일수록 수요(공급)곡선의 기울기는 보다 완만해진다.

             완전 비탄력적         비탄력적            탄력적          완전 탄력적
```

```
               Q = 200                                      P = 200

#### 02. 극단적인 시장의 균형 변화의 예외

```

(4)부동산의 사회성 · 공공성으로 인한 필요성토지는 국토를 이루고, 주거환경을 이루고, 국민의 재산권을 이루는 높은 사회성 · 공공성이 있다. 따라서 부동산의 경제가치는 이 사회에 미치는 영향이 크기 때문에 높은 전문성과 윤리성을 갖춘 전문가에 의해서 가치가 평가될 필요가 있다.(5)부동산가격형성의 기초감정평가사에 의해 판정된 가격은 다시 일반부동산시장에서 거래의 기준을 제시하므로 적절한 균형가치를 파악할 필요가 있다. 이를 위해 정부는 부동산가격공시제도를 운영하고 있다. (6)부동산거래의 특수성부동산거래는 급매 · 당사자간의 거래 등 개별적 · 비정상적 사정의 개입이 쉽고, 이러한 사정의 파악이 어려워 전문가에 의한 가치판단이 필요하다.
