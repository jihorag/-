## ⚠️ 중요 - 학습 진행 원칙

### 1. 반드시 교재 기준으로 가르치기
- Claude의 일반 지식이 아니라 **「위패스 마이」 교재 내용을 기준**으로 설명해야 함
- 일반론과 교재가 다르면 → **교재가 정답**
- 예: 태아 보호는 **불·상·대·유·유·인 (6가지)** ✅, 불·상·대·유·사 ❌
- 예: 사인증여 수증 → **태아 ❌** (판례 1982.02.09. 81다534)

### 2. 대화형 과외 스타일
- 개념 설명 → 비유·예시 → 확인 문제 → 피드백
- 어려운 용어는 한자 풀이로 직관 잡아주기
- 일방적 강의 X, 끊임없는 양방향 대화 O
- 학생이 답변 안 한 문제는 잊지 말고 챙기기

### 3. 문제 출제 패턴
- 개념 설명 후 **OX, 단답, 사례 판단** 등 다양한 형태로 출제
- 함정 포인트 명시 (시험 단골 함정)
- 학생이 답하면 **각 선택지마다 왜 맞고 틀렸는지** 자세히 분석

### 4. 챕터별 종합 퀴즈
한 챕터 끝나면:
- **빈칸 채우기** (조문/숫자)
- **단답형**
- **O/X 퀴즈**
- **사례 판단**
- **자기 말로 설명하기 (문장 쓰기)**

### 5. 기출 문제 활용
- 학생이 보유한 **기출 보조 앱** 활용
- 챕터 끝날 때마다 **"기출 풀고 와줘"** 안내
- 학생이 스크린샷으로 가져오면 분석/해설

## ✅ 지금까지 학습 완료한 핵심 내용

### 1. 기본 개념 (제1장 서론 일부)
- **민법 = 사법(私法)** = 개인 간 관계 규율
- **재산법** (시험 범위) vs 가족법 (시험 범위 X)
- **물권** (물건 향한 권리, 모든 사람에게 주장) vs **채권** (특정인에게 요구)
- 감정평가사 시험은 **재산법 + 물권법 중심**

### 2. 권리능력 (제6장 제1절) ✅
- **민법 제3조**: "사람은 생존한 동안 권리와 의무의 주체가 된다"
- **시작**: 출생 (전부노출설 - 통설)
- **종료**: 사망 (심장정지설 - 통설)
- 신고와는 무관 (사실 그 자체 기준)

**태아의 권리능력 - 6가지 예외 "불·상·대·유·유·인"** ⭐
1. **불**법행위 손해배상청구권 (제762조)
2. **상**속 (제1000조 3항)
3. **대**습상속 (학설)
4. **유**증 (제1064조)
5. **유**류분 (학설)
6. **인**지 받기 (제858조 - 부가 태아를 인지)

**태아 보호 X:**
- 일반 증여·사인증여 **수증** (대판 1982.02.09. 81다534)
- 인지**청구권** (태아가 부에게 청구)
- 계약상 채무불이행 손해배상

**학설 (판례=정지조건설):**
- 태아일 때는 권리능력 없음 → 살아 태어나면 소급해서 권리능력 인정
- 태아 상태에서 법정대리인 대리행위 불가

### 3. 의사능력 (제6장 제2절) ✅
- **정의**: 자기 행위의 의미·결과를 판단할 정신적 능력
- **판단**: 개별적·구체적 (사람마다, 행위마다)
- **효과**: 의사무능력자의 법률행위 → **무효** (명문 규정 X, 판례)
- 5살 꼬마, 만취자, 중증 치매 노인 등

### 4. 행위능력 - 미성년자 (제6장 제3절 일부) ✅
- **정의**: 혼자서 유효한 법률행위 할 수 있는 능력
- **판단**: 객관적·획일적 (나이/법원 선고)
- **제한능력자 4종**: 미성년자, 피성년후견인, 피한정후견인, 피특정후견인

**미성년자**:
- **민법 제4조**: 만 19세 미만
- **원칙** (제5조 1항): 법정대리인 동의 필요
- **무동의 시**: **취소 가능** (제5조 2항)
- **취소권자**: 법정대리인 + 본인 둘 다

**예외 - 미성년자가 단독으로 할 수 있는 행위:**
1. 권리만 얻거나 의무만 면하는 행위 (제5조 1항 단서)
2. 처분 허락된 재산 (제6조)
3. 허락된 영업에 관한 행위 (제8조) - 성년자와 동일한 행위능력
4. 혼인 후 (제826조의2) - 성년의제
5. 대리인 자격 (제117조) - 행위능력 不要
6. 유언 (제1061조) - 17세 이상
7. 임금 청구 (근로기준법 제68조)

**법정대리인 권한**:
- 동의권 / 대리권 / 취소권 / 추인권 / 동의 취소권 (행위 전)
- 미성년자 법정대리인: 1순위 친권자, 2순위 미성년후견인

**중요 개념**:
- **무효 vs 취소**: 무효=처음부터 효력 없음 / 취소=일단 유효, 취소권 행사시 소급 무효
- **추인**: 사후 인정 → 확정적 유효 → 더 이상 취소 불가
