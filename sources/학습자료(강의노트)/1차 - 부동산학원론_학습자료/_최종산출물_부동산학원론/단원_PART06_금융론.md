### Chapter 31. 부동산 금융의 분류

#### 01. 부채금융과 지분금융

```
              의미   돈을 빌리는 방식

     부채금융          ∙ 채권 및 사채 발행
              종류   ∙ 저당금융(대출), 신탁증서금융(대출), 프로젝트 금융(대출)
```

∙ 각종 유동화 증권 : ABS, MBS, CMBS, ABCP

```
              의미   돈을 투자받는 방식
     지분금융          ∙ 주식의 발행 / 공모를 통한 증자, 보통주
              종류
                   ∙ 신디케이션, 조인트 벤처, 부동산투자회사

              의미   부채금융과 지분금융의 중간적 성격을 갖는 금융
     메자닌금융         ∙ 신주인수권부사채, (주식)전환사채
```

종류 ∙ 후순위 채권, 상환우선주, 교환사채

#### 02. 주택소비금융과 주택개발금융

```
              의미   주택 구입과 개량에 필요한 자금을 주택소비자에게 대출하는 행위
 주택소비금융
              유형   주택담보대출(주택저당대출)

              의미   주택 건설에 필요한 자금을 건설업자에게 대출하는 행위
 주택개발금융
              유형   건축대부
```

① 주택 금융은 주택 수요자에게 자금을 융자해 줌으로써 주택 구매력을 높여준다.
② 주택소비금융은 주택을 구입하려는 사람이 부동산을 담보로 제공하고, 자금을 제공받는 형태 의 금융을 말한다.

③ 주택자금 융자는 주로 장기융자 형태이므로, 대출기관의 유동성 제약이 발생할 우려가 있어 주택저당채권의 유동화 필요성이 있다.

#### 03. 주택자금 대출시장과 주택자금 공급시장

```
          의미   은행이 주택구입에 필요한 자금을 차입자에게 대출해주는 시장
 주택자금
 대출시장          ∙ 차입자와 은행 등 대출기관으로 구성된 시장
          특징
               ∙ 1차 저당시장

          의미   은행 등 금융기관에 대출에 필요한 자금을 공급해주는 시장
 주택자금
 공급시장          ∙ 은행 등 대출기관과 자금을 공급하고자 하는 투자자로 구성된 시장
```

특징 ∙ 2차 저당시장, 유동화 시장

### Chapter 32. 부동산 금융의 위험

#### 01. 이자율 위험과 인플레이션 위험

은행이 고정금리 상품을 판매한 경우, 의미
```
 이자율 위험              시장금리가 상승하면 은행의 수익성이 악화된다.

               대책    변동금리 상품

                     은행이 고정금리 상품을 판매한 경우,
     인플레이션     의미
                     시장의 인플레이션이 예상되면 은행은 불리해진다.
      위험
               대책    변동금리 상품
```

① 대출금리가 고정된 상태에서 시장이자율이 상승하면 대출기관의 수익성이 악화된다.
② 대출기관은 이자율변동에 따른 위험을 회피하기 위해 변동금리 상품을 판매한다.

③ 은행은 인플레이션 위험을 차입자에게 전가시키기 위해서 변동금리 상품을 선호한다.

#### 02. 조기상환 위험과 채무불이행 위험

```
               의미    차입자의 조기상환이 발생하면 은행은 불확실해진다.
     조기상환
              조기상환   차입자의 조기상환은 시장금리가 하락할 때 나타나는 현상이다.
      위험
               대책    조기상환 수수료 또는 조기상환 벌금을 부과

               의미    차입자의 채무불이행이 발생하면 은행은 불리해진다.
     채무불이행
      위험             ∙ 대부비율(LTV), 부채상환비율(DTI) 등의 하향 조정
```

대책 ∙ 부채감당률이 1보다 큰 사업에 대출

① 대출금리가 고정된 상태에서 시장이자율이 약정이자율보다 낮아지면 차입자는 조기상환을 고려한다.
② 시장이자율 하락 시 고정금리대출을 실행한 대출기관은 차입자의 조기상환으로 인한 위험이 커진다.

③ 은행은 대출의 위험을 낮추기 위해 LTV(대부비율)⋅DTI(총부채상환비율)을 하향 조정한다.
④ 은행은 대출의 위험을 낮추기 위해 부채감당률이 1 이상인 투자안에 대출하고자 한다.

#### 02. 대출금리

(1) 고정금리

```
              의미   상환기간 동안 대출금리가 고정되는 상품
     고정금리
      상품           대출금액, 상환기간 등의 조건이 동일하다면,
```

특징 고정금리 상품의 대출금리가 변동금리 상품의 대출금리보다 높다.

(2) 변동금리

```
              의미   특정 지표에 대출금리가 변동되는 상품

              구조          대출금리 = 기준 금리(지표)  가산 금리
     변동금리
      상품
                   ∙ 기준 금리 : CD유통수익률
              내용   ∙ 기준 지표 : 코픽스(COFIX; Cost Of Fund Index, 자금조달비용지수)
```

∙ 가산 금리 : 차입자의 신용도 등 대출의 위험에 따라 가산되는 금리

① 변동금리 상품의 대출금리는 기준 금리(또는 기준 지표)와 가산 금리로 구성되어 있다.

② 현재 우리나라는 기준 금리로 CD유통수익률을 활용하고, 기준 지표로 COFIX(자금조달비용 지수)를 활용한다.
③ 가산 금리는 차입자의 신용도, 담보 유무 등으로 판단된 대출 위험에 따라 기준 금리에 가산되 는 금리이다.

④ 변동금리방식을 적용함에 있어서 이자율 조정주기를 짧게 할수록 대출자인 은행의 위험은 차 입자에게 보다 빠르게 전가된다.
⑤ 변동금리대출의 경우, 시장이자율 상승 시 이자율 조정주기가 짧을수록 대출기관에게 유리하다.

⑥ 향후 시장이자율이 하락할 것으로 예상되면, 차입자는 변동금리방식을 선호한다.

#### 03. 저당잔금

(1) 저당잔금

```
       의미      특정 시점에서 상환되지 않고 남아있는 대출 원금
```

∙ 미상환 원리금을 현재가치로 환산하고, 이를 합산하여 산정할 수 있다. ∙ t시점의 저당잔금 저당잔금 저당잔금 = 원리금 상환액 × 연금의 현재가치계수(r%, N-t)

(r%: 대출금리, N: 대출기간, N-t: 잔여기간)

(2) 잔금비율

```
       의미      대출총액(A)에서 저당잔금(B)이 차지하는 비율
```

잔금비율 (=B/A)

a × 연금의 현재가치계수( %, 7년) 잔금비율(t) = a × 연금의 현재가치계수( %, 10년)

① 잔금비율이란 대출총액에서 미상환된 저당원금(잔금)이 차지하는 비율이다.
② 잔금비율은 연금의 현재가치계수를 통해 구할 수 있다.

③ 상환비율과 잔금비율을 합하면 1이 된다. (상환비율 ＋ 잔금비율 ＝ 1)

### Chapter 34. 대출의 상환 방식

#### 01. 원리금 균등 상환 방식

∙ 대출금액: 1억원 / 대출금리: 10% / 상환기간: 10년 공통주제 ∙ 저당상수 : 0.163

(1) 상환 흐름의 이해

```
         구분            1기        2기         3기          …       …
```

주1)
```
 1. 원금+이자           1,630만원    1,630만원    1,630만원
```

```
 2. 이자              1,000만원   (증가, 감소)    (증가, 감소)   (증가, 감소)
```

```
 3. 원금               630만원    (증가, 감소)    (증가, 감소)   (증가, 감소)
```

주1) 원금 + 이자(저당지불액) : 대출금액(1억원) × 저당상수(0.163) = 1,630만원

① 매기 상환하는 원금과 이자 합계, 즉 저당지불액이 동일하도록 상환하는 방식은 원리금 균등 상환 방식이다.
② 차입자의 소득에 변동이 없는 경우, 원리금 균등 상환 방식의 총부채상환비율(DTI)은 대출기간 동안 일정하게 유지된다.

③ 원리금 균등 상환 방식은 매기 지급하는 원리금상환액은 동일하지만, 원리금 중에서 원금과 이자 가 차지하는 비중은 상환시기에 따라 달라진다.
④ 원리금 균등 상환 방식은 매기 이자가 감소하는 만큼 원금 상환액이 증가한다.

(2) 상환 흐름의 계산

```
         구분            1기            2기     3기          …       …
```

주1)
```
 1. 원금+이자           1,630만원    1,630만원    1,630만원
```

```
 2. 이자              1,000만원     937만원     867.7만원
```

```
 3. 원금 주2)           630만원      693만원     762.3만원
```

주1) 원금 + 이자(저당지불액) : 대출금액(1억원) × 저당상수(0.163) = 1,630만원 주2) 원금 상환액은 2기부터 전기의 10%씩 증가한다.

#### 02. 원금 균등 상환 방식

∙ 대출금액 : 1억원 / 대출금리 : 10% / 상환기간 : 10년 공통주제 ∙ 저당상수 : 0.163

(1) 상환 흐름의 이해

```
        구분           1기        2기        3기          …             …
```

주1)
```
 1. 원금            1,000만원    1,000만원   1,000만원
```

```
 2. 이자            1,000만원   (증가, 감소)   (증가, 감소)   (증가, 감소)
```

```
 3. 원금 + 이자       2,000만원   (증가, 감소)   (증가, 감소)   (증가, 감소)
```

주1) 원금 : 대출금액(1억원) ÷ 10년 = 1,000만원

① 매기 상환하는 원금이 균등하도록 상환하는 방식은 원금 균등 상환 방식이다.

② 원금 균등 상환 방식의 경우 매기에 상환하는 원리금은 일정하게 감소한다.
③ 차입자의 소득에 변동이 없는 경우, 원금 균등 상환 방식의 총부채상환비율(DTI)은 만기에 가까워질수록 낮아진다.

④ 원금 균등 상환 방식의 대출 잔액은 상환기간이 경과할수록 매기 일정금액이 감소한다.

(2) 상환 흐름의 계산

```
        구분           1기        2기        3기          …             …
```

주1)
```
 1. 원금            1,000만원    1,000만원   1,000만원
```

```
 2. 이자 주2)        1,000만원    900만원      800만원
```

```
 3. 원금 + 이자       2,000만원    1,900만원   1,800만원
```

주1) 원금 : 대출금액(1억원) ÷ 10년 = 1,000만원 주2) 이자 지급액은 2기부터 매년 100만원(= 1,000만원 × 10%)씩 감소한다.

#### 03. 체증식 상환 방식

① 원금과 이자의 합계가 점점 증가하도록 상환하는 방식은 체증식 상환 방식이다.

② 체증식 상환 방식은 미래 소득이 증가할 것으로 기대되는 젊은 계층에 유리한 방식이다.
③ 체증식(점증식) 상환 방식은 부(負)의 상환이 발생할 수 있다.

### Chapter 35. 주택저당채권 유동화

#### 01. 유동화 제도의 이해

```
                 의미   은행이 주택저당채권을 매각하여 새로운 자금을 도입하고자 하는 제도
 주택저당채권
                 목적   은행의 유동성 증가
      유동화
                 특징   유동화는 자산을 쉽게 매각하기 위하여 자산을 증권으로 변화시킨다.
```

구조

① 주택저당증권(MBS)이 도입되면, 대출기관의 자금이 풍부해져 궁극적으로 주택자금대출이 확대 될 수 있다.

② 주택저당채권이란 은행의 대출채권 중 주택담보대출과 관련된 채권이다.
③ 주택저당증권(MBS)이란 주택저당채권(mortgage) 유동화를 위해 유동화 중개기관이 주택저당 채권(M)을 기초로(B) 발행하는 새로운 형태의 증권(S)이다.

④ 우리나라의 모기지 유동화 중개기관(유동화기관)으로 한국주택금융공사가 있다.

#### 02. 주택저당증권의 비교

```
            구분             MPTS        MBB       MPTB / CMO

            성격            (지분형)       (채권형)       (혼합형)
          소유권
                           투자자         발행자         발행자
       (채무불이행위험)

        원리금 수취권            투자자         발행자         투자자

           조기상환위험          투자자         발행자         투자자
```

주의

한국주택금융공사 = 발행자 = 유동화(중개)기관

(1) MPTS(mortgage pass through securities)의 특성

① MPTS는 지분형 주택저당증권이다.
② MPTS의 경우 주택저당채권의 관련 위험이 모두 투자자에게 이전된다.
③ MPTS의 투자자는 주택저당채권 풀(pool)에 대한 원리금 수취권을 갖는다.

④ MPTS의 경우 발행된 증권은 유동화기관의 부채로 표시되지 않는다.

⑤ MPTS의 경우 증권의 수익은 기초자산인 주택저당채권집합물의 현금흐름에 의존한다.
⑥ MPTS의 경우 차입자가 금융기관에 지불하는 저당지불액이 증권 발행자를 통하여 투자자에게 그대로 전달되는 형태이다.

(2) MBB(mortgage backed bonds)의 특성

① MBB는 채권형 주택저당증권이다.
② MBB의 경우 주택저당채권의 관련 위험은 모두 발행자가 보유한다.
③ MBB의 경우 주택저당채권 풀(pool)에 대한 원리금 수취권은 발행자가 보유한다.

④ MBB의 투자자는 주택저당대출의 채무불이행위험과 조기상환위험을 부담하지 않는다.

⑤ MBB의 발행자는 초과담보를 제공하는 것이 일반적이다.
⑥ MBB의 경우 주택저당대출차입자의 채무불이행이 발생하더라도 발행자는 MBB에 대한 원리금 을 투자자에게 지급하여야 한다.
⑦ 투자자의 입장에서 MBB의 현금흐름은 MPTS의 현금흐름에 비해 보다 안정적이다.

(3) MPTB(mortgage pay through bonds), CMO(collateralized mortgage obligation)의 특성

① MPTB는 이체증권(MPTS)과 주택저당담보부채권(MBB)을 혼합한 성격의 증권이다.
② MPTB의 발행자는 최초의 주택저당채권 집합물에 대한 소유권을 갖는다.
③ MPTB의 투자자는 최초의 주택저당채권 집합물에 대한 원리금 수취권을 갖는다.

④ 다계층저당증권(CMO)은 주택저당채권의 현금흐름을 다양한 형태의 채권에 재분배한 형태 이다.
⑤ CMO의 발행자는 일정한 가공을 통해 위험-수익 구조가 다양한 트렌치의 증권을 발행한다.

(1) 부동산투자회사

① 위탁관리 부동산투자회사, 기업구조조정 부동산투자회사는 명목형 회사이다.
② 위탁관리 부동산투자회사는 본점 외의 지점을 설치할 수 없으며 직원을 고용하거나 상근임원 을 둘 수 없다.
③ 위탁관리 부동산투자회사는 자산의 투자⋅운용을 자산관리회사에 위탁하여야 한다.

(2) 회사의 설립

① 부동산투자회사는 주식회사로 한다.
② 부동산투자회사는 발기설립의 방법으로 하여야 한다.
③ 부동산투자회사는 현물출자에 의한 설립을 할 수 없다.

④ 설립자본금
1. 자기관리 부동산투자회사의 설립자본금 : 5억원 이상
2. 위탁관리 및 기업구조조정 부동산투자회사의 설립자본금 : 3억원 이상

⑤ 자기관리 부동산투자회사는 그 설립등기일부터 10일 이내에 설립보고서를 작성하여 국토교통 부장관에게 제출하여야 한다.

(3) 영업의 인가 등

① 부동산투자회사가 업무를 하려면 부동산투자회사의 종류별로 대통령령으로 정하는 바에 따라 국토교통부장관의 인가를 받아야 한다.
② 일정 요건을 갖춘 위탁관리 부동산투자회사 및 기업구조조정 부동산투자회사가 업무를 하려면 대통령령으로 정하는 바에 따라 국토교통부장관에게 등록하여야 한다.

(4) 자본의 모집

① 최저자본금(인가를 받거나 등록을 한 날부터 6개월이 지난 부동산투자회사의 자본금)
1. 자기관리 부동산투자회사 : 70억원 이상
2. 위탁관리 및 기업구조조정 부동산투자회사 : 50억원 이상

② 부동산투자회사는 영업인가를 받고 최저자본금 이상을 갖추기 전에는 현물출자를 받는 방식으 로 신주를 발행할 수 없다.

③ 주식의 공모 : 부동산투자회사는 영업인가를 받거나 등록을 한 날부터 2년 이내에 발행하는 주 식 총수의 30% 이상을 일반의 청약에 제공하여야 한다.
④ 주식의 분산 : 부동산투자회사는 주주 1인과 그 특별관계자는 발행주식 총수의 50%(1인당 주 식소유한도)를 초과하여 소유하지 못한다.

(5) 자산의 구성

① 부동산투자회사는 매 분기 말 현재 총자산의 80% 이상을 부동산, 부동산 관련 증권 및 현금으 로 구성하여야 한다.
② 이 경우 총자산의 70% 이상은 부동산(건축 중인 건물 포함)이어야 한다.

(6) 수익의 배당

① 부동산투자회사는 해당 연도 이익배당한도의 90% 이상을 주주에게 배당하여야 한다. 이 경우 이익준비금은 적립하지 아니한다.
② 위탁관리 부동산투자회사가 이익을 배당할 때에는 이익을 초과하여 배당할 수 있다.

(7) 기타

① 부동산투자회사는 기존 차입금 및 발행사채를 상환하기 위하여 자금을 차입하거나 사채를 발 행할 수 있다.
② 부동산투자회사는 부동산 등 자산의 운용에 관하여 회계처리를 할 때에는 금융위원회가 정하는 회계처리기준에 따라야 한다.

③ 기업구조조정 부동산투자회사에 대해서는 다음 사항을 적용하지 아니한다.

1. 주식의 공모, 주식의 분산
2. 부동산 처분 제한
3. 자산의 구성

④ 자기관리 부동산투자회사의 자산운용전문인력의 요건

```
     의미       프로젝트로부터 발생하는 미래 현금흐름을 상환재원으로 자금을 공급하는 방식
```

∙ 사업주 : 비소구 금융 또는 제한적 소구 금융 주된 특징 ∙ 사업주 : 부(簿)외 금융효과(회계장부에 표시되지 않는 효과)


∙ 시공사에 책임준공 의무 부과 기타 특징 ∙ 개발사업지 등에 대한 담보신탁 활용 ∙ 요건을 갖춘 경우, 법인세 감면 혜택

① 프로젝트 대출은 프로젝트 완성 이후에 발생하는 미래 현금흐름을 상환재원으로 자금을 조달 하는 기법이다.

② 프로젝트 대출은 사업주와 개발사업의 현금흐름을 분리시켜, 개발사업주의 파산이 개발사업에 영향을 미치지 못한다.
③ 사업주는 해당 프로젝트가 파산한 경우에도 개인적인 채무를 부담하지 않는다.

④ 프로젝트 대출은 상환책임이 프로젝트의 현금흐름의 범위로 한정되는 비소구 또는 제한적 소구 금융이다.
⑤ 프로젝트 대출은 비소구 금융이 원칙이나, 사업주의 도덕적 해이를 방지하기 위해 금융기관은 제한적 소구 금융의 장치를 마련해두기도 한다.
⑥ 프로젝트가 파산한 경우, 채권자들은 사업주에게 상환을 청구할 수 없고 프로젝트 회사에 원리 금 상환을 청구할 수 있다.

⑦ 해당 프로젝트의 대출은 사업주의 회계 장부에 부채로 표시되지 않는다. 이를 부외 금융효과 라고 한다.
⑧ 프로젝트 대출은 부외 금융효과를 통해 사업자(차입자)의 채무수용능력이 제고된다.

⑨ 부동산 개발사업의 현금흐름을 통제하기 위해서 에스크로(escrow) 계정을 운영한다.
⑩ 일정한 요건을 갖춘 프로젝트회사는 법인세 감면을 받을 수 있다.

```
     의미       수탁자로 하여금 수익자의 이익 또는 특정한 목적을 위하여 그 재산권을 관리⋅
```

∙ 형식적인 소유권 이전 특징 ∙ 신탁이익을 받는 수익자는 위탁자가 지정한 제3자가 될 수도 있다.

① 위탁자가 부동산의 관리와 처분을 부동산신탁회사에 신탁한 후 수익증권을 발급받아 이를 담보 로 금융기관에서 대출을 받는 신탁방식은 담보신탁이고, 이를 신탁증서대출이라고 한다.
② 부동산 담보신탁은 저당권 설정보다 소요되는 경비가 적고, 채무불이행 시 부동산 처분 절차가 간편하다.

③ 부동산 신탁계약의 소유권 이전은 실질적 이전이 아니라 등기부상의 형식적 소유권 이전이다.
④ 부동산 신탁의 수익자란 신탁행위에 따라 신탁이익을 받는 자로, 위탁자가 지정한 제3자가 될 수도 있다.

제1절부동산 금융의 의의1.부동산 금융의 정의①부동산 금융이란 부동산과 관련된 자금조달 활동을 의미한다. 일정한 부동산 자금을 확보하여 무주택서민과 주택건설업자에게 장기 저리로 대출해 줌으로써 주택의 구입을 용이하게    하는 한편 주택공급을 확대하게 하는 특수금융을 말한다.②부동산금융이 일반금융과 다른 큰 차이점은 담보기능과 감가상각 및 차입금 이자에 대한 세금감면이며, 투자수익률도 개별사업단위보다는 기업이나 개인의 포트폴리오적인 차원에서 다루어진다는 점이다.③부동산금융은 기본적으로 자산금융(asset finance)의 일종으로서의 금융자산이 아니라 부동산을 운용대상으로 하여 자본을 조달하는 일련의 과정이라고 할 수 있다. ④우리나라에서도 최근에는 금융의 세계화와 부동산증권화의 추세에 발맞추어 부동산신탁제도가 도입되고 <자산유동화에 관한 법률>, <주택저당채권유동화회사법>, <부동산투자회사법> 등이 제정됨으로써 금융시장과 부동산시장 간의 장벽이 허물어지고 있는 추세이다. 2.자본조달방식에 따른 부동산 금융의 종류(1)부채금융(debt project financing)저당권 설정이나 사채발행으로 타인자본을 조달하는 것으로, 자금조달자의 장부에는 부채가 증가하게 된다.①저당금융(mortgage financing): 차입자가 소유권을 보유한 채 대상부동산에 저당을 설정하고, 금융기관으로부터 직접 자금을 대출받는 방법이다.②신탁금융(trust deed financing): 담보신탁을 통해 대출을 받는 방법을 말한다. 신탁금융(신탁증서금융)신탁금융은 대출자와 금융기관 외의 신탁회사가 관여하게 되는데, 차입자는 우선 신탁회사의 담보부 신탁약정에 의해 부동산을 신탁하고 담보 신탁의 수익증권을 교부받아 이를 금융기관에 제출함으로써 융자를 받게 되는 것이다.

②주택개발금융: 주택건설을 촉진하려는 목적에서 주택건설업자의 건설활동에 필요한 자금을 지원해 주는 공급자(건설업자)에 대한 금융이다. 공급자금융이라고도 한다.(2)주택금융의 필요성①주택의 고가성: 주택은 일반재화와는 달리 보통 연소득의 5배 이상인 고가의 내구재이며 필요한 만큼 수시로 분할해서 구입할 수 없는 재화이므로 주택금융이 필요하다.②주거서비스의 적정한 소비: 주택금융이 존재하지 않는다면, 일반가계에서는 주택구입을 위하여 많은 저축과 주택구입시까지 과소소비를 함으로써 가계에 일생주기에 걸친 효용극대화를 위한 적정소비곡선을 달성할 수 없기 때문이다. 따라서 주거서비스의 적정한 소비와 생애주기에 걸친 효용극대화를 위해서 주택금융이 필요하다.(3)주택금융의 기능①주택거래의 활성화: 주택을 담보로 구입하거나 개량하고자 하는 수요자에게 주택자금을 융자해 줌으로써 주택거래의 활성화를 도모한다.②자가소유를 촉진: 주택금융은 임차가구가 자가주택을 소유하도록 하는데 기여한다. 즉 주택금융은 주택구입능력 제고를 통해 주택수요를 주택의 유효수로 전환시키는 역할을 함으로써 자가소유를 촉진한다.③저축유도와 주택자금 조성: 수요자와 주택마련 저축을 유도하고, 동시에 이러한 저축을 통해 필요한 주택자금을 조성하게 한다.④경기조절: 주택금융은 주택경기 부양을 유도하며, 주택경기의 부양은 전반적인 경기조절의 기능을 수행하기도 한다.⑤주거생활의 안정: 주택금융은 국민의 주거 불안정을 해소하는 기능을 지니고 있다.⑥부동산 공급확대에 기여: 부동산의 개발 및 건설 소요자금의 공급을 통해 부동산공급의    확대에 직접 기여할 수 있다.(4)주택금융의 특수성주택자금 융자는 차입자(일반적으로 무주택 서민)에 대한 개인대출이고, 융자금액이 소득에 비하여 비교적 많으며, 부동산을 담보로 하고, 융자기간은 10년 내지 20년에 이르는 장기저리금융이라는 특징을 가지고 있다.

2.저당대출의 위험과 이자율 결정(1)저당대출의 위험①채무불이행 위험(default risk): 저당대출 차입자가 원리금에 대한 채무상환의무를 이행하지    않을 위험이다. 위험의 강도는 차입자의 신용도나 대출의 내용에 따라 다르다.    채무불이행 가능성이 있다면 대출자는 대손 가능성을 축소하기 위하여 프리미엄을 징수한다.    즉 대출금리를 인상하는 방법으로 위험을 회피하려고 한다.②조기상환 위험(만기전변제 위험, prepayment risk): 조기상환이란 차입자가 저당대출의 만기 이전에 대출자에게 원금과 이자를 조기에 상환하는 것을 말한다. 만기전변제라고도 한다. 주택저당대출을 할 때 차입자가 조기에 상환이 가능하도록 콜옵션(call option) 규정을 명시한 조기상환가능 대출 즉, 콜옵션부 대출에서 조기상환위험이 발생한다. 그리고 조기상환 위험은 금리하락기에 발생하는 경우가 많다. 차입자는 대출금리보다 시장금리가 하락할 경우 대출금의 원리금을 상환하고 보다 낮은 금리로 대출을 받음으로써 금융비용을 감소시킬 수 있다. 반면에 콜옵션부 주택저당대출을 해준 대출자는 원금 및 이자를 조기에 상환받게 되므로 보다 높은 수익률을 추구할 수 있는 기회를 상실하게 되는 조기상환위험이 발생하게 된다.이와 같은 위험을 방지하기 위하여 대부분의 주택담보대출계약에는 명시적으로 조기상환에 따른 위약금(만기전 변제 벌금)을 물도록 콜방어 약정이 되어 있는 경우가 많으며, 채권을 발행할 때는 콜방어를 위하여 콜옵션을 금지하는 채권을 발행하기도 한다. ③금리 위험: 현재 시점에서의 대출금리는 시장참여자들이 미래의 변수에 대한 예측치의    합의점을 반영하여 결정되는 것이다. 그러나 향후 경제 전반의 자금의 수급, 인플레이션 수준    등에 따라 대출자들의 자금비용(cost)이 변화하여 대출로부터 손실이 발생할 위험이 따른다.    금리위험은 기본적으로 자금비용과 대출금리의 차이에서 발생하는 것으로 특히 고정금리의   장기대출에서 더욱 위험이 크다. ④유동성 위험: 대출이나 투자자산에 대한 유통시장이 존재하거나 또는 시장성이 높을 경우, 매각하기 어려운 자산보다 낮은 수익률 프리미엄이 형성되나, 부동산대출은 유통시장이 발달되지 못했으므로 차입자는 상대적으로 높은 프리미엄을 지급해야 한다.⑤법적 위험: 부동산 조세제도의 변화, 임대료 규제, 금리수준에 대한 규제 등은 대출자들이   대출 후에 직면하는 사항들이다.

CMO는 이체증권과 저당채권의 두 가지 성질을 다 가지고 있다. CMO는 이체증권처럼 저당차입자의 원금과 이자를 트렌치별로 직접 지급하고 있다. 그리고 트렌치의 규모와 수 등을 조정함으로써 저당채권처럼 그 존속기간을 다양하게 하여 장기투자자들이 원하는 콜방어를 실현시키고 있다. CMO의 트렌치 수는 같은 CMO의 여러 개의 트렌치 중 적어도 마지막 한 개는 중간에 이자와 원금을 전혀 지불받지 않고 만기 때에 원금과 누적된 이자를 한꺼번에 지급받는 것으로 하고 있다. 이 같은 마지막 트렌치를 보통 ‘Z 트렌치’라 부른다.

2.부동산투자신탁의 종류(1)자금운용방법에 따른 분류①회사형 부동산투자신탁: 부동산투자신탁회사에서 다수의 투자자로부터 자금을 조성하여 부동산 등에 투자하고 그 수익을 배당하는 형태로 부동산투자회사법에서 규율하고 있다. 일반적으로 REITs란 회사형을 의미한다.②계약형 부동산투자신탁: 신탁업법상 금전신탁상품 중 한 종류로서 신탁겸업은행에서 판매하는 부동산투자신탁상품을 말한다. 현재에 계약형 부동산투자신탁은 모집된 부동산투자신탁자금을 대부분 부동산개발 관련자금에 융자하는 프로젝트파이낸싱 방식을 택하고 있다.(2)투자대상에 따른 분류①지분형 부동산투자신탁(equity REITs): 총투자자산의 75% 이상이 부동산의 지분권(equity ownership)에 직・간접으로 투자되는 부동산투자신탁으로, 부동산에 직접 투자하여 장기 보유하면서 발생하는 임대수입(rent)을 주된 수입원으로 한다. 가장 일반적인 부동산투자신탁이다. 우리나라의 경우 부동산투자회사법에서는 총 자산의 70% 이상을 부동산에 투자해야 한다고 규정하고 있다.②모기지형 부동산투자신탁(mortgage REITs): 총 투자자산의 75% 이상을 부동산 관련 대출이나 주택저당증권(MBS)에 투자되고 있는 부동산투자신탁이다. 이는 부동산담보대출의 이자를 주 수입원으로 한다.③혼합형 부동산투자신탁(hybrid REITs): 투자자산이 부동산소유지분이나 부동산담보대출, 주택저당증권 등에 분산 투자되어 있기 때문에 지분형이나 모기지형으로 분류될 수 없는 부동산투자신탁이다.(3)환매 가부에 따른 분류①개방형(open-end) 부동산투자신탁: 자금의 추가발행(추가 자금모집)이 가능하므로 부동산투자신탁 모집자가 투자자의 환매 요구에 언제든지 응하는 형태이다.②폐쇄형 부동산투자신탁: 자금의 모집은 최초의 모집 시기에 국한되는 것으로, 투자자가 직접 자금 모집자에 대하여 환매 요청을 할 수 없는 형태이다. 그러나 증권시장에 상장된 경우에 증권시장에서 주식을 매각하여 투자한 자금을 회수할 수 있다. (4)기한한정여부에 따른 분류①무기한부 부동산투자신탁(perpetual REITs): 존속기한이 정해져 있지 않은 형태의 부동산투자신탁이다. 우리나라 부동산투자회사법에서는 무기한부 부동산투자신탁의 형태를 규정하고 있으므로, 일반적으로 K-REITs는 무기한부로 볼 수 있다.

②기한부 부동산투자신탁(finitelife REITs or self=liquidating REITs): 일정기간 후에 보유자산을 매각하여 매각대금을 투자자에게 배분하고 해산되는 부동산투자신탁이다. 3.부동산투자회사제도의 장점(1)정책면에서의 장점①대규모 부동산 소유의 기회 제공: 소액 투자자에게 대규모 부동산을 공동으로 소유할 기회를 제공해주고 있다. 일반적으로 부동산투자는 투자금액의 규모가 클수록 수익률도 비례하여 커지는 경향이 있다.②투자와 부동산의 유동성 증대: REITs제도는 ABS, MBS와 마찬가지로 유동성이 결여된 부동산을 증권화를 통하여 현금화가 용이한 형태로 전환시켰다는 점이 장점이다. 이에 따라 금융회사들도 REITs를 통해 부동산을 쉽게 유동화시킬 수 있어 자기자본비율(BIS)도 안정적으로 유지시킬 수 있다.③부동산 전문가의 활용: REITs는 주주의 수동성 원칙에 의해 각각의 주주가 직접 회사 경영에 참여하는 것이 금지되어 있으므로, 부동산 투자 및 관리 능력을 갖춘 전문가를 활용함으로써 수익성도 증대될 수 있다.(2)투자자 입장에서의 장점①소액자본의 활용: 투자자는 적은 자금으로 다양한 부동산을 선택할 수 있는 기회가 생기며, 동시에 안정적인 높은 배당과 주가변동에 따른 자본이득의 가능성도 기대할 수 있다.②세재 혜택: REITs는 회사 수익의 대부분을 투자자에게 배당하여야 하는 일종의 도관체이므로, 회사의 수익에 대해서는 법인 차원의 세금이 감면되는 장점이 있다. 다만 우리나라의 경우 실체회사인 경우에는 법인세를 부담해야 하며, 명목상 회사일 경우에는 법인세가 감면되고 있다.③높은 수익률: 모든 REITs는 배당을 하게 되며, 은행 예금 등에 비해 배당률이 높은 편이다.④투자의 안전성: 부동산투자의 장점인 인플레이션 헤지(inflation hedge)의 기회가 되기도 한다.⑤분산투자를 통한 위험의 제거: 다양한 REITs를 활용하여 포트폴리오를 구성함으로써 위험을 줄일 수 있다. ⑥효율적 감사: REITs의 성과는 항상 회사 내부의 감사나 주주총회, 외부의 감독기구나 언론 등을 통해 감시되어 운영의 투명성이 확보된다는 점도 장점이 된다.

(3)부동산소유자 입장에서의 장점①부동산의 유동성 증대: REITs의 도입으로 부동산시장이 활성화되어 부동산을 통한 부채상환이나 재투자를 위한 자금조달이 용이해지고, 부동산의 매각도 손쉬워져 부동산의 가격상승까지도 기대해볼 수 있다.②자본조달이 용이: REITs 제도는 부동산의 유동성 위험을 감소시키므로, 부동산을 담보로 대출받은 차입자 입장에서는 금리 인하와 차입 기회가 확대되므로 자본 조달이 용이해진다.4.부동산투자회사의 종류(1)자기관리부동산투자회사자산운용전문인력을 포함한 임・직원을 상근으로 두고 자산의 투자・운용을 직접 수행하는 회사로서, 실체회사가 된다.(2)위탁관리부동산투자회사자산의 투자・운용을 자산관리회사에 위탁하는 회사로서, 명목회사로서 본점 외의 지점을 설치할 수 없으며, 직원을 고용하거나 상근인 임원을 둘 수 없는 명목회사(paper company)로서 자산운용은 자산관리회사에 위탁한다는 점 이외에는 자기관리REITs와 구분되지 않는다.(3)기업구조조정부동산투자회사(CR-REITs)기업구조조정용 부동산(총자산의 100분의 70 이상)을 투자대상으로 하며 자산의 투자・운용을 자산관리회사에 위탁하는 회사로서, 명목상 회사이며, 다른 회사에 비해 많은 특례가 인정되고 있다.

제4절공급자금융1.부동산투자회사(REITs) 2.부동산 신디케이션(1)부동산 신디케이션의 의의①의의: 부동산 신디케이션(real estate syndication)이란 부동산 개발사업을 공동으로 수행하기 위하여 일반 투자자들의 자금과 부동산개발업자의 전문성이 결합된 투자자 집단을 말한다.②신디케이트(syndicate): 신디케이션이 부동산을 취득, 개발, 관리, 운영, 매도하기 위해서는 법인의 형태를 가져야 하는데, 이를 신디케이션 회사 또는 신디케이트라고 한다.③신디케이터(syndicator): 신디케이터란 신디케이션의 결성에 주도적인 역할을 하며, 결성된 신디케이션의 운영과 관리의 책임을 지는 법인이나 자연인을 말하며, 보통 건설회사, 개발회사, 리츠회사 등이 신디케이터로서의 역할을 한다. (2)신디케이션의 운영①신디케이션의 결성시기: 개발업자들은 개발사업의 시작부터 신디케이션을 결성하기도 하지만 경우에 따라서는 자신의 자본으로 개발사업을 완공하고 임대차를 완료한 후에 신디케이션을 결성하기도 한다.②출구전략: 완성된 개발사업의 가치가 원래의 건축비용을 크게 초과할 경우, 개발업자는 완성된 개발사업을 신디케이션에 매도하여 자신이 투자한 건축비용과 개발수수료는 현금으로 회수하고, 그 초과분만큼은 신디케이션의 지분소유권(equity ownership)으로 획득하는 것이다. 개발업자들은 이 같은 출구전략을 씀으로써 개발수수료를 획득하고 자기자본을 유지한 채 다른 개발사업에도 전념할 수 있다. (3)자금모집방식①사모방식과 공모방식㉠신디케이션 방식은 신규부동산을 개발할 경우 뿐만 아니라 기존 부동산을 매수하여 운영하고자 할 경우에도 활용된다.㉡대상부동산의 규모가 작을 경우에는 사모방식이, 규모가 클 경우에는 공모방식이 사용된다.

(4)순가중개위임제①개념: 매도자가 받아들일 수 있는 최소의 가격을 미리 정하고, 실제 매매가격이 이를 초과할 경우 이 초과분을 수수료로 하는 중개위임제도이다. ②문제점: 순가중개제는 다른 나라에서는 대부분 오래 전에 불법화된 것인데, 우리나라에서는 일부 중개업자들간에 여전히 성행되고 있다. 대리인인 중개업자는 본인에 대해 법적으로 <신의성실의 의무>를 지고 있다. 순가중개제는 본인에 대한 신의성실의 의무를 위배할 뿐만 아니라, 부동산 거래가격을 조작하여 투기를 조장하는 등 거래질서를 문란케 할 가능성이 있다. 3.중개위임계약서의 기재사항①중개위임계약 당사자의 서명날인②중개위임된 부동산의 지적과 주소③매매조건: 부동산의 가격, 저당잔금, 기타 계약조건 등④중개위임계약의 개시일과 종결일⑤중개위임계약의 유형: 공개중개제, 독점매도권중개제 등⑥중개수수료⑦거래에 포함되는 물품의 종류: 가구설비, 텔레비전 안테나, 카페트, 차양막 등4.중개위임계약의 종료①보통 대상부동산이 매매됨으로써 종결된다. ②중개위임계약기간이 만료되었음에도 대상부동산이 팔리지 않았을 때에도, 계약기간을 연장하는 재계약이 없으면 중개위임계약은 종료된다.

6.일본기준상의 시장가치 외의 가치(1)특정가격①특정가격의 의의특정가격이란 시장성을 갖는 부동산이지만 법령 등의 따른 사회적 요청을 배경으로 하는 평가목적 하에서, 시장가치의 전제가 되는 제 조건을 만족하지 않는 경우의 부동산 경제가치를 적정하게 표시하는 가격을 말한다.②특정가격으로 평가하는 경우㉠<자산의 유동화에 관한 법률> 또는 <투자신탁 및 투자법인에 관한 법률>을 근거로 하는 평가목적 하에서 투자가에게 제시하기 위한 투자채산가치를 표시하는 가격을 구하는 경우㉡<민자재생법>에 근거한 평가목적 하에서 조기매각을 전제로 한 가치를 구하는 경우㉢<회사갱생법> 또는 민사재생법에 근거한 평가목적 하에서 사업의 계속을 전제로 하여 가격을 구하는 경우(2)특수가격①특수가격의 의의특수가격이란 문화재 등 일반적으로 시장성이 없는 부동산의 이용상황 등을 전제로 하여 대상 부동산의 경제가치를 적정하게 표시하는 가격을 말한다. ②특수가격으로 평가하는 경우특수가격을 구하는 경우를 예시하면, 문화재의 지정을 받은 건조물, 종교건축물 또는 현황과 같이 관리를 계속하는 공공 · 공익시설의 용도로 제공되는 부동산을 그 보존 등에 주안점을 두어 감정평가하는 경우이다.
