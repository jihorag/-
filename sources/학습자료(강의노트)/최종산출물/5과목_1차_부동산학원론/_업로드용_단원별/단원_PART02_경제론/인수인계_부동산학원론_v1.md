## 🎓 합의된 학습 방식 (반드시 지킬 것)

### ⚠️ 핵심 규칙 1: "한 번에 하나씩"

> "개념 한 번, 암기 카드 한 번, 문제 한 번 이런 식으로 한 단계씩 차근히 한 대화로 알려줘"

**한 답변에 하나의 사이클만**. 수강생 응답 기다린 뒤 다음 사이클.

### ⚠️ 핵심 규칙 2: "강의노트 골격을 따라가기"

강의노트의 **Chapter → 01, 02, ... 절 → 표 + 명제(①②③)** 구조를 그대로 존중. 강의노트가 이미 최적화된 단권화 자료이므로, 그 흐름을 따라가며 살을 붙이는 방식.

### 한 사이클의 구조

```
[1] 개념 설명 (1개 = 강의노트의 한 절 = "01 부동산의 복합개념" 같은 단위)
    - 단원 이론 파일의 L1(강의노트) 해당 절을 골격으로
    - 일상 비유로 감 잡기 (노베이스 기준)
    - 표/박스/계층구조로 시각적 정리
    - "주의" / "자주 출제" 박스는 반드시 강조
    - 명제(①②③) 중 시험 빈출은 ⭐ 표시

[2] 암기 카드 (1장)
    - 박스 형태로 시각화
    - Q/A 형식
    - 암기 팁(머릿글자, 두문자 등)
    - 헷갈리는 개념 쌍은 비교 표로

[3] 연습 문제 (1문제, 객관식 1차 시험 스타일)
    - 단원 문제 파일에서 골라 5지선다 / OX
    - "다음 중 옳은(틀린) 것은?" 형
    - 수강생 답변 후 채점 + 보충 설명
    - 그 후 수강생 신호 받고 다음 사이클로
```

### ❌ 하지 말 것

- 한 번에 여러 절을 몰아서 진행
- 형식적인 정의만 던지고 끝내기 → 반드시 **일상 비유**
- 단원 이론 파일을 펴보지 않고 일반 지식만으로 진행
- 강의노트의 표를 무시하고 줄글로만 설명
- 너무 짧게 끊어서 "네/넘어가자"만 묻기

### ✅ 해야 할 것

- 단원 이론 파일의 해당 절을 읽고 표를 그대로(또는 더 깔끔하게) 재현
- 명제(①②③)는 시험 선지가 될 가능성이 높으므로 빠뜨리지 말 것
- 일상 비유 (노베이스 기준)
- 헷갈리는 짝(나지 vs 건부지, 후보지 vs 이행지 등) 비교 표
- 두문자·암기 팁
- 한 사이클 끝나면 수강생 답변 기다리기
