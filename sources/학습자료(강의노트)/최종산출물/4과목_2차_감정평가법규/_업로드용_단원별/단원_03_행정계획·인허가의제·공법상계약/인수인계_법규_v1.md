## 🎓 합의된 학습 방식 (반드시 지킬 것)

### ⚠️ 핵심 규칙 1: "한 번에 하나씩"

> "개념 한 번, 답안 양식 한 번, 문제 한 번 이런 식으로 한 단계씩 차근히 한 대화로 알려줘"

**한 답변에 하나의 사이클만**.

### ⚠️ 핵심 규칙 2: "출제빈도 우선 + 단원 순서"

법규는 **개별법(단원 7,8)이 출제 1·3위**라 이 단원을 먼저 학습하는 것 추천 (옵션 A).
정공법은 행정법(단원 1)부터 단원 10까지 순서.

### 법규 학습의 핵심 (이론·실무와 다른 점)

- 법규는 **서술형 시험** (이론과 비슷). 답안에 **조문·판례 인용 필수**.
- 답안 양식: **개념 → 조문 → 학설 → 판례 → 검토** 흐름.
- 매년 4문제 (40·30·20·10 또는 30·30·20·20).
- 1번은 보통 공용수용/손실보상 (개별법) → 단원 7, 8 집중.

### 한 사이클의 구조

```
[1] 개념 설명 (1개 논점)
    - 단원의 📖 핵심요약서(개별법) 정의 확인
    - 📚 기본서 본문에서 답안 양식·논점 가져오기
    - ⚖️ 관련 조문 인용 (법전 매칭 페이지)
    - 일상 비유로 감 잡기 (노베이스 기준)

[2] 답안 양식 (1개)
    - 답안 작성 순서: 의의(조문 인용) → 요건 → 절차 → 효과
    - 판례 추가 (`_판례특강.md` 활용)
    - 점수별 분량 안내 (10점 vs 30점)

[3] 연습 문제 (1문제)
    - 기출 회차 (1번 메인 단원 우선) → GS 페이지 발췌
    - 답안 작성 → 채점 + 보충 설명
```

### ❌ 하지 말 것

- 조문 없이 일반론으로만 답하기 → **반드시 조문 인용**
- 판례 없이 학설만 적기 → **판례번호·요지 인용** (대법 2003두7507 등)
- 점수에 맞지 않는 분량 (10점에 너무 깊이, 40점에 너무 얕게)
- 단원 순서 무시·논점 들쭉날쭉

### ✅ 해야 할 것

- 조문은 정확한 조문번호·항·호로 인용
- 판례는 사건번호·요지 인용
- 답안 양식 (의의→요건→효과→권리구제) 통일화
- 단원 7,8 (★★★)을 가장 깊이있게

## ⚠️ v1 알려진 한계

1. **5개 PDF 추출 실패**: 26년 GS 0/1/2기 + 행정법·개별법 연습문제는 이미지 스캔본이라 텍스트 추출 실패. 학습 시 PDF 원본 직접 참조 필요.

2. **GS 회차별 분할 X**: GS PDF는 회차 마커가 명확하지 않아 페이지별 키워드 매칭으로 분류. 회차 단위 학습은 어려움.

3. **법전 단원 분할 키워드 기반**: 법전 594p를 단원에 균등 분배 안 하고 키워드 매칭. 일부 조문은 누락 가능 → 학습 중 부족하면 `참조_법전.md`에서 직접 검색.

4. **기본서 v1·v2 둘 다 있음**: 행정법·개별법 모두 v1(스터디파이터)·v2(보상법규_기본서) 두 판본. 단원에는 **v2 최신본**만 사용. v1은 raw 추출본에만 보관.

5. **답안 양식 추출 안 함**: 이론과 달리 법규는 답안 양식이 본문 내 자연스럽게 녹아 있어 자동 추출 어려움. 학습 시 기본서 본문에서 직접 추출.

6. **조문특강·판례특강 페이지 적음**: 조문특강 행정법 9p / 개별법 37p, 판례특강 16p. 본격적인 조문·판례는 `참조_법전.md` (594p)에서 찾기.
