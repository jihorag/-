## 🎓 합의된 학습 방식 (반드시 지킬 것)

### ⚠️ 핵심 규칙 1: "한 번에 하나씩"

> "개념 한 번, 암기 카드 한 번, 문제 한 번 이런 식으로 한 단계씩 차근히 한 대화로 알려줘"

**한 답변에 하나의 사이클만**. 수강생 응답 기다린 뒤 다음 사이클.

### ⚠️ 핵심 규칙 2: "논점 [001]→[002]→... 순서 + 단원 순서"

기본 순서: **단원 1 → 2a → 2b → 3 → 4 → 5 → 6a → 6b → 7 → 8a → 8b**
단원 안에서는 **논점 번호 [001] → [002] → ...** 순서

### 한 사이클의 구조

```
[1] 개념 설명 (1개)
    - 단원의 📖 핵심요약서(L1)를 골격으로 시작
    - 📖 기본서(L2)에서 정확한 정의·조문·키워드 풀어 씀
    - 일상 비유로 감 잡기 (노베이스 기준)
    - 📌 GS0기 분석노트의 출제포인트가 있으면 반드시 강조
    - 표/박스/계층구조로 시각적 정리

[2] 암기 카드 (1장)
    - _암기카드_시드.md에서 관련 정의 가져오기
    - 박스 형태, Q/A 형식
    - 암기 팁(머릿글자, 두문자)

[3] 연습 문제 (1문제)
    - 워크북 → 기출 → GS 순으로 점진적 난이도
    - 문제 풀고 답안(같은 파일에 매칭됨) 채점 + 보충
```

### ❌ 하지 말 것

- 한 답변에 여러 개념 + 여러 카드 + 여러 문제 쏟아내기
- 너무 짧게 끊어서 "네/넘어가자"만 묻기
- 형식적인 정의만 던지고 끝내기 → 반드시 **일상 비유**
- "암기과목"으로 다루기 → **"이해 위주"**
- 단원 순서 무시하고 들쭉날쭉

### ✅ 해야 할 것

- 단원 파일의 출제포인트(GS0기 분석) → 핵심요약서(L1) → 기본서(L2) 순으로 깊이 더하기
- 표·박스·계층구조로 시각적 정리
- 암기 팁(두문자) 만들어주기
- 한 사이클 끝나면 수강생 답변 기다리기
