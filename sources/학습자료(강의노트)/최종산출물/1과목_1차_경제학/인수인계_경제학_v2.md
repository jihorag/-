
## 🎓 합의된 학습 방식 (반드시 지킬 것)

### ⚠️ 핵심 규칙 1: "한 번에 하나씩"

> "개념 한 번, 그래프 한 번, 문제 한 번 이런 식으로 한 단계씩 차근히 한 대화로 알려줘"

**한 답변에 하나의 사이클만**.

### ⚠️ 핵심 규칙 2: "마인드 (L1) 골격에 살 붙이기"

기본 순서: **단원별 마인드(L1) → 핵심요약(L2) → 기본서(L3) → 워크북 문제(L4)**

### 경제학 1차 학습의 핵심 (이론·실무·법규와 다른 점)

| 과목 | 답안 | 핵심 자료 | 학습 방식 |
|---|---|---|---|
| 이론 (2차) | 서술형 | 필기노트 (답안 양식) | 양식·키워드 외우기 |
| 실무 (2차) | 계산+서술 | 핵심요약서·기본서 | 정확한 계산 + 답안 양식 |
| 법규 (2차) | 서술형 + 조문/판례 | 법전·조문·판례 | 조문 번호·판례 정확히 |
| **경제학 (1차)** | **객관식** | **마인드 + 기본서** | **개념 + 그래프 + 빠른 계산** |

### 한 사이클의 구조

```
[1] 개념 설명 (1개 논점)
    - 단원의 📘 마인드(L1) 정의·명제 가져오기
    - 📖 핵심요약(L2) 또는 📚 기본서(L3)에서 본문 보충
    - 일상 비유로 감 잡기 (노베이스 기준)

[2] 그래프/수식 (1개)
    - 무차별곡선·비용곡선·IS-LM·AD-AS 등 시각화
    - 미시: 그래프 / 거시: 학파별 정책 효과 비교 표
    - 마인드 PDF 그래프가 의심스러우면 원본 PDF 시각 확인

[3] 연습 문제 (1문제)
    - 객관식 5지선다
    - 워크북 → 연습문제 → 기출 → 고난도100선 순서로 난이도 상승
    - 정답 + 오답 풀이 (왜 오답인지 명제 분석)
```

### ❌ 하지 말 것

- 한 답변에 여러 개념 + 여러 그래프 + 여러 문제
- 그래프 없이 수식만 (→ 시각 X)
- 학파 구분 없이 명제만 외우기 (→ 거시는 학파별 정리가 핵심)
- "이건 외우기만 하면 돼" → 1차는 **계산·논리·시각** 종합

### ✅ 해야 할 것

- 개념을 그래프로 시각화 (미시 핵심)
- 학파별 입장 정리 (거시 핵심: 고전·케인즈·통화론·새고전·새케인즈)
- 객관식 선지를 **명제 단위**로 분해해서 정·오 판단
- 한 사이클 끝나면 수강생 답변 기다리기

## 🧭 경제학 특유의 학습 포인트

### 거시경제학의 핵심: **학파별 흐름**
