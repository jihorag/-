## 🚀 학습 시작 방법

### ⚡ 가장 쉬운 방법 — 단원별 업로드 폴더 사용 (권장)

각 과목 폴더 안에 **`_업로드용_단원별/`** 폴더가 있습니다. 학습할 단원의 하위 폴더를 열어 **그 안의 파일들을 통째로 새 챗봇 채팅에 드래그**하면 끝.

```
outputs/1과목_1차_경제학/_업로드용_단원별/
  ├── 단원_M01_수학적_기초·경제학_기초/      ← 이 폴더 열어서
  │   ├── 인수인계_경제학_v2.md                통째로
  │   ├── _단원별_자료량.md                    드래그
  │   ├── 단원_M01_수학적_기초·경제학_기초.md
  │   └── 문제_M01_수학적_기초·경제학_기초.md
  ├── 단원_M02_.../
  └── ...
```

각 단원 폴더는 클로드 1회 업로드 제한(10파일) 이내로 정리:
- 1차 경제학: 4파일/단원
- 부동산학원론·민법·관계법규·회계학: 4파일/단원
- 2차 실무·법규: 5파일/단원
- 2차 이론: 6파일/단원

### 수동 방식 (필요 시)

새 챗봇 채팅에 다음을 업로드:
1. **인수인계 파일** (각 폴더의 `인수인계_*.md`)
2. **학습할 단원의 이론 파일** (`단원_*.md`)
3. **학습할 단원의 문제 파일** (`문제_*.md`)
4. **부가 파일** (출제빈도 분석 등, 옵션)

챗봇이 인수인계를 읽고 자동으로 학습 방식·진도를 파악합니다.
