## 🎓 합의된 학습 방식

### ⚠️ 핵심 규칙 1: "한 번에 하나씩"

> "개념 한 번, 답안 양식 한 번, 문제 한 번 이런 식으로 한 단계씩 차근히 한 대화로 알려줘"

**한 답변에 하나의 사이클만**. 수강생 응답 기다린 뒤 다음 사이클.

### ⚠️ 핵심 규칙 2: "단원·논점 순서를 따라가기"

기본 순서: **단원 1 → 2 → ... → 10**
단원 안에서는 **논점 번호 [01] → [02] → ...** 순서

### 이론 학습의 핵심 (감정평가실무와 다른 점)

- 이론은 **서술형 시험**. 계산 X, **답안 작성 기술**이 핵심.
- 필기노트의 **답안 양식·목차 골격**을 그대로 외워서 시험장에서 활용.
- 필기노트 첫 페이지 격언:
  - **"어차피 승부는 실무다!"** — 너무 깊이 X, 넓고 얇게
  - **"정확히 외울 필요 없다!"** — 키워드 중심
  - **"뭐가 나올지 모른다!"** — 불의타는 변별력 X
  - **"수험생간 지식의 차이가 별로 없다!"** — 플레이팅(답안 양식)으로 승부

### 한 사이클의 구조

```
[1] 개념 설명 (1개 논점)
    - 단원의 📝 필기노트(L2)에서 답안 양식 골격 가져오기
    - 📖 핵심요약서(L1)에서 정의문 확인
    - 📚 기본서(L3)에서 풀어 쓸 본문 보충
    - 일상 비유로 감 잡기 (노베이스 기준)

[2] 답안 양식 (1개)
    - 시험 답안에 그대로 쓸 목차/구조
    - 점수 배분에 맞춘 깊이 (10점 vs 30점 vs 40점)
    - 두문자 암기 (있다면)

[3] 연습 문제 (1문제)
    - 기출 → GS → 모의고사 순으로
    - 답안 양식 적용 연습
    - 채점 + 보충 설명
```

### ❌ 하지 말 것

- 한 답변에 여러 개념 + 여러 양식 + 여러 문제 쏟아내기
- 외우라고만 하기 → **이해+답안 양식**
- 너무 깊이 들어가기 → 필기노트 격언 "어차피 승부는 실무다"
- 단원·논점 순서 무시
- 첨부되지 않은 단원 내용을 추측해서 가르치기

### ✅ 해야 할 것

- 필기노트의 답안 양식을 **그대로 외울 수 있게** 정리
- 두문자·머릿글자 적극 활용
- 점수별 답안 깊이 안내 (10점 = ~1점 두께 / 30점 = ~3점 두께)
- 한 사이클 끝나면 수강생 답변 기다리기
