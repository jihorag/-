(2) 이론 (지오 평가사님) 이론의 경우, 지오 평가사님의 커리큘럼을 따라가면서 기출을 최대한 많이 보려고 노력했던 것 같습니다. 마찬가지로 타 학원 자료는 보지 않았습니다. - 사용 교재 : 기본서 / 기본문제집 / 0,1,2,3,4기 스터디자료 / 이론 서브노트 / 실무기준 / 감칙 이론은 기간별로 나누어 설명할 거리가 별로 없어서 통으로 작성하겠습니다. 해가 넘어가기 전에는 실무에 비교적 시간을 쏟느라 이론은 지오 평가사님의 강의만 듣고, 기출문제 15개년을 2회독 정도하는 데에 그쳤습니다. 이때 실무기준해설서를 한 번 완독한 후에 실무기준을 따로 정리했고, 지오 평가사님의 서브노트에 기본서에 있는 내용을 키워드 위주로 정리했습니다. 해가 넘어가고 나서는 꾸준히 기출 회독을 늘리면서 스터디 참여 + 이론 개념암기 + 실무기준 암기 + 이론서 목차 암기 >를 병행했습니다. 이론서 목차암기의 경우 평일 5분할하여 말 그대로 목차만 암기했고, 스터디에서 자주 등장하는 비교설명과 같은 목차도 추가하여 암기했습니다. 개념 암기는 개별 스터디를 통해 분량을 정해 매일 15개에서 25개 랜덤으로 암기하였고, 실무기준도 중요한 쟁점 위주로 5분할하여 암기했습니다. 결과적으로 기출 15개년 4회독 / 스터디자료 (0-3기) 각 기마다 약 3회독 / 이론서 목차 암기 (5분할해서 매주 외워서 몇 회독했는지 기억이 안납니다. 최소 10회독 이상) / 실무기준 10회독 이상 / 개념은 대부분 암기하였습니다.
