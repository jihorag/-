# 감정평가사 합격후기 DB

실제 합격 수기를 **레코드 단위로** 모은 데이터셋. 앱의 학습 계획·기능 기획 근거로 사용한다.

- `pass_stories.json` — **정독·구조화한 후기 레코드**(아래 스키마). 현재 **17건 verified_raw**.
- `pmg_index.json` — 박문각 합격수기 게시판 **전량 543건 인덱스**(ID·NUMBER·제목). 제목에 기수/년차/전업·직장/온오프/수석이 담겨 경량 메타로 활용.
- `pmg_raw/` — 박문각 게시글 **본문 원문(txt) 전량**(curl 스크랩). 심층 분석·추가 구조화 소스.
- `pmg_board_analysis.md` — 박문각 게시판 **전수 통계·패턴 분석** + 수집 방법(재현 가능).
- 관련 집계 인사이트: [../next-update-plan-from-pass-stories.md](../next-update-plan-from-pass-stories.md) — 22개 출처·23개 검증 클레임의 초기 패턴 분석.
- 스크래퍼: [../../scratch/scrape_pmg_pass_stories.py](../../scratch/scrape_pmg_pass_stories.py) (`index`/`bodies`).

## 스키마 (레코드 1개 = 후기 1개)

| 필드 | 설명 |
|---|---|
| `id` | 고유 slug (`{출처}-{기수}-{이름}`) |
| `source` | `{ name, title, author, url, type, contact }` — 출처 |
| `verified_raw` | 원문 전체를 확보/확인했는가 (true=풀 레코드, false=집계·2차 인용 기반 stub) |
| `year`, `cohort` | 합격 연도 / 기수 |
| `track` | `동차` \| `유예` \| `장수` |
| `working` | 직장 병행 여부 (bool) |
| `total_period_months` | 총 수험 기간(개월) |
| `study_hours` | `{ weekday, weekend }` 하루 공부량 |
| `scores` | `{ round1{연도:점수}, round2{연도:{avg,과목별,result}} }` |
| `instructors` | 과목별 강사/학원 |
| `materials` | 사용 교재·도구·단권화 방식 |
| `methods` | `{ round1, round2_common, 실무, 이론, 법규, ... }` 과목별 공부법 |
| `failure_factors` | 실패·고전 요인 (배열) |
| `key_takeaways` | 결정적 요인·후배 조언 (배열) |
| `notes` | 기타 특이사항 |

> 원칙: **지어내지 않는다.** 원문에서 확인된 것만 기록하고, 불확실하면 `verified_raw:false` + 빈 값으로 둔다. 점수·시간은 1인칭 자기보고임을 감안.

## 현황

- ✅ **정독·구조화 78건 (verified_raw)** — 박문각 게시글/PDF 65건 + 랜드잇 oopy 개인수기 10건 + eduspa PDF + 법률저널 + 디시 2024 1차.
  - 트랙: 동차 44 · 유예 23 · 장수 9 (기수 제12~36회, 최근 34·35·30회 집중)
  - 각 레코드에 점수(과목별)·강사·과목별 공부법·1차 회독수·2차 서브/목차/인출/완주·실패요인·조언·근거인용(`_evidence`).
  - ⚠️ **샘플링 편향**: 구조화 대상을 앱 기획 우선순위(동차·직장/학업병행·수석)로 골라 **동차가 실제 게시판(약 18%)보다 과대표집**됨. 전체 분포는 `pmg_index.json`(543건 전량)이 정확.
- ✅ **박문각 게시판 전량 543건** — 인덱스(`pmg_index.json`) + 본문 원문(`pmg_raw/`, 인라인 281건). 통계는 `pmg_board_analysis.md`.
  - 참고: 최근 글 상당수(261건)는 본문이 네이버 카페·이미지 '원본 바로가기'라 헤더만 저장됨.

### 수집 시 채울 우선 항목 (앱 기획 직결)
1. 동차/유예/장수 + 직장병행 여부, 총기간·과목별 시간배분
2. 1차 기출 **회독 수**·오답 재풀이 방식
3. 2차 **서브노트 단권화 / 목차잡기 / 인출암기** 노하우, 답안 분량·시간배분
4. 사용 도구(모바일 기출앱 등)·교재·인강
5. 반복되는 **실패 원인**(버리기→과락, 완주 실패, 계산실수, 인출 실패)
