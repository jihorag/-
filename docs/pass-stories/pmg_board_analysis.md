# 박문각 감정평가사 합격수기 게시판 — 전수 분석

출처: 박문각 서울법학원 합격수기 게시판 `bbsid=2500` · 전량 **543건**(2012~2025, 제12~36회).

## 수집 방법 (재현 가능)
- WebFetch/브라우저 외 서버 fetch는 `www.pmg.co.kr`이 **연결 리셋(ECONNRESET)** 으로 차단 → 개별 글 접근 불가.
- **우회: `curl`(브라우저 User-Agent)** 은 HTTP 200으로 접근됨. 목록 페이지(`&CP=1..28`)에서 각 글의 `ID`·`NUMBER`·`title` 수집 → 글은 **`ID` 파라미터**가 본문을 결정(NUMBER는 표시용) → `ID`로 본문 요청·추출.
- 스크립트: `scratch/scrape_pmg_pass_stories.py` (`index` = 목록/인덱스, `bodies` = 본문 전량 저장).
- 산출물: `pmg_index.json`(543건 인덱스), `pmg_raw/`(글별 본문 원문 txt).

## 핵심 패턴 (인덱스 + 정독한 20건 기반)

1. **유예(2년차)가 최빈(38%)** — 대다수가 초시에 2차를 경험하고 **2년차에 합격**. "초시는 감 잡기, 2년차 합격"이 표준 경로. 동차(18%)도 상당하나 소수.
2. **실무 과락이 반복 실패요인** — 라주현(31회 실무 1점차 과락), 박래권(초시 실무 25.5), 양해진(2년차 실무편식→이론·법규 과락), 정지인(1년차 전과목 저조). → 실무는 **다양한 학원 문제로 회독**해 안정화가 관건.
3. **2차 합격 공식**: 서브노트 **단권화** → **목차 암기**(무엇을 쓸지 즉시 인출) → **완주**("80점보다 100점 다 쓰기"). 여러 수기에서 반복.
4. **1차 과투입 경계** — 라주현·박태빈: "1·2차 연계 약함, 1차는 짧고 컴팩트하게, 2차를 먼저·비중 있게."
5. **직장·학업 병행이 104건(명시분의 절반)** — 온라인 인강 + 주말·자투리 시간, 퇴근 후 4~5h가 전형. 동차 앱의 '병행 트랙' 설계와 부합.

> 주의: 트랙·형태는 **제목 문자열 파싱** 결과라 근사치(제목에 미표기면 '미상'). 정밀 수치는 `pmg_raw/` 본문 정독 필요. 점수·기간은 1인칭 자기보고.
