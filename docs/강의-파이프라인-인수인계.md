## 5. 밟았던 지뢰 (같은 데서 또 막히지 말 것)

### 5-1 `__pycache__`에 옛 경로가 남는다 ⚠ 가장 최근에 당함
외장을 WD_Black → T7 Shield로 옮긴 뒤, `scripts/lectures/__pycache__`에 컴파일된 옛 `_paths`가 남아 전사본을 못 찾고 **전 관이 "강의 구간 없음"으로 조용히 건너뛰어졌다.** 오류가 안 난다는 게 최악이다.

```bash
rm -rf scripts/lectures/__pycache__
```
경로 관련 수정 뒤에는 무조건 지운다.

### 5-2 드라이브 이름
`_paths.py`가 `/Volumes`를 훑어 `인터넷강의/감정평가사 인터넷강의`가 있는 볼륨을 자동으로 찾는다. 이름이 바뀌어도 스크립트는 괜찮다.

**다만 `catalog.json`은 절대경로를 저장한다.** 드라이브가 바뀌면 5개 카탈로그를 치환해야 한다.
```bash
# viewer/public/data/study/*/lectures/catalog.json 에서
#   /Volumes/옛이름/인터넷강의  →  /Volumes/새이름/인터넷강의
```

### 5-3 파일명이 NFD다
macOS 외장의 한글 파일명은 NFD로 저장돼 있어 한글 정규식이 **0건 매칭**된다.
```python
unicodedata.normalize('NFC', name)
```
`._*` AppleDouble 파일 2,482개(5GB)도 `! -name '._*'`로 제외한다.

### 5-4 교재 PDF는 사다리로 못 쓴다
강의 제목에 면수가 거의 100% 있어서 "쪽 → 관" 매핑을 기대했지만:
- 법규(이상곤)·민법(김묘엽) — **스캔본, 텍스트 0자**
- 회계(황윤하) — OCR 깨짐 + 강사(신은미)와 다른 저자라 쪽수 불일치

**그래서 면수는 절대 위치가 아니라 "교재의 몇 %쯤"이라는 비율로만 쓴다.**

### 5-5 매핑 신호는 과목마다 다르다
`align_transcript_direct.py` 상단 상수를 보라.

| 과목 | 쓰는 신호 |
|---|---|
| 부동산·경제 | 파일명 편(編) ↔ taxonomy PART가 **정확히 대응** |
| 법규 | 편 번호가 **안 맞는다**(강사마다 교재가 달라 도승하 제1편=PART 04). 법률 이름으로 좁힌다 |
| 민법 | 편 표기가 아예 없다(0/66강). 면수 밴드 + 제목 유사도 |
| 회계 | 편은 있으나 대분류와 대응 안 됨. 민법과 같은 방식 |

**면수 밴드는 민법·법규·회계에서만 켠다**(`USE_PAGE_BAND`). 부동산에 켰더니 정확한 편 신호를 희석해 제목 일치가 73%→63%로 떨어졌다. 부동산의 '면수'는 본교재가 아니라 빵구노트 쪽수라 위치를 잘못 짚는다.

### 5-6 한 과목에 강좌가 여럿이면 따로 정렬해야 한다
- 회계 = 재무회계 63강 + 원가회계 21강 (둘 다 1강부터)
- 법규 = 도승하 36강 + 김희상 39강 (같은 범위를 각자 처음부터)

강번호로만 정렬하면 두 강좌가 지그재그로 섞이고, **단조 DP는 뒤로 못 돌아가서 뒤쪽 강좌가 통째로 잘못된 관에 붙는다.** `course` 필드로 묶어 정렬하고 강좌가 바뀌면 위치를 0으로 되돌린다.

회계는 한 걸음 더 — `COURSE_ROOTS`로 원가회계 강좌는 원가관리회계 35관만, 재무회계 강좌는 나머지 160관만 보게 못박았다. 재고자산처럼 이름이 겹치는 관이 양쪽에 있기 때문이다.

### 5-7 전사 프롬프트가 커리큘럼 전체를 덮어야 한다
`transcribe.py`의 `PROMPT`. 법규에 앞쪽 법률만 적어 두면 지적·등기·국유재산 용어가 통째로 오인식된다. 9개 법률을 다 적어 뒀다.

### 5-8 숫자를 지어낸다
음성 전사는 숫자에 약하다("제99조"가 "제98조"로 들린다). `generate_notes.py`의 `SUBJECT_RULES`에 과목별 금지 규칙을 넣어 뒀다 — **법규·민법은 조문·판례 번호를 교재로 확인되지 않으면 쓰지 말 것.** 틀린 번호는 수험생이 그대로 외우므로 없느니만 못하다.

### 5-9 mlx-whisper는 `.venv`에만 있다
홈브루 파이썬은 외부 관리(PEP 668)라 설치가 막힌다. 전사는 반드시 `.venv/bin/python`으로 돌린다.

## 6. 필기 md 형식

```markdown
<!-- leaf: {leaf_id} -->        ← 관 구분
## 관 제목

<!-- after: 교재소제목 -->      ← 이 소제목 뒤에 삽입
본문…  [12강 23:10]             ← 되짚기용, 화면에는 안 보임

> 🐶 **복습 메이트** — 학습 조언만. 내용 설명 금지.
```

화면에서는 `mergeLectureIntoDoc()`이 앵커를 보고 교재 소제목 사이사이에 끼워 넣는다. 앵커가 `🧠 암기법`처럼 다른 탭 소제목을 가리키면 `splitLectureByTab()`이 그 탭으로 보낸다.

**문체 규칙**: "강사/강의/선생님" 단어 금지. 출처를 밝히지 않고 교재처럼 단정적으로 쓴다. 현재 3과목 전량에서 금지어 **0건**.
