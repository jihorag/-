# 2차 모범답안 = 구조화 학습 콘텐츠 — "풀이=학습" 고도화 계획

> 작성 2026-06-06 · 방향 전환: **문제풀이 스킬 기능(타이머·필터·선구안)은 보류.**
> 앱의 본질 = **"인강·별도 학습 없이, 문제만 풀어도 전 범위 내용이 머릿속에 내재화된다."**
> 따라서 문항은 '채점 대상'이 아니라 **콘텐츠 전달 매체**다. 모범답안/해설은 정답이 아니라 **미니 강의**여야 한다.

---

## 0. 한 줄 정의

> **풀고 나면 그 논점(개념)이 완성된다.** 각 기출 문항에 "정의 → 답안 골격(목차) → 논점별 서술 → 근거(조문·판례·산식) → 암기 키워드 → 출제 포인트"의 **학습 레이어**를 붙여, 회독만으로 전 논점이 인출 가능해지게 한다.

이것이 2차에서 가장 강력한 이유: 2차는 범위가 '논점'으로 떨어지고, 각 논점의 **모범 서술 자체가 곧 학습 콘텐츠**다. 문제 = 그 논점을 꺼내는 트리거.

---

## 1. 핵심 발견 — 소스가 이미 '레이어드'로 가공돼 있다

`Claude KAPA CHATING copy/_최종산출물`에 단원·논점별로 학습 레이어가 분리 정리돼 있음:

| 레이어 | 이론 | 법규 | 용도 |
|---|---|---|---|
| **L1 정의** | 핵심요약서(정의문) | 핵심요약서 | 답안 첫 문장(개념 정의) |
| **L2 답안양식·키워드** ★ | 필기노트(답안양식)·답안양식 모음 61 | 답안양식 | **목차 골격**(Ⅰ.Ⅱ.Ⅲ.) |
| **L3 서술** | 기본서 본문 | 기본서 본문 | 논점별 본격 서술 |
| **근거** | (학설) | **관련 조문(법전 매칭)·판례특강·조문특강** | 조문·판례 인용 |
| **메타** | 논점별 출제빈도·21논점 | 단원별 출제빈도·회차매핑 | 빈출도·출제포인트 |

→ **추출형(예시답안 PDF 긁기)이 아니라 조립형(structured assembly)** 이 가능하고, 학습목표에 더 부합. 레이어가 그대로 학습 단계가 된다.

## 2. 모범답안 스키마 (레이어드)

문항 JSON의 `modelAnswer`(평문) 대신 **구조화 필드 `lesson`** 추가:

```json
"lesson": {
  "logicalPoints": ["사업인정의 의의", "법적 성질", "권리구제"],   // 논점(태그)
  "outline": [                                                  // L2 답안 골격
    { "h": "Ⅰ. 논점의 정리", "kw": ["쟁점", "검토 순서"] },
    { "h": "Ⅱ. 사업인정의 의의·법적 성질",
      "body": "사업인정이란 … (L1 정의 + L3 서술 발췌)",
      "law": ["토지보상법 §20", "§22"], "cases": ["대법 2017두…"],
      "kw": ["설권행위", "처분성", "재량행위"] },
    { "h": "Ⅲ. 권리구제", "body": "…", "law": ["§21"], "kw": ["사전·사후"] },
    { "h": "Ⅳ. 결어", "body": "…" }
  ],
  "mnemonics": "의·성·구 (의의·성질·구제)",                       // 두문자
  "examPoint": "처분성 인정 → 항고소송. 22·30회 변형 출제.",       // 출제포인트
  "sources": ["핵심요약서 p..", "기본서 p..", "법전 §20"]          // 추적성
}
```

UX에서 이 구조를 **단계 공개**(목차→키워드→서술→조문/판례)로 노출 → 인출 훈련과 직결.

## 3. 조립 엔진 (핵심 작업)

`scripts/build_essay_lesson.py` 신설. 문항별로:

```
1) 논점 식별   기출 본문 → 논점 매핑
                · 법규: 회차→4문제→단원 표(이미 보유) + 단원 논점 인덱스
                · 이론: 21논점 키워드 매칭(기존 build_essay_pdf 로직 재사용·고도화)
2) 레이어 수집  해당 논점의 L1정의·L2양식·L3서술·조문·판례·키워드를 단원 md에서 발췌
3) 조립        outline(목차)=L2양식, 각 항목 body=L1+L3 발췌, law/cases=조문·판례,
                kw=필기노트 키워드, examPoint=출제빈도/회차
4) AI 다듬기    조립된 뼈대 + 발췌를 컨텍스트로 LLM이 답안 문장으로 매끄럽게 정리
                (RAG: 발췌만 근거로 → 환각 억제. 새 사실 생성 금지 프롬프트)
5) 검수 플래그  sources 추적 + 길이/조문번호 형식 검증 → 의심 항목 표시
```

**왜 하이브리드(조립+AI)인가**: 순수 추출은 정렬·깨짐, 순수 AI는 환각. **조립으로 사실(조문·판례·정의)을 고정**하고 AI는 연결 문장만 쓰게 하면 정확성과 가독성을 동시에.

---

## 4. 단계적 롤아웃 (빈출 우선 — 풀면서 가장 자주 만나는 것부터)

| 단계 | 범위 | 근거 |
|---|---|---|
| **P1** | 법규 단원 7·8(공용수용·손실보상) + 이론 단원 8·6·3(물건별·수익환원·가격제원칙) | 출제빈도 ★★★(38·24·16·8·8회) — 풀이 빈도 최고 |
| **P2** | 법규 5·9·10, 이론 1·2·4 | ★★ |
| **P3** | 나머지 + 행정법 저빈출 단원 | ★ |
| **P4** | 예시답안 PDF(기출예해집·GS)로 **교차검증·보강** | 정확도 |

각 단계 후 빌드·표본 검수·커밋. P1만으로도 "가장 자주 나오는 논점은 풀이만으로 학습" 달성.

## 5. 학습 UX — "풀이 → 학습" 전환 설계

모범답안이 채워지면 EssayMode를 **인출 학습기**로:

1. **목차 먼저** — 제출 후 모범답안 전문 대신 **목차(outline 헤더)만** 먼저 공개 → "이 골격이 떠올랐나?" 자가체크 → 펼치면 논점별 서술·조문·판례.
2. **레이어 토글** — 정의(L1) / 골격(L2) / 서술(L3) / 근거(조문·판례) 단계별 on-off → 얕게~깊게 반복.
3. **암기 키워드·두문자** 카드화 — 회독 시 키워드만 보고 인출.
4. **회독 내재화** — 같은 문항 N회독 시 노출 레벨 자동 축소(서술→키워드→목차만) = 자연스러운 인출 강화.
5. **출제포인트** 배지 — "이 논점은 22·30회 변형" → 풀이가 곧 기출 분석.

→ 인강의 '설명'을 모범답안 레이어가, 인강의 '반복'을 회독 노출조절이 대체.

---

## 6. 1차도 '내용 학습'으로 (풀이스킬 아님, 해설=강의)

1차 객관식도 같은 철학으로: **해설 = 개념 완성**.
- 각 문항: 정답 근거 + **5지 보기별 정오 이유** + **관련 개념 박스(정의·비교표)** + 함정 포인트.
- 데이터: 기존 해설 + (부족하면) 단원 콘텐츠 기반 조립/AI 보강.
- 효과: 한 문제를 풀면 그 개념의 정·오 경계까지 학습 → 보기 4개가 4개의 미니 개념.
- ※ 타이머·필터·선구안 등 '푸는 기술' 기능은 **이번 방향에서 제외**.

---

## 7. 내재화 측정 — '콘텐츠 커버리지' 진도

정답률·풀이수 대신 **"전 논점 중 학습 완료 비율"** 을 진도로:
- 논점 단위 마스터리: 그 논점 문항을 풀고 모범답안을 본 횟수·인출 성공 → 논점 커버리지.
- 현황에 **"감정평가이론 21논점 중 14 내재화 · 법규 핵심 28논점 중 19"** 식 표시.
- "이 앱만으로 전 범위" 목표를 가시화 → 풀이=학습 루프의 동기.

---

## 8. 제외/보류 (이번 방향과 불일치)

- ❌ 퀴즈 세션 타이머, 목록 필터, 선구안 트레이너, 문항당 시간배분 — '푸는 기술'이라 내용 내재화 목표와 약함.
- △ 2차 타임드 완주 모의 — 콘텐츠 충분히 쌓인 뒤 후순위.

---

## 9. 실행 순서 (제안)

1. **조립 엔진 v1**(`build_essay_lesson.py`) — 논점 매핑 + 레이어 수집 + 조립(AI 다듬기는 후속) → P1 단원.
2. **EssayMode 학습 UX** — `lesson.outline` 단계공개·레이어 토글·키워드 카드.
3. **AI 다듬기 패스** — 조립 뼈대 → 문장화(RAG·환각억제) → 표본 검수.
4. **P2~P4 확장** + 예시답안 교차검증.
5. **콘텐츠 커버리지 진도**(현황).
6. (후속) 1차 해설=개념강의 보강.

> 먼저 **1번(조립 엔진 v1, P1 빈출 단원)** 부터 착수 권장 — 가장 자주 푸는 논점이 즉시 '풀이=학습'이 된다.
