# 출제기록 — 토픽 1-1 화폐의 시간가치(TVM) 6공식 (단원 1 기초)

> 절차 [`_출제방법론.md`](_출제방법론.md) · 난이도 [`_난이도설계.md`](_난이도설계.md). 포맷: L1 단답·5지선다·계산, L2+ 서술.

## 1. 주변 문제 분석
- 기출/GS 전반의 DCF·투자·환원 문제에서 TVM 계수가 상시 사용됨. 실제 쓰인 용어 확인:
  복리현가·복리종가·연금현가·연금종가·감채기금·상환기금·저당상수·연부상환·자본회수·(일시불)현가/내가계수.
- → 6공식은 모든 수익·투자·보상(현가) 계산의 토대. L1 계산 드릴로 무한 변형 가능.

## 2. 개념 카드 — TVM 6공식 (r=이자율, n=기간)
| 계수(별칭) | 산식 | 의미 |
|---|---|---|
| **일시불 내가계수** FVF (복리종가율) | $(1+r)^n$ | 현재 1원의 n년 후 가치 |
| **일시불 현가계수** PVF (복리현가율) | $\dfrac{1}{(1+r)^n}$ | n년 후 1원의 현재가치 |
| **연금 내가계수** FVAF (연금종가율) | $\dfrac{(1+r)^n-1}{r}$ | 매년 말 1원 적립 시 n년 후 합 |
| **감채기금계수** SFF (상환기금율) | $\dfrac{r}{(1+r)^n-1}$ | n년 후 1원 만들 매년 적립액 |
| **연금 현가계수** PVAF (연금현가율) | $\dfrac{1-(1+r)^{-n}}{r}$ | 매년 말 1원 n년 수령의 현재가치 |
| **저당상수** MC (연부상환율) | $\dfrac{r}{1-(1+r)^{-n}}$ | 1원 대출의 매기 원리금 균등상환액 |

- **역수 관계**: PVF·FVF=1, SFF·FVAF=1, MC·PVAF=1
- **핵심 관계**: **MC = SFF + r** (저당상수 = 감채기금 + 이자율)
- 암기: "내가↔현가 역수 / 적립=SFF / 상환=MC / MC=SFF+r"
- r=10%,n=5 기준값: FVF 1.61051 · PVF 0.62092 · FVAF 6.10510 · SFF 0.16380 · PVAF 3.79079 · MC 0.26380

## 3. 시드 (★재보정 — [`_난이도설계.md`](_난이도설계.md) §2.5)
**L1 = 표준 계산 실행** (계수/현금흐름 제시 → 셋업+계산). 6공식 대입·다단 PV·NPV·잔금·거치·월환산·적립/상환. → **34문 완료.**

**L2(서술) — 역산·비표준 구조 (구조를 직접 만들어야)**: 7시드
1 **IRR 보간 역산**: 두 할인율의 NPV 제시 → NPV=0 되는 IRR 선형보간.
2 **등비 증가 현금흐름**: NOI가 매년 g% 성장 → 현가(등비연금·R=r−g 활용).
3 **기초연금(annuity due)**: 기초·기말 차이 + 기초연금 현가/내가 = 기말×(1+r).
4 **미지수 역산**: 월상환액(또는 연상환액)이 주어졌을 때 **대출가능액·만기** 역산.
5 **원리금 분해**: 1회차 상환액을 **원금·이자로 분해** + 차회 잔금 산정.
6 **영구연금/영구성장**: 환원율 R=r(−g) 도출, 영구 현금흐름 현가.
7 **기간별 변동금리**: 연도마다 다른 r로 단계별 현가.

**L3(서술) — 모델 구축 + 판단 (narrative→현금흐름 설계+의사결정)**: 5시드
1 **투자 의사결정**: 임대·매각 시나리오에서 현금흐름 구성 → NPV·IRR 산정 → **타당성 판단**+한계 서술.
2 **두 자금조달 대안 비교**: 저당비율·금리·만기 다른 안 → 매기 부담·총비용 현가 → **선택**.
3 **상환표(amortization) 작성**: 매년 원금/이자/잔금 표 → 특정시점 잔금 + **차환 판단**.
4 **거치+성장 임대료 복합** 현금흐름을 narrative에서 구성 → 현가.
5 **수익환원 DCF 내 TVM**: 복귀가치 내부추계·보유기간 현금흐름 등 TVM이 내장된 종합.
