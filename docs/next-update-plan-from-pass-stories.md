> 작성일 2026-06-06 · 근거: deep-research 하베스트(6각도 병렬 검색 → 22개 출처 fetch → 81개 클레임 → 23개 검증 통과)
> 목적: 합격생들이 **실제로 효과를 본 학습행동**과 **반복되는 미충족 니즈**를 이 앱의 기능으로 전환

## 0. 한눈 요약

- **1차의 정답 행동**: 인강 + 기출 **다회독(7~8회)** + **"틀린 부분만" 재풀이**로 회독 속도를 극단적으로 끌어올림(막판 1시간에 400~500점 분량).
- **2차의 정답 행동**: **직접 만든 서브노트 단권화** → **목차 잡기**(2차 최중요) → **상황=멘트 인출 암기** → **완주(답안 다 채우기)**. "80점 잘 쓰기보다 100점 다 쓰기"가 점수에 결정적.
- **대표 실패**: 2차에서 빈출 낮은 과목(감정평가사법·부동산공시법)을 버리는 **선택적 학습 → 과락**. 그 외 답안 미완주·계산실수·인출 실패.
- **앱 기회**: 이 앱은 1차 기출/AI채팅/2차 답안작성/모의/통계를 이미 갖춤 → 위 정답 행동을 **전용 트레이닝 모드**로 제품화하면 차별화. 특히 **2차(논술) 영역이 가장 큰 미개척 임팩트**.

## 1. 리서치 방법과 한계 (투명성)

- 검증 클레임 23개(3-0 다수), 출처: 박문각/서울법학원 공식 합격수기 게시판(1차 633+·2차 433+건 존재), 하우패스 유튜브 합격 인터뷰, 개인 수기(이승재·조영신 평가사 oopy), eduspa 합격자 PDF(제29기), 법률저널 기사(제30회), 이동현 평가사 총평 PDF, 나무위키(시험구조).
- **한계**: 본문 인용 수준으로 깊이 검증된 개별 수기는 약 6~8개. 나머지는 게시판 목록으로 "존재"만 확인 → **빈도 수치는 정량 카운트가 아니라 "반복 등장" 정성 평가**. 점수·시간 수치는 1인칭 자기보고(객관 채점 데이터 아님). 시간배분 클레임 2건은 본문 불일치로 기각.
- **1차 과목별(민법·경제학·부동산학원론·회계학·관계법규) 세부 회독/시간배분은 이번에 얕게 다뤄짐** → 후속 리서치 권장.

### 2차 (논술)
| 행동 | 근거(검증) |
|---|---|
| **직접 서브노트 단권화**(기본서는 서브 제작용으로만) — 실무54p/이론110p/법규130p+목차서브20p | 3-0 |
| **목차가 최중요** — 매일 이론·법규 각 200점 분량 목차잡기, 평가개요 빠짐없이 기재(없어도 "없다" 목차화) | 3-0 |
| **인출 암기** — "A상황=A멘트" 기계적 매칭, 목차당 키워드 2~3개 압축 | 3-0 |
| **완주 > 잘 풀기** — "100점 다 쓰기", 엉망이어도 푼 문제의 45~50% 득점 | 3-0 |
| 실무 **풀이틀**(기/처/대/자/자/평/평), 아는 방식부터 즉시 작성, 불의타 50:50 배분 | 3-0 |
| **오답노트 매일 점검** + **채점평을 답안지에 옮겨 득점/감점 지점** 반복 → 실무 31→61점 | 3-0 |
| 표준 도구 조합: **인강 + GS 오프라인 모의** → 논점을 답안 분량으로 정리해 단권화 | 3-0 |

### 미충족 니즈 (반복 등장)
1. 서브노트/목차의 **디지털 단권화·재활용**이 번거로움(종이·노션 수작업)
2. **상황→멘트/목차 인출** 훈련 도구 부재(읽기는 많은데 인출 연습이 적음)
3. 내 답안의 **득점/감점 지점**을 객관적으로 짚어주는 피드백 부재
4. **완주 압박** 하의 시간배분·분량 감각을 키울 실전 환경 부족
5. 빈출 낮은 과목을 버려 생기는 **과락 리스크**를 알려주는 커버리지 경고 부재

## 4. 우선순위 기능 백로그 (임팩트 × 난이도)

### Tier 1 — 다음 업데이트 강력 추천 (임팩트 大 · 난이도 小~中 · 근거 强)

**T1-1. 오답 전용 회독 모드 "틀린 문제만 다시"** · 1차 · 난이도 小
- 문제풀이에 "오답만 모아 풀기" + **회독 N회 카운터**. 맞히면 다음 회독에서 제외(체화). `quizStatsByLeaf`·WeaknessPanel 데이터 재사용.
- 근거: 7~8회독+틀린 것만 재풀이(3-0). **가장 빠른 win**.

**T1-2. 2차 목차 트레이너** · 2차 · 난이도 中
- 문제 제시 → 사용자가 **목차만** 빠르게 입력 → AI가 ① 모범 목차 ② **누락 항목**(예: 평가개요/권리금 "없다" 목차) ③ 순서/논리 피드백. EssayMode에 `essay_outline` 모드 추가, 채점 프롬프트 일부 재사용.
- 근거: 목차=2차 최중요, 매일 200점 목차잡기(3-0).

**T1-3. AI 채점 강화 — 득점/감점 지점 + 완주율** · 2차 · 난이도 中
- EssayMode/answer_write 채점 출력에 **득점 포인트·감점 포인트(지점 명시)** + **완주율(요구 분량 대비)** 지표 추가. "채점평을 답안지로 옮기는" 행동을 자동화.
- 근거: 채점평 기반 분석으로 실무 31→61점(3-0), 완주가 결정적(3-0).

**T1-4. 상황→멘트 인출 트레이너** · 2차 · 난이도 中
- "A상황" 카드 제시 → 사용자가 멘트/키워드 **인출 입력** → 정답 멘트와 비교(자기채점 or AI 유사도). 통암기 카드 엔진 변형(T5 카드와 통합).
- 근거: 인출 암기 핵심·기계적 매칭(3-0).

### Tier 2 — 그 다음 (임팩트 大 · 난이도 中~大)

**T2-1. 디지털 단권화/서브노트(AI 보조)**
- 단원 학습 후 AI가 **서브노트 초안**(핵심 압축) 생성 → 사용자 편집·재배열·태그 → 단원/문제와 연결, 검색. NotesPanel 확장.
- 근거: 서브노트 단권화가 2차 중심축(3-0). 임팩트 큼, 구현 비용 큼.

**T2-2. 2차 완주 모의 (시간배분 모드)**
- 과목당 **100분 타이머** + 분량/목차 수 목표 + **완주율 측정** + 끝나면 AI 채점. MockExam의 2차판.
- 근거: 완주·시간배분(3-0), 3교시×100분 구조.

**T2-3. 실무 풀이틀 템플릿 + 부분점수 가이드**
- 실무 답안에 **기/(처)/대/자/자/평/평** 골격 체크리스트, "아는 방식부터 즉시 작성", 불의타 **일반론 50:50** 배분 가이드. AILearning `template` 강화.
- 근거: 정형 풀이틀·부분작성(3-0).

**T2-4. 과락 위험 커버리지 경고**
- 현황 탭에 **과목/단원 커버리지 맵** + "빈출 낮지만 **미학습** → 과락 위험" 경고. WeaknessPanel/leafStats 확장.
- 근거: 선택적 학습→보상법규 과락 낙방(3-0).

### Tier 3 — 보조/장기

- **회독 플래너**(회독 N회 목표·진척 시각화) — DDayPlanner 확장 (근거: 회독 가속).
- **출퇴근 5분 모드**(짧은 세션·오프라인 강화) — 직장병행 다수.
- **백지 인출/두문자 카드**(60개 쟁점 백지 인출형) — 통암기 확장 (근거: 두문자 백지인출 3-0).
- **GS 논점→단권화 파이프라인**(스터디 논점을 답안 분량으로 정리) — 장기.

## 5. 다음 업데이트 추천 패키지 (Top 5)

> "1차 회독 효율 1개 + 2차 논술 3개 + 안전망 1개"로 구성 — 임팩트 대비 빠른 출시 가능.

1. **T1-1 오답 전용 회독 모드** (1차, 즉효)
2. **T1-2 2차 목차 트레이너** (2차 최중요 행동)
3. **T1-3 AI 채점: 득점/감점 지점 + 완주율** (기존 채점 강화)
4. **T1-4 상황→멘트 인출 트레이너** (인출 훈련)
5. **T2-4 과락 위험 커버리지 경고** (실패 예방, 통계 확장)

→ 1·3·5는 **기존 데이터/모듈 재사용**으로 비용이 낮고, 2·4가 신규 트레이닝 모드. 한 사이클에 1·3·5 먼저, 다음에 2·4 권장.

# 부록 A — Round 2 추가 리서치 (2026-06-06, 새 기능 후보)

> 2차 리서치(1차 과목별·장수생·디지털 도구·계산실수·메타인지 집중, 102 에이전트). **이미 발굴/구현한 것 제외**한 새 후보.
> ⚠️ 한계: 근거 대부분 1인칭 합격수기(landit·DCInside) 표본 1 주관 진술. **최신 디지털 도구(노션·ChatGPT·Anki) 실사용 데이터는 미확보**(refute됨). '버리기' 단원·회독수는 **연도 의존**(2026 회계 과락 57%대 등).

## A-1. 구현 완료 (이번 턴)
- ✅ **오답 회독 모드** (복습 홈) — 다회독 루프 + 회독 카운터
- ✅ **AI 채점 강화** — 완주율 + 득점/감점 지점(목차·논점 위치). → 아래 (b)의 1단계에 해당

## A-2. 새 기능 후보 (우선순위)

### ★ 1순위 — 과목별 목표점수·'버리기' 보드 (신규·강근거·고유용)
- 과목별 **목표점수** 등록(예: 민법60·경제50·회계50·법규70) + **전략적 포기 단원** 지정 → 모의·기출 점수를 목표 대비 추적, **버린 단원은 풀이/통계에서 자동 스킵**.
- 근거: 다수 수기의 '버리기+과목별 목표점수'(경제 현시선호·솔로우 버림, 회계 법인세·리스 버림, 원가회계는 유지)(3-0). 현재 앱 현황 통계엔 목표·버리기 관리 없음.
- 확장: 현황/WeaknessPanel + 문제풀이 필터.

### ★ 2순위 — '다른 방식 검산' 트레이너 (신규·강근거·계산과목)
- 계산 문제(경제·회계·2차 실무)에서 정답 공개 전 **역연산/괄호계산 등 2차 검증을 유도**하고, 검산으로 잡은 실수를 **실수 유형별로 통계화**.
- 근거: '동일 방식 재계산은 뇌가 정답으로 인식→실수 못 잡음, 다른 방식 검산 필수'(3-0), '복잡 사칙연산은 즉시 계산기·공학용 괄호로 입력오류 추적'(3-0).

### ★ 3순위 — 메타인지 타이머 / 숙달 추세 (신규·강근거)
- 회독·암기 **단위별 소요시간 측정** + 추세 그래프(**시간 단축 = 숙달 지표**). "1시간에 N점 분량" 같은 회독 속도 표시.
- 근거: '스톱워치로 암기·회독 시간 측정→메타인지↑, 시간 줄어드는 것으로 진척 확인'(3-0), 1차 막판 '1시간 400~500점'(3-0).

### 4순위 — 셀프진단 '안다/모른다' 신뢰도 라벨 (신규·강근거)
- 항목별 **자기확신도(안다/애매/모른다)** 라벨 → '모른다/애매'만 보충 회독. 강사 이해≠내 이해의 **'이해 착시'를 셀프테스트로 깨기**.
- 근거: '무엇을 알고 모르는지 객관 파악이 효율 핵심'(3-0), 불합격 원인 '강사 말 이해≠내 이해·과도한 단권화'(3-0). 현재 북마크 사유(중요/헷갈림/실수)를 확신도로 확장 가능.

### 5순위 — 채점평 카드화 반복 인출 ((b) 2단계, AI 채점 후속)
- 방금 만든 AI 채점의 **감점/득점 지점을 인출 카드로 전환** → 주 2~3회 반복 인출(채점평 내재화).
- 근거: '채점평을 답안지로 옮겨 득점/감점 암기·주2~3회 반복→실무 31→61점'(3-0). AI 채점 강화의 자연스러운 다음 단계.

### 보조 (낮음)
- **청각 두문자·노래 암기 모드**(이동 중 TTS 복습) — 기존 Speech.jsx 확장. 근거: 감관법 노래·두문자(3-0). 단 니치.
- **키워드→목차 역인출 카드** — 이미 계획된 목차 트레이너·상황-멘트 인출과 중첩 → 변형으로 흡수 권장.

## A-3. 후속 타겟 리서치 (이번에도 약했던 것)
- 2023~2026 합격생의 **실제 디지털 도구(노션/ChatGPT/Anki)** 사용·니즈 — 별도 리서치 필요.

# 부록 B — Round 3 리서치 (2026-06-06, 50개+ 타겟: 디지털도구·실수·스터디·멘탈·트렌드)

> 검증 클레임 21개. **신뢰도 분리**: 출제 트렌드(경제 미시편중·회계 과락 최고)는 **primary 강사 총평+공단 데이터 → high**. 개인 학습법(디지털 도구·목차 스터디·백지 인출)은 **단일 블로그/포럼 일화 → medium/low**. 한 블로그의 합격률(28%/15%) 수치는 **refute됨(신뢰 불가)**.

## B-1. 구현 완료 (직전 턴)
- ✅ ★1 목표·버리기 보드 · ★2 검산 트레이너 · ★3 회독 타이머 · ★4 셀프진단 라벨 · 보조 해설 청각복습

## B-2. 새로 검증된 인사이트
- **출제 트렌드(high)**: 경제학은 구조적으로 **미시 편중**(8년 미시 51.6%/거시 42.8%/국제 5.6%), 2025(36회) 난도 다소 완화·경제 과락률 40.92%→27.39%↓. **회계학이 과락 최고(~46.76%)**로 최대 병목. → 과락 모델링은 **회계 가중**, 경제는 '계산속도=체감난도' 변수.
- **경제 '버릴 문제 vs 챙길 문제'가 명확(high)**: 강사 총평이 **버릴 함정**(카르텔 붕괴 수리모형·비대칭비용 스택켈버그·시점간 모형 "매우 지엽적")과 **반드시 챙길 것**(솔로우 계산문제—흔히 버리는데 챙겨야, IS-LM 역산형)을 구체 지목. "문제 선별만 잘하면 난도 급락, 잘못하면 급등."
- **합격생 암기 도구는 의외로 아날로그(medium)**: 수첩 두문자·물리 스톱워치·인강/유튜브. 노션/Anki/ChatGPT/녹음 = 미발견(1인·argument-from-silence). → **자투리 두문자/cloze 모바일 모드** 미충족.
- **2차 핵심은 범용 도구로 운용(medium)**: 구글닥스+20분 타이머로 **각자 목차 작성→모범답안·서로 목차 비교**, **백지 인출**(안 보고 목차·조문·논점 전부 쓰기). 전용 도구 없음.
- **GS 첨삭이 약하다 → AI 첨삭이 최대 기회(medium, 핵심)**: GS의 석차·부분점수는 가치 있으나 **첨삭(피드백)은 부실**하다는 평이 많고, 일부는 GS를 건너뛰고 **기출 1~34회 해부**를 택함. → 방금 만든 AI 채점 강화가 **핵심 가치**임을 검증.

## B-3. 새 기능 후보 (이미 한 것 제외)

### ★★ 최우선 — 선구안(選球眼) 트레이너 (신규·high 근거·차별적)
- 기출 문항에 **'버릴 함정 / 챙길 득점'** 태그 → 시간 압박 하에 **버릴지/풀지 분류**를 맞히는 훈련. 경제 카르텔붕괴=버려, 솔로우=챙겨 등.
- 근거: 강사 총평 "선별이 난도를 좌우"(high). **현존 앱에 없는 새 학습축**(실력 아닌 '전략' 훈련). → 모의시험·문제풀이와 결합.

### ★ AI 첨삭 = 핵심 가치로 격상 (검증·확장)
- GS 첨삭 약점을 AI가 대체. 방금 만든 완주율·득점/감점에 더해 **'출제자 의도' 레이어**(왜 이게 정답/함정인지)와 **재작성 루프**를 강화. 근거: GS 첨삭 부실·기출 출제의도 학습이 결정적(medium).

### ★ 타임드 목차 캔버스 + 백지 인출 + 모범답안 비교 (목차 트레이너 확장)
- 20분 타이머로 목차 작성 → **모범답안 자동 대조(diff)**. **백지 인출 모드**: 키워드만 입력→앱이 전체 목차·조문·논점 공개해 자가채점. 근거: 구글닥스 목차 스터디·백지 인출(medium).

### 기출 해부 모드 (신규)
- 문항별 **출제의도·빈출 연계·변형 가능성**을 붙인 1~34회 심층 분석. 근거: GS 대신 기출 해부로 합격(medium).

### 과목별 실수노트(실수 유형 태깅) (오답노트 확장)
- 오답을 **회계 분개/세무·경제 계산·실무 산식** 등 실수 유형으로 태깅→유형별 집계·시험모드 휴대. 근거: 합격생 시험 허용 실수노트 유지(low).

### 보조 — 자투리 두문자 카드 모바일 모드
- 수첩 두문자 워크플로의 모바일판(이동·식사 자투리). 근거: 부산 합격생 수첩 두문자(medium). 청각복습과 결합.

## B-4. 한계·후속
- 개인 학습법은 **표본 1 일화** 다수 → 일반화 금지. **2024~2026 최신 디지털 도구 실사용**은 여전히 미확보(별도 타겟 필요).
