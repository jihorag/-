10 · 리디자인할 때 알아야 할 제약

1. 팔레트가 두 갈래다. tokens.css 는 무채색 단일 액센트로 잘 정돈돼 있지만, 화면 16곳이 인라인 hex 약 1,800개를 들고 있어 매핑을 타지 않습니다. 리디자인의 본체는 이 hex 제거입니다.
2. 라운드·그림자가 제각각. 8/12/14/16/18/20px 라운드가 공존하고, 그림자도 토큰 2단계 외에 0 2px 8px rgba(0,23,51,.06), 0 6px 16px rgba(49,130,246,.28) 등이 따로 삽니다.
3. 이모지가 UI 아이콘 역할을 한다. 홈·레일만 lucide 라인 아이콘이고 나머지는 📅🎯🔀⭐ 이모지입니다. 플랫폼마다 다르게 렌더되고 톤도 안 맞습니다.
4. 콘텐츠 밀도가 진짜 요구사항이다. 교재 패널에 표·수식(KaTeX)·SVG 그래프·판례 인용·형광펜이 한 문서에 다 들어옵니다. 여백을 늘리는 방향의 리디자인은 실사용에서 스크롤 지옥이 됩니다.
5. 접근성은 이미 지키고 있다. 44px 터치 타깃, role="progressbar" + aria-valuetext, prefers-reduced-motion, 색만으로 상태를 전하지 않기(마커에 ✓/도형 병기), --ink-3 를 흰 배경 AA 통과선까지 낮춤 — 되돌리지 마세요.
6. 사용자 선호는 무채색. 컬러는 자제, 아이콘은 단색. 반복적으로 요구된 사항입니다.
