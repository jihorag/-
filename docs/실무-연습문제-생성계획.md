# 실무 연습문제 생성 계획 (5단계 사다리) — 실행 로드맵

> 작성 2026-06-07 · 전제: 실무 기출 1~36회(163문) + GS 0·1·2·3기(233문) = **396문 전사·단원분류·예시답안 완비**.
> 설계 표준은 [`2차-5단계-문제설계-plan.md`](2차-5단계-문제설계-plan.md) 참조. **이 문서는 "무엇을·몇 개·어떤 순서로 만들지"의 생산 계획.**
> 목표: 인강 없이 **문제 풀이 + 해설만으로 개념 체화 + 서술형 근육** → 2차 합격.

## 1. 진단 — 데이터가 말하는 공백 (실측)

### 1.1 보유 396문 난이도 분포
| L1 | L2 | L3 | L4 | L5 |
|---|---|---|---|---|
| 18 | 67 | 98 | 118 | 95 |

→ 기출·GS는 본질적으로 **L3~L5 주관식**. **개념 체화의 입구인 L1·L2가 거의 없다**(특히 L1).
**"문제만 풀어 개념 학습"의 출발선(암기·이해 단계)이 비어 있는 것이 최대 공백.**

### 1.2 110 LOGUMS 논점 × 단계 커버리지 (실측)
| 구분 | 논점 수 | 의미 | 처방 |
|---|---|---|---|
| **L3+ 앵커 보유, L1·L2 공백** | **44** | 기출은 있는데 입문 사다리가 없음 | **★최우선 스캐폴딩(L1·L2)** |
| L1·L2 일부 보유 | 49 | 입구는 있음, 보강·균질화 | 채움·표준화 |
| 무앵커(기출/GS 0) | 17 (실질 ~11)* | 출제 이력 없음 | L3~L5 신규 정성제작 |

*무앵커 17 중 6개(106~111 "N순환/N기 스터디 논점")는 분류용 placeholder → 실질 무앵커는 ~11개(수익분석법·광천지·맹지·공동주택·묘목·농작물·분묘·일시영업보상·매후환대차·부가세절세·기타토지).

### 1.3 결론
- **개념 백본은 이미 있다**: 110 논점 + 근거조문(`silmu_logum_map.json`) + 396 L5 앵커 + 예시답안.
- 할 일은 **"앵커(L5)에서 거꾸로 내려오는 L1~L4 사다리"를 논점마다 채우는 것.** 무에서 창작이 아니라 **기출 역설계(reverse-engineering)**.

## 2. 핵심 전략 — "L5 앵커 역설계로 사다리 채우기"

각 논점은 이미 L5 기출/GS를 갖고 있다(대부분). 그 앵커의 **계산을 쪼개고 개념을 추출**해 아래 단계를 만든다:

```
[기존 L5 기출/GS 40점]  ← 이미 보유 (예시답안 포함)
   ↑ 역설계
[L4] 그 기출에서 논점 2~3개만 떼어 20~30점 중형      ← 자료 일부 재사용
[L3] 단일 방식만 10~20점 (예: 원가법 적산가액만)      ← 자료 1블록 + 기초계산
[L2] 그 방식의 핵심 구분 박스형 + 한 줄 산식적용        ← 개념카드에서 조립
[L1] 그 방식의 정의·산식·근거조문 OX/빈칸/단답          ← 개념카드에서 조립
```

→ 사다리를 1단계부터 풀면 **그 기출을 풀 수 있는 개념·계산이 누적 완성**. 풀이 동선 = 학습 커리큘럼.

## 3. 개념 카드 (Concept Dossier) — 모든 문제의 single source of truth

L1~L4를 조립하려면 논점마다 **개념 카드**를 먼저 만든다(104개 = 110 − placeholder 6):

```json
{
 "no":"001","name":"공시지가기준법","chapter":"2a","law":"감칙 14조",
 "definition":"비교표준지 공시지가에 시점·지역·개별·그밖요인을 곱해 토지가액 산정",
 "formula":"토지가액 = 표준지공시지가 × 시점수정 × 지역요인 × 개별요인 × 그밖의요인",
 "keywords":["비교표준지 선정","시점수정(지가변동률)","그 밖의 요인 보정"],
 "mnemonic":"표·시·지·개·그",
 "compareWith":[{"vs":"거래사례비교법","point":"기준=공시지가 vs 실거래"}],
 "pitfalls":["그밖요인 산정근거 누락","비교표준지 선정사유 미기재"],
 "relatedNo":["002","075","078"],
 "anchors":["ki-r1-q1","gs0-1-1-q1"]   // 보유 L5 앵커 id
}
```
- 카드는 **예시답안·근거조문에서 발췌 조립**(창작 최소화) → 사실 정확성 확보.
- 카드 1장 = L1·L2 문항 + L3 채점키워드 + 해설의 원천.

## 4. 단계별 산출 규격 & 수량 목표

| 단계 | 포맷 | 논점당 | 생성법 | 채점 | 해설(lesson) |
|---|---|---|---|---|---|
| **L1** | OX·빈칸·단답 | 8문 | 개념카드 결정적 조립(API 0) | 자동 | 정의+산식+두문자 |
| **L2** | 박스형 MCQ·한줄서술 | 5문 | 카드 조립 + 비교표 | 자동/키워드 | 유사개념 비교대조표 |
| **L3** | 10~20점 소물음(기초계산) | 2문 | 기출 역설계(단일방식) | 키워드+AI | 목차 가이드 + 키워드 채점표 |
| **L4** | 20~30점 중형(복합) | 1~2문 | 기출 역설계(논점결합) | AI | 논리전개 + 응용 시나리오 |
| **L5** | 40점 기출/GS | 보유 | **기존 396 활용** | AI | 모범답안+시간배분+채점위원 |

**총량 추정(신규 L1~L4)**: 104논점 기준 L1 ≈830 · L2 ≈520 · L3 ≈210 · L4 ≈90 → **약 1,650문 신규**. L5는 396 보유분 해설 보강.

> 측정지표 = **"논점 104 × 5단계 = 520칸 채움률"** (정답률 아님). "이 앱만으로 전 범위" 가시화.

## 5. 우선순위 티어 (출제빈도 × 공백 기준)

### Tier A — 빈출 핵심 25논점 (먼저 L1~L5 완성)
3방식 기초(001 공시지가·002 거래사례·003 원가·004 분해법·014 직접환원·015 DCF) · 집합/복합(010·020·021·022 임대사례·023 적산법) · 유형(044 기계기구·047 광업권) · 투자(049 기업가치·061 최유효) · 담보경매(068·069) · 보상(077 손실보상원칙·078 토지보상·080 특수토지·083 잔여지·094 휴업보상) · 정비표준지(072·075).
→ 풀이 빈도 대비 학습 효율 최대. **MVP는 이 중 5개.**

### Tier B — 나머지 앵커 논점 (★44 L1·2공백 우선)
L3+ 기출 있으나 L1·L2 없는 44논점에 **L1·L2 스캐폴딩 집중**(입구 뚫기).

### Tier C — 무앵커 ~11논점
L3~L5를 **기출 구조 본떠 신규 정성제작**(자료블록 ≥3 + 실수치). placeholder 6개(106~111)는 분류축에서 정리.

## 6. 데이터 스키마 (기존 essay 확장)

설계표준 §3 스키마 채택. 핵심 추가 필드:
```json
{ "source":"practice-set", "level":1, "format":"ox|cloze|mcq|short|essay",
  "conceptNo":"001", "conceptName":"공시지가기준법", "unit":"2a",
  "options":[...], "answer":2,           // 객관식/OX/단답
  "modelAnswer":"...",                     // L3+ 주관식
  "lesson":{ "definition":"","mnemonic":"","compareTable":[],
             "outline":[{"h":"","kw":[],"law":[]}], "scoringKeys":[],
             "examiner":"" } }
```
- `conceptNo` = LOGUMS no → **논점별 사다리 그룹핑**의 키.
- EssayMode: `format`별 채점 UI 분기(OX/빈칸/MCQ는 즉시채점, essay는 키워드+AI). 기존 `source='practice-set'` 필터·`subchapter` 재사용.

## 7. 파이프라인 & 품질 게이트

```
0) 개념카드 104장 조립(예시답안·조문 발췌)
1) Tier A 5논점 파일럿: 카드→L1·L2 결정조립 / L3·L4 기출역설계 → 사다리 1세트
2) 품질 게이트 통과분만 route → build → commit (기출과 동일 워크플로)
3) 검수 OK → Tier A 확장 → Tier B(L1·2) → Tier C(신규)
```

**품질 게이트(미달 폐기)** — 설계표준 §5 + 실무 특화:
- L1·L2: 정답 유일·명확, 해설에 정의+근거조문, 오답 보기 그럴듯(매력적 오답).
- L3+: **자료블록·실수치 필수**(메타 서술 금지), 계산은 **파이썬으로 재현 검증**(예시답안 수치와 일치), 채점키워드 ≥3, 본문 길이 하한(L3≥150·L4≥400자).
- 모든 단계: 근거조문 정확(`silmu_logum_map` 대조), 중복 방지(conceptNo+level+해시).

## 8. 앱 학습 동선 (이미 있는 인프라 활용)

- 단원 탭 소스 필터에 **`📝 연습문제`** 이미 존재 → level 필터(L1~L5)와 결합.
- **논점 모드 신설(권장)**: 단원 → 논점 선택 → **L1부터 순차 풀이**(잠금 해제식). 해설이 곧 강의.
- 진도: conceptNo×level 매트릭스 채움률 + 사용자 풀이율 시각화("이 논점 개념 완성").

## 10. MVP 파일럿 정의 (다음 액션)

**논점 001 공시지가기준법** 1개로 전체 사다리 1세트를 만들어 표준을 확정:
- L1 ×8 (정의·산식·근거조문 OX/빈칸/단답) · L2 ×5 (vs 거래사례비교 박스형+비교표) ·
  L3 ×2 (비교표준지 선정 + 그밖요인 보정 10~20점, 자료 1블록 계산) ·
  L4 ×1 (공시지가+그밖요인+개별요인 결합 25점) · L5 = 기출 `ki-r1-q1` 등 매핑·해설보강.
- → 품질·스키마·채점 UI·학습동선을 이 1세트로 검증한 뒤 P2 확장.

> 핵심 전환: **"많이"가 아니라 "L5 앵커에서 역설계한 정성 사다리 + 계산 재현 검증".**
> 무에서 창작하지 않는다 — 396 기출·예시답안·110 논점·조문이 이미 원천.
