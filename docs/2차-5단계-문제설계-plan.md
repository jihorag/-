# 2차 5단계 문제설계 계획 — "인강 없이 문제풀이만으로 합격"

> 작성 2026-06-06 · 기존 기출 심층분석 기반. 자체제작 문제의 '대충 출제' 실패를 진단하고,
> 5단계 난이도(L1 객관식 암기 → L5 실전 기출)로 **문제만 풀어도 개념이 완성되는** 출제 표준을 정의.

---

## 0. 목표·제약
- **목표**: 개념 인강 없이, 문제 풀이 + 해설만으로 감정평가사 2차 합격 가능한 문제풀이 앱.
- **제약**: 2차는 주관식이지만, **개념 학습을 위해 하위 단계는 객관식/단답**으로 스캐폴딩. 한 논점을 L1→L5로 풀면 개념이 누적 완성.
- **품질 제1원칙**: 문제는 **실제 자료·수치·풀 수 있는 물음**을 가져야 한다. "복잡한 사안이다" 같은 메타 서술은 문제가 아니다.

## 1. 기존 기출 심층분석 (증거)

### 1.1 자체제작 문제 실패 진단 (왜 못 쓰나)
| | 실무 기출(official, 157문) | 자체제작(practice-set, 3,754문) |
|---|---|---|
| 본문 median | **1,827자** | **150자** |
| 배점 median | 20점 | 10점 |
| 자료블록 | 104/157 보유(평균 4.7개) | 거의 없음 |

- **가짜 난이도5**: 자체제작 40점 문제가 *"다중 평가 방식의 종합 적용과 복잡한 시나리오… 다층 분쟁 가능성… 적용 필수"* 식 **메타 서술뿐, 실제 자료·수치·물음 없음 → 풀 수 없음.** 진짜 기출은 `y=0.06(1-x/240)` 일조 산식·가격시점·세대 데이터가 구체적.
- **깨진 모범답안**: `① 자가는 ② 토지·건축물 가치도 ① 보상받으므로 ② 추가 이전비` — 번호 토큰이 깨져 의미 불명.
- **결론**: 양(3,754)만 많고 **기출과 구조·난이도 괴리**. 폐기/재제작 대상. → **소수라도 기출 구조를 그대로 따른 정성 출제**로 전환.

### 1.2 기출 해부 — 과목별 구조 (출제 설계도)
| 과목 | 묻는 유형(빈도순) | 소물음 | 자료 | 성격 |
|---|---|---|---|---|
| **실무** | 계산·산정 87 · 비교 80 · 타당성 55 · 설명 41 | 0~11개 혼재 | **자료블록 평균 4.7** | 사례+자료표+**계산** |
| **이론** | 설명 111 · 논술 33 · 의의 31 · 비교 27 | 0~4개 | 거의 없음 | **개념 설명·논술**(계산 0) |
| **법규** | 설명 63 · **타당성검토 36** · 논술 23 · 보상액계산 9 | 0~3개 | 사례 지문 | **사례 적용·행정쟁송 검토** |

→ **과목마다 좋은 문제의 형태가 다르다.** 실무=자료 있는 계산 사례, 이론=개념 설명/논술, 법규=사례형 법적 타당성 검토. 자체제작도 이 형태를 따라야 한다.

### 1.3 빈출 논점 (이미 보유한 출제빈도 데이터)
- 이론 21논점 ★★★: 물건별평가(16회)·가격형성(8)·수익환원(8)·가격제원칙(8)·3방식(7)·기초(6)
- 법규 단원 ★★★: 손실보상(38)·공용수용(24)·행정쟁송(23)·감평법(15)
- → **빈출 논점부터 5단계 세트**를 채우면 풀이 빈도 대비 학습 효율 최대.

## 2. 5단계 난이도 설계 (과목 공통 + 과목별 구체화)

| 단계 | 학습목표 | 문제유형(포맷) | 배점 | 해설·피드백 | 채점 | 생성 |
|---|---|---|---|---|---|---|
| **L1** | 핵심 개념·용어 암기 | **O/X · 빈칸 · 단답 객관식** | — | 기본 정의 + 암기법(두문자) | 자동 | 조립(L1 정의) |
| **L2** | 개념의 정확한 이해·구분 | **박스형 객관식 · 한 줄 서술** | — | 오답노트 + **유사개념 비교대조표** | 자동/키워드 | 조립(L1+비교) |
| **L3** | 단일 논점 주관식 서술 | **10~20점 소물음 주관식**, 기초계산 | 10~20 | **목차 잡기 가이드 + 필수 키워드 채점기준표** | 키워드+AI | 조립(L2양식+L3) |
| **L4** | 복합 논점 분석·적용 | **20~30점 중형 주관식**, 복합계산 | 20~30 | **판례·법령 논리전개 + 응용 시나리오** | AI 채점 | AI 출제(RAG) |
| **L5** | 실전 기출 완벽대비 | **40점 종합 + 실제 기출** | 40~50 | **모범답안 + 시간배분 + 채점위원 시각** | AI 채점 | 기출 보유 |

### 2.1 과목별 L1~L2(객관식) 예시
- 이론 L1(O/X): "최유효이용은 물리적 채택가능성만으로 판단한다. (O/X)" → 해설: 4요건(물리·합법·합리·최고수익) 두문자 '물합합최'.
- 법규 L1(빈칸): "사업인정은 토지보상법 제__조의 처분으로 수용권을 설정하는 ___행위이다." (20 / 설권)
- 실무 L1(단답): "감가수정 3유형을 쓰시오." → 물리·기능·경제.
- L2(박스형): "다음 중 형성권에 해당하는 것은?" + 보기 → 해설에 **형성권 vs 청구권 비교표**.

### 2.2 과목별 L3~L5(주관식) 형태
- 실무: L3=단일 방식 계산(원가법 적산가액), L4=2~3방식 비교+시산조정, L5=자료 4~5블록 종합 기출.
- 이론: L3=단일 논점 설명(수익환원법 의의·산식), L4=논점 결합 논술(가격제원칙↔최유효이용), L5=기출 논술.
- 법규: L3=단일 쟁점(사업인정 법적성질), L4=사례 적용(취소소송 인용가능성), L5=기출 사례.

## 3. 데이터 스키마 확장
현재 essay 문항은 전부 주관식(body+modelAnswer). L1~L2 객관식을 담으려면:
```json
{
  "id": "...", "subject": "...", "logicalPoints": ["수익환원법"],   // 논점 태그(다중)
  "level": 1, "format": "ox|cloze|mcq|short|essay",
  "body": "...",
  "options": ["①…","②…"], "answer": 2,            // 객관식/OX/단답 정답
  "modelAnswer": "...",                            // 주관식
  "lesson": {                                      // 해설=학습 콘텐츠(레이어드)
    "definition": "...", "mnemonic": "물합합최",
    "compareTable": [["구분","A","B"], …],           // L2 비교대조표
    "outline": [{ "h":"Ⅰ.…","kw":[…],"law":[…],"cases":[…] }],  // L3+ 목차
    "scoringKeys": ["키워드1","키워드2"],            // 채점기준표
    "examiner": "채점위원 시각/시간배분",            // L5
    "sources": ["핵심요약서 p..","법전 §20"]
  }
}
```
- `level`(1~5) = 새 정렬·필터 축. 기존 `difficulty`는 호환 유지.
- `format`별 채점 UI 분기(EssayMode/QuestionItem 확장).

## 4. 논점 단위 출제 — "논점 도시에(dossier) → 5단계 세트"
각 논점마다 **출제 도시에**를 먼저 만들고, 거기서 5단계를 파생:
```
[논점 도시에]  예: 법규 '사업인정'
 · 정의(L1) · 핵심키워드/두문자 · 유사개념 비교(사업인정 vs 사전결정)
 · 법적 성질·요건·효과(L3 목차) · 관련 조문(§20~22)·판례 · 출제이력(8·15·22회)
 · 채점 키워드 · 흔한 함정
   ↓ 파생
 L1 OX/빈칸 2~3, L2 박스형 2, L3 소물음 1~2, L4 사례 1, L5 기출 매핑
```
→ 논점당 ~8문 사다리. 도시에는 §1의 레이어드 소스(L1정의/L2양식/L3서술/조문/판례)에서 조립.

## 5. 출제 파이프라인 + 품질 게이트
```
1) 논점 인벤토리(출제빈도순)  →  2) 논점 도시에 조립(레이어 발췌)
3) L1~L2 객관식 = 결정적 조립(API 0)   4) L3 = 조립+AI 다듬   5) L4 = AI 출제(RAG)
6) 품질 게이트(아래)  →  7) practice_to_app 동기화
```
**품질 게이트(자체제작 실패 재발 방지) — 통과 못하면 폐기**
- ❌ 메타 서술만("복잡한 사안") · 자료 없는데 계산 요구 · 풀 수 없는 물음
- ❌ 모범답안 토큰 깨짐(①② 오용)·키워드 나열만·길이 미달
- ✅ 실무 L4~5는 **자료블록 ≥3 + 실제 수치/산식** 필수
- ✅ 모범답안에 **조문·판례·산식 근거**(sources 추적) · 채점 키워드 ≥3
- ✅ 본문 길이 하한(L3 ≥150자, L4 ≥400자, L5 ≥800자)

## 6. 롤아웃
- **P0(앵커 정비)**: 기출 난이도 배점기반 재산정(50→5…), 이론 단원 오분류 교정, 본문 노이즈 정리. *(스캐폴딩 토대)*
- **P1**: 빈출 논점(법규 사업인정·손실보상 / 이론 물건별·수익환원·가격제원칙)에 **L1~L3 조립**.
- **P2**: 위 논점 **L4 AI 출제** + 품질검수.
- **P3**: 전 논점 확장 + 실무(자료블록 계산 사례 L3~L5 정성 제작).
- **P4**: 모범답안 `lesson` 전 레이어 + 채점위원 시각.

> 실무 자체제작 3,754문은 **품질 게이트로 재심사 → 미달분 폐기/재생성**.

## 7. 측정 — 콘텐츠 커버리지
정답률이 아니라 **"논점 × 단계 매트릭스 채움률"**: 예) 법규 핵심 28논점 × 5단계 = 140칸 중 채워지고 학습된 비율. "이 앱만으로 전 범위" 가시화.

## 9. 과목별 5단계 적용 방안 (과목 성격 = §1.2 해부 결과와 일치)

각 과목의 기출 성격(실무=계산·자료, 이론=설명·논술, 법규=사례 검토)에 맞춰 단계별 훈련 초점을 다르게.

### 9.1 감정평가실무 — "공식 암기 → 3방식 논점 → 종합 자료해석"
| 단계 | 초점 | 문제 형태 |
|---|---|---|
| L1 | **공식 암기·숫자 대입** | 산식 빈칸/단답(적산가액=재조달원가×(1-감가율)), 단위·계수 |
| L2 | 방식별 핵심 구분 | 박스형(시점수정 vs 사정보정), 한 줄 산식 적용 |
| L3 | **3방식 개별 논점** | 원가/비교/수익 단일방식 계산(소물음 10~20점) |
| L4 | 방식 결합·시산조정 | 2~3방식 비교 + 시산조정 + 타당성(20~30점, 자료 2~3블록) |
| L5 | **종합 자료해석·타당성 검토** | 자료 4~5블록 사례, 다물음, 보상/정비 종합(40점 기출) |

### 9.2 감정평가이론 — "의의·요건 암기 → 시장현상+이론 접목 → 시사 결합 논술"
| 단계 | 초점 | 문제 형태 |
|---|---|---|
| L1~L2 | **의의·성립요건 확실 암기** | O/X·빈칸·박스형(가격제원칙 4요건, 최유효이용 판단요건), 한 줄 서술 |
| L3 | 단일 논점 설명 | 수익환원법 의의·환원이율 산정 등(10~20점) |
| L4 | **시장 현상 ↔ 평가이론 논리전개** | 부동산경기변동↔가격제원칙, 시장분석↔3방식 접목 논술(20~30점) |
| L5 | **시사 결합 종합 논술** | ESG·빅데이터·정책 등 시사 + 이론 결합(40점 기출) |

### 9.3 감정평가 및 보상법규 — "조문 암기 → 판례 요지 서술 → 사실관계 쟁점도출·법적판단"
| 단계 | 초점 | 문제 형태 |
|---|---|---|
| L1~L2 | **행정법 기본개념 + 개별법 조문 암기** | 빈칸(토지보상법 §20 사업인정), O/X(처분성), 박스형(행정행위 분류) |
| L3 | **주요 판례 요지 서술** | 단일 쟁점 + 판례 요지(사업인정 법적성질, 10~20점) |
| L4~L5 | **사실관계 속 쟁점 도출·법적 판단** | 사례형(취소소송 인용가능성·보상금증감소송) 검토(20~40점 기출) |

> 출제 시 §1.2 묻는유형 분포를 준수: 실무는 계산·비교·타당성, 이론은 설명·논술, 법규는 설명·타당성검토 중심.

## 10. 앱 성공 3대 핵심 시스템 (인강 대체 = 취약점 완전 보완)

### 10.1 동적 해설 시스템 (대부분 신규)
사용자의 **틀린 선지·놓친 키워드에 맞춰 해설 깊이를 가변**.
- **L1~L2(객관식)**: 고른 오답 선지별 **맞춤 오답 해설**("②를 골랐다면: ②는 ~와 혼동. 차이는 비교표 →"). `lesson.distractorWhy[선지]` 필드.
- **L3+(주관식)**: 모범답안을 바로 보여주지 않고 **① 목차(뼈대)만 먼저 → ② 스스로 채움 → ③ 채점 후 놓친 논점만 펼침**. = §5 '목차 단계공개'와 통합. 힌트 단계: 목차 헤더 → 키워드 → 서술.
- **깊이 가변 로직**: 정답·완주 시 짧게(핵심만), 오답·키워드 누락 多 시 깊게(정의→비교→근거까지). 채점 결과(놓친 keyPoints) → 해당 레이어만 자동 확장.
- 데이터: `lesson`(§3)에 `distractorWhy`, `hintLevels`(목차/키워드/서술), `compareTable` 추가.

### 10.2 LLM 기반 주관식 키워드 채점 (★ 약 80% 이미 구현 — 확장)
- **현재**: `aiClaudeClient.js`의 `ANSWER_RULES`가 이미 **배점분배·완주율(completion_pct)·득점/감점 위치 명시·키워드/조문/판례/식 채점·JSON 출력** 수행. AI학습 탭 답안작성에서 작동.
- **확장(신규)**:
  1. EssayMode L3~L5 **문제풀이 화면에 직접** 채점 연결(현재는 AI학습 챗 경유) → 풀고 바로 첨삭.
  2. 문항 `lesson.scoringKeys`(필수 키워드) + `outline`을 채점 컨텍스트로 주입 → **문항 맞춤 채점**(일반 루브릭보다 정확).
  3. 결과를 "키워드 체크리스트(있음/없음) + 논리흐름 피드백 + 다음에 채울 것" 카드로. 오답 키워드는 10.3 SRS로 적재.
- → 강사 첨삭 대체. **신규 비용 작음**(기존 프롬프트·UI 재사용).

### 10.3 망각곡선 기반 복습 주기 (leaf SRS 보유 → 개념/문항 단위로 확장)
- **현재**: `aiLearningStore.js`에 `SRS_LADDER`·`srs_box`·`next_review`·graduated가 **단원(leaf) 단위**로 존재.
- **확장(신규)**: **L1·L2에서 틀린 '개념/문항' 단위 SRS**.
  - 틀린 L1·L2 문항 → box 0 진입, 정답 시 box↑(간격 ↑), 오답 시 box 0 리셋 = 체화까지 반복 노출.
  - "오늘 복습할 개념 N개"(due) 큐 → 홈/복습 탭. 기초 뼈대(L1·L2)가 무너지지 않게 유지.
  - 데이터: `q-srs-v1`(문항ID별 box·due) — 기존 SRS_LADDER 로직 재사용, 키만 문항 단위로.
- 1·2단계 개념은 **graduated(체화) 전까지 계속 큐에 노출** → "기초 뼈대 튼튼" 보장.

### 10.4 시스템 ↔ 5단계 연결 요약
```
L1·L2 (객관식)  → 자동채점 → 오답 → [10.3 SRS 반복] + [10.1 선지별 동적해설]
L3~L5 (주관식)  → [10.2 LLM 키워드 채점] → 놓친 키워드 → [10.1 목차 힌트·깊은 해설]
                                         → 놓친 핵심개념은 [10.3 SRS] 역류
```
→ 틀린 곳이 자동으로 복습 큐·맞춤 해설로 순환. 이것이 '인강 없이 취약점 보완'의 엔진.
