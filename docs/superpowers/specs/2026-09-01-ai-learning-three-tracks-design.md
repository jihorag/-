## 1. 무엇을 만드나

관 하나를 열면 상단 탭에서 **개념 완성 · 기출 분석 · 심화** 셋 중 하나를 고른다.
(시안 표기를 따른다 — 「기출분석」이 아니라 「기출 분석」이다.)
세 탭은 같은 단원 체계, 같은 화면 구조, 같은 말풍선 렌더러를 쓴다.

지금 흩어져 있는 것들을 이 셋 안으로 넣는다.

### 성공 기준

1. 관 하나에서 세 탭을 오갈 때 **화면 구조가 바뀌지 않는다**(같은 셸·같은 렌더러).
2. API 키 없이도 **개념 완성과 기출 분석을 끝까지 진행**할 수 있다.
3. 학습 중 아무 때나 **끼어들어 묻고, 정확히 그 자리로 돌아온다**.
4. 1차 과목의 심화 대화가 `DeepChat.jsx` 500줄 이하로 선다
   (`AILearning.jsx` 4,114줄은 2차 전용으로 남는다 — §12).

## 2. 접근 — 한 렌더러, 세 트랙

`ConceptScene` 이 `turns` 스키마를 그리는 **유일한 렌더러**가 된다.
세 탭은 무엇을 물리느냐만 다르다.

| 탭 | 트랙 파일 | 저작 |
|---|---|---|
| 개념 완성 | `{unit}.basic.json` | 기존 940논점 + 이번에 증보 |
| 기출 분석 | `{unit}.exam.json` | **신규 — 720문항 전부 저작** |
| 심화 | 없음 (실시간) | — |

트랙 파일은 `public/data/study/{과목}/lectures/track/` 에 둔다.
색인은 트랙별로 나눈다 — `_index.json`(개념) · `_index.exam.json`(기출).

**왜 이 접근인가.** 「모든 탭의 디자인이 통일감 있게」를 사람이 지키는 규율이 아니라
구조로 보장한다. 탭마다 화면을 따로 만들면 시간이 지나며 반드시 갈라진다.
한 컴포넌트에 모드 분기를 넣는 방식은 이미 해 봤고, 그 결과가 지금의 4,114줄이다.

**대가.** 기출 문항의 특수 요구(선지 5개·계산식·표)를 `turns` 스키마에 맞춰야 한다.
스키마가 이미 quiz 턴과 viz 를 갖고 있어 큰 무리는 없지만, 맞지 않는 것이 나오면
스키마를 넓히지 말고 **그 문항을 안 넣는** 쪽을 택한다(§10).

## 4. 개념 완성 — 넷을 흡수한다

### 4-1. 교재 전체

강의가 다루지 않은 논점을 교재로 메운다. 이미 22관을 그렇게 채웠고
(`source: "textbook"`), 남은 범위도 같은 방식으로 훑는다.

교재 원문 패널을 **없애지 않는다.** `/교재` 명령으로 연다. 대화가 근거를 못 대면
확인할 데가 있어야 한다.

시안(334:229)은 이를 **4단째 우측 패널**로 그린다 — 레일 72 · 트리 280 · 대화 · 교재.
대화 열이 그만큼 좁아진다(560 → 약 470). 좁아지는 것을 감수하는 대신 교재와 대화를
나란히 본다.

패널에서 두 가지가 더 있다.

- **교재 원문에도 형광펜이 그어져 있다.** 대화의 강조 규칙(노랑=공식, 보라=뒤집힘)을
  교재 본문에도 그대로 적용한다. 같은 색이 같은 뜻이어야 한다.
- 하단에 **「이 부분 물어보기」** 버튼. 교재를 읽다 막히면 그 문단을 물고 대화로
  돌아간다 — §7 끼어들기의 또 다른 입구다.

### 4-2. OX → quiz 턴

교재의 `#### ✅ OX 확인문제` 섹션에 **경제학 기준 507지문**이 있다(17개 단원 전부 보유).
지문 하나가 O/X 2지선다 quiz 턴이 된다. 시안(330:126)이 이를 확인해 준다 —
논점 대화가 이어지다가 선생이 「『매입할인은 수익으로 잡는다』 맞을까요, 틀릴까요?」로 묻고,
하단 도크에 **O / X 큰 버튼 둘**이 나란히 선다. 선지 다섯 개짜리와 같은 자리, 같은 컴포넌트다.

- 그 관의 논점 중 **주제가 맞는 논점 뒤에** 붙인다. 관 끝에 몰아넣지 않는다 —
  배운 직후에 물어야 인출이다.
- 붙일 논점을 못 찾은 지문은 관 끝 「확인」 묶음으로 간다.
- 변환은 스크립트가 하되 **붙일 자리는 제가 정한다**. 자동 매칭만으로는
  엉뚱한 논점에 붙는다.

### 4-3. 암기법 → 복습 메이트 대사

`#### 🧠 암기법` 섹션(17개 단원 전부 보유)의 두문자·연상법을 그 관 마지막
복습 메이트 턴으로 넣고, 관 완료 화면의 「챙길 것」에도 올린다.

### 4-4. 인출 — 두 가지다

시안(330:309)을 보고 초안을 고친다. 초안은 인출을 「만기된 문항 재출제」 하나로만
봤는데, 시안의 인출은 **백지에서 꺼내 쓰기**다.

```
선생   취득원가에 들어가는 세 가지를 써보세요.

  ┌───────────────────────────────────┐
  │ 매입원가, 전환원가,                 │   ← 여러 줄 입력창
  └───────────────────────────────────┘
              [ 답 제출 ]
```

선지를 고르는 것과 백지에 쓰는 것은 **인출 강도가 다르다.** 고르기는 알아보기(recog)고
쓰기는 꺼내기(recall)다. 시험장에서 필요한 것은 뒤쪽이다.

그래서 인출은 둘로 나눈다.

**(가) 자유 서술 인출** — 논점 흐름 중에 뜬다. 개념 완성 탭 안.
- 채점: 정답을 펴 보이고 **자기 채점**(맞음/부분/틀림). AI 채점은 키가 있을 때만.
- 계약: `f: 'recall'`, `g: 'self'`(또는 키가 있으면 `'ai'`), `axis: 'knowledge'`.

**(나) 간격 반복 재출제** — 논점을 통과하는 순간 그 논점의 quiz·OX·서술 인출을
`studyDrill.js` 의 SRS 사다리(1→3→7→16→35일)에 올린다. 관을 마칠 때까지 기다리지
않는다 — 관이 20논점이면 첫 논점의 복습 시점이 그만큼 밀린다.
다시 그 관에 들어오면 **만기된 것부터** 묻고, 그 뒤 이어보기 위치로 간다.
홈의 「오늘의 인출」은 과목을 가로질러 그대로 둔다.

**(나)의 두 자리가 같은 큐를 쓴다.** 따로 만들면 어디서 풀었는지에 따라 복습 주기가 갈린다.
**(가)는 (나)에 올라탄다** — 백지에 쓴 것도 날이 되면 다시 묻는다.

## 5. 기출 분석 — 신규

### 5-1. 재료

감정평가사 경제학 기출 **720문항**. 160관에 나누면 관당 평균 4.5문항.
해설은 **720문항 전부** 있고 이미 단계로 쪼개져 있다.

```
① [한계비용 공식] MC = dTC/dQ = 8Q
② [숫자 대입] 32 = 8Q
③ [최종 결과] Q = 4
```

**없는 것: 선지별 「왜 틀렸나」**(`option_meta` 0건). 이것을 제가 저작한다.
오답을 골라도 이유를 못 들으면 깨달음이 없다.

### 5-2. 한 문항의 대화 (시안 316:3 · 316:230)

```
              2023년 제34회 · 34번          ← 출처 라벨, 가운데
선생    재고자산의 취득원가에 관한 설명으로 옳지 않은 것은?
        [논점 3 · 취득원가]  [출제 4회]     ← 칩 둘
        (선지 5개 → 하단 도크)
[선택]
선생    ②를 고르셨네요. 매입할인을 수익으로 본 겁니다.
        ==뒤집힘:매입원가에서 차감합니다==
┌─────────────────────────────────────────┐
│ 개념 완성 논점 3에서 다룬 자리입니다.        │  ← 탭 간 딥링크
│ [ 논점 3 다시 보기 › ]                    │
└─────────────────────────────────────────┘
                              [ 다음 문제 › ]
```

시안에서 읽은 것 넷 — 앞선 초안과 다르다.

1. **오답 대사의 화자는 「선생」이다.** 초안은 깐깐이였다. 기출은 이미 틀린 상황이라
   한 번 더 몰아붙일 자리가 아니다.
2. **문제 말풍선에 칩이 둘 붙는다.** 「논점 N · 제목」(개념 완성의 어느 논점인가)과
   「출제 N회」(빈출). 둘 다 이미 있는 데이터로 만든다.
3. **채점 뒤에 탭 간 딥링크 카드가 뜬다.** 「개념 완성 논점 3에서 다룬 자리입니다」 +
   「논점 3 다시 보기 ›」. 이게 세 탭을 한 시스템으로 묶는 고리다 —
   틀린 기출에서 그 개념으로 곧장 돌아간다.
4. **「다시 풀어보기」가 없다.** 「다음 문제 ›」 하나뿐이다. 기출은 한 번 본 문항을
   그 자리에서 다시 푸는 것보다 다음으로 넘어가는 편이 낫다고 본 것이다.
   다시 풀기는 인출 큐(§4-4)가 날을 잡아 가져온다.

진행 표시는 우측 상단에 **「기출 8 / 68」** — 관이 아니라 **절 단위**다.
시안의 68 은 좌측 트리의 「기출 72」와 어긋나는데, 숫자 자체는 예시라
맞출 필요가 없다(2026-09-01 확인). **분모는 그 절에 실제로 저작된 기출 문항 수**를
쓰고, 좌측 트리의 「기출 N」은 **분류된 전체 문항 수**를 쓴다. 둘은 다른 값이고,
저작이 끝나면 같아진다.

선지 도크·정답/내 답 라벨은 개념 완성과 **완전히 같은 컴포넌트**다.

### 5-3. 저작 규칙

- 문항 하나 = point 하나. `id` 는 기출 문항 id 에서 파생한다.
- 해설 단계(①②③)는 **원문을 옮긴다.** 다시 쓰지 않는다 — 검증된 해설이다.
- 선지별 오답 이유는 **틀리는 이유의 유형**을 말한다. 「③은 틀렸습니다」가 아니라
  「MC 를 구하지 않고 TC 를 그대로 썼습니다」.
- 계산 문항은 `viz` 로 그림을 붙일 수 있으면 붙인다. 억지로 만들지 않는다.
- **문항마다 「어느 논점인가」를 적는다**(`point_ref`). 칩과 딥링크가 이 값을 쓴다.
  이걸 안 적으면 §5-2 의 고리가 끊어져 기출 분석이 개념 완성과 무관한 탭이 된다.

### 6-1. 걷어내는 것

| 모드별 조건부 자료 로딩 | 있음 | 검색이 대신한다 |

남기는 것은 **자유 대화 하나**. 말풍선은 개념 완성과 같은 렌더러로 그린다.

### 6-1-b. 빈손으로 시작하지 않는다 (시안 316:506)

탭을 열면 커서만 깜빡이는 게 아니라 **약점 카드**가 먼저 뜬다.

```
선생   이 관에서 두 번 이상 틀린 곳입니다.
       눌러서 바로 이야기해요.

  ┌ 매입할인의 처리        기출 3문제 중 3개 오답 · 논점 3 ┐
  ├ 고정제조간접원가 배부   기출 2문제 중 2개 오답 · 논점 7 ┤
  └ 저가법 적용 단위       확인 문제 2회 오답 · 논점 9    ┘

       목록에 없는 것도 아래에 바로 물어보세요.
```

**부제가 근거다** — 「기출 3문제 중 3개 오답」처럼 왜 약점으로 뽑혔는지 숫자로 말한다.
자유 대화는 「무엇을 물어야 할지 모르겠다」에서 막힌다. 약점 카드가 그 첫 발을 대신 뗀다.

카드의 재료는 §6-4 의 학습 기록 다섯과 같다. 화면과 프롬프트가 같은 것을 본다.

**파일은 줄이는 게 아니라 새로 만든다.** `AILearning.jsx`(4,114줄)를 깎지 않고
`DeepChat.jsx`(500줄 목표) + `rag.js`(200줄 목표)를 새로 쓴다. 이유는 §12 에 있다 —
2차 시험 과목(답안·양식·논점·실전)은 당분간 지금 화면을 계속 쓴다. 깎으면 그 기능이
같이 사라진다. `AILearning.jsx` 는 2차 전용으로 남았다가, 2차까지 옮긴 뒤 지운다.

### 6-2. 검색 인덱스 — 빌드 때 만든다

```
sync-data → units/G*.md ─ 소제목(####) 단위 청크 ─→ {과목}/rag/{unit}.chunks.json
                                                    [{ id, path, text, terms }]
```

경제학 기준 **청크 1,300개 · 중앙값 472자**. 전체 약 600KB 로 브라우저가 들 수 있다.

### 6-3. 검색은 키 없이 — 생성만 키를 쓴다

**임베딩을 기본으로 쓰지 않는다.** Anthropic 은 임베딩 엔드포인트가 없어
제공자를 바꾸면 인덱스를 다시 만들어야 한다. 어느 제공자든 최소한은 동작해야 한다.

기본은 **어절 + 2-gram 키워드 점수**(BM25 축약형). 한국어 형태소 분석기 없이도
「한계대체율」·「구축효과」 같은 시험 용어는 그대로 매칭된다.

**정직하게 적어 둔다:** 키워드 검색은 임베딩보다 약하다. 「물가가 오르면 실질임금은?」
처럼 용어가 안 겹치는 질문은 잘 못 찾는다. 임베딩은 나중에 제공자가 지원할 때
**추가 선택지**로 연다. 기본을 갈아치우지 않는다.

### 6-4. 프롬프트 예산 — 못 박는다

| 블록 | 내용 | 상한 |
|---|---|---|
| 교재 청크 | 질문 관련 상위 6개 | 3,000자 |
| 이 관 논점 | 제목 + gist 목록 | 600자 |
| 학습 기록 | 아래 다섯 | 800자 |
| 강의 필기 | 이 관 슬라이스 | 800자 |

지금은 `sectionMd || unitMd` 를 통째로 넣는다 — 단원 md 평균 **10만 자**다.
관련 없는 부분까지 매번 들어가고, 질문이 무엇이든 같은 덩어리가 간다.

**학습 기록 다섯**(지금 빠져 있는 것):

1. 개념 완성에서 못 넘은 논점 — 두 번 틀려 답을 본 자리
2. 기출분석에서 틀린 문항 — 번호와 고른 선지
3. 틀린 OX 지문
4. 만기된 인출 항목
5. 사용자 메모

### 6-5. 근거를 밝히게 한다 (시안 316:717)

시스템 프롬프트가 강제한다:

> 답한 내용이 어느 논점에서 온 것인지 반드시 밝혀라.
> 준 자료에 없는 내용은 「교재에 없습니다」라고 말하고 지어내지 마라.

**출처는 교재 문단 번호가 아니라 「논점」이다.** 시안은 답변 말풍선 아래에
`[논점 3 · 취득원가]` 칩을 붙인다. 초안은 `[§3-②]` 같은 교재 좌표를 썼는데,
학습자가 아는 단위는 교재 문단이 아니라 **자기가 익힌 논점**이다.
칩을 누르면 개념 완성의 그 논점으로 간다 — §5-2 의 딥링크와 같은 고리다.

교재 청크는 검색해서 넣되, **인용 표시는 그 청크가 속한 논점 이름으로 환산**한다.
청크에 논점이 안 붙어 있으면 「교재」라고만 표시한다.

### 6-6. 기출을 불러온다

답변 뒤에 **「같은 자리를 물은 기출」** 카드가 붙는다.

```
같은 자리를 물은 기출
  2019년 제30회 28번 · 내가 틀린 문제
  2021년 제32회 31번 · 맞힌 문제

선생   2019년 28번을 다시 풀어볼까요?
       「/기출」이라고 쓰면 바로 가져올게요.
```

`/기출` 은 그 문항을 **기출 분석 탭에서 연다**. 심화 → 기출, 기출 → 개념,
개념 → 심화. 세 탭이 서로를 부른다.

### 6-7. 키가 없으면 (시안 284:2)

심화 탭 자리에 키 입력 화면이 선다.

- 제목 「AI 튜터와 단원별 1:1 학습」 + 할 수 있는 일 세 줄
- **제공자 셋(anthropic·openai·google)을 그대로 받는다.** 시안 284:2 는 Claude 만
  그렸지만 화면이 좁아서지 제공자를 줄이자는 뜻이 아니다(2026-09-01 확인).
  Claude 를 기본으로 앞에 두고 나머지를 고를 수 있게 한다.
- 「키는 이 기기에만 저장되고 서버로 전송되지 않습니다」
- `console.anthropic.com` 발급 링크

**개념 완성과 기출 분석 탭은 그대로 동작한다.** 키는 심화와 끼어들기만 막는다.

## 7. 학습 중 끼어들어 묻기

요청의 핵심이라 따로 세운다. **세 탭 모두**에 적용된다.

### 7-1. 하단 입력줄에 그냥 쓴다

```
선생    구축효과는 소득 → 화폐수요 → 이자율 → 투자 순서로…

┃ [나]   잠깐, 화폐수요가 왜 소득이 늘면 늘어요?      ← 좌측 파란 띠 3px
┃ 선생   거래적 동기 때문입니다. 소득이 늘면 사고파는…   ← 배경 --accent-bg
┃ [나]   아 그럼 투기적 동기는요?
┃ 선생   그건 이자율에 반응하는 쪽이라…
┃                              [ ↩ 돌아가기 ]

선생    …그래서 투자가 줄어듭니다.                    ← 원래 자리 그대로
```

### 7-2. 지키는 것 넷

1. **트랙 상태를 건드리지 않는다.** 끼어들기는 `conceptTurns` 의 `cursor` 를
   움직이지 않는다. 돌아가면 정확히 그 턴이다.
2. **샛길임이 색으로 보인다.** 배경 `--accent-bg` 와 좌측 3px `--accent` 띠.
   구분선이나 「샛길」 머리글은 두지 않는다 — 색이 그 일을 한다.

   **왜 파랑인가.** 남는 색이 없어서가 아니라 뜻이 맞아서다. 파랑은 이미
   「시스템이 개입한 자리」다 — 선택된 관, 「이어서」 카드, 현재 위치.
   샛길도 같은 계열이다. 노랑·보라는 본문 강조 전용이라 말풍선 배경으로 쓰면
   형광펜과 충돌하고, 빨강은 오답 전용이다. 초록은 §강조 규칙에서 뺐다.

   **색만으로는 부족하다.** 화자 이름 옆에 작은 「AI」 표식을 함께 둔다.
   색각 이상이면 파란 면과 흰 면이 구분되지 않는데, 이 구분은
   **어디까지가 검증된 내용인가**를 가르는 것이라 놓치면 안 되는 종류다.
3. **샛길은 논점에 붙어 남는다.** 다시 오면 「이 논점에서 3번 물었습니다」로
   접혀 있고 펴서 볼 수 있다.
   저장 키는 **`ailearn-side:{leafId}:{pointId}`**. 기존 `ailearn-room:{leafId}`
   (심화 탭의 관 단위 대화)와 **다른 키다** — 논점에 붙은 즉문즉답과 관 전체를 놓고
   하는 대화는 다시 열었을 때 보여야 할 것이 다르다.
4. **측정에 넣지 않는다.** `g: 'none'` — 채점 근거가 없으므로 실력 점수에 섞지
   않는다. 「몇 번 물었나」만 남긴다.

### 7-3. 무엇을 물고 들어가나

- 지금 논점 — 제목·gist·지금까지 나온 대사
- 교재 청크 — 질문 관련 상위 6개 (§6-3)
- 학습 기록 — 이 관에서 틀린 것들 (§6-4)
- 기출분석이면 지금 문항과 내가 고른 선지

그래서 「이거 왜요?」처럼 짧게 물어도 무엇을 가리키는지 안다.

### 7-4. 키가 없으면

입력줄은 그대로 두되, 보내면 이렇게 답한다.

> 물어보려면 API 키가 필요합니다. **설정에서 키 넣기 →**
> 키 없이도 논점 대화와 기출 풀이는 끝까지 진행됩니다.

**학습 자체는 막히지 않는다.** 끼어들기만 잠긴다.

### 7-5. 심화 탭과의 관계

| | 끼어들기 | 심화 탭 |
|---|---|---|
| 범위 | 지금 논점 하나 | 관 전체 |
| 계기 | 진행 중 막힐 때 | 다 익힌 뒤 더 파고 싶을 때 |
| 저장 | 그 논점에 | 그 관에 |

심화 탭을 열면 **그 관에서 했던 샛길 질문들이 먼저 뜬다** — 「이 관에서 이런 걸
물으셨습니다」. 두 곳이 따로 놀지 않게.

## 10. 하지 않는 것

- **기출분석에 실시간 생성을 섞지 않는다.** 섞으면 키 없는 사용자에게
  탭이 반쪽이 된다. 저작분만으로 끝까지 굴러가야 한다.
- **심화 탭에 트랙 파일을 만들지 않는다.** 만들면 개념 완성과 같아진다.
- **탭마다 다른 말풍선·선택지 컴포넌트를 만들지 않는다.**
- **`turns` 스키마를 기출 때문에 넓히지 않는다.** 안 맞는 문항은 넣지 않는다.
- **임베딩을 기본 검색으로 만들지 않는다.** 제공자 종속이 생긴다.
- 모드 추천(`recommendMode`)·자동 암기카드 생성·형광펜 가리기 — **폐지**.
  13개 모드와 함께 사라진다.

## 12. 열린 위험

**기출 720문항 저작이 길다.** 관 단위로 커밋하고 진행 기록을 남긴다
(심화 보충 때 쓴 `_progress.json` 방식). 중간에 멈춰도 어디까지 했는지 알 수 있어야 한다.

**OX 지문을 붙일 논점을 못 찾는 경우.** 자동 매칭이 엉뚱한 자리에 붙이면 학습이
망가진다. 매칭은 제안까지만 하고 **붙일 자리는 사람이 정한다.**

**키워드 검색의 한계.** §6-3 에 적었다. 검색이 빈손이면 튜터가 「교재에서 못 찾았습니다」
라고 말하게 한다 — 조용히 지어내는 것보다 낫다.

**시안이 답하지 않았던 것 셋 — 2026-09-01 확정** (더 이상 미해결이 아니다)

1. **끼어들기 구분은 색으로.** 배경 `--accent-bg` + 좌측 3px 파란 띠.
   구분선·머리글은 두지 않는다. 색각 대비로 「AI」 표식만 함께 둔다(§7-2).
2. **제공자는 셋 다 유지.** 시안이 Claude 만 그린 것은 화면 사정이다(§6-7).
3. **기출 카운터의 숫자는 맞출 필요 없다.** 분모는 저작된 문항 수, 트리의
   「기출 N」은 분류된 전체 수. 저작이 끝나면 같아진다(§5-2).

**AILearning.jsx 를 줄이며 잃는 기능.** 13개 모드 중 2차 시험용(답안·양식·논점·실전)은
경제학에 없지만 다른 과목에는 쓰인다. **1차 과목만 새 3탭으로 옮기고, 2차 과목은
당분간 지금 화면을 유지한다.** 한꺼번에 갈아치우지 않는다.
