## 1. 핵심 원칙

**감정평가실무는 논술형 서술 시험이다.**

기출 26개년 분석 결과, 모든 문제는 다음 4요소를 반드시 갖춘다:

1. **시나리오 도입** (의뢰인·평가목적·기준시점·점수)
2. **체계화된 자료** ([자료 01]~[자료 N])
3. **완결문장 물음** (~을 평가하시오, ~을 산정하시오)
4. **논술형 모범답안** (Ⅰ.평가개요 / Ⅱ.본건 평가 / Ⅲ.가격결정 의견)

### 1.1 절대 금지 (v1 폐기 사유)

| 금지 사항 | 사유 |
|----------|------|
| 물음을 주제 나열 ("1. 토지평가 2. 건물평가") | 기출에 없음, 채점 기준 모호 |
| 답안을 bullet point만으로 구성 | 논술형 평가 불가 |
| 자료 → 물음 순서 (역순) | 평가 행위가 마지막에 와야 명확 |
| 법령 인용 없음 | 감정평가는 법령 기반 행위 |
| 시나리오 없이 자료만 나열 | 누가/왜/언제 평가하는지 불명 |
| 본문 < 200자 (입문 약술 제외) | 1방식 적용도 불가능한 부실 |
| 모범답안에 처리방침 없음 | 가장 핵심적인 평가사 역량 누락 |

### 1.2 필수 준수

| 필수 요소 | 기출 실증 |
|----------|----------|
| 평가개요 (평가목적·기준시점·법령) | 11회~36회 100% |
| 처리방침 (왜 이 방법을 쓰는지) | 11회~36회 100% |
| 법령 인용 (구체적 §) | 11회~36회 100% |
| 산식 + 근거 설명 | 11회~36회 100% |
| 가격결정 의견 | 11회~36회 100% |

## 2. 기출 구조 분석

### 2.1 회차별 출제 패턴 (11~36회)

기출 회차당 4~6문제 출제, 점수 배분 패턴:

| 패턴 | 배점 구성 | 회차 예 |
|-----|----------|---------|
| **A형** | 40 + 25 + 20 + 15 | 11회, 12회, 13회 |
| **B형** | 40 + 30 + 20 + 10 | 14회, 15회, 16회 |
| **C형** | 40 + 30 + 20 + 5 + 5 | 17회, 18회 |
| **D형** | 40 + 25 + 20 + 10 + 5 | 19회 이후 다수 |
| **E형** | 40 + 30 + 20 + 10 | 30회 이후 다수 |

**공통점:**
- 항상 **1번 문제는 40점 종합형** (3방식 종합 또는 보상 종합)
- **마지막 문제는 5~10점 약술** (개념 정의·요건·절차)
- 중간 문제는 25~30점 응용 + 20점 표준

### 2.2 문제 본문 구성 표준

기출 모든 종합문제의 본문은 다음 8요소를 갖춘다:

```
1. 시나리오 도입
   "감정평가사 K씨는 ○○로부터 ○○사업에 편입된 다음의 부동산에 대한
    보상평가를 의뢰받았다. 다음 자료를 활용하여 ~을 산정하시오. (40점)"

2. 평가의뢰 부동산 (구조화된 표)
   가. 소재지·지번
   나. 지목·면적
   다. 용도지역
   라. 도로조건
   마. 가격시점
   바. 사업인정일 (보상의 경우)
   사. 현지답사 내용

3. 평가기초자료 (비준표·계수표)
   - 지가상승률 (연도별·일단위)
   - 용도지역별 토지가격 비준표
   - 이용상태별 비준표
   - 경사방향별·도로조건별 효용성 비교
   - 표준지 공시지가 내역

4. 사례·선례 자료 [자료 01], [자료 02], ...
   - 각 자료는 구체적 수치·표 포함
   - 거래사례 (소재지·거래시점·거래가·도로조건)
   - 임대 자료 (사용료·임대조건)
   - 건물 자료 (구조·연면적·신축연도·공사비)

5. 다중 물음 (번호 매김, 완결문장)
   물음1) ~을 평가하시오
   물음2) ~의 산정과정을 산식으로 표시하고 ~을 결정하시오
   물음3) ~에 관한 의견을 기술하시오

6. 요구사항 명시
   - "각 평가방식에 적용한 자료 선택의 주안점과 산출과정을 산식으로 표시하고"
   - "가격결정에 관한 의견을 기술한 후"
   - "㎡당 단가로 구하라"

7. 단위 정밀도
   - "천단위 미만은 절사하시오"
   - "지가상승률 계산은 일단위로 계산할 것"
   - "총액비에 의한 배분율은 평점적수를 이용할 것"

8. 법령·기준 표기
   - 토지보상법 §70, 시행규칙 §22 등 구체 명시
```

### 2.3 기출 모범답안 골격

11~36회 모든 모범답안의 공통 골격:

```markdown
## Ⅰ. 평가개요

본건은 [평가대상]에 대한 [평가목적]의 감정평가로서,
[기준시점]을 기준시점([근거법령 §])으로 하여 [기준가치]를 기준으로 평가함.

[처리방침 한 줄: 어떤 방식으로 평가하는지]


## Ⅱ. 본건 평가 (또는 물음1, 물음2, ...)

### 1. 처리방침
[적용 법령 인용]
[왜 이 방식을 선택하는지 근거]
[다른 방식으로 합리성 검토 여부]

### 2. 비교표준지/사례의 선정 (해당시)
가. 선정기준 (법령 인용)
나. 채택: 기호 #N — 이유
다. 배제: 기호 #M — 이유

### 3. 시점수정
[계산식]
[근거 자료 인용]

### 4. 지역요인 / 개별요인 보정
[종합 비교치]
[근거]

### 5. 그밖의요인 보정 (해당시)
[보정치 산정 근거]
[보상선례 시점환산]
[한도 검토 (1.5)]

### 6. 평가단가 / 평가가액
[산식 명시]
[결과 + 단위]


## Ⅲ. 가격결정 의견

본건 [평가대상]의 [기준가치 또는 평가가액]을
**[금액] (@[단가])** 으로 결정함.

[합리성 근거 한 줄: 시산조정 결과, 한도 검토, 사례 부합 등]
```

## 3. 물음(問) 작성 원칙

### 3.1 기출 실제 물음 표현 (그대로 사용 가능)

**평가/산정 명령형:**
- "본건 토지의 보상가액을 산정하시오"
- "본건의 시점별 토지가격을 평가하시오"
- "다음 자료를 활용하여 ~을 평가하시오"
- "본건 부동산의 시장가치를 산정하시오"
- "물건별 감정평가액을 산정하시오"

**산정과정 + 결정 요구:**
- "각 평가방식의 산출과정을 산식으로 표시하고 평가가액을 결정하시오"
- "가격결정에 관한 의견을 기술하시오"
- "각 평가방식에 적용한 자료 선택의 주안점과 산정과정을 약술하시오"

**검토/판단 요구:**
- "투자타당성을 검토하시오"
- "매수청구 인용 시 보상가액을 결정하시오"
- "~의 적정성을 검토하고 의견을 기술하시오"
- "각 가격간 차이의 원인을 분석하시오"

**약술/설명 요구:**
- "~의 의의를 설명하고 ~를 약술하시오"
- "~의 적용 방법과 산정과정을 약술하시오"
- "~의 처리방법과 ~에 대하여 약술하시오"

### 3.2 평가 행위 동사 (필수 사용)

| 동사 | 사용 상황 |
|------|----------|
| **평가하시오** | 종합 평가 명령 |
| **산정하시오** | 특정 단가·가액 계산 |
| **결정하시오** | 시산조정 후 최종가액 |
| **검토하시오** | 적정성·타당성 판단 |
| **약술하시오** | 5~10점 개념 설명 |
| **논하시오** | 25점+ 종합 의견 |
| **기술하시오** | 의견·근거 서술 |
| **분석하시오** | 원인·차이 분석 |
| **제시하시오** | 의견 제출 |

### 3.3 물음 작성 형식 표준

**❌ 잘못된 예 (v1 폐기):**
```
[ 물음 ]
1. 필지별 토지 보상
2. 건축물 보상
3. 영업 보상
4. 총 보상
```

**✅ 올바른 예 (v3 기준):**
```
물음 1) 본건 토지의 보상감정평가액을 산정하시오. (20점)

물음 2) 본건 지장물(건축물, 공작물 등)의 보상평가액을
        시행규칙 §33에 따라 산정하시오. (15점)

물음 3) 본건 영업의 휴업손실에 대한 보상액을 시행규칙 §46에
        따라 산정하시오. (5점)
```

각 물음은:
- **완결된 명령문**
- **점수 명시**
- **법령 인용** (해당 시)
- **평가 대상과 행위 명확화**

## 4. 모범답안 작성 원칙

### 4.1 표준 구조 (Ⅰ-Ⅱ-Ⅲ 체계)

```markdown
## Ⅰ. 평가개요
- 평가목적, 기준시점, 적용법령, 기준가치 명시
- 처리방침 개관

## Ⅱ. 본건 평가 (물음별)
- 처리방침 (구체적 법령 + 방법 선택 근거)
- 산정과정 (단계별 산식 + 근거)
- 결정

## Ⅲ. 가격결정 의견
- 최종 가액 결정
- 합리성 근거
```

### 4.2 처리방침 작성 표준

기출의 모든 답안은 산정에 들어가기 전 **처리방침**을 명시한다:

```markdown
### 1. 처리방침

본건은 [평가목적]의 감정평가로서, 감정평가규칙 §[N]에 따라
[주된 방법]을 적용하되, [부수 방법]으로 합리성을 검토함.
```

**예시 (기출 18회 변형):**
```markdown
### 1. 처리방침

본건은 토지·건물로 구성된 복합부동산에 대한 일반거래목적의
감정평가로서, 가치 §7①에 따라 토지·건물을 개별평가하여
합산함. 가치 §12②에 따라 일괄거래사례비교법 및 일괄
수익환원법으로 그 합리성을 검토함.
```

### 4.3 법령 인용 표준 형식

기출 모범답안의 모든 법령 인용 패턴:

| 표기 형식 | 의미 | 예 |
|----------|------|-----|
| **법 §N** | 토지보상법 제N조 | 토지보상법 §70④ |
| **시행규칙 §N** | 토지보상법 시행규칙 제N조 | 시행규칙 §22 |
| **시행령 §N** | 토지보상법 시행령 제N조 | 시행령 §40 |
| **감정평가규칙 §N** 또는 **가치 §N** | 감정평가규칙 제N조 | 가치 §14②3호 |
| **K-IFRS [번호]** | 한국채택국제회계기준 | K-IFRS 1113 |
| **부공법 §N** | 부동산공시법 | 부공법 §3 |
| **도시정비법 §N** | 도시 및 주거환경정비법 | 도시정비법 §74 |

**구체 인용 예 (기출 그대로):**
- "토지보상법 §67① (협의·재결시점)"
- "시행규칙 §22 3항 (비교표준지 선정)"
- "감정평가규칙 §14 1항 (공시지가기준법)"

## 11. 부적격 사례 모음

다음 조건 중 **하나라도 해당하면 작성 즉시 폐기**:

1. 본문 200자 미만 + 답안 400자 미만 (입문 약술 제외)
2. 물음이 주제 나열형 ("1. 토지평가 2. 건물평가")
3. 답안이 bullet만으로 구성 (Ⅰ-Ⅱ-Ⅲ 구조 없음)
4. 법령 인용 없음 (모든 평가는 법령 근거 필수)
5. 시나리오 없이 자료만 나열
6. 처리방침 누락
7. 가격결정 의견 누락
8. 시점수정·지역요인·개별요인·그밖의요인 중 하나라도 누락 (표준 이상 보상평가)
9. 산식만 있고 근거 설명 없음
10. 정답이 여러 가지 가능 (채점 불가)

## 13. 향후 작성 시 적용

향후 모든 신규 문제는 v3 기준으로 작성한다.

기존 v1 시기 작성 문제는:
1. **유지 가능**: 완결문장 물음 + Ⅰ-Ⅱ-Ⅲ 답안 보유 시
2. **재작성**: 주제 나열 물음, bullet 답안 → 점진적 교체
3. **폐기**: 본문 100자 미만 + 답안 200자 미만 부실 문제

작성 절차:
1. 단원·난이도 선정
2. 기출 11~36회 중 유사 주제 1개 이상 확인 (구조 모방)
3. 시나리오 도입 작성
4. 평가의뢰 부동산 상세 작성
5. 자료 [자료 01]~[자료 N] 작성 (난이도별 최소 개수)
6. 물음 작성 (완결문장, 평가 동사 사용, 법령 인용)
7. 모범답안 작성 (Ⅰ-Ⅱ-Ⅲ, 줄글, 처리방침, 법령 인용)
8. 체크리스트로 자체 검토
9. 채점 기준 명시
