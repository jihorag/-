# A부. 기출 정밀 분석

## 1. 회차별 핵심 인용 분석

기출 답안에서 실제 인용된 텍스트를 회차별로 추출. 모든 표현은 그대로 또는 변형하여 신규 문제에 사용 가능.

### 1.1 평가개요 (Ⅰ. 평가개요) — 원문 인용

**[11회 문제2]:**
> "본건의 토지에 대한 일반거래 목적의 감정평가로서, 2000.8.1.을 기준시점으로 하여 시장가치를 기준으로 평가함. 제시된 자료에 따라 공시지가기준법과 수익환원법을 적용한 후 최종 감정평가액을 결정함."

**[12회 문제1]:**
> "A빌딩의 감정평가액을 결정하고, '가' 시장에서 5년간 소유 후 매각시 투자타당성을 검토한다. (기준시점: 2001.8.26.)"

**[13회 문제1]:**
> "본건은 토지·건물로 구성된 복합부동산에 대한 일반거래목적의 감정평가로서, 2002.8.25.을 기준시점으로 하여 시장가치를 기준으로 평가함. 가치 §7①에 따라 토지와 건물을 개별평가한 후 합산하여 최종 감정평가액 결정함."

**[14회 문제1]:**
> "본건은 토지·건물에 대한 매매타당성 검토 목적의 감정평가로서, 의뢰인이 제시한 2003.8.31.을 기준시점으로 하여 각 물음에 답함."

**[15회 문제1]:**
> "본건은 복합부동산에 대한 일반거래 목적의 감정평가로서, 가치 §9②에 따라 가격조사완료일인 2004.9.1.을 기준시점으로 하여 시장가치를 기준으로 평가함."

**[18회 문제1]:**
> "본건은 토지·건물에 대한 담보목적의 감정평가에 대한 심사 건으로서, 주어진 물음에 답함."

**[21회 문제1]:**
> "본건은 토지 및 건물에 대한 담보 및 보상목적의 감정평가로서, 가치 §9②에 따라 가격조사완료일인 2010.09.04.에 기준시점으로 하여 각 물음에 답함."

**[27회 문제1]:**
> "본건은 사무용 복합부동산에 대한 일반거래 목적의 감정평가로서, 2016.8.27.을 기준시점으로 하여 시장가치를 기준으로 평가함."

**[36회 문제1]:**
> "본건은 토지 및 건물에 대한 일반거래(시가참고) 목적의 감정평가로서, 2025.7.15.을 기준시점으로 하여 시장가치를 구함."

**공통 구조 (필수 4요소):**
1. **본건은** + 평가대상 + **에 대한** + 평가목적 + **의 감정평가로서,**
2. **[기준시점]을 기준시점**(근거법령) **으로 하여**
3. **[기준가치]를 기준으로 평가함** (또는 "각 물음에 답함")
4. **처리방침** (적용 법령 + 방식)

### 1.2 처리방침 (적용 법령) — 원문 인용

**공시지가기준법 처리방침:**

[11회] "가치 제14조 1항에 의거 공시지가기준법을 적용함"

[14회] "토지보상법 §70 및 시행규칙 §22에 따라 공시지가기준법을 적용함"

[18회] "토지보상법 §70 및 시행규칙 §22에 의거 공시지가기준법으로 평가함"

[31회] "가치 §14①에 의거 공시지가기준법을 적용함"

**원가법 처리방침:**

[11회] "가치 §15에 따라 원가법을 적용함"

[14회] "가치 제15조 1항에 의거 적산법(원가법)을 적용함. 사조달원가는 직접법 우선하여 적용하고, 감가수정 방법은 정액법, 잔존가치율 0%, 만년감가 가정"

**시산조정 처리방침:**

[13회] "가치 12조에 따라 ... 두 시산가액이의 차이는 ① ~ ② ~ 등 고려"

[31회] "감정평가규칙 §12에 따라 ... 두 시산가액이 비교적 인접하므로 시산조정함"

### 1.3 비교표준지 선정 — 원문 인용

**선정 + 배제 사유 (필수 구조):**

[11회] "가치 제14조 2항에 따라 인근지역에 있는 표준지 중에서 용도지역(일반상업지역), 이용상황(상업용) 등이 동일하여 비교가능성이 가장 높은 #1 선정. 배제: #2, 3은 용도지역 상이"

[14회] "토지보상법 시행규칙 §22 3항에 따라 ... 용도지역(자연녹지), 이용상황(전) 등이 동일하여 비교가능성이 가장 높은 #2 선정. #1, 3은 도로조건 상이로 배제"

[18회] "보상평가의 비교표준지는 ... 시행규칙 §22 3항에 의거 ... 기호 1, 2, 3 중 ... 「용도지역, 이용상황 등 동일·유사」하여 비교가능성이 가장 높은 〈#기호3〉선정"

[27회] "근린생활시설, 사무용 등이 동일하여 비교가능성이 가장 높은 #1 선정"

**필수 패턴:**
```
[법령]에 따라 [기준]이 동일·유사하여 비교가능성이 가장 높은
#[N] 선정. #[M]는 [구체적 사유]로 배제.
```

### 1.4 시점수정 — 원문 인용

**일단위 산식 표기 (절대 표준):**

[11회] "2000.1.1. ~ 8.1 일단위 변동률
1.03200 × 1.04000 × (1 + 0.04000 × 32/91) = 1.08838"

[14회] "2003.1.1. ~ 8.31. 지가변동률, 일단위
1.02540 × 1.03000 × (1 + 0.03000 × 56/91) = 1.07566"

[18회] "2008.1.1. ~ 8.25. 지가변동률, 일단위
1.02520 × (1 + 0.02520 × 56/91) = 1.04079"

[31회] "2021.1.1. ~ 8.7. 지가변동률, 일단위
1.02645 × (1 + 0.00420 × 38/30) = 1.03191"

**시점수정 형식 표준:**
```
[시작일] ~ [종료일] [지가변동률 유형] (일단위)
[월변동률1] × [월변동률2] × ... × (1 + [최종월변동률] × [경과일수]/[월일수])
= [누적변동률]
```

### 1.5 그밖의요인 보정 — 원문 인용

**보상평가의 정형 패턴 (필수):**

[18회] "시행규칙 §22 4항에 따라 인근 보상선례를 활용하여 ...
보상선례 평균 시점환산단가 / 표준지 보정 후 단가 = 보정치
... 1.27 적용, 한도(1.5) 내 합리성 인정"

[28회] "표준지 보정 단가 285,000 × 1.0185 × 1.000 × 0.985 = 286,300원
선례 평균: 416,000원
보정치: 416,000 / 286,300 = 1.45 → 시행규칙 한도 내"

**일반평가의 그밖의요인 보정:**

[27회] "거래사례비교법에 의한 비준가액 참작 시, 공시지가기준법에 의한 가액 보정 필요. ... 그밖의요인 보정치 1.20 적용"

### 1.6 가격결정 의견 (Ⅲ. 결정) — 원문 인용

**단일 방식 적용 시:**

[11회] "가치 제14조 1항에 따라 토지 감정평가의 주된 방법인 공시지가기준법에 의한 가액으로 최종 감정평가액 결정함. 최종 감정평가액 단가: @726,000, 총액: @726,000 × 350㎡ = 254,100,000원"

**시산조정 적용 시:**

[12회] "가치 12조 의거, 두 시산가액이의 차이는 ① A빌딩의 시장가치 감정평가인 점, ② 기능적 감가로 시장성을 분리한 점 등 고려 〈3,220,000,000원〉"

[13회] "공시지가기준법에 의한 가액과 거래사례비교법에 의한 가액이 합리성이 입증되며, 수익환원법에 의한 가액이 공시지가기준법에 의한 가액에 비해 낮게 산출되었으나 이는 자료의 정착성 등에 따라 수익가액이 낮게 산출되는 현상에 기인한 것으로 ... 가치 §14①에 따라 ... 공시지가기준법에 의한 가액으로 결정함"

**보상평가 결정:**

[14회] "본건 토지의 보상가액을 @[금액] × [면적]㎡ = [총액]원으로 결정함"

**필수 결정 패턴:**
```
[방식 선택 근거 (법령)] + [시산조정 근거 또는 합리성 의견]
+ [최종 감정평가액 (단가, 총액)]
```

## 2. 모범답안 구조 정형 (Anatomy)

### 2.1 40점 종합형 답안 구조 (11회 문제1 분해)

```
[40점 문제: 토지보상 + 노상영업 보상]

Ⅰ. 평가개요 (전체 평가의 방향성 명시)
   "본건은 토지 및 노상영업 보상목적의 감정평가로서,
    2000.6.20.(재결일)을 기준시점(토지보상법 §67①)으로
    하여 각 물음에 답함"

Ⅱ. 노상영업 보상액 산정 (물음 1)
   1. 노상영업 보상액 산정 방법
      (1) 토지보상법 시행규칙 §48 1항 (원칙)
      (2) 토지보상법 시행규칙 §48 2항 (특례)
   2. 보상대상여부 검토
      1) 기호 1 — 보상대상 (사유 명시)
      2) 기호 2 — 보상대상
      3) 기호 3 — 보상대상
      4) 기호 4 — 별도 처리
   3. 보상액 산정
      (개별 산식 + 결과)
   4. 결정

Ⅲ. 토지 보상가액 산정 (물음 2)
   1. 처리방침
   2. 비교표준지 선정
   3. 시점수정
   4. 지역요인 / 개별요인
   5. 그밖의요인 보정
   6. 평가단가
   7. 평가가액
   8. 결정 의견

Ⅳ. 종합 보상액 결정 (있는 경우)
```

**규칙성:**
- 각 물음은 별도 로마숫자 섹션
- 각 섹션 안에 1, 2, 3... 하위 구조
- 각 하위 구조 안에 (1), (2), 1), 2) 등 다층 구조
- 마지막에 명시적 "결정" 또는 "결정 의견" 단락

### 2.2 25점 응용형 답안 구조 (11회 문제2 분해)

```
[25점 문제: 토지 + 시산조정]

Ⅰ. 평가개요

Ⅱ. 공시지가기준법
   1. 비교표준지 선정 (선정 + 배제 사유)
   2. 시점수정 (일단위)
   3. 지역요인
   4. 개별요인
   5. 그밖의요인 보정
   6. 산정가액 (산식 + 결과)

Ⅲ. 수익환원법 (또는 거래사례비교법)
   1. 토지귀속순수익 산정
   2. 환원이율
   3. 산정가액

Ⅳ. 감정평가액 결정
   1. 각 방법에 의한 시산가액 비교
   2. 감정평가액의 결정 (시산조정 근거 + 최종가액)
```

### 2.3 20점 표준형 답안 구조 (14회 문제2 분해)

```
Ⅱ. [평가대상] 감정평가

   2. [방식별 산정 단계]
      가. 비교표준지 선정 / 사례 선정
      나. 시점수정
      다. 지역요인
      라. 개별요인
      마. 그밖의요인 보정
      바. 평가단가
   3. 평가가액

Ⅲ. 가격결정 의견
```

### 2.4 10점 약술/계산 답안 구조

## 3. 표준 표현 카탈로그 (Phrasebook)

기출에서 반복 사용되는 표현. 신규 문제 작성 시 그대로 또는 변형하여 사용.

### 3.1 평가개요 정형 (Ⅰ. 평가개요)

| 패턴 | 사용 시점 |

## 13. 작성 체크리스트 + 부적격 사례

### 13.1 작성 체크리스트

**문제 본문:**
- [ ] 시나리오 도입 ("감정평가사 K씨는 ○○로부터 ~ 의뢰받았다")
- [ ] 평가목적·기준시점·점수 명시
- [ ] 평가의뢰 부동산 상세 (소재지·면적·용도·도로·가격시점)
- [ ] 자료 [자료 01]~[자료 N] 번호 매김
- [ ] 난이도별 최소 자료 수 충족
- [ ] 시행규칙 등 법령 인용 자료 포함
- [ ] 단위 정밀도 명시 ("천단위 미만 절사")

**물음:**
- [ ] **완결된 명령문** ("~을 평가하시오", "~을 산정하시오")
- [ ] **주제 나열 금지**
- [ ] 평가 행위 동사 사용
- [ ] 점수 명시 (각 물음별)
- [ ] 해당 법령 인용 (시행규칙 §46 등)
- [ ] 평가 대상·행위가 명확

**모범답안:**
- [ ] **Ⅰ. 평가개요 / Ⅱ. 본건 평가 / Ⅲ. 가격결정** 구조
- [ ] **줄글(논술) 작성** — bullet 단독 사용 금지
- [ ] 처리방침 명시 (적용 법령 + 방식 선택 근거)
- [ ] 법령·법조문 구체 인용 (감정평가규칙 §14, 토지보상법 §70 등)
- [ ] 산식 + 인자 설명 (각 인자가 무엇인지)
- [ ] 단위 명시 (원/㎡, ㎡, 원)
- [ ] 가격결정 의견 (단순 숫자가 아닌 합리성 근거)
- [ ] 시산조정 (다방식 시) — 가중치 + 근거

**자체 검증:**
- [ ] 기출 11~36회 중 유사 주제 1개 이상 확인
- [ ] 채점 기준 명확화 (어디서 몇 점 받는지)
- [ ] 정답이 모호하지 않음 (시산결과 ±5% 이내 수렴)
- [ ] 법령 인용 정확 (조문 번호·내용 일치)
- [ ] 자료 모순 없음 (가격시점·사업인정일 등 시계열 일관성)

### 13.2 부적격 사례 (작성 즉시 폐기)

다음 조건 중 **하나라도 해당하면 작성 즉시 폐기**:

1. 본문 200자 미만 + 답안 400자 미만 (입문 약술 제외)
2. 물음이 주제 나열형 ("1. 토지평가 2. 건물평가")
3. 답안이 bullet만으로 구성 (Ⅰ-Ⅱ-Ⅲ 구조 없음)
4. 법령 인용 없음 (모든 평가는 법령 근거 필수)
5. 시나리오 없이 자료만 나열
6. 처리방침 누락
7. 가격결정 의견 누락
8. 시점수정·지역요인·개별요인·그밖의요인 중 하나라도 누락 (표준 이상 보상평가)
9. 산식만 있고 근거 설명 없음
10. 정답이 여러 가지 가능 (채점 불가)
