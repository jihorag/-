## 공통 구조 (모든 난이도)

기출은 다음 8요소로 구성:

1. **시나리오 도입**
   - "감정평가사 ○○씨는 ... 의뢰를 받고, 예비조사 및 실지조사를 한 후 다음과 같이 자료를 정리하였다."
   - 평가 목적·기준시점·평가가액 결정 의견 기술 요구

2. **평가의뢰 부동산 자료** (구조화된 표)
   - 소재지·지번·지목·면적·용도지역·도로조건·가격시점
   - 현지답사 내용 (자연환경·접도·이용상황)

3. **평가기초자료** (비준표·계수표)
   - 지가상승률 (연도별·일단위)
   - 용도지역별 토지가격 비준표
   - 이용상태별 비준표
   - 경사방향별·도로조건별 효용성 비교
   - 표준지 공시지가 내역

4. **사례·선례 자료** `[자료 01]`, `[자료 02]`, ...
   - 각 자료는 구체적 수치·표 포함
   - 거래사례 (소재지·거래시점·거래가·도로조건)
   - 임대 자료 (사용료·임대조건)
   - 건물 자료 (구조·연면적·신축연도·공사비)

5. **다중 물음** (번호 매김)
   ```
   1. 원가법에 의한 토지가격
   2. 거래사례비교법에 의한 토지가격
   3. 수익환원법에 의한 토지가격
   4. 공시가격에 의한 토지가격
   ```

6. **요구사항 명시**
   - "각 평가방식에 적용한 자료 선택의 주안점과 산출과정을 산식으로 표시하고"
   - "가격결정에 관한 의견을 기술한 후"
   - "㎡당 단가로 구하라"

7. **단위 정밀도**
   - "천단위 미만은 절사하시오"
   - "지가상승률 계산은 일단위로 계산할 것"
   - "총액비에 의한 배분율은 평점적수를 이용할 것"

8. **법령·기준 표기**
   - 토지보상법 §70, 시행규칙 §22 등 구체 명시

## 난이도별 차등 원칙

### 표준 (15~25점) — "1방식 종합 적용"

**본문 1,500~2,500자, 자료 3~5개, 물음 3~8개**

- 1개 평가방식의 종합 적용 (예: 공시지가기준법 전체)
- 시점수정·지역요인·개별요인·그밖의요인 모두 적용
- 단일 시나리오 (변동 없음)
- 산식 명시 + 단가·총액 산정
- 평가 능력: **표준 산식의 정확한 적용**

### 응용 (25~35점) — "다중 방식·시산조정"

**본문 2,500~4,000자, 자료 5~8개, 물음 8~16개**

- 2~3개 평가방식 적용 (원가·비교·수익 등)
- 시산조정 + 가중치 결정
- 다중 사례 (사례 3건 이상 보정)
- 의사결정 1단계 포함 (예: 시나리오 비교)
- 평가 능력: **다중 자료 통합·시산조정·판단**

### 고난도 (35~45점) — "복합 시나리오·종합 판단"

**본문 4,000자 이상, 자료 6개 이상, 물음 10개 이상**

- 3방식 시산조정 + 복합 부동산 (토지+건물+영업+권리)
- 보상 종합 (편입+잔여지+영업+이전+이주)
- 시나리오 분석 (낙관·중립·비관) + 판단 요구
- 단계별 계산 → 종합 → 의견 기술
- 평가 능력: **복합 종합·시나리오 분석·전체 의사결정**

## 답안 구조 (모범)

기출 답안은 다음 구조:

```markdown
## Ⅰ. 서론
- 평가 방식 선정 근거 (법령·규칙)
- 평가 목적·기준시점 확인

## Ⅱ. 본론
### 1. 비교표준지 선정
  - 적격 검토 + 채택 사례
### 2. 시점수정
  - 단계별 변동률 + 누계 (산식)
### 3. 지역요인
### 4. 개별요인 (6대 종합)
### 5. 그밖의요인 보정
### 6. 평가단가·평가총액

## Ⅲ. 결론
- 결정가액 명시
- 의견 기술

## ★ 핵심 학습 포인트
- 적용 산식·법령
- 실무 디테일
```

## 자료 구조 표준

| 자료 유형 | 구조 |
|-----------|------|
| **공시지가 / 비교표준지** | 표 (기호·소재지·면적·지목·용도지역·도로·공시지가) |
| **거래사례** | 표 + 부가설명 (시점·가격·사정 등) |
| **시점수정** | 연도별/월별 변동률 표 (사업영향 배제 명시) |
| **지역·개별요인** | 비준표 (대상 vs 사례 평점) |
| **건물 자료** | 구조·신축연도·공사비·내용연수·잔존가치율 |
| **수익 자료** | PGI·공실률·운영경비·환원율 (4방식 도출) |
| **그밖의요인 선례** | 시점환산 단가 표 (3~5건) |
| **시행규칙 인용** | §22·§24·§32·§46 등 구체 표기 |

## 평가 능력 본질 차등

| 난이도 | 평가하는 능력 | 산식 적용 | 의사결정 |
|--------|--------------|-----------|----------|
| 표준 | 산식 정확 적용 | 1방식 종합 | 없음 (단순 산정) |
| 응용 | 다중 자료 통합 | 2~3방식 시산 | 1~2단계 (시산조정) |
| 고난도 | 복합 종합·판단 | 3방식+시산조정 | 3+단계 (시나리오·전략) |

## 부적격 (불량 문제) 판정 기준

기존 문제 1,054개 삭제한 기준:
- 표준 본문 400자 미만 → 단순 산식 1단계 = **기초로 강등 또는 삭제**
- 응용 본문 800자 미만 → 자료 부족·물음 1~2개 = **삭제**
- 고난도 본문 1,500자 미만 → 시나리오 없음 = **삭제**

새 문제는 반드시 위 본문 길이·자료·물음 수 기준 충족.
