# 감정평가실무 문제 출제 원칙 (v2)

> 기출 11~36회 분석 기반. 사용자 피드백 반영(2026-05-29).

## 핵심 원칙

**감정평가실무는 논술형 시험이다.** 문제·자료·답안 모두 줄글이어야 하며, 채점 기준이 명확해야 한다.

### 절대 금지

- ❌ 물음을 주제 나열로 작성 ("1. 토지평가 2. 건물평가 ...")
- ❌ 답안을 bullet point만으로 구성
- ❌ 자료를 먼저 보여주고 물음을 뒤에 배치하는 어색한 구조
- ❌ 무엇을 묻는지 모호한 물음
- ❌ 채점 기준이 산식 결과만으로 환원되는 문제

### 필수 준수

- ✅ 물음은 완결된 의문문/명령문 ("~을 평가하시오", "~의 산정과정을 산식으로 표시하고 평가가액을 결정하시오")
- ✅ 답안은 줄글(논술) 구조 — Ⅰ.평가개요 / Ⅱ.본건 평가 / Ⅲ.가격결정
- ✅ 법령·법조문 명시적 인용 (토지보상법 §70②, 시행규칙 §22 등)
- ✅ 산정과정에 "처리방침" 명시 — 왜 이 방법을 쓰는지 근거 제시
- ✅ 자료는 표(table) 형식으로 구조화

## 기출 문제 구조 (11~36회 공통)

### 1. 문제 도입부 — 시나리오 제시

```
감정평가사 K씨는 ○○공사로부터 ○○사업에 편입되는 다음의 부동산에 대한
보상평가를 의뢰받았다. 다음 자료를 활용하여 토지에 대한 보상평가액과
지장물에 대한 보상평가액을 산정하시오. (40점)
```

- 의뢰인(누가) + 평가목적 + 평가대상 + 점수 명시
- 기준시점·평가가액 결정 의견 기술 요구가 명시되거나 자료에 포함됨

### 2. 자료 섹션 — [자료 01], [자료 02], ...

| 자료 종류 | 구조 |
|-----------|------|
| **평가의뢰 부동산** | 소재지·지번·지목·면적·용도지역·도로조건·가격시점·자연환경·이용상황 |
| **공시지가 / 비교표준지** | 표 (기호·소재지·면적·지목·용도지역·도로·공시지가) |
| **거래사례** | 표 + 사정·금융조건 부가설명 (시점·가격) |
| **시점수정** | 연도별/월별 변동률 표 (사업영향 배제 명시) |
| **지역요인** | 비준표 (대상 vs 사례 평점) |
| **개별요인** | 6대 조건(가로·접근·환경·획지·행정·기타) 비준표 |
| **건물 자료** | 구조·신축연도·공사비·내용연수·잔존가치율 |
| **수익 자료** | PGI·공실률·운영경비·환원율 |
| **그밖의요인 선례** | 시점환산 단가 표 (3~5건) |
| **시행규칙 인용** | §22·§24·§32·§46 등 구체 표기 |

### 3. 물음 — 완결된 문장형

기출 실제 표현:
- "물음1) 본건의 시점별 토지가격을 평가하시오"
- "물음2) 매수청구 인용 시 보상가액을 결정하시오"
- "물음3) 가격결정에 관한 의견을 기술하시오"
- "다음 자료를 활용하여 K아파트 3층 1호의 임료를 비교방식 및 원가방식으로 평가하시오. (20점)"
- "본건 토지에 대한 일반시가 평가액과 담보평가액을 각각 산정하시오"

물음은 평가의 **수행 행위**를 명령해야 한다:
- 평가하시오 / 산정하시오 / 결정하시오 / 검토하시오 / 약술하시오 / 논하시오 / 기술하시오

### 4. 모범답안 구조 — 논술 (줄글)

```markdown
## Ⅰ. 평가개요
본건은 ○○ 목적의 감정평가로서, ○○○○.○.○.을 기준시점
(토지보상법 §67①)으로 하여 각 물음에 답함.

## Ⅱ. 물음1) [구체적 평가내용]

### 1. 처리방침
공시지가기준법(감정평가규칙 §14)에 의하되, 거래사례비교법으로
합리성을 검토함.

### 2. 비교표준지 선정
가. 선정기준
   - 용도지역(일반상업) 동일
   - 이용상황(상업용) 동일
   - 도로조건(광대한면) 동일
나. 선정: 기호 #1 채택, #2~3는 도로조건 상이로 배제

### 3. 시점수정
2024.1.1. → 2025.7.1. 일단위 지가변동률
1.02540 × 1.03000 × (1+0.03000×56/91) = 1.07566

### 4. 지역요인 및 개별요인
지역요인: 인근지역이므로 1.000
개별요인: 도로조건 1.05 × 형상 1.00 × 지세 1.00 = 1.050

### 5. 그밖의요인 보정
보상선례 #가의 시점환산단가 등을 고려하여 1.30 적용

### 6. 평가단가 및 평가가액
3,000,000 × 1.07566 × 1.000 × 1.050 × 1.30 = @4,400,000
4,400,000 × 850㎡ = 3,740,000,000원

## Ⅲ. 가격결정 의견
본건 토지의 보상평가액을 3,740,000,000원으로 결정함.
```

## 난이도별 출제 원칙

### 입문 (1) — 5점 약술

| 항목 | 기준 |
|------|------|
| 본문 길이 | 30~80자 (개념 약술) |
| 자료 | 없음 또는 매우 간단 |
| 물음 | 1개, 개념 정의/요건/효과 |
| 답안 | 200~400자, 줄글 |
| 예시 | "공시지가기준법에서 그밖의요인 보정의 의의를 설명하고, 보상선례 참작 시 유의사항을 약술하시오. (5점)" |

### 기초 (2) — 10점 약술 또는 단순 계산

| 항목 | 기준 |
|------|------|
| 본문 길이 | 100~300자 |
| 자료 | 1~2개 (간단한 표) |
| 물음 | 1~2개 |
| 답안 | 400~800자, 줄글 + 산식 |
| 예시 | "다음 자료를 활용하여 비교표준지의 시점·지역·개별요인 보정 후 평가단가를 산정하시오. (10점)" |

### 표준 (3) — 15~25점 종합 1방식

| 항목 | 기준 |
|------|------|
| 본문 길이 | 800~1,500자 (시나리오 + 자료 도입) |
| 자료 | 3~5개 ([자료 01]~[자료 05]) |
| 물음 | 1~3개 (모두 완결문장) |
| 답안 | 1,500~3,000자, **반드시 줄글** |
| 능력 | 1방식의 종합 적용 (예: 공시지가기준법 전체) |
| 핵심 | 처리방침 → 자료 검토 → 산정 → 결정 의견 |

### 응용 (4) — 25~35점 다중 방식·시산조정

| 항목 | 기준 |
|------|------|
| 본문 길이 | 1,500~3,000자 |
| 자료 | 5~8개 |
| 물음 | 2~5개 |
| 답안 | 3,000~6,000자 |
| 능력 | 2~3방식 + 시산조정 + 의사결정 |
| 핵심 | 방식별 처리방침 차이, 시산조정 가중치 근거, 가격결정 의견 |

### 고난도 (5) — 35~45점 복합 시나리오

| 항목 | 기준 |
|------|------|
| 본문 길이 | 3,000~6,000자 |
| 자료 | 6개 이상, 표·그림·법령 인용 다수 |
| 물음 | 3~6개 |
| 답안 | 6,000~12,000자 |
| 능력 | 3방식 시산조정 + 복합부동산(토지+건물+영업+권리) + 시나리오 분석 + 종합 판단 |
| 핵심 | 단계별 처리방침 → 계산 → 종합 → 의사결정 자료 → 가격결정 의견 |

## 단원별 출제 영역

### 단원 2a — 3방식 기초 (공시지가·거래사례·원가)
- 공시지가기준법 종합 (비교표준지 선정, 시점·지역·개별·그밖의요인)
- 거래사례비교법 (사례 적격, 사정보정, 시점·요인 보정)
- 원가법 (재조달원가, 감가수정, 적산가액)
- 시산조정

### 단원 3 — 건물·복합·구분·임대료
- 건물 원가법 (구조별 단가, 정액·정률 감가)
- 복합부동산 (개별평가 vs 일괄평가)
- 구분소유 (집합건물, 층별효용비, 면적효용비)
- 임대료 (적산법·임대사례비교법·수익분석법)

### 단원 4 — 유형별 평가
- 농지·임야·골프장·공장·산업단지
- 종교용지·종중재산
- 공익시설용지 (학교·병원·도로)
- 광업권·어업권·신재생에너지

### 단원 5 — 비가치추계·기업가치·무형자산
- 시산조정 (자료 신뢰도, 시장변동, 가중치)
- 기업가치 (자산·수익·시장접근법, DCF, WACC, PER, EV/EBITDA)
- 무형자산 (특허·상표·영업권, Royalty Relief, MEEM, PPA, K-IFRS 38)

### 단원 6a — 토지보상 기본·원칙
- 정당보상 원칙 (헌법 §23③, 토지보상법 §70)
- 시점수정·지역요인·개별요인·그밖의요인 보정
- 보상선례 활용 (시행규칙 §22)
- 협의·재결·소송 단계별 평가

### 단원 6b — 공법상제한·특수 보상
- 도시계획시설 결정 (장기미집행 매수청구)
- 개발제한구역·자연공원·문화재보호구역
- 잔여지 손실·매수청구 (§73·§74)
- 미지급용지·환매권 (§62·§91)

### 단원 7 — 건축물·영업·기타 보상
- 건축물 (이전비 vs 가격, 시행규칙 §33)
- 영업손실 (휴업 §46, 폐업 §47, 영업권 §21)
- 농작물·영농 (§48·§54)
- 이주 (주거이전비 §54, 정착금 §54의2, 이사비 §55)
- 분묘 이장료 (§42)

### 단원 8a — 목적별 평가
- 담보평가 (LTV, DSCR, 권리분석, 처분 위험)
- 경매평가 (매각가, 배당 순위, 명도 위험)
- 국공유재산 (시가 × 5%, 매각·임대·교환)
- 소송평가 (분쟁 부동산)

### 단원 8b — 표준지·정비·불의타
- 표준지공시지가 (부공법 §3 적정가격)
- 정비사업 (종전·종후·비례율·권리가액·분담금)
- 도시정비법 §72·§74·§85
- 불의타 (화재·침수·풍수해, 손해배상·보험)

## 문제 작성 체크리스트

새 문제를 작성할 때 다음을 모두 만족해야 한다:

### 문제 본문
- [ ] 시나리오 도입 ("감정평가사 K씨는 ○○로부터 ~ 의뢰받았다")
- [ ] 평가목적·기준시점·점수 명시
- [ ] 평가의뢰 부동산 상세 (소재지·면적·용도지역·도로조건·가격시점)
- [ ] 자료가 충분 (난이도별 최소 개수 충족)
- [ ] 자료는 [자료 01]~[자료 N]으로 번호 매김

### 물음
- [ ] 완결된 문장 ("~을 평가하시오", "~의 산정과정을 산식으로 표시하시오")
- [ ] 주제 나열 금지 ("1. 토지평가 2. 건물평가" 같은 형식 금지)
- [ ] 평가 행위 동사 사용 (평가/산정/결정/검토/약술/논함)

### 모범답안
- [ ] Ⅰ. 평가개요 / Ⅱ. 본건 평가 / Ⅲ. 가격결정 구조
- [ ] 줄글(논술) 작성 — 단순 bullet 금지
- [ ] 처리방침 명시
- [ ] 법령·법조문 인용 (구체적 §)
- [ ] 산식과 함께 근거 설명
- [ ] 가격결정 의견 (단순 숫자가 아닌 합리성 근거)

### 부적격 (작성 즉시 폐기)
- 본문 200자 미만 (입문 약술 제외)
- 물음이 주제 나열형
- 답안이 bullet만으로 구성
- 법령 인용 없음
- 시나리오 없이 자료만 나열

## v1 시기 작성 문제 처리 방침

2024~2025 quality_*.py 스크립트로 생성된 문제 중 다수가 v1 기준이며, 다음과 같이 처리한다:

1. **유지 가능**: 완결문장 물음 + 줄글 답안 보유 문제
2. **재작성 필요**: 주제 나열 물음, bullet 답안 문제 → 점진적 교체
3. **폐기**: 본문 100자 미만 + 답안 200자 미만 부실 문제

기존 데이터를 일괄 변경하지 않고, 향후 신규 작성 분부터 v2 기준을 적용한다.
