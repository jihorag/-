## 2. 출제 매뉴얼 (작성 표준)

### 2.1 5지선다 발문 표준 형식

```
{주제명}에 관한 설명으로 옳지 않은 것은? (다툼이 있으면 판례에 따름)
```

- **첫 절**: `{주제}에 관한 설명으로`
- **끝 절**: `옳지 않은 것은?` (67.6%) ≫ `옳은 것은?` (16.7%)
- **단서**: `(다툼이 있으면 판례에 따름)` ← 85.8% 필수 부착
- 사례형의 경우: 사례 본문 + `다음 중 옳지 않은 것은? (…)`

### 2.2 쟁점당 25문항 구성 표준 (`mix_profile`)

`mix_profile`: **`case5-statute5-judge5-theory7-combo3`**

| 유형 | 수 | 설명 | 발문 길이 가이드 |
|---|---:|---|---|
| **사례형** (case) | 5 | 甲乙丙丁 등장 + 구체 금액·일자·부동산 | 100-160자 |
| **조문형** (statute) | 5 | 민법 제X조 요건·효과를 직접 묻기 (단어·요건·효과 1개 오답) | 40-55자 |
| **판례형** (judge) | 5 | 대법원 판례 입장 묻기 (`대판 YYYY.MM.DD, YYYY다XXXXX`) | 40-60자 |
| **이론형** (theory) | 7 | 학설·체계·구별 | 40-50자 |
| **결합형** (combo) | 3 | 옵션을 ㄱ·ㄴ·ㄷ·ㄹ 4개로 분해 후 조합 (ㄱ,ㄷ / ㄴ,ㄹ 등) | 40-60자 (옵션은 길어짐) |

### 2.5 정답 번호 분포 (쟁점당 25문)

기출 실측은 1~5번 거의 균등 (19-21%). 따라서:

| 정답 | 권장 수 |
|---:|---:|
| 1번 | 5 |
| 2번 | 5 |
| 3번 | 5 |
| 4번 | 5 |
| 5번 | 5 |

**중요**: 경제학 v2 처럼 "정답 1번 몰빵"은 민법에서 **금지**.
이유: 민법 기출 정답 분포가 균등하여 학습자 패턴 추정을 방해해야 함.

### 2.6 사례형 작성 템플릿

```
{등장인물} 甲은 {목적물(A토지·B건물 등)}의 {권리관계}에 관하여
{상대방} 乙과 {법률행위} 하였다. {추가 사실관계 1-2문}.
다음 중 옳지 않은 것은? (다툼이 있으면 판례에 따름)
```

**규칙**:
- 등장인물: 甲 → 乙 → 丙 → 丁 순 (4명 이내 권장)
- 목적물: 한글 부동산명 (`A토지`, `Y건물`, `X아파트 201호` 등)
- 금액: `1억 원`, `5천만 원` (한글 단위)
- 시점: `2024. 3. 1.` (감정평가사 출제 관례 마침표 4개)
- 발문 본문 100-160자 목표 (median 129자)

### 2.7 조문형 작성 템플릿

```
민법상 {제도명}에 관한 설명으로 옳지 않은 것은?
```

**옵션**: 5개 중 4개는 조문대로(정답), 1개는 조문을 변형
- 변형 패턴: **수치·기한 변경**, **요건 추가/누락**, **주체 바꿔치기**, **임의·강행 뒤집기**

### 2.8 판례형 작성 템플릿

```
{주제}에 관한 판례의 태도로 옳은 것은? (다툼이 있으면 판례에 따름)
```

**의무**: 해설에 **반드시** `대판 YYYY.MM.DD, YYYY다XXXXX` 인용.
판례 인용 형식 예:
- `대판 2003. 1. 10, 2002다63558`
- `대판(전합) 2017. 5. 18, 2012다86895`

### 2.9 결합형 (ㄱ·ㄴ·ㄷ·ㄹ) 작성 템플릿

```
{주제}에 관한 설명으로 옳은 것을 모두 고른 것은? (다툼이 있으면 판례에 따름)

ㄱ. {진술 1}
ㄴ. {진술 2}
ㄷ. {진술 3}
ㄹ. {진술 4}
```

**옵션 5개**: `① ㄱ ② ㄱ, ㄴ ③ ㄴ, ㄷ ④ ㄴ, ㄷ, ㄹ ⑤ ㄱ, ㄷ, ㄹ` 식 조합.

### 2.10 오답 선지 생성 5대 전략 (NRT: Negative Response Tactics)

1. **수치/기간 변경**: "10년" → "20년", "5년" → "3년"
2. **요건 누락/추가**: "선의·무과실" → "선의만" (제249조 선의취득)
3. **주체 뒤집기**: "채무자" → "물상보증인" (저당권)
4. **효과 정반대**: "이전한다" → "이전하지 않는다", "효력이 있다" → "효력이 없다"
5. **유사 제도 혼동**: 지상권 ↔ 전세권, 유치권 ↔ 동시이행항변권, 시효취득 ↔ 선의취득
