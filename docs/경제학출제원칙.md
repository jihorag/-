## B부. 연습문제 출제 원칙

### §7. 기본 형식 (v1 표준)

**필수 요건**:
- 5지선다 객관식 (4지선다 금지, 기출 표준 따름)
- 본문 30~250자 (난이도별 차등)
- 해설 100자 이상 (단계별 풀이 또는 정오 근거)
- `id` 형식: `practice-econ-{과목}-{관코드}-{N}`
- `source`: `"practice-set"` (기출과 구분)
- `tags.is_practice`: `true`
- `tags.question_type`: `계산문제` / `옳은 것 고르기` / `틀린 것 고르기` / `이론형` / `보기 결합형`

### §8. 본문 작성 규칙

**① 변수 정의 명시** (필수)
- 모든 변수는 `(단, …이다.)` 단서로 정의
- 예: `(단, Y는 국민소득, C는 소비, I는 투자이다.)`

**② 수식 표기**
- 본문 인라인: `TC = 4Q² + 160`
- 분수: `MR = dTR/dQ` 또는 `MR = ΔTR/ΔQ`
- 그리스 문자: `π, α, β, ε, σ` 그대로 사용
- 위첨자: `Q²` (Q의 2제곱)
- LaTeX는 해설에만 사용: `$MC = \frac{dTC}{dQ}$`

**③ 표 처리 (자료 제시형)**
- 마크다운 표 사용: `| 헤더 | 헤더 |`
- `[자료]`로 시작
- 3행 이상 자료가 있으면 표 권장

**④ 금지 사항**
- ❌ "다음 중 알맞은 것을 모두 고르시오" (보기 결합형은 `'ㄱ,ㄴ,ㄷ' 패턴`만 허용)
- ❌ 반말 종결 ("~인가?", "~지?")
- ❌ 변수 정의 누락
- ❌ 5개 미만 선택지

### §9. 선택지 작성 규칙

**① 길이 균형**
- 5개 선택지의 길이 차이 ±30% 이내
- 한 선택지만 유난히 길거나 짧으면 안 됨 (정답 힌트가 됨)

**② 단정형 문장**
- 명확한 평서문 ("X 가격이 상승한다.", "X 가격이 하락한다.")
- 모호한 표현 금지 ("X 가격에 영향을 미칠 수 있다.")

**③ 계산문제 오답 설계**
- 정답값을 중심으로 가까운 값 분포
- 흔한 오류 유발값 포함:
  - 부호 오류 (양수↔음수)
  - 단위 오류 (만원↔억원)
  - 공식 혼동 (한계비용↔평균비용)
  - 미분 누락 (적분 결과 그대로)

**④ 정답 위치**
- 1~5번 균등 분포 원칙 (전체 출제 기준)
- 한 단원 내 30문제라면 1~5번 각 6개씩

### §10. 해설 작성 규칙

**계산문제 해설 (필수 3단)**
```
① [기본 공식]: 적용 공식 명시
② [숫자 대입]: 수치 대입 과정
③ [최종 결과]: 답과 단위
```

**이론형 해설**
- 정답 근거: 핵심 이론·법칙 인용
- 오답 설명: 각 오답이 왜 틀렸는지
- 길이: 최소 100자

**LaTeX 사용 가능** (해설 한정):
- `$MC = \frac{dTC}{dQ} = 8Q$`
- `$P = MC \implies 32 = 8Q$`

### §12. 난이도별 출제 사례

**[난이도 1 - 기초]**
```
Q. 기회비용의 정의로 옳은 것은?
① 어떤 선택을 위해 포기한 차선의 가치
② 화폐로 지불한 모든 비용의 합계
③ 회계장부상 기록된 비용
④ 시장가격으로 평가된 자원의 가치
⑤ 매몰비용을 포함한 총비용
정답: ①
해설: 기회비용(opportunity cost)은 어떤 행동을 선택함으로써 포기해야 하는 차선책의 가치이다. 명시적 비용(회계적 비용)과 암묵적 비용을 모두 포함하나, 매몰비용은 제외된다.
```

**[난이도 2 - 쉬움]**
```
Q. 수요함수가 Q = 100 - 2P, 공급함수가 Q = 20 + 2P일 때 균형가격은?
(단, P는 가격, Q는 수량이다.)
① 10  ② 15  ③ 20  ④ 25  ⑤ 30
정답: ③
해설: 100 - 2P = 20 + 2P, 4P = 80, P = 20
```

**[난이도 3 - 보통]**
```
Q. 완전경쟁시장에서 어떤 기업의 단기총비용함수가 TC = Q² + 4Q + 100이고
가격이 24일 때, 이윤극대화 생산량과 단기이윤은?
(단, TC는 단기총비용, Q는 생산량, P=24이다.)
① Q=10, π=0       ② Q=10, π=-100
③ Q=12, π=12      ④ Q=12, π=-44
⑤ Q=8,  π=-68
정답: ②
해설:
① [한계비용] MC = 2Q + 4
② [P = MC] 24 = 2Q + 4 → Q = 10
③ [총수입] TR = 24 × 10 = 240
④ [총비용] TC = 100 + 40 + 100 = 240... 재계산
④' [총비용] TC = 10² + 4×10 + 100 = 100 + 40 + 100 = 240
⑤ [이윤] π = TR - TC = 240 - 240 = 0
→ 다시: Q = 10일 때 π = 0이므로 ①
```
(주의: 정답·해설 일관성 검수 필수)

**[난이도 4 - 어려움]**
```
Q. 개방경제 모형에서 다음 자료를 활용한 균형국민소득은?

[자료]
- 소비함수: C = 100 + 0.75(Y - T)
- 투자: I = 200
- 정부지출: G = 150
- 조세: T = 0.2Y
- 수출: X = 300
- 수입: M = 0.1Y

(단, Y는 국민소득, C는 소비, T는 조세이다.)
① 1,200  ② 1,500  ③ 1,800  ④ 2,000  ⑤ 2,250
정답: ②
해설:
Y = C + I + G + X - M
Y = 100 + 0.75(Y - 0.2Y) + 200 + 150 + 300 - 0.1Y
Y = 100 + 0.75 × 0.8Y + 650 - 0.1Y
Y = 750 + 0.6Y - 0.1Y
Y = 750 + 0.5Y
0.5Y = 750
Y = 1,500
```

**[난이도 5 - 최상]**
```
Q. 다음 IS-LM-BP 모형의 자본 완전이동 상황에서 변동환율제 하에 통화정책의 효과를 분석한 것으로 옳은 것은?

[설정]
- 자본이동 완전탄력
- 변동환율제도
- 단기 가격 경직성 (수직 LM에서 수평)
- 환율 e는 자국통화/외국통화

(단, 통화당국이 통화량을 확대하는 정책을 시행한다.)
① LM 우측이동 → 이자율 하락 → 자본유출 → e 상승 → 순수출 증가 → IS 우측이동 → 국민소득 큰 폭 증가
② LM 우측이동 → 이자율 하락 → 자본유출 → e 하락 → 순수출 감소 → IS 좌측이동 → 국민소득 불변
③ LM 좌측이동 → 이자율 상승 → 자본유입 → e 하락 → 순수출 감소 → IS 좌측이동 → 국민소득 감소
④ LM 우측이동 → 이자율 하락 → 자본유입 → e 하락 → 순수출 감소 → IS 좌측이동 → 국민소득 불변
⑤ LM 불변 → 이자율 불변 → e 불변 → 국민소득 불변

정답: ①
해설: 먼델-플레밍 모형에서 자본이동이 완전한 변동환율제 하 통화정책은 매우 효과적이다.
① 통화량 확대 → LM 우측이동
② 이자율 하락 압력 → 자본유출 (자국 → 해외)
③ 외환수요 증가 → 자국통화 절하 (e 상승)
④ 순수출 증가 (NX↑) → IS 우측이동
⑤ 국민소득은 LM·IS 양쪽 이동으로 크게 증가
→ 변동환율제 + 자본이동 완전 시 통화정책 효과 극대화 (재정정책은 무효)
```

### §13. 난이도 분류 알고리즘

문제 작성 후 다음 기준으로 자동 분류:

```python
def classify_difficulty(body_len, answer_len, calc_steps, models_used):
    # 본문 길이
    if body_len < 80:
        base = 1 if calc_steps == 0 else 2
    elif body_len < 150:
        base = 2 if calc_steps <= 1 else 3
    elif body_len < 250:
        base = 3
    elif body_len < 350:
        base = 4
    else:
        base = 5
    
    # 모형 결합 가산
    if models_used >= 2:
        base = max(base, 4)
    if models_used >= 3:
        base = 5
    
    # 보기 결합형(ㄱㄴㄷ)은 +1
    return base
```

```
예: practice-econ-micro-ch05-sec13-item02-001
    practice-econ-macro-ch04-sec09-item01-015
```

- `sub`: `micro` / `macro` / `intl` / `fiscal`
- `ch`: 장 번호 (`ch01`~`ch08`)
- `sec`: 절 번호 (`sec01`~`sec24`)
- `item`: 관 번호 (`item01`~`item04`)
- `seq`: 시퀀스 (`001`~`030`)

### §17. 앱 표시 규칙

- 기출: `[감정평가사 2024]` 등 시험명+연도
- 연습: `[연습문제]` + 난이도 뱃지 (★~★★★★★)
- 필터: "연습문제만" / "기출만" / "전체" 3가지 선택
