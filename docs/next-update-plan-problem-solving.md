# 문제풀이 보강 업데이트 계획

> 작성일 2026-06-06 · 근거: 합격수기 3회차 리서치 + 현 코드 갭 분석
> 범위: **문제풀이 영역**(1차 객관식 퀴즈 + 2차 논술 EssayMode + 둘러보기/검색/모의)

---

## 0. 한눈 요약

문제풀이의 "입력(문항)–풀이–피드백" 루프 중 **풀이 과정의 시간/전략**과 **풀이 후 피드백(왜 틀렸나·출제의도)**이 비어 있다. 합격 수기의 핵심("문제 선별=선구안", "출제자 의도 학습이 결정적", "계산 시간 관리")과 직결되는 지점이다. 1차는 **세션 타이머·문항당 시간·선구안·AI 해설**, 2차는 **모범답안·목차/백지 인출·타임드 완주**가 가장 큰 보강 기회.

**이미 추가된 것**(중복 제외): 오답 회독 모드, 검산 위젯, 셀프진단(안다/애매/모른다) 라벨, 해설 청각복습, 과목별 목표/버리기 보드, 메타인지 회독 타이머(현황), AI 채점(완주율·득점/감점), 2차 멀티과목 + 기출 전수.

---

## 1. 현재 상태

### 1차 객관식 (퀴즈/목록/둘러보기)
- 통일된 BrowseCard 진입(과목·둘러보기·드릴) → question_list → study(퀴즈)
- 문항: 5지선다 + 해설 + 북마크(중요/헷갈림/실수) + 셀프진단 라벨 + 해설 읽어주기 + (경제·회계) 검산 위젯
- 오답 회독 모드·SRS 복습·약점 통계

### 2차 논술 (EssayMode)
- 3과목(실무·이론·법규) 멀티과목, 기출 전수(이론 154·법규 128·실무 4045)
- 답안 작성 → 자기채점(키워드) + AI 채점(완주율·득점/감점, AI학습 탭)
- 모범답안: 실무만 있음, **이론·법규 비어 있음**

---

## 2. 갭 분석 (확인됨)

| 영역 | 현재 | 갭 |
|---|---|---|
| 퀴즈 세션 타이머·종료 요약 | 없음(회독 타이머는 현황에 별도) | **퀴즈 안에 시간·요약 없음** |
| 문항당 풀이시간 기록 | 없음 | 계산과목 time-sink 파악 불가 |
| 1차 question_list 필터 | 연도/번호 정렬만 | **난이도·오답만·북마크·신뢰도 필터 없음** |
| 풀이 후 피드백 | q.explanation 표시뿐 | **출제의도·함정·왜 틀렸나·AI 질문 없음** |
| 유사·변형 문제 | 없음 | 전이학습(같은 논점 변형) 없음 |
| 선구안(버릴/챙길) | 없음 | research 최우선 후보 |
| 2차 모범답안(이론·법규) | 비어 있음 | 자기채점만 가능 |
| 2차 목차/백지 인출 | 없음 | research 핵심 행동 |
| 2차 타임드 완주 모의 | 없음(MockExam=객관식) | 완주·시간배분 훈련 부재 |

## 3. 우선순위 백로그

### Tier 1 — 임팩트 大 · 난이도 小~中 (다음 업데이트 추천)

**T1. 퀴즈 세션 타이머 + 종료 요약 카드** · 1차 · 小
- study(퀴즈)에 경과 타이머 + 세션 종료 시 요약(푼 문항·정답률·평균 초/문·약점 단원·다음 추천). 기존 메타인지 타이머와 데이터 연계("시간 단축=숙달").
- 근거: 스톱워치 메타인지·회독 속도(3-0). 모듈: study 뷰 + studyMeta 타이머 로그.

**T2. 1차 목록 필터 강화** · 1차 · 小
- question_list에 **난이도·오답만·북마크·신뢰도(애매/모름)·미풀이** 필터(EssayMode 필터 UX 차용). 약점만 골라 풀기.
- 근거: 틀린 것만 재풀이·약점 집중(3-0). 모듈: question_list.

**T3. 풀이 후 "출제의도·왜 틀렸나" + 이 문제 AI에게 묻기** · 1차 · 中
- 채점 후 해설 옆에 **"🎯 출제의도·함정 보기"**(AI on-demand) + **"이 문제 질문하기"**(해당 문항을 AILearning으로 전달). 오답 시 "내가 고른 ②가 왜 틀렸나" 설명.
- 근거: 출제자 의도 학습이 결정적·해설강의로 의도 파악(3-0, research 핵심). 모듈: QuestionItem + AILearning 연결.

**T4. 2차 모범답안 채우기(이론·법규)** · 2차 · 中
- 이론 기출예해집 / 법규 GS 예시답안 PDF에서 추출·문항 정렬 → modelAnswer 채움. (검수 부담 있어 단계적: 빈출 단원 우선.)
- 근거: 모범답안 대조 학습·완주(3-0). 모듈: build_essay_pdf 확장.

### Tier 2 — 임팩트 大 · 난이도 中~大

**T5. 선구안(選球眼) 트레이너** · 신규 · 中 · research 최우선
- 기출에 '버릴 함정/챙길 득점' 태그 → 시간압박 하 버릴지/풀지 분류 훈련(경제 카르텔붕괴=버려, 솔로우=챙겨). 모의·문제풀이와 결합.
- 근거: "선별이 난도를 좌우"(high). 신규 학습축(전략 훈련).

**T6. 2차 목차 트레이너 + 백지 인출** · 2차 · 中
- 문제 → 목차만 입력 → 모범목차/누락 피드백(평가개요 빠짐 등). 백지 인출: 키워드만 → 전체 목차·조문·논점 공개 자가채점.
- 근거: 목차=2차 최중요·백지 인출(3-0). 모듈: EssayMode 모드 추가.

**T7. 2차 타임드 완주 모의** · 2차 · 中
- 과목당 100분 타이머 + 분량/목차 목표 + 완주율 측정 → AI 채점. MockExam의 2차판.
- 근거: 완주·시간배분(3-0).

**T8. 문항당 풀이시간 기록 + 시간배분 피드백** · 1차 · 中
- 문항별 소요시간 기록 → 느린 문항(계산과목) 표시·시간배분 통계(현황). T1과 연계.
- 근거: 경제 계산 time-sink·체감난도(high).

### Tier 3 — 보조/장기

- **유사·변형 문제 생성**(AI): 현재 문항의 논점을 바꾼 변형으로 전이 점검.
- **해설 없는 문항 AI 해설 on-demand**(1차 일부 미공개 정답/해설 보강).
- **이론 단원 배정 정교화**(현재 단원1 catch-all 42문 → 키워드/분류 개선).
- **모의고사 강화**: 선구안·완주·과목별 시간배분 리포트.

---

## 4. 추천 패키지 (Top 5)

> "1차 풀이 경험 3 + 2차 콘텐츠 2"로 빠른 출시.

1. **T1 퀴즈 세션 타이머·요약** (즉효, 메타인지 연계)
2. **T2 목록 필터 강화** (약점만 풀기, 저비용)
3. **T3 출제의도·왜 틀렸나 + AI 질문** (research 핵심, 차별화)
4. **T4 2차 이론·법규 모범답안** (2차 완성도)
5. **T5 선구안 트레이너** (신규 학습축, research 최우선)

→ 1·2는 기존 데이터/UX 재사용으로 비용 낮음. 3은 AI 연결. 4는 데이터 추출(검수). 5는 신규 모드.

---

## 5. 리서치 근거 매핑 (요약)
- 출제자 의도 학습 결정적 / GS 첨삭 약함→AI 첨삭 (T3) — round2·3
- 문제 선별=선구안이 난도 좌우 (T5) — round3 high(강사 총평)
- 메타인지 스톱워치·회독속도 (T1·T8) — round2
- 틀린 것만·약점 집중 (T2) — round1
- 목차·백지 인출·완주·모범답안 대조 (T4·T6·T7) — round1·2·3

> ⚠️ 개인 학습법 근거는 표본 1 일화 다수(일반화 주의). 출제 트렌드·선구안은 primary 강사 분석(high).
