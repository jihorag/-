# 전환율 감사 — 감정평가사 기출 PWA

> 관점: Linear / Superhuman / Vercel / Raycast / Arc를 픽셀 단위로 연구한, 전환율에 미친 창업자.
> 이 앱엔 "무료 체험 가입"이 없다. 그러므로 **전환 = 첫 방문자가 5초 안에 첫 문제를 풀고 "이거 쓸만하다"를 느끼는 것(활성화) + 다시 오는 것(리텐션)**.
> 결론 먼저: **이 앱은 단 하나의 가치(문제 풀고→해설로 이해)를 전달하기 전에, 포스터 → 모달 → 0으로 가득 찬 화면 → 4갈래 내비 선택을 강요한다. 첫 방문자는 "지금 뭘 해야 하지?"에 5초 안에 답하지 못하고 이탈한다.**

---

## PASS 1 — 디자이너 해부 (모든 시각적 결정)

- **배너 그라데이션 `#1e293b→#334155` + 흐린 파란 radial blob** = 전형적인 "AI가 짠 대시보드" 템플릿. Linear/Vercel은 진흙색 슬레이트 히어로를 쓰지 않는다. 50피트 밖에서 바이브 코딩 티가 난다.
- **`PROFESSIONAL APPRAISER EXAM`** — 한국 사용자용 앱에 영어 대문자 키커. 정보량 0, 순수 장식.
- **`banner-title`에 `linear-gradient(to right,#fff,#94a3b8)` 실버 그라데이션 텍스트** — 2021년 SaaS 클리셰. 즉시 제거.
- **배너 min-height 280px** — 폰 첫 화면의 ~35%를, 아무 행동도 못 하는 포스터에 낭비. 활성화에 치명적.
- **타이포 스케일 없음**: screen-title 1.4 / card-title 1.1 / q-text 1.125 / banner 2.25 — 모듈러 스케일 부재, 숫자가 즉흥적.
- **블루가 두 개**: 토큰은 `#2563eb`로 통일했지만 진행바·주요 버튼에 `#3b82f6`가 12곳 인라인으로 공존. 시스템이 아님.
- **그림자 3종**(`0 2px 8px/.05`, `--shadow-sm`, `--shadow-md`)·**라운드 6종**(8·10·12·14·16·999) 혼용. 리듬 없음.
- **study-card 정보 토사물**: badge + subtitle + title + "총 N·평균 X" + tag + progress + "학습 a/b" + "%" + 떠 있는 **"Q"** 원. 8개가 경쟁. "Q"는 정체불명 어포던스(로고? 버튼?).
- **로딩 화면**: 24MB JSON을 받는데 진행률·% 없이 포스터+스켈레톤+"불러오는 중…"만. 모바일 데이터에서 수 초 정적 → "고장났나?" 이탈. **첫 방문 단 한 번의 순간을 날린다.**
- **loadError 화면**: app-shell 밖, 브랜드 없음, 생 `#3b82f6` 버튼 → 다른 앱/크래시 페이지처럼 보임.
- **빈 상태**: 신규 사용자 첫 화면이 "오늘 목표 0/20", "🔥 0일", 죽은 진행바, 커버리지 전부 0, 시험별 0%. **0의 벽**. "여기서 시작" 단일 행동 없음.
- **하단 내비 이모지 아이콘 🏠📚🔁📊** — 바이브 코딩 1순위 신호. 기기별 렌더 제각각, 굵기 제어 불가. `lucide-react` 이미 의존성에 있는데 미사용.
- **"🔍 통합 검색·필터 (시험·과목·연도·난이도·키워드)"** 회색 고스트 버튼 — 스펙 나열 괄호. 기능이 아니라 placeholder처럼 보임.
- **온보딩**: 앱을 보기도 전에 모달이 솟구침. 3~4줄 문단 × 3. Arc/Superhuman이 명시적으로 피하는 패턴(가치 먼저, 맥락에서 교육).

## PASS 2 — 첫 사용자 클릭 동선 (혼란·이탈 지점)

- **0s** URL 진입 → 흰 화면 → 포스터 "감정평가사 1차 기출 완전정복 / 합격을 위한 최단기…". 스켈레톤. 24MB 다운로드. *"고장났나? 왜 안 떠?"* — 진행 표시 없음. **이탈 위험 #1.**
- **3s** 본 적 없는 화면 위로 온보딩 시트가 솟음. 문단 3개. *읽기 전에* "건너뛰기" 혹은 "다음 다음 시작" 난타. 학습량 0. 온보딩이 앱을 설명한 게 아니라 **앱을 못 보게 막았다.**
- **5s** 홈. 맨 위 "🎯 오늘의 목표 0/20", 빈 주간 점, "🔥 0일". *"아무것도 안 했는데 벌써 실패한 기분."* 아래 빠른시작 4개 중 뭘? "오늘의 추천"이 맞는 것 같지만 뭘 하는지 모름. 약점집중 없음(데이터 0). 진행 0/3000. 시험별 0%. **첫 화면 전체가 0. 명확한 "여기부터" 없음.**
- **~10s** "오늘의 추천" 탭 → 곧장 전체화면 문제. 동그라미 보기, 난이도 칩, "감정평가…▸…▸…" 브레드크럼, 이해 안 되는 🔀/⏩ 토글, **"키보드 1~5 보기"** 힌트(난 폰인데?). *"내가 지금 뭘 하는 거지? 무슨 시험? 내가 고른 거 맞아?"*
- 정답 후 일부 문항 "**정답 정보 없음 (채점 제외)**" → *"앱이 정답을 몰라? 고장?"* 신뢰 급락.
- 뒤로가기 → 본 적 없는 목록/홈으로. 예측 불가.
- 📚 둘러보기 → 회색 고스트 + 시험별/과목별/단원별/연도별 + Q 디스크 카드 격자. *"시험별과 연도별 차이? 단원별이 뭐? Q는 왜?"* 결정 마비. 기본 경로 없음.
- 복습 "없음" 막다른 길. 현황 전부 0/빈 차트.
- **순결과: 첫 사용자는 "뭘 먼저, 왜?"에 5초 안에 답 못 함 → 바운스.**

## 수정 우선순위

### 🔴 CRITICAL (바운스·활성화 킬러 — 지금 수정)

1. **콜드 스타트 로딩 재설계** — 24MB를 스트리밍해 **실제 % 진행률** + 안심 문구("최초 1회만 받으면 오프라인에서도 작동"). "고장났나" 이탈 차단.
2. **첫 실행은 포스터·모달 건너뛰고 즉시 가치** — 첫 방문자는 "지금 1문제 풀기" 단일 히어로 액션으로 착지. 온보딩 모달 제거(개념은 빈 상태 히어로에 압축 내장).
3. **빈 상태 홈에서 0의 벽 제거** — 활동 0이면 목표/연속/진행 0을 숨기고, 자신감 있는 단일 CTA + "30초 안에 첫 문제" 프레이밍.
4. **학습 진입 자기설명화** — 1줄 컨텍스트 헤더("추천 학습 · N문제 · 약점 위주") + 터치 기기에서 "키보드" 힌트 숨김.

### 🟠 HIGH-IMPACT (명확성·신뢰·완성도)

5. **배너 정리** — 실버 그라데이션 텍스트·영문 키커 제거, 높이 절반, 단일 블루.
6. **시각 시스템 통일** — 단일 블루(`#2563eb`, `#3b82f6` 박멸), 그림자 1종, 라운드 스케일, 모듈러 타이포. 내비 이모지 → lucide 아이콘.
7. **study-card 비우기** — 제목+총문제+진행만. 정체불명 "Q" → 명확한 "풀기". 세그먼트 탭 1줄 설명.
8. **loadError 브랜드화** — app-shell 안, 차분하게.
9. **"정답 정보 없음" 카피 재프레이밍** — 결함이 아니라 의도("공식 정답 미공개 문항 · 채점 없이 학습용").

### 🟢 NICE-TO-HAVE

10. 온보딩 → 탭별 첫 진입 시 맥락 툴팁.
11. 하단 내비 활성 인디케이터 굵기/위계.
12. 검색 고스트 버튼 → 라벨 있는 실제 진입점.
13. spacing 스케일 토큰 전면 적용.
