#### 05. 수요의 증가⋅감소 / 공급의 증가⋅감소

(1) 수요의 변화 요인

```
               수요의 증가 요인              수요의 감소 요인
```

∙ 인구 증가 ∙ 시장이자율⋅대출금리 하락 ∙ LTV⋅DTI 상승 ∙ 소득의 증가(정상재) ∙ 대체부동산의 가격 상승 ∙ 보완부동산의 가격 하락 ∙ 주택거래규제의 완화 ∙ 미래가격 상승에 대한 기대

① 소비자의 실질소득이 증가하면, 주택의 수요는 증가한다.
② 아파트와 대체관계에 있는 오피스텔의 가격이 상승하면, 아파트의 수요곡선은 우측으로 이동 하게 된다.

③ 대부비율(LTV)이 하락하면, 아파트의 수요는 감소한다.
④ 주택의 거래세가 인상되면, 주택의 수요곡선은 좌측으로 이동하게 된다.

```
⑤ 대부비율(LTV)이 상승하면, (       ), 아파트의 가격은 상승한다.
```

(2) 공급의 변화 요인

```
               공급의 증가 요인              공급의 감소 요인
```

∙ 주택건설업자 수의 증가 ∙ 건축(건설)기술의 진보 ∙ 생산요소 가격의 하락 ∙ 건축원자재 가격의 하락 ∙ 건축허가 요건의 완화

① 건설기술의 진보로 인한 생산성이 향상되면, 주택의 공급을 증가시킨다.
② 건설 노동자의 임금이 하락하면, 주택의 공급곡선은 우측으로 이동하게 된다.

```
③ 건축 원자재 가격이 상승하면, (        ), 주택의 가격은 상승할 수 있다.
```

#### 06. 균형을 변화시키는 4가지 규칙

```
                        구분    균형 가격   균형 거래량

                       수요증가    상승      증가

      가격 이외            수요감소    하락      감소
                   ⇨
      요인의 변화           공급증가    하락      증가

                       공급감소    상승      감소
```

(1) 수요와 공급이 동시에 변화하는 경우(힘의 크기가 주어지지 않은 경우)

① 수요가 증가하면서 동시에 공급이 증가하면, 균형 가격의 변화는 알 수 없고 균형 거래량은 증가한다.

② 수요가 증가하면서 동시에 공급이 감소하면, 균형 가격은 상승하고 균형 거래량의 변화는 알 수 없다.

③ 수요가 감소하면서 동시에 공급이 증가하면, 균형 가격은 하락하고 균형 거래량의 변화는 알 수 없다.

④ 수요가 감소하면서 동시에 공급이 감소하면, 균형 가격의 변화는 알 수 없고 균형 거래량은 감소한다.

주의(정답을 찾는 요령)

① 문제가 되는 것이 가격인지? 거래량인지? 확인한다.
② 문제가 되는 논점 : ‘알 수 없다’ 또는 ‘수요와 공급의 변화 폭에 의해 결정된다’

(2) 알 수 없다(= 수요와 공급의 힘의 크기로 결정된다).

⑤ 수요가 증가하면서 동시에 공급이 증가하였다면, 균형 가격의 변화는 수요와 공급의 변화 폭에 의해 결정된다. (=균형 가격의 변화는 알 수 없다.)

⑥ 수요가 증가하면서 동시에 공급이 감소하였다면, 균형 거래량의 변화는 수요와 공급의 변화 폭에 의해 결정된다. (=균형 거래량의 변화는 알 수 없다.)

(3) 수요와 공급이 동시에 변화하는 경우(힘의 크기가 주어진 경우)

⑦ 수요의 증가가 공급의 증가보다 크다면, 균형 가격은 상승하고 균형 거래량은 증가한다.
⑧ 공급의 증가가 수요의 증가보다 크다면, 균형 가격은 하락하고 균형 거래량은 증가한다.

⑨ 수요의 증가 폭과 공급의 증가 폭이 동일하다면, 균형 가격은 불변이다.

### Chapter 06. 수요와 공급의 탄력성

#### 01. 탄력성의 이해

```
                   의미      양의 변화 정도(%)를 측정하는 지표
         탄력성               ∙ 수요의 탄력성 : 수요량의 변화 정도(%)를 측정하는 지표
```

구분 ∙ 공급의 탄력성 : 공급량의 변화 정도(%)를 측정하는 지표

```
                   탄력적     ‘양’의 변화 정도가 많다.
         해석
                   비탄력적    ‘양’의 변화 정도가 적다.
```

```
① 수요의 가격탄력성이            탄력적이라면, 가격의 변화율보다 수요량의 변화율이 보다 크다.
```

② 수요의 가격탄력성이 비탄력적이라면, 가격의 변화율보다 수요량의 변화율이 보다 적다.

```
③ 수요의 가격탄력성이 완전           탄력적이라면, 가격 변화에 수요량이 무한대( ∞ )로 변화한다.
```

④ 수요의 가격탄력성이 완전 비탄력적이라면, 가격이 변화하더라도 수요량은 고정된다.

#### 02. 수요의 탄력성

수요량 변화율(%)
```
                     의미     수요의 가격 탄력성 =
                                                 가격 변화율(%)

                            완전비탄력적       단위탄력적                   완전탄력적

 수요의 가격 탄력성                       비탄력적                     탄력적

                     구분                                                  ∞
                              0            1           2
```

∙ 수요의 가격탄력성은 0 또는 양수(+)의 값으로 측정된다. ∙ 1을 기준으로, 1보다 크면 탄력, 1보다 작으면 비탄력

수요량 변화율(%)
```
                     의미     수요의 소득 탄력성 =
```

소득 변화율(%) 수요의 소득 탄력성 ∙ 양수(+) 값 : 정상재 특징 ∙ 음수(-) 값 : 열등재

수요량 변화율(%)
```
                   의미      수요의 교차 탄력성 =
```

다른 재화의 가격 변화율(%) 수요의 교차 탄력성 ∙ 양수(+) 값 : 대체관계 특징 ∙ 음수(-) 값 : 보완관계

#### 03. 공급의 탄력성

공급량 변화율(%)
```
                   의미      공급의 가격 탄력성 =
```

가격 변화율(%) 공급의 가격 탄력성 ∙ 공급의 가격탄력성은 0 또는 양수(+)의 값으로 측정된다. 구분 ∙ 1을 기준으로, 1보다 크면 탄력, 1보다 작으면 비탄력

#### 04. 탄력성을 결정하는 요인

```
          수요가 보다 탄력적인 경우                    공급이 보다 탄력적인 경우

∙ 대체재가 많을수록                         ∙ 생산에 유리한 상황일수록
 ㉠ 부동산 시장을 세분할수록                     ㉠ 생산에 소요되는 기간이 짧을수록
 ㉡ 부동산의 분류 범위가 좁을수록                  ㉡ 생산비가 감소할수록
 ㉢ 용도변경이 용이할수록                       ㉢ 용도변경이 용이할수록

∙ 측정 기간이 장기일수록                      ∙ 측정 기간이 장기일수록
```

#### 05. 탄력성과 기울기

```

             완전 비탄력적         비탄력적            탄력적          완전 탄력적
```

### Chapter 01 경제론의 기본개념

> 📖 경제론의 문법을 정하는 관이다. **수요량의 변화와 수요의 변화**를 구별하지 못하면 이 단원 전체가 무너진다.
> 그리고 **유량(flow)과 저량(stock)** 은 매년 다른 단원(투자론·시장론)에서도 계속 쓰인다.

> ⭐ **이 관에서 반드시 챙길 3가지**
> ① 원인이 ==해당 재화의 가격==이면 "==량==의 변화"(곡선 **위** 이동), ==가격 이외 요인==이면 "수요·공급의 변화"(곡선 **자체** 이동).
> ② 유량은 ==일정 기간==, 저량은 ==일정 시점==. ==가격·자산가치·재고량·인구 규모==는 저량이다.
> ③ 수요는 ==유량==이고, ==사전적(계획된)== 개념이며, 구매력을 갖춘 ==유효수요==다.

| 구분 | 측정 | 사례 |

| ==유량== | ==일정 기간== | 가계소득·급여·월급·연봉 / ==임대료 수입·지대 수입== / 연간 이자비용 / ==순영업소득·당기순이익== / ==수요량·공급량== / 신규주택 공급량·아파트 생산량 / ==거래량== / 수출·수입·소비·투자 |
| ==저량== | ==일정 시점== | ==가격== / 실물자산·==자산가치== / ==도시 인구 규모== / ==주택 재고량== / 통화량·자본량·부채·외환보유고 |

> 🔑 판별법: **"1년 동안"을 붙여 말이 되면 유량, "○월 ○일 현재"를 붙여야 말이 되면 저량.**
> ⚠️ **가격은 저량**이다. "가격은 기간 개념이므로 유량"이라는 선지가 자주 나온다.

#### 3. 수요·공급의 의미

| 구분 | 의미 | 특징 |
|---|---|---|
| 수요 | 일정 기간 소비자들이 재화를 ==구매하고자 하는 욕구== | ==유량== 개념 / ==사전적(계획된)== 수량 / 구매력을 갖춘 ==유효수요== |
| 공급 | 일정 기간 공급자들이 재화를 ==판매하고자 하는 욕구== | 유량 개념 / 사전적 수량 / ==유효공급== |

- ==수요의 법칙==: 다른 조건이 일정할 때 가격이 상승하면 수요량 감소, 하락하면 수요량 증가 → 수요곡선은 ==우하향==.
- ==공급의 법칙==: 가격과 공급량은 ==정(+)의 관계== → 공급곡선은 ==우상향==.

**수요곡선이 우하향하는 이유**

| 근거 | 내용 |
|---|---|
| ==기회비용== | 임대료가 오르면 같은 공간을 쓰기 위해 다른 재화의 사용을 희생해야 한다 |
| ==소득효과== | 가격 상승 = 실질소득 감소 → 소비량 감소 |
| ==대체효과== | 가격이 오른 재화의 소비를 줄이고 대체재로 이동 |
| (소득효과+대체효과 = ==가격효과==) | 둘을 합한 합성효과 |

**수요법칙의 예외**

| 예외 | 내용 |
|---|---|
| ==가수요== | 가격이 오를 것으로 예상될 때 오히려 늘어나는 수요 |
| ==기펜재== | 가격이 하락할 때 수요량이 ==감소==하는 재화 |
| ==베블렌 효과== | 가격 상승 시 수요량이 증가하는 ==과시성 소비== |

#### 4. 개별곡선과 시장곡선 — 수평적 합계

- 시장수요곡선은 개별수요곡선의 ==수평적 합계==로 도출한다. 반드시 ==Q에 대하여 정리한 뒤== 더한다.
- 일반적으로 시장수요곡선은 개별수요곡선보다 ==완만(더 탄력적)==하다. 공급도 같다.

> ✏️ **예시(기본서)** 甲의 수요함수 $q = 40 - 2P$, 乙의 수요함수 $q = 30 - 3P$
> → 시장수요함수 $Q = (40-2P) + (30-3P) = 70 - 5P$.
> ⚠️ P에 대해 정리된 식(예: $P = 20 - 0.5q$)을 그대로 더하면 **틀린다.** 반드시 Q 형태로 바꾼 뒤 더하라.

#### 5. 부동산 공급의 특징

| 논점 | 내용 |
|---|---|
| 재고와 신규 | 내구성 때문에 ==신규건설 부동산 + 재고 부동산==이 함께 공급된다 |
| 공급 시차 | 생산에 장기간이 걸려 ==시차==가 발생한다 → ==거미집 이론==의 전제 |
| 물리적 공급 | 지표 총량. ==인위적 증가 불가== → 공급곡선 ==완전비탄력적== |
| ==경제적 공급== | 개발, 토지이용의 ==집약화==, ==용도전환==, 공법상 ==규제 완화==, 세필화, 교통체계 건설 등 → ==가능== |
| 주택 저량·유량 | 저량 공급량 = ==일정 시점==의 주택량(고정) / 유량 공급량 = ==일정 기간== 공급되는 양(신축으로 증가 가능) |
| 단기·장기 공급곡선 | 단기(저량) = ==수직(완전비탄력적)== / 장기(유량) = ==우상향(더 탄력적)== |

#### ⭐ 기출 출제포인트

- **"수요량"과 "수요"의 단어 하나**로 정답이 갈린다. 지문을 읽을 때 원인이 가격인지부터 보라.
- **유효수요**(구매의사 + 지불능력)는 가치발생요인 문항에서도 그대로 출제된다(2020 제31회 36번 ①).
- 부동산 공급량은 "주어진 가격 수준에서 일정기간에 ==판매하고자 하는== 최대수량"이다(2024 제35회 22번 ②, 옳은 지문).

#### 📊 기출 분석

| 연도·회차 | 출제 형태 | 핵심 논점 |
|---|---|---|
| 2020 제31회 36 | 옳지 않은 것 | ==유효수요==(구입의사+지불능력), 효용, 상대적 희소성, 이전성 |
| 2024 제35회 22 | 옳지 않은 것 | 단기 공급의 비탄력성, 공급량의 정의, 장기의 탄력성 증가, ==수요량=유효수요== |

#### 🔍 문항으로 배우는 논점

> 자체 연습문항의 선지를 놓고 O/X와 이유를 확인한다.

**①** 가격 변화로 수요곡선 위에서 점이 이동하는 것을 수요량의 변화라 한다. — **O** / 근거: 원인이 해당 재화의 가격이면 언제나 '량'의 변화다. `practice-re-p02c05s01-L1-01`
**②** 아파트 가격이 상승하면 아파트 수요가 감소한다. — **X** / 어디가 틀렸나: ==수요량==의 감소다. 수요(곡선) 자체는 이동하지 않는다. `practice-re-p02c05s01-L2-01`
**③** 연봉·월급·임대료 수입은 일정 기간을 설정해야 측정되는 유량이다. — **O** / 근거: 유량의 대표 사례군이다. `practice-re-p02c05s01-L2-09`
**④** 주택재고량은 유량이다. — **X** / 어디가 틀렸나: 특정 ==시점==의 양이므로 ==저량==이다. `practice-re-p02c05s01-L3-05`
**⑤** 수요량·공급량은 저량 개념이다. — **X** / 어디가 틀렸나: 일정 기간을 전제하므로 ==유량==이다. `practice-re-p02c05s01-L4-07`
**⑥** 소비자 소득의 증가는 수요의 변화 요인이고, 건축원자재 가격 상승은 공급의 변화 요인이다. — **O** / 근거: 둘 다 해당 재화의 가격이 아닌 요인이다. `practice-re-p02c05s01-L3-13`
**⑦** 자산가치는 일정 시점에 평가하는 저량이다. — **O** / 근거: 가격·자산가치는 모두 저량이다. `practice-re-p02c05s01-L2-09`
**⑧** 수요곡선이 이동하면 반드시 균형 가격이 변한다. — **O**(원칙) / 단, ==공급이 완전탄력적==이면 가격은 불변이다. 극단적 시장은 예외라는 점을 함께 기억하라. `practice-re-p02c05s01-L4-07`

#### ✏️ 대표 예제

> **문제** 甲의 수요함수가 $q = 40 - 2P$, 乙의 수요함수가 $q = 30 - 3P$일 때 시장수요함수는? 또한 P = 5일 때 시장수요량은?

**풀이**
1. 두 식이 이미 **Q에 대해 정리**되어 있는지 확인한다 → 되어 있다.
2. 수평합: $Q = (40 - 2P) + (30 - 3P) = 70 - 5P$.
3. $P = 5$ 대입: $Q = 70 - 25 = 45$.
4. **검산** — 甲 $40 - 10 = 30$, 乙 $30 - 15 = 15$, 합 45. 일치.
→ 시장수요함수 $Q = 70 - 5P$, 시장수요량 **45**.

#### ⚠️ 이 관의 함정 총정리

1. "가격 하락으로 수요가 증가했다"라고 하면 틀림 → ==수요량==의 증가다.
2. "소득 증가로 수요량이 증가했다"라고 하면 틀림 → ==수요==의 증가(곡선 우측 이동)다.
3. "가격은 일정 기간을 두고 측정하므로 유량이다"라고 하면 틀림 → ==저량==이다.
4. "부동산의 물리적 공급이 불가능하므로 경제적 공급도 불가능하다"라고 하면 틀림 → ==경제적(용도적) 공급은 가능==하다.
5. "시장수요함수는 개별수요함수를 수직으로 합해 구한다"라고 하면 틀림 → ==수평적 합계==(Q 기준 합)다.

#### ✅ OX 확인문제

> 다음 진술의 참·거짓을 판단하시오.

**1.** 수요의 변화는 수요곡선 자체의 이동으로 나타난다.
→ **O**. 우측 이동이 증가, 좌측 이동이 감소다.

**2.** 수요량의 변화는 해당 재화의 가격 변화가 원인이다.
→ **O**. 곡선 위에서 점만 움직인다.

**3.** 순영업소득과 당기순이익은 저량 변수다.
→ **X**. 일정 기간에 발생하므로 ==유량==이다.

**4.** 도시의 인구 규모는 저량 변수다.
→ **O**. 특정 시점의 크기다.

**5.** 수요는 구매력을 갖춘 유효수요를 의미한다.
→ **O**. 구매의사만으로는 수요가 아니다.

**6.** 공급은 실제로 판매한 양이 아니라 판매하려는 사전적·의도된 양이다.
→ **O**. 수요도 마찬가지로 사전적 개념이다.

**7.** 기펜재는 가격이 하락할 때 수요량이 증가하는 재화다.
→ **X**. ==감소==하는 재화다. 수요법칙의 예외다.

**8.** 베블렌 효과는 가격이 상승할 때 수요량이 증가하는 과시성 소비를 말한다.
→ **O**. 가수요·기펜재와 함께 수요법칙의 예외다.

**9.** 시장수요곡선은 개별수요곡선보다 일반적으로 더 탄력적(완만)이다.
→ **O**. 수평으로 합해지기 때문이다.

**10.** 주택의 단기공급곡선은 완전비탄력적이고, 장기공급곡선은 우상향한다.
→ **O**. 저량공급과 유량공급의 차이다.

#### 🧠 암기법

> 🔑 **"가격이면 량, 그 외면 곡선"** — 원인이 ==가격==이면 "수요==량==", 가격 ==이외==면 곡선 자체가 움직인다.

> 🔑 **"기간은 유, 시점은 저"** — ==기==간→==유==량 / ==시==점→==저==량. 헷갈리면 "1년 동안"을 붙여 보라.

> 🔑 **수요법칙 예외 "가·기·베"** — ==가==수요, ==기==펜재, ==베==블렌 효과.

### Chapter 02 수요와 공급이론 / 제1절 수요와 공급

> 📖 **무엇이 수요를 움직이고 무엇이 공급을 움직이는가**를 정리하는 관이다.
> 문제는 항상 "다음 중 아파트 수요를 증가시키는 요인은?" 형태로, ==수요량의 변화==나 ==공급의 변화==를 섞어 놓고 골라내게 한다.

> ⭐ **이 관에서 반드시 챙길 3가지**
> ① 대체재는 ==교차탄력성 양수==(A가격↑ → B수요↑), 보완재는 ==교차탄력성 음수==(A가격↑ → B수요↓).
> ② 수요 증가 요인의 핵심은 ==인구 증가·소득 증가(정상재)·금리 하락·LTV/DTI 상승·대체재 가격 상승·보완재 가격 하락·가격 상승 기대==.
> ③ 가격 상승 기대는 ==신규건설시장에서는 공급 증가==, ==기존주택시장에서는 공급 감소==로 갈린다.

#### 1. 연관재 — 대체재·보완재·독립재

| 관계 | 정의 | 결과 | 교차탄력성 |
|---|---|---|---|
| ==대체재== | 서로 대신 소비할 수 있는 관계(콜라·사이다) | A 가격 ==상승== → B 수요 ==증가== | ==양수(+)== |
| ==보완재== | 함께 소비할 때 효용이 커지는 관계(치킨·맥주) | A 가격 ==상승== → B 수요 ==감소== | ==음수(−)== |
| 독립재 | 서로 영향이 없는 관계 | B의 수요곡선 불변 | ==0== |

**대체재·보완재 6문장 (강의노트 그대로)**

| 대체(콜라-사이다) | 보완(치킨-맥주) |
|---|---|
| 콜라 수요 증가 → 사이다 수요 ==감소== | 치킨 수요 증가 → 맥주 수요 ==증가== |
| 콜라 수요 감소 → 사이다 수요 ==증가== | 치킨 수요 감소 → 맥주 수요 ==감소== |
| 콜라 가격 상승 → 사이다 수요 ==증가== | 치킨 가격 상승 → 맥주 수요 ==감소== |
| 콜라 가격 하락 → 사이다 수요 ==감소== | 치킨 가격 하락 → 맥주 수요 ==증가== |
| 콜라 가격 상승 → 사이다 가격 ==상승== | 치킨 가격 상승 → 맥주 가격 ==하락== |
| 콜라 가격 하락 → 사이다 가격 ==하락== | 치킨 가격 하락 → 맥주 가격 ==상승== |

> 🔑 **대체는 같은 방향(가격↑→가격↑), 보완은 반대 방향(가격↑→가격↓).** 마지막 두 줄이 함정으로 자주 쓰인다.

> 📌 소득과의 관계: ==정상재==(소득↑ → 수요↑), ==열등재==(소득↑ → 수요↓), ==중간재==(소득이 변해도 수요량 불변).

#### 2. 수요의 변화 요인

| 수요 증가 요인 | 수요 감소 요인 |
|---|---|
| ==인구 증가==, 핵가족화·가구 수 증가 | 인구 감소 |
| 시장이자율·대출금리 ==하락== | 금리 ==상승== |
| ==LTV·DTI 상승==(대출규제 완화) | LTV·DTI 하락 |
| ==소득 증가==(정상재) | 소득 감소(정상재) |
| ==대체 부동산의 가격 상승== | 대체 부동산의 가격 하락 |
| ==보완 부동산의 가격 하락== | 보완 부동산의 가격 상승 |
| 주택거래규제 완화, ==거래세 인하== | 거래세 인상, 규제 강화 |
| ==미래 가격 상승에 대한 기대== | 미래 가격 하락에 대한 기대 |
| 기호·선호의 증가, 광고 증가 | 기호·선호의 감소 |

#### 3. 공급의 변화 요인

| 공급 증가 요인 | 공급 감소 요인 |
|---|---|
| ==주택건설업자 수의 증가== | 건설업자 수 감소 |
| ==건축(건설)기술의 진보== | — |
| ==생산요소 가격의 하락==(건설 노동자 임금 하락) | 생산요소 가격 상승 |
| ==건축원자재 가격의 하락== | ==건축원자재 가격의 상승== |
| ==건축허가 요건의 완화== | 건축허가 요건의 강화 |

> ⚠️ **아파트 가격의 상승·하락은 공급"량"의 변화**다. 공급곡선을 이동시키는 요인이 아니다.

#### 4. 가격 변화 기대의 효과 — 시장별로 갈린다

| 기대 | 수요 | 신규 건설시장의 공급 | 기존 주택시장의 공급 |
|---|---|---|---|
| 가격 ==상승== 기대 | ==증가== | ==증가==(지으면 남으니까) | ==감소==(안 팔고 기다린다) |
| 가격 ==하락== 기대 | ==감소== | ==감소== | ==증가==(먼저 팔자) |

#### ⭐ 기출 출제포인트

- 선지에 **"○○ 가격의 하락/상승"** 이 있으면 그것은 대개 ==량==의 변화다. 정답에서 제외된다.
- **건축원자재 가격**은 언제나 ==공급== 쪽 요인이다. 수요 요인 문항에 섞여 나오면 오답.
- **LTV·DTI**의 방향을 반대로 서술하는 함정이 흔하다. 규제 비율이 ==올라가면 대출이 늘어== 수요가 증가한다.

#### 🔍 문항으로 배우는 논점

> 자체 연습문항의 선지를 놓고 O/X와 이유를 확인한다.

**①** 함께 소비할 때 효용이 증가하고, 한 재화의 가격이 오르면 다른 재화의 수요도 감소하는 관계를 보완재라 한다. — **O** / 근거: 보완재의 정의다. `practice-re-p02c05s02-L1-01`
**②** 대체재 관계에서 A의 가격이 하락하면 B의 수요는 증가한다. — **X** / 어디가 틀렸나: 소비자가 싸진 A로 옮겨가므로 B의 수요는 ==감소==한다. `practice-re-p02c05s02-L2-05`
**③** 보완재 관계에서 A의 수요가 증가하면 B의 수요도 증가한다. — **O** / 근거: 함께 소비되기 때문이다. `practice-re-p02c05s02-L2-05`
**④** 시장이자율 하락은 수요 증가 요인, 건축원자재 가격 상승은 공급 감소 요인, 취득세 인하는 수요 증가 요인이다. — **O** / 근거: 세 요인의 방향이 모두 표준이다. `practice-re-p02c05s02-L3-07`
**⑤** 인구·가구 수의 증가는 공급 증가 요인이다. — **X** / 어디가 틀렸나: ==수요== 증가 요인이다. 사람이 늘면 사려는 쪽이 늘어난다. `practice-re-p02c05s02-L4-05`
**⑥** 건설기술의 진보는 공급 증가 요인이다. — **O** / 근거: 같은 비용으로 더 많이 지을 수 있다. `practice-re-p02c05s02-L4-05`
**⑦** 원격근무 확산으로 오피스 수요가 감소하고 동시에 신규 공급도 감소하면, 거래량은 반드시 감소하고 가격은 알 수 없다. — **O** / 근거: 수요 감소 + 공급 감소 → ==거래량 감소 확정, 가격 불확정==. `practice-re-p02c05s02-L5-04`
**⑧** 대부비율(LTV)이 하락하면 아파트 수요는 증가한다. — **X** / 어디가 틀렸나: 대출 가능액이 줄어 ==수요는 감소==한다. `practice-re-p02c05s02-L3-13`

#### ✏️ 대표 예제

> **문제** 다음 중 아파트 시장의 **수요를 증가**시키는 요인을 모두 고르면?
> ① 아파트 가격의 하락 ② 건축원자재 가격의 상승 ③ 핵가족화로 인한 가구 수 증가
> ④ LTV·DTI의 하락 ⑤ 시장이자율의 상승 ⑥ 미래 가격 상승에 대한 기대 ⑦ 소득의 증가(정상재) ⑧ 대체주택의 가격 상승 ⑨ 보완주택의 가격 상승

**풀이**
1. ①은 해당 재화의 가격 → ==수요량==의 변화 → 제외.
2. ②는 ==공급== 쪽 요인 → 제외.
3. ④ LTV·DTI ==하락==은 대출 축소 → 수요 감소 → 제외. ⑤ 금리 ==상승==도 수요 감소 → 제외.
4. ⑨ 보완재 가격 ==상승==은 수요 감소 → 제외.
5. 남는 것: ③ 가구 수 증가, ⑥ 가격 상승 기대, ⑦ 소득 증가, ⑧ 대체주택 가격 상승.
→ 정답 **③ ⑥ ⑦ ⑧** (강의노트 예제와 동일한 구조).

#### ⚠️ 이 관의 함정 총정리

1. "아파트 가격 하락은 아파트 수요의 증가 요인이다"라고 하면 틀림 → ==수요량==의 변화다.
2. "대체재의 가격이 하락하면 해당 재화의 수요가 증가한다"라고 하면 틀림 → ==감소==한다.
3. "보완재의 가격이 상승하면 해당 재화의 수요가 증가한다"라고 하면 틀림 → ==감소==한다.
4. "LTV·DTI가 하락하면 수요가 증가한다"라고 하면 틀림 → ==감소==한다.
5. "가격 상승이 예상되면 기존주택시장의 공급도 증가한다"라고 하면 틀림 → 기존주택시장은 ==공급 감소==(매물 잠김)다.

#### ✅ OX 확인문제

> 다음 진술의 참·거짓을 판단하시오.

**1.** 아파트와 대체관계인 오피스텔의 가격이 상승하면 아파트 수요곡선은 우측으로 이동한다.
→ **O**. 대체재 가격 상승 → 해당 재화 수요 증가.

**2.** 주택의 거래세가 인상되면 주택 수요곡선은 좌측으로 이동한다.
→ **O**. 거래비용 증가로 수요가 감소한다.

**3.** 소비자의 실질소득이 증가하면 정상재인 주택의 수요는 증가한다.
→ **O**. 열등재라면 반대가 된다.

**4.** 건설 노동자의 임금이 하락하면 주택 공급곡선은 우측으로 이동한다.
→ **O**. 생산요소 가격 하락 = 공급 증가.

**5.** 건축허가 요건이 완화되면 주택 공급은 감소한다.
→ **X**. ==증가==한다.

**6.** 아파트 가격의 상승은 아파트 공급곡선을 우측으로 이동시킨다.
→ **X**. 공급==량==의 변화이며 곡선은 이동하지 않는다.

**7.** 독립재 관계에서는 한 재화의 가격 변화가 다른 재화의 수요곡선을 이동시키지 않는다.
→ **O**. 교차탄력성이 0이다.

**8.** 열등재는 소득이 증가하면 수요가 감소하는 재화다.
→ **O**. 정상재와 반대다.

**9.** 주택가격 상승이 예상되면 신규 건설시장의 공급은 증가한다.
→ **O**. 기존주택시장에서는 반대로 공급이 감소한다.

**10.** 광고의 목적은 수요곡선을 우측으로 이동시키고 보다 비탄력적으로 만드는 것이다.
→ **O**. 기본서 서술 그대로다.

> 🔑 **"대는 같이, 보는 반대"** — ==대==체재는 가격끼리 같은 방향, ==보==완재는 반대 방향.

> 🔑 **수요 증가 "인·소·금(↓)·비율(↑)·기대(↑)"** — ==인==구, ==소==득, ==금==리 하락, LTV·DTI ==상승==, 가격 상승 ==기대==.

### Chapter 02 수요와 공급이론 / 제2절 균형을 변화시키는 4가지 규칙

> 📖 **PART 02의 최빈출 관.** 2024·2025년 연속으로 나왔고, 시장론·정책론에서도 계속 재활용된다.
> 규칙 자체는 네 줄이면 끝난다. 시험이 노리는 것은 **수요와 공급이 동시에 변할 때 무엇이 "알 수 없다"가 되는가**이다.

> ⭐ **이 관에서 반드시 챙길 3가지**
> ① 한쪽만 변하면 가격·거래량이 ==모두 확정==된다(4가지 규칙).
> ② 동시에 ==같은 방향==으로 변하면 ==거래량 확정·가격 불확정==, ==반대 방향==으로 변하면 ==가격 확정·거래량 불확정==.
> ③ "알 수 없다" = "==수요와 공급의 변화 폭(힘의 크기)에 의해 결정된다==". 같은 말이다.

#### 1. 균형을 변화시키는 4가지 규칙

| 변화 | 균형 가격 | 균형 거래량 |
|---|---|---|
| 수요 ==증가== | ==상승== | ==증가== |
| 수요 ==감소== | ==하락== | ==감소== |
| 공급 ==증가== | ==하락== | ==증가== |
| 공급 ==감소== | ==상승== | ==감소== |

> 🔑 **수요는 가격과 거래량이 같은 방향, 공급은 가격과 거래량이 반대 방향.** 이 한 문장이 표 전체다.

#### 2. 동시에 변하는 경우 — 힘의 크기가 주어지지 않았을 때

| 동시 변화 | 균형 가격 | 균형 거래량 |
|---|---|---|
| 수요 ==증가== + 공급 ==증가== | ==알 수 없다== | ==증가== |
| 수요 ==증가== + 공급 ==감소== | ==상승== | ==알 수 없다== |
| 수요 ==감소== + 공급 ==증가== | ==하락== | ==알 수 없다== |
| 수요 ==감소== + 공급 ==감소== | ==알 수 없다== | ==감소== |

> 🔑 **판별 원리** — 수요와 공급이 **거래량에 미치는 방향**은 항상 같고(둘 다 증가하면 거래량↑),
> **가격에 미치는 방향**은 항상 반대다(수요↑는 가격↑, 공급↑는 가격↓).
> 그래서 **같은 방향으로 변하면 거래량이 확정**되고, **반대 방향으로 변하면 가격이 확정**된다.

#### 3. 힘의 크기가 주어졌을 때

| 조건 | 균형 가격 | 균형 거래량 |
|---|---|---|
| 수요 증가 ==&gt;== 공급 증가 | ==상승== | 증가 |
| 공급 증가 ==&gt;== 수요 증가 | ==하락== | 증가 |
| 수요 증가폭 ==＝== 공급 증가폭 | ==불변== | 증가 |
| 수요 감소 ==&gt;== 공급 감소 | ==하락== | 감소 |
| 공급 감소 ==&gt;== 수요 감소 | ==상승== | 감소 |
| 수요 증가 + 공급 감소(폭 무관) | ==반드시 상승== | 불확정 |

> ⚠️ **"수요 증가폭과 공급 감소폭이 같으면 가격이 불변"은 틀린다.** 반대 방향 변화에서는 힘이 같아도 ==가격은 반드시 상승==하고,
> 대신 ==거래량이 불변==이 된다. 힘이 같을 때 '불변'이 되는 것은 **같은 방향 변화에서의 가격**뿐이다.

#### 4. 정답을 찾는 요령

1. 문제가 묻는 것이 ==가격==인지 ==거래량==인지 먼저 표시한다.
2. 수요·공급이 ==한쪽만== 변했는지, ==둘 다== 변했는지 본다.
3. 둘 다 변했다면 **방향이 같은지 반대인지**만 보면 어느 쪽이 불확정인지 즉시 나온다.
4. 힘의 크기(변화 폭)가 주어졌다면 불확정이었던 변수의 답도 확정된다.

#### ⭐ 기출 출제포인트

- **2025 제36회 07번**은 힘의 크기가 주어진 유형만으로 5개 선지를 구성했다. 표 3을 그대로 대입하면 풀린다.
- **2024 제35회 27번**은 4가지 규칙 + 극단적 시장(완전탄력·완전비탄력)을 섞었다.
- "==알 수 없다==", "==변화 폭에 의해 결정된다==" 두 표현이 같은 뜻임을 모르면 함정에 걸린다.

**①** 수요가 증가하면 균형 가격은 상승하고 균형 거래량은 증가한다. — **O** / 근거: 4규칙의 첫 줄이다. `practice-re-p02c05s03-L1-01`
**②** 수요 감소와 공급 증가는 모두 균형 가격을 하락시키는 요인이다. — **O** / 근거: 가격 하락 요인 두 가지다. 다만 거래량 방향은 서로 반대다. `practice-re-p02c05s03-L2-02`
**③** 수요와 공급이 동시에 증가하면 균형 가격은 반드시 상승한다. — **X** / 어디가 틀렸나: 가격은 ==알 수 없다==. 확정되는 것은 ==거래량 증가==뿐이다. `practice-re-p02c05s03-L3-01`
**④** 수요가 증가하고 동시에 공급이 감소하면 균형 가격은 반드시 상승한다. — **O** / 근거: 반대 방향 변화이므로 가격이 확정된다. 거래량이 불확정이다. `practice-re-p02c05s03-L3-10`
**⑤** 수요 증가폭과 공급 감소폭이 같으면 균형 가격은 불변이다. — **X** / 어디가 틀렸나: 가격은 ==반드시 상승==하고, 오히려 ==거래량이 불변==이 된다. `practice-re-p02c05s03-L4-08`
**⑥** 수요와 공급이 모두 감소하면 균형 거래량은 반드시 감소한다. — **O** / 근거: 같은 방향 변화 → 거래량 확정. `practice-re-p02c05s03-L4-08`
**⑦** 건설업체 수가 증가하면 공급이 증가하여 균형 가격은 하락하고 거래량은 증가한다. — **O** / 근거: 공급 증가의 4규칙 적용. `practice-re-p02c05s03-L3-13`
**⑧** 대체재의 임대료가 상승하면 해당 부동산의 매매수요가 증가하여 균형 가격이 상승한다. — **O** / 근거: 대체재 가격 상승 → 수요 증가 → 가격 상승. `practice-re-p02c05s03-L3-13`

#### ✏️ 대표 예제

> **문제** 부동산 매매시장에서 수요와 공급이 동시에 변화할 때, 시장균형의 변화로 **옳지 않은 것**은?
> ① 동시 증가·공급 증가폭이 더 크면, 가격 하락·거래량 증가
> ② 동시 감소·수요 감소폭이 더 크면, 가격 하락·거래량 감소
> ③ 동시 증가·증가폭이 같으면, 가격 불변·거래량 증가
> ④ 동시 감소·공급 감소폭이 더 크면, 가격 하락·거래량 감소
> ⑤ 동시 증가·수요 증가폭이 더 크면, 가격 상승·거래량 증가

**풀이**
1. 모두 **같은 방향** 동시 변화이므로 거래량은 전부 확정된다(증가면 증가, 감소면 감소). ①②③④⑤ 거래량 서술은 전부 맞다.
2. 가격은 **힘이 센 쪽**이 결정한다.
3. ④ 동시 감소에서 ==공급 감소폭이 더 크면== 공급 쪽 힘이 이기고, 공급 감소는 가격을 ==상승==시킨다. 선지는 '하락'이라 했으므로 **틀렸다.**
→ 정답 **④** (2025년 제36회 07번).

#### ⚠️ 이 관의 함정 총정리

1. "수요·공급이 동시에 증가하면 가격이 상승한다"라고 하면 틀림 → ==알 수 없다==.
2. "수요 증가 + 공급 감소이면 거래량이 증가한다"라고 하면 틀림 → ==알 수 없다==(가격만 상승 확정).
3. "수요 증가폭과 공급 감소폭이 같으면 가격이 불변이다"라고 하면 틀림 → ==가격 상승, 거래량 불변==이다.
4. "동시 감소에서 공급 감소폭이 더 크면 가격이 하락한다"라고 하면 틀림 → ==상승==한다.
5. "'알 수 없다'와 '변화 폭에 의해 결정된다'는 다른 뜻이다"라고 하면 틀림 → ==같은 뜻==이다.

#### ✅ OX 확인문제

> 다음 진술의 참·거짓을 판단하시오.

**1.** 공급이 감소하면 균형 가격은 상승하고 균형 거래량은 감소한다.
→ **O**. 공급은 가격과 거래량이 반대 방향이다.

**2.** 수요가 감소하면 균형 가격은 하락하고 균형 거래량도 감소한다.
→ **O**. 수요는 가격과 거래량이 같은 방향이다.

**3.** 수요가 증가하고 공급도 증가하면 균형 거래량은 반드시 증가한다.
→ **O**. 가격만 불확정이다.

**4.** 수요가 감소하고 공급이 증가하면 균형 가격은 반드시 하락한다.
→ **O**. 거래량이 불확정이다.

**5.** 수요가 감소하고 공급도 감소하면 균형 가격은 반드시 하락한다.
→ **X**. 가격은 ==알 수 없다==. 확정되는 것은 거래량 감소다.

**6.** 수요의 증가가 공급의 증가보다 크면 균형 가격은 상승하고 거래량도 증가한다.
→ **O**. 힘이 센 쪽이 가격 방향을 정한다.

**7.** 공급의 증가가 수요의 증가보다 크면 균형 가격은 하락한다.
→ **O**. 거래량은 그래도 증가한다.

**8.** 수요와 공급의 증가 폭이 같으면 균형 가격은 불변이다.
→ **O**. 거래량만 증가한다.

**9.** 건축원자재 가격이 상승하면 균형 가격은 상승하고 균형 거래량은 감소한다.
→ **O**. 공급 감소의 결과다.

**10.** "균형 가격의 변화는 알 수 없다"와 "균형 가격의 변화는 수요·공급의 변화 폭에 의해 결정된다"는 서로 다른 결론이다.
→ **X**. 같은 말이다.

#### 🧠 암기법

> 🔑 **"수는 같이, 공은 반대"** — ==수==요 변화는 가격·거래량이 같은 방향, ==공==급 변화는 반대 방향.

> 🔑 **"같으면 량, 다르면 가"** — 동시 변화의 방향이 ==같==으면 거래==량==이 확정, ==다==르면 ==가==격이 확정.

> 🔑 **"불확정 = 힘겨루기"** — 답이 '알 수 없다'인 자리는 곧 '변화 폭이 정한다'는 자리다.

### Chapter 02 수요와 공급이론 / 제3절 계산 문제

> 📖 균형 계산은 **연립방정식 한 번**이면 끝난다. 그런데 실전에서 틀리는 이유는 계산이 어려워서가 아니라
> ① 함수가 ==P에 대해 정리==되어 있는데 그대로 연립하거나, ② ==계수(2Qs, 2P)== 를 놓치거나, ③ 검산을 안 해서다.
> **모든 문제를 "Q = ○ − ○P" 꼴로 통일한 뒤 연립**하는 습관을 들여라.

> ⭐ **이 관에서 반드시 챙길 3가지**
> ① 균형조건은 ==Qd = Qs==. 반드시 ==Q에 대해 정리==한 뒤 연립한다.
> ② 초과수요·초과공급은 ==해당 가격에서 Qd − Qs==. 양수면 초과수요, 음수면 초과공급.
> ③ y축·수요곡선·공급곡선이 둘러싼 삼각형 면적 = ==½ × (수요곡선 P절편 − 공급곡선 P절편) × 균형거래량==.

#### 1. 산식과 기호

| 기호 | 의미 |
|---|---|
| $Q_d$ | 수요량 |
| $Q_s$ | 공급량 |
| $P$ | 가격(임대료) |
| 균형조건 | $Q_d = Q_s$ |
| 초과수요량 | $Q_d - Q_s \;(\gt 0)$ |
| 초과공급량 | $Q_s - Q_d \;(\gt 0)$ |

$$Q_d = Q_s \;\Rightarrow\; P^* \;\Rightarrow\; Q^* = Q_d(P^*) = Q_s(P^*)$$

#### 2. 계산 절차 (이 순서를 벗어나지 마라)

1. **형태 통일** — 주어진 식이 $P = \cdots$ 꼴이면 $Q = \cdots$ 꼴로 바꾼다. $2Q_s = -40 + 3P$ 처럼 계수가 붙어 있으면 반드시 양변을 나눈다.
2. **연립** — $Q_d = Q_s$ 로 두고 $P$ 를 구한다.
3. **대입** — 구한 $P$ 를 두 식 중 하나에 넣어 $Q$ 를 구한다.
4. **검산** — 나머지 식에도 넣어 같은 $Q$ 가 나오는지 확인한다. 여기서 틀린 답의 90%가 걸러진다.
5. **변화 문제라면** — 변화 전·후 균형을 각각 구해 ==차이==를 답한다. 묻는 것이 가격인지 거래량인지 다시 확인한다.

#### 3. 유형별 예제

**✏️ 예제 1 — 기본 균형 (검산 포함)**

> 수요함수 $Q_d = 80 - 2P$, 공급함수 $Q_s = 20 + 3P$. 균형가격과 균형거래량은?

1. 연립: $80 - 2P = 20 + 3P$
2. $60 = 5P \Rightarrow P^* = 12$
3. 대입: $Q_d = 80 - 24 = 56$
4. **검산**: $Q_s = 20 + 36 = 56$ ✓
→ 균형가격 **12**, 균형거래량 **56**.

**✏️ 예제 2 — 수요 변화와 도형 면적 (2018년 제29회)**

> 공급함수 $Q_s = -40 + 2P$ 로 일정하고, 수요함수가 $Q_{d1} = 50 - P$ 에서 $Q_{d2} = 80 - P$ 로 변했다.
> y축·수요곡선·공급곡선으로 둘러싸인 도형의 면적과 균형거래량의 변화는?

1. **변화 전 균형**: $50 - P = -40 + 2P \Rightarrow 90 = 3P \Rightarrow P = 30$, $Q = 20$. (검산: $-40+60=20$ ✓)
2. **변화 후 균형**: $80 - P = -40 + 2P \Rightarrow 120 = 3P \Rightarrow P = 40$, $Q = 40$. (검산: $-40+80=40$ ✓)
3. **거래량 변화**: $40 - 20 = 20$ 증가.
4. **절편 확인**: 수요곡선 P절편은 $Q=0$ 일 때 → 변화 전 50, 변화 후 80. 공급곡선 P절편은 $Q=0$ 일 때 $P=20$.
5. **면적**: 변화 전 $\frac{1}{2} \times (50-20) \times 20 = 300$, 변화 후 $\frac{1}{2} \times (80-20) \times 40 = 1{,}200$.
6. **면적 변화**: $1{,}200 - 300 = 900$ 증가.
→ **면적 900 증가, 균형거래량 20 증가**.

**✏️ 예제 3 — 공급 변화 (2025년 제36회 10번 구조)**

> 기존 수요함수 $2P = -Q_d + 400$, 기존 공급함수 $P = Q_{s1} + 20$.
> 이후 수요는 그대로이고 공급함수가 $P = Q_{s2} + 80$ 으로 변했다. 균형의 변화는?

1. **형태 통일**: $Q_d = 400 - 2P$, $Q_{s1} = P - 20$, $Q_{s2} = P - 80$.
2. **기존 균형**: $400 - 2P = P - 20 \Rightarrow 420 = 3P \Rightarrow P = 140$, $Q = 400 - 280 = 120$. (검산: $140-20=120$ ✓)
3. **변화 후 균형**: $400 - 2P = P - 80 \Rightarrow 480 = 3P \Rightarrow P = 160$, $Q = 400 - 320 = 80$. (검산: $160-80=80$ ✓)
4. **해석**: 공급함수의 상수가 커진 것은 ==같은 수량을 공급하는 데 더 높은 가격이 필요==하다는 뜻 → ==공급 감소(좌측 이동)==.
→ 균형가격 **20 상승**(140→160), 균형거래량 **40 감소**(120→80).
> ⚠️ "공급량의 증가로 공급곡선이 좌측 이동"이라는 선지는 용어부터 틀렸다. 좌측 이동은 ==공급의 감소==다.

**✏️ 예제 4 — 초과수요량 (2019년 제30회 28번)**

> $Q_d = 100 - \frac{1}{2}P$, $Q_s = 20 + \frac{1}{3}P$ (단위: 천호, 만원).
> 정부가 임대료를 시장균형임대료보다 36만원 낮추었을 때 초과수요량은?

1. **균형**: $100 - \frac{1}{2}P = 20 + \frac{1}{3}P \Rightarrow 80 = \frac{5}{6}P \Rightarrow P^* = 96$, $Q^* = 100 - 48 = 52$. (검산: $20+32=52$ ✓)
2. **규제가격**: $96 - 36 = 60$.
3. $Q_d(60) = 100 - 30 = 70$, $Q_s(60) = 20 + 20 = 40$.
4. **초과수요** $= 70 - 40 = 30$.
→ **30천호**. 임대료 규제가 초과수요(주택 부족)를 낳는다는 정책론의 결론과 그대로 이어진다.

**✏️ 예제 5 — 단기·장기 균형 (2021년 제32회 09번)**

> 단기공급함수 $Q = 300$, 장기공급함수 $Q = P + 250$, 수요함수는 장단기 동일하게 $Q = 400 - \frac{1}{2}P$.

1. **단기 균형**: $300 = 400 - \frac{1}{2}P \Rightarrow \frac{1}{2}P = 100 \Rightarrow P = 200$, $Q = 300$.
2. **장기 균형**: $P + 250 = 400 - \frac{1}{2}P \Rightarrow \frac{3}{2}P = 150 \Rightarrow P = 100$, $Q = 350$. (검산: $400-50=350$ ✓)
3. **변화**: 가격 $200 \to 100$ (==100 감소==), 거래량 $300 \to 350$ (==50 증가==).
→ 단기의 ==완전비탄력적 공급==(수직선 $Q=300$)이 장기에 탄력적으로 바뀌면서 가격이 내리고 거래량이 는다.

#### ⭐ 기출 출제포인트

- 공급함수가 $2Q_s = -40 + 3P$ 처럼 주어지면 ==반드시 양변을 2로 나눈 뒤== 연립한다. 이 실수가 가장 많다.
- 면적 문제는 ==절편 두 개와 균형거래량== 세 숫자만 있으면 된다.
- 단기(수직) → 장기(우상향)의 변화는 ==가격 하락 + 거래량 증가==로 고정된 결론이다.

**④** 같은 함수에서 P = 24는 초과수요 상태다. — **X** / 어디가 틀렸나: $Q_d = 24$, $Q_s = 48$ 이므로 ==초과공급==이다. 부호 방향을 반대로 읽은 함정. `practice-re-p02c08s01-L2-07`

**⑥** 같은 함수에서 P = 20이면 초과수요가 발생한다. — **X** / 어디가 틀렸나: $Q_d = 100 \lt  Q_s = 150$ → ==초과공급==이다. `practice-re-p02c08s01-L2-09`
**⑦** 균형가격을 구한 뒤 한쪽 식에만 대입하고 답을 확정해도 된다. — **X** / 어디가 틀렸나: 선지에 ==P는 맞고 Q만 틀린== 조합이 반드시 섞여 있다. 반대 식 검산이 필수다. `practice-re-p02c08s01-L2-04`
**⑧** 수요함수가 $Q_d = 285 - 4P + 3Y$, 공급함수가 $Q_s = 5P$ 이고 $Y = 25$ 이면 균형가격은 40, 균형거래량은 200이다. — **O** / 근거: $285 + 75 - 4P = 5P \Rightarrow 360 = 9P \Rightarrow P = 40$, $Q = 200$. `practice-re-p02c08s01-L5-05`

#### ⚠️ 이 관의 함정 총정리

1. $P = Q_s + 20$ 을 그대로 $Q_d$ 와 연립하면 틀림 → $Q_s = P - 20$ ==으로 바꾼 뒤== 연립한다.
2. $2Q_s = -40 + 3P$ 에서 계수 2를 무시하면 틀림 → ==양변을 2로 나눈다==.
3. "공급곡선이 좌측으로 이동했으므로 공급량이 증가했다"라고 하면 틀림 → 좌측 이동은 ==공급의 감소==다.
4. 규제가격에서 $Q_s - Q_d$ 를 초과수요라고 하면 틀림 → 초과수요는 ==수요량에서 공급량을 뺀 값==이다.
5. 면적 문제에서 균형가격을 높이로 쓰면 틀림 → 높이는 ==두 곡선의 P절편 차이==, 밑변은 ==균형거래량==이다.

#### ✅ OX 확인문제

> 다음 진술의 참·거짓을 판단하시오.

**1.** 균형조건은 수요량과 공급량이 같아지는 것이다.
→ **O**. $Q_d = Q_s$ 로 두고 연립한다.

**2.** 함수가 P에 대해 정리되어 있어도 그대로 연립하면 된다.
→ **X**. ==Q에 대해 정리==한 뒤 연립해야 한다.

**3.** $Q_d = 80 - 2P$, $Q_s = 20 + 3P$ 의 균형가격은 12다.
→ **O**. 균형거래량은 56이다.

**4.** 시장가격이 균형가격보다 낮으면 초과수요가 발생한다.

**10.** y축·수요곡선·공급곡선이 둘러싼 삼각형의 면적은 두 곡선 P절편의 차에 균형거래량을 곱하고 2로 나눈 값이다.
→ **O**. 2018년 제29회 문제의 계산 구조다.

### Chapter 03 수요와 공급의 탄력성 / 제1절 탄력성의 의미

> 📖 **균형과 함께 이 단원의 양대 축.** 탄력성은 "==양의 변화 정도(%)를 측정하는 지표=="다.
> 정의식·부호·구간만 정확하면 개념 문항은 전부 맞는다. 부호를 묻는 문제(정상재·열등재, 대체재·보완재)가 특히 잘 나온다.

> ⭐ **이 관에서 반드시 챙길 3가지**
> ① 세 탄력성의 ==분자는 모두 "수요량 변화율"==, 분모만 가격·소득·다른 재화 가격으로 달라진다.
> ② 가격탄력성은 ==절댓값==으로 쓰므로 0 또는 양수. 소득탄력성·교차탄력성은 ==부호가 정보==다.
> ③ 소득탄력성 ==음수=열등재==, 교차탄력성 ==양수=대체재 / 음수=보완재 / 0=독립재==.

#### 1. 정의식

$$E_d(\text{가격}) = \left| \frac{\text{수요량 변화율(\%)}}{\text{가격 변화율(\%)}} \right| \qquad E_Y(\text{소득}) = \frac{\text{수요량 변화율(\%)}}{\text{소득 변화율(\%)}}$$

$$E_{xy}(\text{교차}) = \frac{\text{X재 수요량 변화율(\%)}}{\text{Y재 가격 변화율(\%)}} \qquad E_s(\text{공급}) = \frac{\text{공급량 변화율(\%)}}{\text{가격 변화율(\%)}}$$

| 탄력성 | 분자 | 분모 | 부호 |
|---|---|---|---|
| 수요의 ==가격==탄력성 | 수요량 변화율 | ==해당 재화의 가격== 변화율 | ==절댓값==(0 또는 양수) |
| 수요의 ==소득==탄력성 | 수요량 변화율 | ==소득== 변화율 | ==양수=정상재 / 음수=열등재 / 0=중간재== |
| 수요의 ==교차==탄력성 | 수요량 변화율 | ==다른 재화의 가격== 변화율 | ==양수=대체재 / 음수=보완재 / 0=독립재== |
| ==공급==의 가격탄력성 | 공급량 변화율 | 가격 변화율 | 0 또는 양수 |

> ⚠️ **분모를 바꿔치기하는 함정**이 흔하다. 교차탄력성의 분모는 ==다른 재화의 가격==이지 소득이 아니다.

#### 2. 탄력성 구간 — 1을 기준으로

| 값 | 명칭 | 의미 | 곡선 형태 |
|---|---|---|---|
| $E = 0$ | ==완전비탄력적== | 가격이 변해도 ==수량 고정== | ==수직선== (예: $Q = 200$) |
| $0 \lt  E \lt  1$ | ==비탄력적== | 가격 변화율 ==&gt;== 수량 변화율 | 가파름 |
| $E = 1$ | ==단위탄력적== | 두 변화율이 같음 | — |
| $1 \lt  E \lt  \infty$ | ==탄력적== | 가격 변화율 ==&lt;== 수량 변화율 | 완만함 |
| $E = \infty$ | ==완전탄력적== | 가격 변화에 수량이 ==무한대(∞)== 로 변화 | ==수평선== (예: $P = 200$) |

> ⚠️ **자주 틀리는 두 줄**
> "완전탄력적 수요곡선은 ==수직선==이다" → **틀림**. 완전탄력적은 ==수평선==, 완전비탄력적이 ==수직선==이다.
> "비탄력적이면 가격 변화율보다 수요량 변화율이 더 크다" → **틀림**. ==더 작다==(2021 제32회 ⑤ 오답 지점).

#### 3. 소득탄력성으로 본 재화의 분류

| 소득탄력성 | 분류 | 예시 |
|---|---|---|
| $E_Y \lt  0$ | ==열등재== | 소득이 늘면 소비를 줄이는 재화 |
| $E_Y = 0$ | 중간재 | 소득과 무관(소금·간장 등) |
| $0 \lt  E_Y \lt  1$ | ==필수재== | 소득 증가율보다 덜 증가 |
| $E_Y \gt  1$ | ==사치재== | 소득 증가율보다 더 증가 |

#### 4. 총수입(임대수입)과의 관계 — 결론만 먼저

| 수요의 가격탄력성 | 가격(임대료) 인상 | 가격(임대료) 인하 |
|---|---|---|
| ==탄력적== | 총수입 ==감소== | 총수입 ==증가== |
| ==비탄력적== | 총수입 ==증가== | 총수입 ==감소== |
| ==단위탄력적== | ==불변== | ==불변== |

> 💡 이 표의 활용은 다음 관(제2절 응용)에서 전략 문제로 다시 나온다. 여기서는 **정의에서 곧바로 따라 나온다는 점**만 확인하라.
> 탄력적이면 가격을 1% 올릴 때 수량이 1%보다 많이 줄어드니 매출은 준다.

#### ⭐ 기출 출제포인트

- **비탄력적/탄력적의 정의 문장**을 뒤집는 함정이 최다(2021 제32회 04번 ⑤).
- **교차탄력성의 부호로 대체·보완을 판정**하는 문제가 계산형으로 나온다(2023 제34회 07번).
- **완전탄력=수평, 완전비탄력=수직**은 그림 없이 문장으로도 물어본다.

#### ✏️ 대표 예제

> **문제** 아파트 가격이 5% 하락함에 따라 아파트 공급량은 6% 감소하고, 연립주택 수요량은 2% 증가했다.
> (ㄱ) 아파트 공급의 가격탄력성과 (ㄴ) 아파트와 연립주택의 관계는?

**풀이**
1. **공급탄력성** $= \dfrac{-6\%}{-5\%} = 1.2$ → 1보다 크므로 ==탄력적==.
2. **교차탄력성** $= \dfrac{+2\%\;(\text{연립 수요량})}{-5\%\;(\text{아파트 가격})} = -0.4$ → 음수이므로 ==보완재==.
3. 부호를 반대로 읽어 '대체재'로 답하는 것이 이 문제의 함정이다. **분모의 부호를 반드시 살려서 나누라.**
→ 정답 **(ㄱ) 탄력적 · (ㄴ) 보완재** (2023년 제34회 07번).

#### ⚠️ 이 관의 함정 총정리

1. "수요의 가격탄력성은 음수로 측정된다"라고 하면 틀림 → ==절댓값==으로 0 또는 양수다.
2. "완전탄력적 수요곡선은 수직선이다"라고 하면 틀림 → ==수평선==이다.
3. "비탄력적이면 가격 변화율보다 수요량 변화율이 크다"라고 하면 틀림 → ==작다==.
4. "소득탄력성이 0이면 열등재다"라고 하면 틀림 → ==중간재==다(열등재는 음수).
5. "교차탄력성이 양수이면 보완재다"라고 하면 틀림 → ==대체재==다.

#### ✅ OX 확인문제

> 다음 진술의 참·거짓을 판단하시오.

**1.** 수요의 가격탄력성은 수요량 변화율을 가격 변화율로 나눈 값의 절댓값이다.
→ **O**. 분자가 수요량, 분모가 가격이다.

**2.** 수요의 가격탄력성이 완전탄력적이면 가격 변화에 수요량이 무한대로 변화한다.
→ **O**. 곡선은 수평선이다.

**3.** 수요의 가격탄력성이 완전비탄력적이면 가격이 변해도 수요량은 고정된다.
→ **O**. 곡선은 수직선이다.

**4.** 소득탄력성이 1보다 크면 사치재로 분류한다.
→ **O**. 0과 1 사이는 필수재다.

**5.** 교차탄력성이 음수이면 두 재화는 대체관계다.
→ **X**. ==보완관계==다.

**6.** 공급의 가격탄력성은 음수로 측정될 수 있다.
→ **X**. 0 또는 ==양수==다.

**7.** 탄력성은 1을 기준으로 크면 탄력적, 작으면 비탄력적이다.
→ **O**. 수요·공급 모두 같은 기준을 쓴다.

**8.** 수요가 탄력적일 때 가격을 인상하면 총수입은 감소한다.
→ **O**. 수량이 더 크게 줄기 때문이다.

**9.** 수요의 가격탄력성이 1이면 가격을 올려도 내려도 총수입은 변하지 않는다.
→ **O**. 단위탄력적의 결론이다.

**10.** 소득이 변해도 수요량이 전혀 변하지 않으면 소득탄력성은 0이다.
→ **O**. 중간재로 분류된다.

#### 🧠 암기법

> 🔑 **"분자는 늘 수요량"** — 세 탄력성 모두 분자는 수요량 변화율. 이름(가격·소득·교차)이 곧 ==분모==다.

> 🔑 **"플러스는 대체·정상, 마이너스는 보완·열등"** — 부호 하나로 네 개를 정리한다.

> 🔑 **"완탄은 눕고, 완비는 선다"** — ==완==전==탄==력적은 수평(누움), ==완==전==비==탄력적은 수직(섬).

### Chapter 03 수요와 공급의 탄력성 / 제2절 탄력성의 응용

> 📖 탄력성을 **결정하는 요인**, **기울기와의 관계**, 그리고 세 가지 응용(==임대수입 전략==, ==극단적 시장의 예외==, ==가격 변화의 폭==)을 다룬다.
> 2021·2023·2024·2025년 모두 이 관에서 나왔다. **결론표를 외워 대입하는 관**이다.

> ⭐ **이 관에서 반드시 챙길 3가지**
> ① 탄력적일수록 곡선은 ==완만==해진다(기울기와 탄력성은 ==반비례==).
> ② 임대수입: ==탄력적이면 인하 전략, 비탄력적이면 인상 전략==.
> ③ 수요 증가 시 ==공급이 비탄력적일수록 가격이 더 많이 상승==한다. 반대도 같은 논리.

#### 1. 탄력성을 결정하는 요인

| 수요가 더 탄력적인 경우 | 공급이 더 탄력적인 경우 |
|---|---|
| ==대체재가 많을수록== | ==생산에 유리한 상황일수록== |
| ㉠ 부동산 시장을 ==세분할수록== | ㉠ 생산에 소요되는 ==기간이 짧을수록== |
| ㉡ 부동산의 ==분류 범위가 좁을수록== | ㉡ ==생산비가 감소==할수록 |
| ㉢ ==용도변경이 용이==할수록 | ㉢ ==용도변경이 용이==할수록 |
| ==측정 기간이 장기==일수록 | ==측정 기간이 장기==일수록 |

> 📌 기본서·기출이 추가하는 요인: 재화의 ==가격이 가계소득에서 차지하는 비중이 클수록== 수요는 더 탄력적이다.
> ⚠️ 2023년 제34회 11번 ⑤ "비중이 ==작을수록== 더 탄력적" → **틀린 선지**였다.
> ⚠️ 토지이용 규제로 ==택지공급이 비탄력적==이면 ==주택공급도 비탄력적==이 된다(2019 제30회 ④, 옳은 지문).

#### 3. 응용 ① 임대수입(총수입) 전략

| 소비자 형태 | 임대료 전략 |
|---|---|
| 수요가 ==탄력적==인 경우 | ==인하 전략== |
| 수요가 ==비탄력적==인 경우 | ==인상 전략== |
| ==단위탄력적==인 경우 | 어느 쪽이든 ==임대수입 불변== |

| 상황 | 임대수입 |
|---|---|
| 탄력적 + 임대료 하락 | ==증가== |
| 탄력적 + 임대료 상승 | ==감소== |
| 비탄력적 + 임대료 상승 | ==증가== |
| 비탄력적 + 임대료 하락 | ==감소== |

#### 4. 응용 ② 극단적인 시장 — 균형 변화의 예외

| 극단적 조건 | 예외 |
|---|---|
| 수요가 ==완전탄력적==일 때 | ==가격 불변== |
| 공급이 ==완전탄력적==일 때 | ==가격 불변== |
| 수요가 ==완전비탄력적==일 때 | ==거래량 불변== |
| 공급이 ==완전비탄력적==일 때 | ==거래량 불변== |

| 사례 | 결과 |
|---|---|
| 공급 완전탄력적 + 수요 증가 | 가격 ==불변==, 거래량 ==증가== |
| 공급 완전비탄력적 + 수요 증가 | 가격 ==상승==, 거래량 ==불변== |
| 수요 완전탄력적 + 공급 증가 | 가격 ==불변==, 거래량 ==증가== |
| 수요 완전비탄력적 + 공급 증가 | 가격 ==하락==, 거래량 ==불변== |

> 🔑 **"완전탄력적인 쪽이 있으면 가격이 안 움직이고, 완전비탄력적인 쪽이 있으면 거래량이 안 움직인다."**

#### 5. 응용 ③ 가격 변화의 폭 (더·덜)

| 상황 | 결과 |
|---|---|
| 수요가 증가할 때 공급이 ==탄력적==일수록 | 가격은 ==덜== 상승 |
| 수요가 증가할 때 공급이 ==비탄력적==일수록 | 가격은 ==더== 상승 |
| 공급이 증가할 때 수요가 ==탄력적==일수록 | 가격은 ==덜== 하락 |
| 공급이 증가할 때 수요가 ==비탄력적==일수록 | 가격은 ==더== 하락 |

- 수요 감소 시 공급이 탄력적일수록 → 가격은 ==덜 하락==하고 거래량은 ==더 감소==.
- 공급 감소 시 수요가 비탄력적일수록 → 가격은 ==더 상승==하고 거래량은 ==덜 감소==.

> 📌 **같은 뜻, 다른 표현** — "가격은 더 상승한다" = "더 많이 상승한다" = "가격 상승의 폭이 ==증가==한다".
> "가격은 덜 상승한다" = "더 적게 상승한다" = "상승의 폭이 ==감소==한다".

> 🔑 **한 줄 요약** — ==비탄력적인 쪽이 가격 충격을 크게 받는다.== 반대편이 뻣뻣할수록 가격이 크게 튄다.

#### ⭐ 기출 출제포인트

- **2024 제35회 22번 ⑤** "공급의 가격탄력성이 작을수록 균형가격의 변동폭은 작지만 거래량 변동폭은 크다" → **틀림**. 반대다.
- **2023 제34회 08번 ⑤** "수요 증가 시 공급탄력성이 작을수록 가격 상승폭은 작고 거래량 증가폭은 크다" → **틀림**. 반대다.
- **2019 제30회 27번 ②** "공급이 탄력적일수록 수요 증가에 따른 가격 변동폭이 크다" → **틀림**. ==작다==.

**①** 수요의 가격탄력성이 완전비탄력적이면 임대료가 변해도 수요량은 전혀 변하지 않는다. — **O** / 근거: 수직선 수요곡선이다. `practice-re-p02c06s02-L1-01`
**②** 수요가 탄력적일 때 임대료를 인상하면 임대수입이 증가한다. — **X** / 어디가 틀렸나: 수요량이 더 크게 줄어 ==임대수입은 감소==한다. 탄력적이면 ==인하==가 전략이다. `practice-re-p02c06s02-L2-02`
**③** 수요가 비탄력적일 때 임대료를 인하하면 임대수입은 감소한다. — **O** / 근거: 수요량이 조금밖에 늘지 않기 때문이다. `practice-re-p02c06s02-L2-02`
**④** 부동산 시장을 세분할수록, 용도변경이 용이할수록 수요는 더 탄력적이다. — **O** / 근거: 둘 다 대체 가능성을 키운다. `practice-re-p02c06s02-L3-01`
**⑤** 분류 범위가 넓을수록 대체재가 많아져 더 탄력적이다. — **X** / 어디가 틀렸나: 범위가 ==좁을수록== 상대적으로 대체재가 많아져 탄력적이 된다("부동산" 전체보다 "강남 아파트"가 더 탄력적). `practice-re-p02c06s02-L3-01`
**⑥** 수요가 단위탄력적이면 임대수입이 최대가 된다. — **X** / 어디가 틀렸나: 단위탄력적은 ==임대수입 불변==을 의미할 뿐, 곡선 전체의 수입 최대점 논의와는 다르다. 시험에서는 ==불변==으로만 답하라. `practice-re-p02c06s02-L4-01`
**⑦** 수요의 가격탄력성이 1.5인 상가에서 임대수입을 늘리려면 임대료를 인하해야 한다. — **O** / 근거: 탄력적(1보다 큼) → 인하 전략. `practice-re-p02c06s02-L5-01`
**⑧** 측정 기간이 장기일수록 수요와 공급은 모두 더 탄력적이 된다. — **O** / 근거: 대체 수단을 찾고 생산을 조정할 시간이 생긴다. `practice-re-p02c06s02-L3-01`

#### ✏️ 대표 예제

> **문제** 부동산의 가격탄력성과 균형변화에 관한 설명으로 **옳지 않은 것**은?
> ① 공급이 완전비탄력적일 때 수요가 증가하면 균형가격은 상승하고 균형량은 불변이다.
> ② 수요가 완전비탄력적일 때 공급이 감소하면 균형가격은 상승하고 균형량은 불변이다.
> ③ 수요가 완전탄력적일 때 공급이 증가하면 균형가격은 불변이고 균형량은 증가한다.
> ④ 공급이 증가할 때 수요의 가격탄력성이 작을수록 균형가격 하락폭은 크고 균형량 증가폭은 작다.
> ⑤ 수요가 증가할 때 공급의 가격탄력성이 작을수록 균형가격 상승폭은 작고 균형량 증가폭은 크다.

**풀이**
1. ①②는 ==완전비탄력적 → 거래량 불변== 규칙에 부합. 옳다.
2. ③은 ==완전탄력적 → 가격 불변== 규칙에 부합. 옳다.
3. ④는 "비탄력적인 쪽이 가격 충격을 크게 받는다"에 부합. 수요가 비탄력적이면 공급 증가 시 가격이 크게 떨어지고 거래량은 조금 는다. 옳다.
4. ⑤는 정반대다. 공급이 ==비탄력적==(탄력성이 작을수록)이면 수요 증가 시 가격이 ==크게 상승==하고 거래량은 ==조금== 는다. **틀렸다.**
→ 정답 **⑤** (2023년 제34회 08번).

#### ⚠️ 이 관의 함정 총정리

1. "탄력적일수록 곡선의 기울기가 가팔라진다"라고 하면 틀림 → ==완만==해진다.
2. "수요가 탄력적일 때는 임대료를 올려야 수입이 는다"라고 하면 틀림 → ==인하==해야 한다.
3. "공급이 탄력적일수록 수요 증가에 따른 가격 상승폭이 크다"라고 하면 틀림 → ==작다==.
4. "공급이 완전비탄력적일 때 수요가 증가하면 거래량이 증가한다"라고 하면 틀림 → ==거래량 불변==, 가격만 상승한다.
5. "재화 가격이 가계소득에서 차지하는 비중이 작을수록 수요는 탄력적이다"라고 하면 틀림 → ==클수록== 탄력적이다.

#### ✅ OX 확인문제

> 다음 진술의 참·거짓을 판단하시오.

**1.** 수요곡선 기울기의 절댓값이 클수록 수요의 가격탄력성은 작아진다.
→ **O**. 기울기와 탄력성은 반비례한다.

**2.** 대체재가 많을수록 수요의 가격탄력성은 커진다.
→ **O**. 다른 데로 옮겨 갈 수 있기 때문이다.

**3.** 생산에 소요되는 기간이 길수록 공급은 더 탄력적이다.
→ **X**. 기간이 ==짧을수록== 탄력적이다.

**4.** 임대수요가 비탄력적일 때 임대료를 상승시키면 임대수입은 증가한다.
→ **O**. 수요량이 조금밖에 줄지 않는다.

**5.** 임대수요의 가격탄력성이 1이면 임대료를 바꿔도 임대수입은 불변이다.
→ **O**. 단위탄력적의 결론이다.

**6.** 공급이 완전탄력적일 때 수요가 감소하면 가격은 불변이고 거래량은 감소한다.
→ **O**. 완전탄력적인 쪽이 있으면 가격이 고정된다.

**7.** 수요가 완전비탄력적일 때 공급이 증가하면 가격은 하락하고 거래량은 불변이다.
→ **O**. 완전비탄력적인 쪽이 있으면 거래량이 고정된다.

**8.** 수요가 증가할 때 공급이 비탄력적일수록 가격 상승의 폭은 커진다.
→ **O**. 공급이 못 따라오기 때문이다.

**9.** 공급이 증가할 때 수요가 탄력적일수록 가격은 더 많이 하락한다.
→ **X**. ==덜== 하락한다.

**10.** 측정 기간이 길수록 수요의 탄력성은 더 탄력적이 된다.
→ **O**. 2023년 제34회에서 옳은 지문으로 출제되었다.

#### 🧠 암기법

> 🔑 **"탄력이면 내리고, 비탄력이면 올린다"** — 임대수입 전략 한 줄. (탄=인하, 비=인상)

> 🔑 **"완탄=가격 고정, 완비=거래량 고정"** — 완전==탄==력적이면 ==가격==이, 완전==비==탄력적이면 ==거래량==이 못 움직인다.

> 🔑 **"뻣뻣한 쪽이 크게 튄다"** — 비탄력적인 쪽이 있으면 가격 변동폭이 커진다.

> 🔑 **"좁을수록·길수록 탄력적"** — 시장을 ==좁게== 나눌수록, 기간이 ==길==수록 탄력적.

### Chapter 03 수요와 공급의 탄력성 / 제3절 계산 문제

> 📖 탄력성 계산은 딱 **두 유형**이다.
> **유형 1 — 변화율형**: %가 주어진다. 나누기만 하면 된다. 여러 탄력성을 ==합성==하는 문제로 확장된다.
> **유형 2 — 함수형(점탄력성)**: 수요·공급함수가 주어진다. 먼저 ==균형을 구하고==, 그 점에서 탄력성을 계산한다.
> 2020·2022년 감정평가사 시험은 모두 유형 2였다.

> ⭐ **이 관에서 반드시 챙길 3가지**
> ① 점탄력성 = ==기울기의 역수 × (P/Q)==. 함수 $Q = a - bP$ 에서 그 값은 $b \times \dfrac{P}{Q}$ 다.
> ② 함수형은 ==반드시 균형점(P, Q)을 먼저== 구한다. 균형을 구하지 않고 절편을 대입하면 전부 틀린다.
> ③ 합성: ==수요량 변화율 = −(가격탄력성 × 가격변화율) + (소득탄력성 × 소득변화율) + (교차탄력성 × 상대재 가격변화율)==.

#### 1. 산식과 기호

| 기호 | 의미 |
|---|---|
| $E_d$ | 수요의 가격탄력성(절댓값) |
| $E_s$ | 공급의 가격탄력성 |
| $E_Y$ | 수요의 소득탄력성 |
| $E_{xy}$ | 수요의 교차탄력성 |
| $\Delta Q / \Delta P$ | 함수의 기울기의 역수(수량을 가격으로 미분한 값) |

$$E_d = \left| \frac{\Delta Q}{\Delta P} \times \frac{P}{Q} \right| \qquad E_s = \frac{\Delta Q_s}{\Delta P} \times \frac{P}{Q}$$

$$\%\Delta Q_d = -\,E_d \cdot \%\Delta P \;+\; E_Y \cdot \%\Delta Y \;+\; E_{xy} \cdot \%\Delta P_y$$

#### 2. 계산 절차

**유형 1 — 변화율형**
1. 무엇을 무엇으로 나눌지 정한다(분자는 항상 ==수요량 변화율==).
2. 부호를 살려서 나눈다. 가격탄력성만 ==절댓값==을 취한다.
3. 교차탄력성의 부호로 ==대체(+)/보완(−)== 를 판정한다.
4. 합성 문제라면 위 합성식에 대입하고, 미지수가 있으면 방정식으로 역산한다.

**유형 2 — 함수형(점탄력성)**
1. 함수를 ==Q에 대해 정리==한다($2Q_s = -40 + 3P$ → $Q_s = -20 + 1.5P$).
2. $Q_d = Q_s$ 로 ==균형 (P, Q)== 를 구하고 검산한다.
3. 각 함수의 ==P 계수==(기울기의 역수)를 확인한다.
4. $E = |{\text{P 계수}}| \times \dfrac{P}{Q}$ 로 계산한다. 분수는 약분하지 말고 선지 형태에 맞춘다.

#### 3. 유형별 예제

**✏️ 예제 1 — 함수형 기본**

> 수요함수 $Q_d = 60 - 3P$ 일 때 $P = 10$ 에서의 수요의 가격탄력성은?

1. $Q = 60 - 30 = 30$.
2. P 계수 $= -3$ → 절댓값 3.
3. $E_d = 3 \times \dfrac{10}{30} = 1.0$.
→ **1.0 (단위탄력적)**. 이 점에서 임대료를 올리든 내리든 총수입은 변하지 않는다.

**✏️ 예제 2 — 균형에서의 수요·공급 탄력성 (2020년 제31회 35번)**

> 시장수요함수 $Q_D = 100 - P$, 시장공급함수 $2Q_s = -40 + 3P$. 균형에서 $E_d$ 와 $E_s$ 는?

1. **형태 통일**: $Q_s = -20 + 1.5P$.
2. **균형**: $100 - P = -20 + 1.5P \Rightarrow 120 = 2.5P \Rightarrow P = 48$, $Q = 100 - 48 = 52$. (검산: $-20 + 72 = 52$ ✓)
3. **수요**: P 계수 절댓값 1 → $E_d = 1 \times \dfrac{48}{52} = \dfrac{12}{13}$.
4. **공급**: P 계수 1.5 → $E_s = 1.5 \times \dfrac{48}{52} = \dfrac{72}{52} = \dfrac{18}{13}$.
→ $E_d = \dfrac{12}{13}$ (비탄력적), $E_s = \dfrac{18}{13}$ (탄력적).
> ⚠️ 계수 2를 무시하고 $Q_s = -40 + 3P$ 로 풀면 균형부터 어긋난다. **형태 통일이 1단계인 이유다.**

**✏️ 예제 3 — 탄력성의 합 (2022년 제33회 06번)**

> $Q_D = 2{,}600 - 2P$, $3Q_S = 600 + 4P$. 균형에서 수요와 공급의 가격탄력성의 합은?

1. **형태 통일**: $Q_S = 200 + \dfrac{4}{3}P$.
2. **균형**: $2{,}600 - 2P = 200 + \dfrac{4}{3}P \Rightarrow 2{,}400 = \dfrac{10}{3}P \Rightarrow P = 720$, $Q = 2{,}600 - 1{,}440 = 1{,}160$. (검산: $200 + 960 = 1{,}160$ ✓)
3. $E_d = 2 \times \dfrac{720}{1{,}160} = \dfrac{1{,}440}{1{,}160} = \dfrac{36}{29}$.
4. $E_s = \dfrac{4}{3} \times \dfrac{720}{1{,}160} = \dfrac{960}{1{,}160} = \dfrac{24}{29}$.
5. **합** $= \dfrac{36 + 24}{29} = \dfrac{60}{29}$.
→ **60/29**. 두 탄력성의 $P/Q$ 는 같으므로 ==계수만 더해서 한 번에== 계산해도 된다($\left(2 + \frac{4}{3}\right) \times \frac{720}{1160} = \frac{10}{3} \times \frac{18}{29} = \frac{60}{29}$).

**✏️ 예제 4 — 소득탄력성 함수형 (제28회 유형)**

> $Q_d = -2P + 6Y + 100$, $P = 5$, $Y = 5$ 일 때 수요의 소득탄력성은?

1. $Q = -10 + 30 + 100 = 120$.
2. Y 계수 $= 6$.
3. $E_Y = 6 \times \dfrac{5}{120} = \dfrac{30}{120} = \dfrac{1}{4}$.
→ **1/4**. 0과 1 사이이므로 ==필수재==다.
> 💡 함수형에서 소득탄력성은 ==Y의 계수 × (Y/Q)==, 가격탄력성은 ==P의 계수 절댓값 × (P/Q)==. 대입하는 값이 다르다는 점만 주의.

**✏️ 예제 5 — 변화율형 3종 세트**

> 아파트 매매가격이 16% 상승하자 다세대주택 매매수요량은 8% 증가하고 아파트 매매수요량은 4% 감소했다.
> 아파트 수요의 가격탄력성(Ⓐ), 다세대주택 수요의 교차탄력성(Ⓑ), 두 재화의 관계(Ⓒ)는?

1. Ⓐ $= \left| \dfrac{-4\%}{+16\%} \right| = 0.25$ → 비탄력적.
2. Ⓑ $= \dfrac{+8\%}{+16\%} = 0.5$ → 양수.
3. Ⓒ 교차탄력성이 ==양수==이므로 ==대체재==.
→ **Ⓐ 0.25 · Ⓑ 0.5 · Ⓒ 대체재**.

**✏️ 예제 6 — 합성(전체 수요량 변화율)**

> 아파트 수요의 가격탄력성 0.6, 소득탄력성 0.4, 오피스텔 가격에 대한 교차탄력성 0.2.
> 아파트 가격·소득·오피스텔 가격이 각각 3%씩 상승하면 아파트 전체 수요량의 변화율은?

1. 가격 효과: $-0.6 \times 3\% = -1.8\%$
2. 소득 효과: $+0.4 \times 3\% = +1.2\%$
3. 교차 효과: $+0.2 \times 3\% = +0.6\%$
4. 합계: $-1.8 + 1.2 + 0.6 = 0\%$
→ **변화 없음**. 가격탄력성 항에는 반드시 ==음(−)의 부호==를 붙인다는 것이 이 유형의 핵심이다.

**✏️ 예제 7 — 역산형**

> 오피스텔 수요의 가격탄력성 0.6, 소득탄력성 0.5. 오피스텔 가격이 5% 상승함과 동시에 소득이 변하여
> 전체 수요량이 1% 감소했다면 소득의 변화율은?

1. 합성식: $-0.6 \times 5\% + 0.5 \times x = -1\%$
2. $-3\% + 0.5x = -1\% \Rightarrow 0.5x = 2\% \Rightarrow x = 4\%$
3. **검산**: $-3\% + 0.5 \times 4\% = -3\% + 2\% = -1\%$ ✓
→ **소득 4% 증가**.

#### 4. 유사 산식 비교표 — 헷갈리지 않게

| 구하는 것 | 곱하는 계수 | 곱하는 비율 | 부호 처리 |
|---|---|---|---|
| 수요의 가격탄력성 | ==P의 계수==(절댓값) | $P/Q$ | ==절댓값== |
| 공급의 가격탄력성 | P의 계수 | $P/Q$ | 그대로(양수) |
| 수요의 소득탄력성 | ==Y의 계수== | $Y/Q$ | ==부호 유지==(음수면 열등재) |
| 수요의 교차탄력성 | ==상대재 가격의 계수== | $P_y/Q$ | ==부호 유지==(양수면 대체재) |

#### ⭐ 기출 출제포인트

- **계수가 붙은 함수**($2Q_s$, $3Q_S$)는 거의 매번 나온다. 나누는 것을 잊지 마라.
- 선지가 ==기약분수가 아닌 형태==(12/13, 18/13, 60/29)로 제시되므로 약분 형태를 선지에 맞춰라.
- 합성 문제에서 **가격탄력성만 음수 부호**를 붙인다.

| 2022 제33회 06 | 계산 | 균형에서 ==탄력성의 합 = 60/29== |
| 2023 제34회 07 | 계산 | 변화율형 — 공급탄력성 1.2(탄력적), 교차탄력성 음수(==보완재==) |

#### 🔍 문항으로 배우는 논점

> 자체 연습문항의 선지를 놓고 O/X와 이유를 확인한다.

**①** 수요의 가격탄력성은 수요량 변화율을 가격 변화율로 나눈 뒤 절댓값을 취한 값이다. — **O** / 근거: 분자·분모를 뒤집은 선지가 늘 함께 제시된다. `practice-re-p02c08s01-L1-01`
**②** $Q_d = 60 - 3P$, $P = 10$ 에서 탄력성은 3.0이다. — **X** / 어디가 틀렸나: $P/Q$ 를 곱해야 한다. $3 \times 10/30 = 1.0$. 계수만 답하면 틀린다. `practice-re-p02c08s01-L2-05`
**③** $Q_d = 150 - 2P$, $P = 30$ 에서 탄력성은 2/3이다. — **O** / 근거: $Q = 90$, $E_d = 2 \times 30/90 = 2/3$. `practice-re-p02c08s01-L3-03`
**④** $\Delta Q / \Delta P$ 는 곡선 기울기의 역수다. — **O** / 근거: 그래서 점탄력성 공식에 그대로 들어간다. `practice-re-p02c08s01-L3-11`
**⑤** 교차탄력성이 0이면 대체재다. — **X** / 어디가 틀렸나: ==독립재==다. 대체재는 양수다. `practice-re-p02c08s01-L3-11`
**⑥** $Q_d = -5P + 10Y + 200$, $P = 20$, $Y = 10$ 이면 $Q = 200$ 이고 $E_d = 1/2$, $E_Y = 1/2$ 이다. — **O** / 근거: $E_d = 5 \times 20/200 = 1/2$, $E_Y = 10 \times 10/200 = 1/2$. `practice-re-p02c08s01-L4-03`
**⑦** 위 문제에서 소득탄력성 0.5이므로 사치재다. — **X** / 어디가 틀렸나: 0과 1 사이는 ==필수재==다. 사치재는 1보다 커야 한다. `practice-re-p02c08s01-L4-03`
**⑧** $Q_d = 285 - 4P + 3Y$, $Q_s = 5P$, $Y = 25$ 이면 균형에서 $E_d = 4/5$, $E_Y = 3/8$ 이다. — **O** / 근거: $P = 40$, $Q = 200$ → $E_d = 4 \times 40/200 = 4/5$, $E_Y = 3 \times 25/200 = 3/8$. `practice-re-p02c08s01-L5-05`

#### ⚠️ 이 관의 함정 총정리

1. $2Q_s = -40 + 3P$ 에서 계수를 나누지 않으면 틀림 → $Q_s = -20 + 1.5P$ 로 바꾼다.
2. 점탄력성을 "P의 계수"만으로 답하면 틀림 → 반드시 ==가격을 수량으로 나눈 값(P/Q)== 을 곱한다.
3. 균형을 구하지 않고 임의의 점에서 계산하면 틀림 → 문제가 "==균형에서=="라고 하면 연립이 먼저다.
4. 합성식에서 가격탄력성에 ==음수 부호를 붙이지 않으면== 틀림 → 가격 상승은 수요량을 줄인다.
5. 소득탄력성 계산에 $P/Q$ 를 곱하면 틀림 → ==소득을 수량으로 나눈 값(Y/Q)== 을 곱한다.

#### ✅ OX 확인문제

> 다음 진술의 참·거짓을 판단하시오.

**1.** 점탄력성은 기울기의 역수에 (P/Q)를 곱해 구한다.
→ **O**. 함수형 문제의 표준 공식이다.

**2.** $Q_d = 60 - 3P$, $P = 10$ 에서 수요의 가격탄력성은 1.0이다.
→ **O**. 단위탄력적이다.

**3.** $2Q_s = -40 + 3P$ 는 $Q_s = -40 + 3P$ 와 같다.
→ **X**. 양변을 2로 나눈 $Q_s = -20 + 1.5P$ 가 맞다.

**4.** $Q_D = 100 - P$, $Q_s = -20 + 1.5P$ 의 균형은 (P, Q) = (48, 52)다.
→ **O**. 여기서 $E_d = 12/13$, $E_s = 18/13$ 이다.

**5.** 위 균형에서 수요는 탄력적이다.
→ **X**. 12/13은 1보다 작으므로 ==비탄력적==이다.

**6.** 두 곡선의 탄력성을 균형에서 구할 때 P/Q 값은 서로 같다.
→ **O**. 같은 균형점이므로 계수만 다르다.

**7.** 가격탄력성 0.6, 소득탄력성 0.4, 교차탄력성 0.2일 때 세 변수가 모두 3% 상승하면 수요량은 변하지 않는다.
→ **O**. −1.8 + 1.2 + 0.6 = 0이다.

**8.** 합성식에서 소득탄력성 항에는 음수 부호를 붙인다.
→ **X**. ==가격탄력성 항==에만 음수 부호를 붙인다.

**9.** 소득탄력성이 1/4이면 그 재화는 필수재로 분류된다.
→ **O**. 0과 1 사이이기 때문이다.

**10.** 아파트 가격이 16% 오를 때 다세대주택 수요량이 8% 늘면 교차탄력성은 0.5이고 두 재화는 대체재다.
→ **O**. 부호가 양수이므로 대체관계다.

#### 🧠 암기법

> 🔑 **"계수 곱하기 피큐(P/Q)"** — 점탄력성은 언제나 ==계수 × (P/Q)==. 소득탄력성만 ==(Y/Q)==.

> 🔑 **"나누고, 연립하고, 곱한다"** — ①계수 ==나누==기 → ②균형 ==연립== → ③P/Q ==곱==하기. 3단계 고정.

> 🔑 **합성식은 "마·플·플"** — 가격은 ==마==이너스, 소득과 교차는 ==플==러스(부호 그대로).

3.시장균형의 안정과 불안정(1)수렴형공급곡선 기울기의 절대값이 수요곡선 기울기의 절대값보다 크면 가격은 균형점으로 접근한다. 
①수요곡선의 기울기 < 공급곡선의 기울기②수요의 가격탄력성 > 공급의 가격탄력성
(2)발산형수요곡선 기울기의 절대값이 공급곡선 기울기의 절댓값보다 크면 가격은 균형점에 접근하지 않고 점차 균형점으로부터 일탈해 간다. 
①수요곡선의 기울기 > 공급곡선의 기울기②수요의 가격탄력성 < 공급의 가격탄력성
(3)순환형수요곡선 기울기의 절댓값과 공급곡선 기울기의 절댓값이 동일하면 같은 궤적으로 거래량과 가격이 순환한다.
①수요곡선의 기울기 = 공급곡선의 기울기②수요의 가격탄력성 = 공급의 가격탄력성

제3편
1.5차 감정평가사 부동산학원론
제1장 감정평가에 관한 기초이론 |271
④용도의 다양성: 부동산은 다양한 용도에 사용될 수 있고, 각 용도마다 각기 다른 가치가 형성된다. 그런데 부동산은 최유효이용을 전제로 가치가 결정되므로, 부동산의 최유효이용을 파악하기 위해서 감정평가활동이 필요하다. (2)합리적 시장의 결여로 인한 필요성일반재화는 시장에서 수요공급의 상호작용으로 균형가격이 결정되나, 부동산시장은 부동산의 자연 · 인문특성으로 인하여 합리적인 시장이 형성되지 않아 전문가에 의한 가치식별이 필요하다. (3)가격형성요인의 다양성부동산의 가격은 다양한 요인에 영향받고 또 항상 변화하는 과정에 있기 때문에 전문적인 지식과 풍부한 경험이 필요하다. 또한 고정성의 특성으로 인해 부동산 자체가 복잡한 법률적 요인으로 구성되어 있어 법률에 관한 특별한 지식도 요구되기 때문에 전문가에 의한 평가가 필요하다. (4)부동산의 사회성 · 공공성으로 인한 필요성토지는 국토를 이루고, 주거환경을 이루고, 국민의 재산권을 이루는 높은 사회성 · 공공성이 있다. 따라서 부동산의 경제가치는 이 사회에 미치는 영향이 크기 때문에 높은 전문성과 윤리성을 갖춘 전문가에 의해서 가치가 평가될 필요가 있다.(5)부동산가격형성의 기초감정평가사에 의해 판정된 가격은 다시 일반부동산시장에서 거래의 기준을 제시하므로 적절한 균형가치를 파악할 필요가 있다. 이를 위해 정부는 부동산가격공시제도를 운영하고 있다. (6)부동산거래의 특수성부동산거래는 급매 · 당사자간의 거래 등 개별적 · 비정상적 사정의 개입이 쉽고, 이러한 사정의 파악이 어려워 전문가에 의한 가치판단이 필요하다.
