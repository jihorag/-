# 회계원리 — 부기·회계순환·계정과목 기초 (박문각 감정평가사 목차 기준·K-IFRS)

## 제1장 회계의 기초

### ❶ 회계의 목적

**회계(accounting)**란 기업의 경제적 활동을 화폐 단위로 **식별·측정·기록**하고, 그 결과를 **정보이용자에게 전달**하여 이용자가 합리적 의사결정을 내릴 수 있도록 돕는 일련의 과정이다. 즉 회계의 궁극적 목적은 **"회계정보이용자의 의사결정에 유용한 정보를 제공하는 것"**이다.

기업을 둘러싼 이해관계자들은 각자 서로 다른 의사결정을 내리며, 그 판단의 근거로 회계정보를 사용한다.

| 구분 | 정보이용자 | 주요 의사결정 | 대표 회계정보 |
|---|---|---|---|
| **내부이용자** | 경영자 | 예산 편성, 원가 통제, 투자·생산 계획 | 부문별 손익, 원가자료, 예측자료 |
| **외부이용자** | 주주(투자자) | 주식의 매입·보유·처분 | 순이익, 배당가능이익, 재무상태 |
| | 채권자(은행·거래처) | 대출·신용 제공 여부, 회수가능성 | 부채비율, 이자보상비율, 현금흐름 |
| | 정부(과세당국) | 세금 부과, 규제 | 과세소득, 재무제표 |
| | 종업원·노동조합 | 임금 협상, 고용 안정성 판단 | 수익성, 계속기업 능력 |
| | 일반대중·거래처 | 거래 지속 여부 판단 | 재무건전성 전반 |

- **내부이용자 = 경영자**: 기업 내부에서 경영 활동을 계획·통제하기 위해 정보를 사용한다. 필요한 정보를 원하는 형식·시점에 얻을 수 있다.
- **외부이용자 = 주주·채권자·정부 등**: 기업 외부에서 제한된 정보만을 얻으며, 표준화된 재무제표에 의존한다. 이 때문에 외부보고를 규율하는 **회계기준**이 필요하다.

> 핵심: 회계의 목적은 다양한 정보이용자(내부=경영자, 외부=주주·채권자·정부 등)의 의사결정에 유용한 정보를 제공하는 것이다.

### ❷ 회계의 구분

회계는 **어떤 정보이용자를 위한 것인가**에 따라 크게 **재무회계**와 **관리회계**로 나뉜다.

| 구분 | 재무회계(Financial Accounting) | 관리회계(Management Accounting) |
|---|---|---|
| 정보이용자 | 외부이용자(주주·채권자·정부 등) | 내부이용자(경영자) |
| 목적 | 재무제표를 통한 외부보고 | 경영 계획·통제·의사결정 지원 |
| 준거 기준 | 일반적으로 인정된 회계원칙(GAAP)·K-IFRS | 일정한 기준·형식 없음(기업 자율) |
| 보고 형식 | 표준화된 재무제표 | 자유로운 형식(부문별·제품별 등) |
| 시간 지향 | 과거 지향(이미 발생한 거래) | 미래 지향(예측·계획 포함) |
| 보고 주기 | 정기적(분기·반기·연차) | 수시(필요할 때마다) |
| 강제성 | 법적 강제(외부감사 대상) | 강제성 없음 |

또한 세무 목적의 과세소득을 계산하는 **세무회계**, 회계 처리 과정을 검증하는 **회계감사** 등도 넓은 의미의 회계 영역에 포함된다.

**(1) 일반적으로 인정된 회계원칙(GAAP)**

외부이용자에게 제공되는 재무회계 정보는 기업마다 제각각이면 비교가 불가능하다. 그래서 사회적으로 합의된 회계처리 기준인 **GAAP(Generally Accepted Accounting Principles, 일반적으로 인정된 회계원칙)**가 필요하다. GAAP은 재무제표 작성의 **공통 언어**로서, 기업 간·기간 간 비교가능성을 확보한다.

**(2) 한국채택국제회계기준(K-IFRS)**

우리나라 상장기업 등은 국제회계기준(IFRS)을 한국이 받아들인 **K-IFRS(한국채택국제회계기준)**를 적용한다. K-IFRS의 주요 특징은 다음과 같다.

| 특징 | 내용 |
|---|---|
| **원칙 중심(principle-based)** | 세부 규칙을 일일이 열거하기보다 큰 원칙을 제시하고, 구체적 적용은 기업의 판단(회계전문가적 판단)에 맡긴다. |
| **연결재무제표 중심** | 지배·종속 관계에 있는 기업집단을 하나의 경제적 실체로 보아 **연결재무제표**를 기본(주재무제표)으로 한다. |
| **공정가치(fair value) 측정 확대** | 취득원가뿐 아니라 자산·부채를 시장의 **공정가치**로 측정·평가하는 범위를 넓혔다. |
| 공시 강화 | 재무제표 본문 외 **주석**을 통한 상세 정보 공시를 중시한다. |

> 참고: '원칙 중심'은 규칙을 촘촘히 정하는 '규칙 중심(rule-based)'과 대비된다. 원칙 중심에서는 형식보다 **거래의 경제적 실질**을 우선한다.

**(3) 회계감사(auditing)**

경영자가 작성한 재무제표를 **독립적인 외부 전문가(공인회계사)**가 회계기준(K-IFRS)에 따라 적정하게 작성되었는지 검증하고 **의견을 표명**하는 절차가 **회계감사**이다. 감사의견에는 적정의견, 한정의견, 부적정의견, 의견거절이 있다. 회계감사는 재무제표의 **신뢰성**을 높여 정보이용자를 보호한다.

> 핵심: 재무회계는 외부이용자를 위해 GAAP·K-IFRS에 따라 표준화된 재무제표를 작성하고, 관리회계는 내부 경영자를 위해 자유로운 형식으로 정보를 제공한다. K-IFRS는 원칙 중심·연결 중심·공정가치 확대가 특징이며, 회계감사는 재무제표의 신뢰성을 보증한다.

### ❸ 재무제표

**재무제표(financial statements)**란 기업의 재무상태와 경영성과 등을 정보이용자에게 전달하기 위해 회계기준에 따라 작성하는 보고서이다. K-IFRS가 규정하는 전체 재무제표(full set)는 다음 다섯 가지와 주석으로 구성된다.

| 재무제표 | 보여주는 것 | 측정 시점·기간 | 성격 |
|---|---|---|---|
| **재무상태표** | 자산·부채·자본(재무상태) | **일정 시점**(보고기간 말) | 저량(stock) |
| **포괄손익계산서** | 수익·비용(재무성과) | **일정 기간** | 유량(flow) |
| **현금흐름표** | 현금의 유입·유출 | **일정 기간**(**현금주의**) | 유량(flow) |
| **자본변동표** | 자본의 변동 내역 | **일정 기간** | 유량(flow) |
| **주석** | 위 표들의 상세 설명·보충 정보 | — | 보충 |

각 재무제표를 좀 더 구체적으로 살펴본다.

**(1) 재무상태표(statement of financial position)**

**일정 시점** 현재 기업이 보유한 자산과 갚아야 할 부채, 그리고 순자산인 자본을 보여준다. "20X1년 12월 31일 현재"처럼 **한 시점**의 재무상태를 나타내므로 **저량(stock)** 개념이다.

**(2) 포괄손익계산서(statement of comprehensive income)**

**일정 기간**(예: 20X1.1.1~20X1.12.31) 동안 벌어들인 수익과 그를 위해 소비한 비용을 대응시켜 **재무성과(경영성과)**를 보여준다. 기간 동안의 흐름을 나타내므로 **유량(flow)** 개념이다. 당기순이익에 기타포괄손익을 더한 **총포괄손익**까지 표시한다.

**(3) 현금흐름표(statement of cash flows)**

**일정 기간** 동안 현금이 어떻게 들어오고 나갔는지를 **영업활동·투자활동·재무활동**으로 구분해 보여준다. 수익·비용을 발생 시점에 인식하는 **발생주의**로 작성되는 다른 재무제표와 달리, 현금흐름표는 실제 현금의 수입·지출 시점을 기준으로 하는 **현금주의**에 기초한다.

**(4) 자본변동표(statement of changes in equity)**

**일정 기간** 동안 자본금·자본잉여금·이익잉여금 등 **자본의 각 구성요소가 어떻게 변동**했는지(유상증자, 배당, 당기순이익 반영 등)를 보여준다.

**(5) 주석(notes)**

재무제표 본문에 표시된 항목의 세부 내역, 회계정책, 우발상황 등 본문만으로는 알기 어려운 정보를 **문장·표**로 보충 설명한다. 주석도 엄연한 재무제표의 일부이다.

> 핵심: 전체 재무제표는 재무상태표(일정 시점)·포괄손익계산서(일정 기간)·현금흐름표(일정 기간·현금주의)·자본변동표(일정 기간)·주석으로 구성된다. 재무상태표만 저량(시점)이고, 나머지 계산서는 유량(기간) 개념이다.

## 제2장 재무상태표

### ❶ 재무상태표 표시

**재무상태표(statement of financial position)**는 **일정 시점** 현재 기업의 **재무상태**, 즉 무엇을 얼마나 가지고 있고(자산), 얼마를 갚아야 하며(부채), 순수한 몫이 얼마인지(자본)를 나타내는 재무제표이다. 재무상태표는 다음의 **회계등식(accounting equation)** 위에서 작성된다.

$$\text{자산} = \text{부채} + \text{자본}$$

이 등식은 항상 성립하므로 **대차평균의 원리**라고도 부른다. 왼쪽(차변)에는 자산을, 오른쪽(대변)에는 부채와 자본을 표시하며, 양변의 합계는 반드시 일치한다.

| (차변) 자산 | (대변) 부채와 자본 |
|---|---|
| 현금및현금성자산 | 매입채무 |
| 매출채권 | 차입금 |
| 재고자산 | (부채 합계) |
| 유형자산 | 자본금 |
| | 이익잉여금 |
| **자산 총계** | **부채와 자본 총계** |

- **자산**: 기업이 조달한 자금을 **어떻게 운용하고 있는가**(자금의 운용)를 보여준다.
- **부채·자본**: 그 자금을 **어디서 조달했는가**(자금의 원천)를 보여준다. 부채는 타인으로부터 빌린 **타인자본**, 자본은 주주가 낸 몫과 벌어서 쌓은 몫인 **자기자본**이다.

**계산 예시** *(숫자는 예시임)*: 어떤 기업이 자산 1,000, 부채 600을 보유한다면, 자본은 회계등식에 의해 다음과 같다.

$$\text{자본} = \text{자산} - \text{부채} = 1{,}000 - 600 = 400$$

> 핵심: 재무상태표는 일정 시점의 재무상태를 '자산 = 부채 + 자본'의 회계등식으로 나타내며, 차변 자산 합계와 대변 부채·자본 합계는 항상 일치한다.

### ❷ 재무상태표에 표시되는 사항

재무상태표는 자산·부채·자본의 세 요소로 구성된다. K-IFRS 개념체계상 각 요소의 정의는 다음과 같다.

**(1) 자산(assets)**

- **정의**: 과거 사건의 결과로 기업이 **통제**하는 **현재의 경제적 자원**이다. 여기서 경제적 자원이란 **경제적 효익을 창출할 잠재력**을 지닌 권리를 말한다.
- **인식 요건(전통적 관점)**: ① 과거의 거래·사건의 결과일 것, ② 기업이 통제할 것, ③ 미래 경제적 효익이 기대될 것.
- **분류**: 1년(또는 정상영업주기) 이내 현금화 여부에 따라 **유동자산**과 **비유동자산**으로 나눈다.

| 구분 | 대표 계정 | 내용 |
|---|---|---|
| 유동자산 | 현금및현금성자산 | 현금, 보통예금, 취득 당시 만기 3개월 이내 금융상품 등 |
| | 매출채권 | 상품·제품을 외상으로 판매하고 받을 대금(외상매출금·받을어음) |
| | 재고자산 | 판매를 목적으로 보유하는 상품·제품·원재료 등 |
| 비유동자산 | 유형자산 | 토지·건물·기계장치 등 장기간 영업에 사용하는 실물자산 |
| | 무형자산 | 영업권·산업재산권 등 물리적 형체가 없는 자산 |
| | 투자자산 | 장기투자 목적의 금융자산·투자부동산 등 |

**(2) 부채(liabilities)**

- **정의**: 과거 사건의 결과로 기업이 경제적 자원을 **이전해야 하는 현재의무**이다. 쉽게 말해 미래에 갚아야 할 빚이다.
- **분류**: 상환 시기에 따라 **유동부채**(1년 이내 상환)와 **비유동부채**(1년 초과)로 나눈다.

| 구분 | 대표 계정 | 내용 |
|---|---|---|
| 유동부채 | 매입채무 | 상품·원재료를 외상으로 매입하고 갚을 대금(외상매입금·지급어음) |
| | 단기차입금 | 1년 이내 상환할 차입금 |
| 비유동부채 | 장기차입금 | 1년 이후 상환할 차입금 |
| | 사채 | 회사가 자금 조달을 위해 발행한 채무증권 |

**(3) 자본(equity)**

- **정의**: 자산에서 부채를 차감한 후의 **잔여지분(residual interest)**이다. 주주에게 귀속되는 몫이므로 **순자산(net assets)** 또는 **자기자본**이라고도 한다.
- **주요 구성**:

| 구분 | 내용 |
|---|---|
| 자본금 | 주주가 납입한 자본 중 액면금액에 해당하는 부분 |
| 자본잉여금 | 주식발행초과금 등 자본거래에서 생긴 잉여금 |
| 이익잉여금 | 벌어들인 이익 중 사외로 배당하지 않고 사내에 유보한 부분 |

**예시 분개** *(이해를 돕기 위한 것으로, 시험에서 분개를 직접 묻지는 않는다)*: 주주가 현금 1,000을 출자하여 회사를 설립한 경우 *(숫자는 예시임)*,

```
(차) 현금(자산 증가)   1,000   (대) 자본금(자본 증가)   1,000
```

자산(현금)과 자본(자본금)이 동시에 같은 금액만큼 증가하여 회계등식이 그대로 유지된다.

> 핵심: 자산은 기업이 통제하는 경제적 자원, 부채는 갚아야 할 현재의무, 자본은 자산에서 부채를 뺀 잔여지분(순자산)이다. 자산·부채는 유동/비유동으로 구분한다.

### ❸ 재무상태표 특징

재무상태표의 근본 특징은 **회계등식이 언제나 성립한다**는 점이다. 이를 여러 형태로 변형해 보면 자본의 의미가 분명해진다.

**(1) 기본형과 변형**

$$\text{자산총액} = \text{부채총액} + \text{자본총액}$$

이를 자본에 대해 정리하면,

$$\text{자본} = \text{자산} - \text{부채} \quad (\text{순자산} = \text{자산} - \text{부채})$$

**어느 한 시점**에서든 이 관계가 성립하므로, 기초 시점에도 다음이 성립한다.

$$\text{기초자본} = \text{기초자산} - \text{기초부채}$$
$$\text{기말자본} = \text{기말자산} - \text{기말부채}$$

**(2) 자본 = 순자산 = 잔여지분**

자본은 독립적으로 측정되는 값이 아니라, **자산에서 부채를 차감한 결과로 결정되는 잔여값**이다. 그래서 자본을 **잔여지분**이라 부르며, 자산·부채가 먼저 측정되면 자본은 자동으로 정해진다.

**계산 예시** *(숫자는 예시임)*: 다음 자료로 각 항목을 구해 본다.

| 항목 | 금액(예시) |
|---|---|
| 기초자산 | 5,000 |
| 기초부채 | 3,000 |
| 기말자산 | 8,000 |
| 기말부채 | 4,500 |

- 기초자본 = 5,000 − 3,000 = **2,000**
- 기말자본 = 8,000 − 4,500 = **3,500**
- 기간 중 자본 증가액 = 3,500 − 2,000 = **1,500**

이 자본 증가액 1,500이 어디서 비롯되었는지(영업으로 번 것인지, 주주가 추가 출자한 것인지)를 규명하는 것이 손익계산과 자본변동 분석의 출발점이다. 이는 제3장에서 이어진다.

**(3) 거래의 이중성과 대차평균**

모든 거래는 반드시 **두 가지 이상의 요소에 영향**을 주며(거래의 이중성), 차변 금액의 합과 대변 금액의 합은 항상 같다(**대차평균의 원리**). 따라서 아무리 많은 거래가 일어나도 회계등식의 균형은 절대 깨지지 않는다.

> 핵심: 재무상태표에서는 항상 '자산 = 부채 + 자본'이 성립하며, 자본은 '자산 − 부채'로 계산되는 순자산(잔여지분)이다. 기초·기말 어느 시점에서도 이 등식이 유지된다.

## 제3장 손익계산서(포괄손익계산서)

### ❶ 손익계산서 표시

**손익계산서(포괄손익계산서, statement of comprehensive income)**는 **일정 기간** 동안 기업이 이룬 **재무성과(경영성과)**를 나타내는 재무제표이다. 재무상태표가 '일정 시점'의 상태(저량)를 보여준다면, 손익계산서는 '일정 기간'의 흐름(유량)을 보여준다.

손익계산서는 그 기간의 **수익(revenue)**과 **비용(expense)**, 그리고 둘의 차이인 **이익(profit)**을 표시한다.

$$\text{이익} = \text{수익} - \text{비용}$$

| 재무상태표 | 손익계산서 |
|---|---|
| 일정 **시점**의 재무상태 | 일정 **기간**의 재무성과 |
| 저량(stock) | 유량(flow) |
| 자산·부채·자본 | 수익·비용·이익 |
| 자산 = 부채 + 자본 | 이익 = 수익 − 비용 |

> 핵심: 손익계산서는 일정 기간의 재무성과를 수익·비용·이익으로 나타내는 유량 개념의 재무제표이며, '이익 = 수익 − 비용'이 기본 구조이다.

### ❷ 손익계산서에 표시되는 사항

**(1) 수익(revenue·income)**

- **정의**: **자산의 증가** 또는 **부채의 감소**로 인해 **자본이 증가**하는 것 중, **주주(소유주)의 출자와 관련된 것을 제외**한 것을 말한다.
  - 예컨대 상품을 팔고 현금을 받으면 자산(현금)이 늘어 자본이 증가하므로 수익이다.
  - 그러나 주주가 추가로 출자하여 자본이 증가한 것은 수익이 **아니다**(소유주 투자 제외).
- **종류**:

| 계정 | 내용 |
|---|---|
| 매출(수익) | 상품·제품·용역을 판매하여 얻는 주된 영업수익 |
| 이자수익 | 예금·대여금 등에서 발생하는 이자 |
| 배당금수익 | 보유 주식에서 받는 배당금 |
| 임대료 | 부동산 등을 빌려주고 받는 대가 |

**(2) 비용(expense)**

- **정의**: **자산의 감소** 또는 **부채의 증가**로 인해 **자본이 감소**하는 것 중, **주주(소유주)에 대한 분배와 관련된 것을 제외**한 것을 말한다.
  - 예컨대 종업원에게 급여를 현금으로 지급하면 자산(현금)이 줄어 자본이 감소하므로 비용이다.
  - 그러나 주주에게 배당금을 지급하여 자본이 감소한 것은 비용이 **아니다**(소유주 분배 제외).
- **종류**: 매출원가, 급여, 임차료, 이자비용, 감가상각비, 광고선전비 등.

> 유의: 수익·비용의 정의에서 **소유주와의 거래(출자·배당)를 제외**하는 것이 핵심이다. 소유주와의 자본거래는 손익이 아니라 **자본의 직접적 증감**으로 처리한다.

**(3) 수익·비용의 기록방법 — T계정**

각 계정은 왼쪽(차변)과 오른쪽(대변)으로 나뉜 **T자 모양(T계정)**으로 기록한다. **자산의 증가는 차변, 감소는 대변**에, **자본·부채의 증가는 대변, 감소는 차변**에 기록하는 것이 기본 원칙이다. 수익과 비용은 자본의 증감을 세분한 것이므로 다음과 같이 기록한다.

- **수익**: 자본을 증가시키므로 **발생 시 대변(오른쪽)**에 기록한다.
- **비용**: 자본을 감소시키므로 **발생 시 차변(왼쪽)**에 기록한다.

```
        비용 계정                         수익 계정
 ┌──────────┬──────────┐         ┌──────────┬──────────┐
 │ (증가/발생) │          │         │          │ (증가/발생) │
 │   차변    │          │         │          │   대변    │
 └──────────┴──────────┘         └──────────┴──────────┘
```

**예시 분개** *(이해용, 숫자는 예시임)*:

- 상품을 판매하고 현금 300을 받은 경우:
```
(차) 현금(자산 증가)  300   (대) 매출(수익 발생)  300
```
- 급여 200을 현금으로 지급한 경우:
```
(차) 급여(비용 발생)  200   (대) 현금(자산 감소)  200
```

> 핵심: 수익은 소유주 출자를 제외한 자본 증가(자산 증가·부채 감소)로 대변에 기록하고, 비용은 소유주 분배를 제외한 자본 감소(자산 감소·부채 증가)로 차변에 기록한다.

### ❸ 당기순손익

한 회계기간의 수익 총액과 비용 총액을 대응시켜 계산한 순액을 **당기순손익(net profit or loss)**이라 한다.

$$\text{당기순이익} = \text{당기수익} - \text{당기비용} \quad (\text{수익} > \text{비용})$$
$$\text{당기순손실} = \text{당기비용} - \text{당기수익} \quad (\text{비용} > \text{수익})$$

- 수익이 비용보다 크면 **당기순이익**이 발생하고, 자본이 증가한다.
- 비용이 수익보다 크면 **당기순손실**이 발생하고, 자본이 감소한다.

**계산 예시** *(숫자는 예시임)*:

| 항목 | 금액(예시) |
|---|---|
| 매출 | 1,000 |
| 이자수익 | 50 |
| 매출원가 | 600 |
| 급여 | 200 |
| 이자비용 | 30 |

- 수익 총액 = 1,000 + 50 = 1,050
- 비용 총액 = 600 + 200 + 30 = 830
- 당기순이익 = 1,050 − 830 = **220**

> 참고: K-IFRS에서는 당기순이익에 재평가잉여금·기타포괄손익-공정가치측정 금융자산평가손익 등 **기타포괄손익**을 가감하여 **총포괄손익**을 별도로 표시한다. 다만 회계원리 단계에서는 '당기순이익 = 수익 − 비용'을 기본으로 이해하면 충분하다.

> 핵심: 당기순손익은 당기수익에서 당기비용을 차감한 값으로, 수익이 크면 당기순이익(자본 증가), 비용이 크면 당기순손실(자본 감소)이 된다.

### ❹ 재무상태표와 손익계산서의 연결관계

재무상태표와 손익계산서는 서로 별개가 아니라 **자본(이익잉여금)을 매개로 긴밀히 연결**된다. 손익계산서에서 계산된 **당기순이익**은 결산을 통해 재무상태표의 **이익잉여금**으로 대체되며, 이는 곧 **자본의 증가**로 이어진다.

$$\text{당기순이익} \;\rightarrow\; \text{이익잉여금 증가} \;\rightarrow\; \text{자본 증가}$$

이러한 연결 고리를 흐름으로 표현하면 다음과 같다.

```
[손익계산서]                       [재무상태표]
 수익 − 비용 = 당기순이익  ───▶  이익잉여금(↑) ───▶ 자본(↑)
```

- 손익계산서의 성과(당기순이익)가 재무상태표의 자본을 늘린다.
- 반대로 당기순손실이 발생하면 이익잉여금이 감소하여 자본이 줄어든다.

이처럼 손익계산서는 **자본이 왜, 얼마나 변했는지를 설명**해 주는 역할을 한다. 즉 두 재무제표는 **당기순이익**이라는 연결고리로 이어져 하나의 정합적인 체계를 이룬다.

> 핵심: 손익계산서의 당기순이익은 이익잉여금을 거쳐 재무상태표의 자본을 증가시킨다. 두 재무제표는 당기순이익을 매개로 연결된다.

### ❺ 기초자본과 기말자본의 차이 원인

한 회계기간 동안 자본은 여러 이유로 변한다. 자본을 변동시키는 거래는 크게 **손익거래**와 **자본거래**로 나뉜다.

| 구분 | 성격 | 대표 거래 | 자본에 미치는 영향 |
|---|---|---|---|
| **손익거래** | 영업활동으로 인한 성과 | 매출, 급여 지급 등 → 당기순손익 | 당기순이익(+), 당기순손실(−) |
| **자본거래** | 소유주(주주)와의 직접 거래 | 유상증자(추가 출자), 현금배당 | 유상증자(+), 현금배당(−) |

**(1) 자본 변동의 전체 등식**

기말자본은 기초자본에서 위 두 종류의 거래 효과를 모두 반영한 값이다.

$$\text{기말자본} - \text{기초자본} = \underbrace{\text{당기순손익}}_{\text{손익거래}} + \underbrace{(\text{유상증자} - \text{현금배당})}_{\text{자본거래}}$$

**(2) 손익을 역으로 구하는 원리**

위 식을 당기순손익에 대해 정리하면, **자본거래를 제외한 자본의 순변동이 곧 당기순손익**임을 알 수 있다.

$$\text{당기순손익} = (\text{기말자본} - \text{기초자본}) - \text{유상증자} + \text{현금배당}$$

즉, **자본의 변동분 중 소유주와의 자본거래(유상증자·현금배당)를 제외한 나머지가 손익거래에 의한 순손익**이다. 이 원리는 회계원리 시험에서 매우 자주 출제된다.

**계산 예시** *(숫자는 예시임)*:

| 항목 | 금액(예시) |
|---|---|
| 기초자본 | 2,000 |
| 기말자본 | 3,500 |
| 기중 유상증자 | 800 |
| 기중 현금배당 | 300 |

- 자본 순변동 = 3,500 − 2,000 = 1,500
- 자본거래 순효과 = 유상증자 800 − 현금배당 300 = +500
- 당기순이익 = 1,500 − 500 = **1,000**

**검증**: 기초자본 2,000 + 당기순이익 1,000 + 유상증자 800 − 현금배당 300 = 기말자본 **3,500** ✔

**예시 분개** *(이해용, 숫자는 예시임)*:

- 유상증자로 현금 800을 추가 출자받은 경우:
```
(차) 현금(자산 증가)   800   (대) 자본금(자본 증가)   800
```
- 주주에게 현금배당 300을 지급한 경우:
```
(차) 이익잉여금(자본 감소)  300   (대) 현금(자산 감소)  300
```

이 두 거래는 손익계산서를 거치지 않고 **자본을 직접 증감**시킨다. 따라서 자본 변동에서 이들 자본거래를 걷어내야 순수한 영업성과인 당기순손익을 구할 수 있다.

> 핵심: 기말자본과 기초자본의 차이는 손익거래(당기순손익)와 자본거래(유상증자·현금배당)로 설명된다. 자본거래를 제외한 자본의 순변동이 곧 당기순손익이다.

## 제4장 회계상 거래와 분개·전기

회계는 기업의 경제활동을 화폐로 기록·측정하여 재무제표라는 결과물로 요약하는 과정이다. 그 출발점이 바로 **회계상 거래**의 인식이며, 이를 장부에 옮기는 첫 절차가 **분개(分介)**와 **전기(轉記)**다. 이 장은 회계순환과정의 기초 문법에 해당하므로, 감정평가사 수험에서 계산·분개 문제의 토대가 된다.

### ❶ 회계상 거래란?

#### 1. 회계상 거래의 정의

회계에서 말하는 **거래(transaction)**란, 기업의 **자산·부채·자본에 증감 변화를 일으키고 그 금액을 화폐로 신뢰성 있게 측정할 수 있는 모든 경제적 사건**을 말한다. 즉, 아래 두 가지 요건을 **모두** 충족해야 회계상 거래로 인식한다.

| 요건 | 내용 |
|---|---|
| ① 재무상태의 변동 | 자산·부채·자본 중 하나 이상에 증감이 발생해야 한다 |
| ② 화폐적 측정가능성 | 그 변동 금액을 신뢰성 있게 화폐로 측정할 수 있어야 한다 |

이 정의는 우리가 일상에서 쓰는 "거래"라는 말과 **범위가 다르다**는 점이 핵심이다.

#### 2. 회계상 거래 vs 일상적 거래

일상적으로는 "거래"라고 부르지만 회계상으로는 거래가 아닌 경우가 있고, 반대로 일상적으로는 거래라고 부르지 않지만 회계상으로는 거래인 경우가 있다. 두 개념의 관계는 서로 겹치되 완전히 일치하지 않는 **교집합 관계**다.

| 사건 | 일상적 거래 | 회계상 거래 | 이유 |
|---|:---:|:---:|---|
| 상품을 주문(발주)함 | O | **X** | 아직 자산·부채 변동 없음 (계약만 체결) |
| 건물 임대차 **계약** 체결 | O | **X** | 계약 시점엔 재무상태 변동 없음 |
| 상품 매입 계약 후 **주문**만 함 | O | **X** | 인도·대금지급 전엔 변동 없음 |
| 종업원 **채용** 결정 | O | **X** | 근무·급여지급 전엔 변동 없음 |
| 화재로 건물이 **소실**됨 | X | **O** | 자산(건물) 감소 → 측정가능 |
| 상품을 **도난**당함 | X | **O** | 자산(상품) 감소 → 측정가능 |
| 상품 가치 **하락(감모·손상)** | X | **O** | 자산 감소 → 측정가능 |
| 현금을 **분실**함 | X | **O** | 자산(현금) 감소 → 측정가능 |

**핵심 포인트**
- **단순 계약·주문·약속**은 재무상태 변동이 없으므로 회계상 거래가 **아니다**. 계약금·착수금을 실제로 주고받으면 그때 비로소 거래가 된다.
- **화재·도난·분실·파손**은 상대방과의 "거래" 상대가 없어 일상적으로는 거래라 하지 않지만, 자산의 감소를 화폐로 측정할 수 있으므로 회계상 **거래에 해당**한다.

> 수험 함정: "임대차 계약을 맺었다" → 회계상 거래 X / "임대차 계약을 맺고 보증금을 지급했다" → 회계상 거래 O

#### 3. 거래의 이중성(去來의 二重性)

모든 회계상 거래는 반드시 **원인과 결과**라는 두 가지 측면을 가진다. 하나의 거래가 발생하면 **차변(왼쪽) 요소와 대변(오른쪽) 요소가 항상 동시에, 같은 금액으로** 나타난다. 이를 **거래의 이중성**이라 한다.

예: "현금 100,000원을 출자하여 사업을 시작했다."
- 결과: 자산(현금) 100,000 증가 → **차변**
- 원인: 자본(자본금) 100,000 증가 → **대변**

이 이중성 때문에 모든 거래는 **차변 금액 합계 = 대변 금액 합계**가 항상 성립한다. 이것이 뒤에서 배울 **복식부기(複式簿記)**와 **대차평균의 원리**의 근거이며, 시산표로 오류를 검증할 수 있는 이유다.

#### 4. 거래의 8요소

회계상 거래는 재무상태표 등식(자산 = 부채 + 자본)과 손익 요소(수익·비용)를 바탕으로 아래 **8가지 요소**의 결합으로 나타난다. 각 요소가 차변에 오는지 대변에 오는지는 **계정의 성격**에 따라 고정된다.

| 차변요소 (왼쪽) | 대변요소 (오른쪽) |
|---|---|
| **자산의 증가** | 자산의 감소 |
| 부채의 감소 | **부채의 증가** |
| 자본의 감소 | **자본의 증가** |
| **비용의 발생** | 수익의 발생 |

정리하면 다음과 같다.

- **차변(왼쪽)에 오는 것**: 자산의 증가 · 부채의 감소 · 자본의 감소 · 비용의 발생
- **대변(오른쪽)에 오는 것**: 자산의 감소 · 부채의 증가 · 자본의 증가 · 수익의 발생

이 8요소는 서로 결합하여 하나의 거래를 이룬다. 예를 들어 "자산의 증가 ↔ 자본의 증가"(현금출자), "자산의 증가 ↔ 부채의 증가"(외상매입), "비용의 발생 ↔ 자산의 감소"(현금 급여지급) 등으로 짝을 이룬다. 다만 **차변요소끼리** 또는 **대변요소끼리**는 서로 결합하지 않는다(예: 자산의 증가와 비용의 발생은 둘 다 차변이므로 하나의 완결된 거래를 이룰 수 없다).

**계정별 증가·감소 방향 요약표**

| 계정 성격 | 증가 위치 | 감소 위치 | 잔액이 남는 쪽 |
|---|:---:|:---:|:---:|
| 자산 | 차변 | 대변 | 차변 |
| 부채 | 대변 | 차변 | 대변 |
| 자본 | 대변 | 차변 | 대변 |
| 비용 | 차변 (발생) | 대변 (소멸) | 차변 |
| 수익 | 대변 (발생) | 차변 (소멸) | 대변 |

> **핵심:** 회계상 거래는 ① 재무상태를 변동시키고 ② 화폐로 측정 가능한 사건이다. 화재·도난·분실은 거래 O, 단순 계약·주문은 거래 X다. 모든 거래는 거래의 이중성에 따라 차변요소·대변요소로 동시에 기록되며, 8요소(차변: 자산↑·부채↓·자본↓·비용발생 / 대변: 자산↓·부채↑·자본↑·수익발생)의 결합으로 표현된다.

### ❷ 분개(分介)

#### 1. 분개란?

**분개(journalizing)**란 하나의 거래가 발생했을 때, 그 거래를 **어느 계정의 차변·대변에 얼마씩 기록할지 결정하는 절차**다. 회계기록의 최초 단계이며, 분개를 날짜순으로 기록하는 장부를 **분개장(分介帳, journal)**이라 한다.

분개는 다음 세 가지를 결정하는 일이다.
1. **어떤 계정과목**을 사용할 것인가
2. 그 계정을 **차변에 쓸 것인가, 대변에 쓸 것인가**
3. **금액**은 얼마인가

#### 2. 차변·대변 결정 규칙

분개는 거래의 8요소를 그대로 적용하면 된다. 순서는 다음과 같다.

**분개의 순서 (5단계)**
1. 거래를 분석하여 관련된 **계정과목**을 파악한다.
2. 각 계정과목이 **자산·부채·자본·수익·비용 중 무엇**인지 판단한다.
3. 그 계정이 **증가했는지 감소(발생/소멸)**했는지 판단한다.
4. 8요소 규칙에 따라 **차변인지 대변인지** 결정한다.
5. **차변 합계 = 대변 합계**가 되는지 확인한다(거래의 이중성).

간단한 판단 기준을 다시 요약하면:

| 판단 | 차변에 기록 | 대변에 기록 |
|---|---|---|
| 자산 | 증가하면 | 감소하면 |
| 부채 | 감소하면 | 증가하면 |
| 자본 | 감소하면 | 증가하면 |
| 비용 | 발생하면 | (소멸하면) |
| 수익 | (소멸하면) | 발생하면 |

#### 3. 분개 연습 예시

아래는 대표적인 거래 유형별 분개다. (차)는 차변, (대)는 대변을 뜻한다.

**[예제 1] 현금 출자 (사업 개시)**
"현금 5,000,000원을 출자하여 영업을 개시하다."
- 현금(자산) 5,000,000 증가 → 차변
- 자본금(자본) 5,000,000 증가 → 대변

```
(차) 현    금   5,000,000   (대) 자 본 금   5,000,000
```

**[예제 2] 상품 외상매입**
"상품 800,000원을 외상으로 매입하다." (3분법 기준)
- 매입(비용) 800,000 발생 → 차변
- 외상매입금(부채) 800,000 증가 → 대변

```
(차) 매    입     800,000   (대) 외상매입금   800,000
```

**[예제 3] 상품 현금매출**
"원가 300,000원의 상품을 500,000원에 현금으로 판매하다." (3분법)
- 현금(자산) 500,000 증가 → 차변
- 매출(수익) 500,000 발생 → 대변

```
(차) 현    금     500,000   (대) 매    출     500,000
```
※ 3분법에서는 매출 시점에 매출원가를 따로 분개하지 않고, 기말에 매출원가를 일괄 산정한다(제6장 참조).

**[예제 4] 급여 지급**
"종업원 급여 1,200,000원을 현금으로 지급하다."
- 급여(비용) 1,200,000 발생 → 차변
- 현금(자산) 1,200,000 감소 → 대변

```
(차) 급    여   1,200,000   (대) 현    금   1,200,000
```

**[예제 5] 비품 구입 (일부 현금·일부 외상)**
"비품 1,000,000원을 구입하고 대금 중 600,000원은 현금으로, 나머지 400,000원은 외상(미지급금)으로 하다."
- 비품(자산) 1,000,000 증가 → 차변
- 현금(자산) 600,000 감소 → 대변
- 미지급금(부채) 400,000 증가 → 대변

```
(차) 비    품   1,000,000   (대) 현    금     600,000
                             미지급금     400,000
```
※ 이처럼 한 거래에서 차변·대변 중 어느 한쪽 이상이 여러 계정으로 구성되는 분개를 **복합분개**라 한다. 이때도 차변 합계(1,000,000) = 대변 합계(600,000+400,000=1,000,000)로 일치한다.

**[예제 6] 차입금 상환 (이자 포함)**
"차입금 2,000,000원과 이자 50,000원을 현금으로 상환하다."
- 차입금(부채) 2,000,000 감소 → 차변
- 이자비용(비용) 50,000 발생 → 차변
- 현금(자산) 2,050,000 감소 → 대변

```
(차) 차 입 금   2,000,000   (대) 현    금   2,050,000
    이자비용      50,000
```

> **핵심:** 분개는 거래를 차변·대변 계정으로 나누어 기록하는 최초 절차이며, 분개장에 기록한다. 계정의 성격(자산·부채·자본·수익·비용)을 파악하고 증감을 판단하여 8요소 규칙대로 차변·대변에 배분한다. 언제나 **차변 합계 = 대변 합계**가 성립해야 한다.

### ❸ 전기(轉記)

#### 1. 전기와 총계정원장

**전기(posting)**란 분개장에 기록한 분개를 **계정과목별 장부인 총계정원장(總計定元帳, general ledger)으로 옮겨 적는 절차**다. 분개장은 거래를 **날짜순**으로 기록하지만, 계정과목별 잔액을 알기 위해서는 같은 계정끼리 모아야 한다. 그 역할을 하는 것이 총계정원장이며, 그 안의 각 계정은 흔히 **T계정(T-account)** 형태로 표현한다.

T계정은 왼쪽(차변)과 오른쪽(대변)으로 나뉜다.

```
        계정과목명
 ─────────────┬─────────────
   (차변)      │    (대변)
              │
```

#### 2. 전기의 방법

전기는 분개된 내용을 그대로 옮기면 된다.
- 분개에서 **차변에 기록된 계정** → 그 계정 T계정의 **차변**에 금액 기입
- 분개에서 **대변에 기록된 계정** → 그 계정 T계정의 **대변**에 금액 기입

이때 기입란에는 보통 **날짜와 상대계정과목**을 함께 적는다(상대계정을 적으면 어떤 거래에서 왔는지 추적이 쉽다).

#### 3. 분개 → 전기 예시

앞의 예제들을 이용해 전기 과정을 살펴본다.

**분개**
```
① (차) 현    금   5,000,000   (대) 자 본 금   5,000,000   [현금출자]
② (차) 매    입     800,000   (대) 외상매입금   800,000   [상품 외상매입]
③ (차) 현    금     500,000   (대) 매    출     500,000   [상품 현금매출]
④ (차) 급    여   1,200,000   (대) 현    금   1,200,000   [급여 지급]
```

**전기 (총계정원장 T계정)**

```
           현 금 (자산)                        자본금 (자본)
 ──────────────┬──────────────      ──────────────┬──────────────
 ① 자본금 5,000,000│④ 급여 1,200,000                    │① 현금 5,000,000
 ③ 매출     500,000│                               │
 ──────────────┴──────────────      ──────────────┴──────────────
  차변합 5,500,000 │ 대변합 1,200,000
  잔액(차변) 4,300,000

           매 입 (비용)                        외상매입금 (부채)
 ──────────────┬──────────────      ──────────────┬──────────────
 ② 외상매입금 800,000│                        │② 매입 800,000
 ──────────────┴──────────────      ──────────────┴──────────────

           매 출 (수익)                          급 여 (비용)
 ──────────────┬──────────────      ──────────────┬──────────────
              │③ 현금 500,000        ④ 현금 1,200,000│
 ──────────────┴──────────────      ──────────────┴──────────────
```

**해설**
- **현금 계정(자산)**: 증가는 차변, 감소는 대변에 기입된다. 출자·매출로 들어온 현금은 차변에, 급여로 나간 현금은 대변에 기록되어 잔액 4,300,000원(차변)이 남는다.
- **자본금 계정(자본)**: 증가는 대변이므로 대변에 5,000,000원.
- **외상매입금 계정(부채)**: 증가는 대변이므로 대변에 800,000원.
- **매입 계정(비용)**: 발생은 차변이므로 차변에 800,000원.
- **매출 계정(수익)**: 발생은 대변이므로 대변에 500,000원.

#### 4. 계정별 증가·감소 위치 정리

전기가 정확하려면 각 계정의 증가·감소가 어느 쪽에 오는지 몸에 익혀야 한다.

| 계정 성격 | 증가 | 감소 | 정상(기말)잔액 |
|---|:---:|:---:|:---:|
| **자산** | 차변 | 대변 | 차변 |
| **부채** | 대변 | 차변 | 대변 |
| **자본** | 대변 | 차변 | 대변 |
| **수익** | 대변(발생) | 차변(소멸) | 대변 |
| **비용** | 차변(발생) | 대변(소멸) | 차변 |

암기 요령: **재무상태표 왼쪽(자산)에 오는 계정은 차변이 증가**, **재무상태표 오른쪽(부채·자본)에 오는 계정은 대변이 증가**한다. 손익 항목은 **비용은 자산처럼 차변**, **수익은 부채·자본처럼 대변**이 정상 위치라고 기억하면 편하다.

#### 5. 대차평균의 원리 재확인

거래의 이중성 때문에 모든 분개는 차변 합계 = 대변 합계이며, 전기 후 모든 계정의 **차변 금액 총합 = 대변 금액 총합**이 성립한다. 이를 **대차평균의 원리**라 하고, 이 성질을 이용해 다음 장의 **시산표**로 전기의 정확성을 검증한다.

> **핵심:** 전기는 분개를 계정별 장부인 총계정원장(T계정)으로 옮기는 절차다. 차변 분개는 해당 계정 차변에, 대변 분개는 해당 계정 대변에 옮긴다. 자산·비용은 차변이 증가, 부채·자본·수익은 대변이 증가이며, 전기 후에도 차변 총합 = 대변 총합(대차평균의 원리)이 유지된다.

## 제5장 회계의 순환과정과 결산

기업은 매 회계기간(보통 1년)마다 거래를 기록하고, 기말에 이를 정리하여 재무제표를 작성한다. 이 일련의 과정이 매 기간 반복되므로 **회계의 순환과정(accounting cycle)**이라 부른다. 이 장에서는 순환과정 전체 흐름과 그 핵심 절차인 **시산표·기말수정분개·마감**을 다룬다.

### ❶ 회계의 순환과정

#### 1. 순환과정의 전체 흐름

회계의 순환과정은 크게 **기중 절차**와 **기말(결산) 절차**로 나뉜다.

```
[기중 절차]
 거래의 발생
      │
      ▼
 ① 분개 (분개장)
      │
      ▼
 ② 전기 (총계정원장)
      │
──────┼──────────────────────  (기말 도래)
      ▼
[기말·결산 절차]
 ③ 수정전시산표 작성 (전기 정확성 1차 점검)
      │
      ▼
 ④ 기말수정분개 (결산수정분개)
      │
      ▼
 ⑤ 수정후시산표 작성 (수정 반영 후 재점검)
      │
      ▼
 ⑥ 장부 마감 (수익·비용 → 집합손익 → 자본 대체)
      │
      ▼
 ⑦ 재무제표 작성
    (재무상태표·포괄손익계산서·자본변동표·현금흐름표·주석)
```

#### 2. 각 단계 설명

| 단계 | 절차 | 내용 |
|---|---|---|
| ① | **분개** | 거래를 차변·대변으로 분석하여 분개장에 기록 |
| ② | **전기** | 분개를 총계정원장의 각 계정으로 옮김 |
| ③ | **수정전시산표** | 전기 후 계정 잔액을 모아 대차평균을 점검 |
| ④ | **기말수정분개** | 발생주의에 맞게 기간귀속을 조정 (선급·선수·미수·미지급·감가상각 등) |
| ⑤ | **수정후시산표** | 수정분개를 반영한 잔액으로 다시 대차평균 점검 |
| ⑥ | **마감** | 수익·비용 계정을 집합손익으로 대체하고 순손익을 자본으로 대체, 장부 마감 |
| ⑦ | **재무제표 작성** | 마감된 자료로 재무제표 작성 |

**기중(期中)에 반복되는 절차**는 ①분개 → ②전기이고, **기말(결산 시점)에 한 번 수행하는 절차**가 ③~⑦이다. 실무에서는 ③~⑥의 과정을 하나의 표로 정리한 **정산표(精算表)**를 이용하기도 한다(❹에서 설명).

> **핵심:** 회계의 순환과정은 「거래발생 → 분개 → 전기 → 수정전시산표 → 기말수정분개 → 수정후시산표 → 마감 → 재무제표」의 순서로 매 기간 반복된다. 분개·전기는 기중 절차, 시산표부터 재무제표까지는 기말(결산) 절차다.

---

### ❷ 시산표(試算表)

#### 1. 작성 목적

**시산표(trial balance)**는 총계정원장의 모든 계정 잔액(또는 합계)을 한곳에 모은 표로, **전기가 정확히 이루어졌는지를 대차평균의 원리로 점검**하기 위해 작성한다. 거래의 이중성에 따라 언제나 차변 총합 = 대변 총합이 성립해야 하므로, 시산표의 차변 합계와 대변 합계가 일치하지 않으면 **어딘가에 오류가 있음**을 알 수 있다.

#### 2. 시산표의 종류

| 종류 | 작성 방법 | 특징 |
|---|---|---|
| **합계시산표** | 각 계정의 차변합계·대변합계를 모음 | 총거래액(거래 규모) 파악 가능 |
| **잔액시산표** | 각 계정의 잔액만 모음 | 재무제표 작성의 기초, 가장 많이 사용 |
| **합계잔액시산표** | 합계와 잔액을 함께 표시 | 합계·잔액 정보 모두 제공 |

**잔액시산표 예시**

| 차변 | 계정과목 | 대변 |
|---:|---|---:|
| 4,300,000 | 현금 | |
| 800,000 | 매입 | |
| 1,200,000 | 급여 | |
| | 외상매입금 | 800,000 |
| | 자본금 | 5,000,000 |
| | 매출 | 500,000 |
| **6,300,000** | **합계** | **6,300,000** |

차변 합계 6,300,000 = 대변 합계 6,300,000 으로 대차가 평균을 이룬다.

#### 3. 시산표에서 발견할 수 있는 오류

시산표는 **차변·대변 금액의 불일치를 초래하는 오류**만 찾아낼 수 있다. 예를 들어,
- 한쪽만 전기(차변만 기입하고 대변 누락)
- 차변·대변 금액을 다르게 전기
- 잔액 계산 오류, 합계 오류

이런 경우 차변 합계 ≠ 대변 합계가 되어 오류가 드러난다.

#### 4. 시산표에서 발견할 수 없는 오류 (중요)

반대로, **차변·대변 합계에는 영향을 주지 않는 오류**는 시산표로 잡아낼 수 없다. 대표적인 유형은 다음과 같다.

| 오류 유형 | 설명 | 대차 일치? |
|---|---|:---:|
| **거래 전체 누락** | 어떤 거래를 분개·전기 자체를 하지 않음 | 일치(발견 X) |
| **이중 분개(중복 기록)** | 같은 거래를 두 번 분개·전기 | 일치(발견 X) |
| **차·대변 반대 전기** | 차변에 올 것을 대변에, 대변에 올 것을 차변에 기록 | 일치(발견 X) |
| **계정과목 오류** | 금액은 맞으나 엉뚱한 계정과목으로 기록 (예: 비품을 소모품으로) | 일치(발견 X) |
| **금액을 양쪽 모두 동일하게 틀림** | 차·대변 모두 같은 금액으로 잘못 기록 | 일치(발견 X) |
| **오류의 상계** | 서로 다른 두 오류가 우연히 상쇄됨 | 일치(발견 X) |

이들은 모두 **차변 합계 = 대변 합계**를 유지한 채 발생하므로 시산표만으로는 발견되지 않는다. 이런 오류는 재검토·대조·내부통제 등 별도의 방법으로 확인해야 한다.

> **핵심:** 시산표는 대차평균의 원리로 전기의 정확성을 점검하는 표로, 합계·잔액·합계잔액시산표가 있다. 그러나 **거래 전체 누락, 이중 분개, 차·대변 반대 전기, 계정과목 오류**처럼 차변·대변 합계에 영향을 주지 않는 오류는 시산표로 발견할 수 없다.

### ❸ 기말수정분개(결산수정분개)

#### 1. 목적

회계는 **발생주의(accrual basis)**에 따라 수익·비용을 **현금 수수 시점이 아니라 그것이 실제로 발생한 기간**에 인식한다. 기중에는 편의상 현금기준으로 기록한 부분이 있어, 기말에 이를 발생주의에 맞게 조정해야 한다. 이 조정 분개가 **기말수정분개(결산수정분개, adjusting entries)**다. 그 목적은 다음과 같다.
- 수익·비용을 **올바른 회계기간에 귀속**시킴 (기간 대응)
- 자산·부채를 **정확한 기말 잔액**으로 표시함

#### 2. 유형과 예시 분개

기말수정분개는 크게 **이연항목·발생항목·추정항목**으로 나뉜다.

##### (1) 이연항목(移延, deferral)

이미 현금을 주고받았으나, 그 수익·비용의 귀속시기가 아직 도래하지 않아 **차기로 이연**시키는 항목이다.

**① 선급비용(prepaid expense)** — 비용을 미리 현금으로 지급한 경우, 아직 기간이 경과하지 않은 부분을 자산(선급비용)으로 이연한다.

예: "10월 1일 1년치 보험료 120,000원을 현금 지급하고 전액 보험료(비용)로 처리했다. 기말(12/31) 미경과분을 정리한다."
- 경과분(10/1~12/31, 3개월) = 120,000 × 3/12 = 30,000 (당기 비용)
- 미경과분(1/1~9/30, 9개월) = 120,000 × 9/12 = 90,000 (선급비용, 자산)

```
(차) 선급비용   90,000   (대) 보 험 료   90,000
```

**② 선수수익(unearned revenue)** — 수익을 미리 현금으로 받은 경우, 아직 제공하지 않은 부분을 부채(선수수익)로 이연한다.

예: "9월 1일 1년치 임대료 240,000원을 현금으로 받고 전액 임대료수익으로 처리했다. 기말 미경과분을 정리한다."
- 경과분(9/1~12/31, 4개월) = 240,000 × 4/12 = 80,000 (당기 수익)
- 미경과분(1/1~8/31, 8개월) = 240,000 × 8/12 = 160,000 (선수수익, 부채)

```
(차) 임대료수익   160,000   (대) 선수수익   160,000
```

##### (2) 발생항목(accrual)

현금 수수는 아직 없으나, 당기에 이미 발생한 수익·비용을 인식하는 항목이다.

**③ 미수수익(accrued revenue)** — 당기에 발생했으나 아직 받지 못한 수익을 자산(미수수익)으로 계상한다.

예: "당기에 발생한 예금이자 15,000원을 아직 받지 못했다."
```
(차) 미수수익   15,000   (대) 이자수익   15,000
```

**④ 미지급비용(accrued expense)** — 당기에 발생했으나 아직 지급하지 않은 비용을 부채(미지급비용)로 계상한다.

예: "당기에 발생한 종업원 급여 200,000원을 아직 지급하지 않았다."
```
(차) 급    여   200,000   (대) 미지급비용   200,000
```

##### (3) 추정항목(estimate)

기간 손익을 정확히 대응시키기 위해 **합리적 추정**으로 계상하는 항목이다.

**⑤ 감가상각비(depreciation)** — 유형자산의 취득원가를 사용기간에 배분한다.

예: "기계장치(취득원가 1,000,000, 잔존가치 0, 내용연수 5년, 정액법)의 당기 감가상각비를 계상한다."
- 감가상각비 = (1,000,000 − 0) ÷ 5 = 200,000
```
(차) 감가상각비   200,000   (대) 감가상각누계액   200,000
```
※ 감가상각누계액은 자산의 차감계정(대변 성격)으로, 유형자산 장부금액을 줄인다.

**⑥ 대손상각비(bad debt expense)** — 매출채권 중 회수 불가능이 예상되는 금액을 추정하여 비용·충당금으로 계상한다.

예: "기말 매출채권 잔액 2,000,000원에 대해 2%의 대손을 추정한다(대손충당금 잔액 0 가정)."
- 대손추정액 = 2,000,000 × 2% = 40,000
```
(차) 대손상각비   40,000   (대) 대손충당금   40,000
```
※ 대손충당금도 매출채권의 차감계정이다.

##### 유형 요약표

| 구분 | 항목 | 성격 | 수정분개 (차) / (대) |
|---|---|---|---|
| 이연 | 선급비용 | 자산 | (차) 선급비용 / (대) 해당비용 |
| 이연 | 선수수익 | 부채 | (차) 해당수익 / (대) 선수수익 |
| 발생 | 미수수익 | 자산 | (차) 미수수익 / (대) 해당수익 |
| 발생 | 미지급비용 | 부채 | (차) 해당비용 / (대) 미지급비용 |
| 추정 | 감가상각비 | 비용·차감계정 | (차) 감가상각비 / (대) 감가상각누계액 |
| 추정 | 대손상각비 | 비용·차감계정 | (차) 대손상각비 / (대) 대손충당금 |

> **핵심:** 기말수정분개는 발생주의에 맞게 수익·비용의 기간귀속을 조정하는 절차다. **이연항목(선급비용·선수수익)**은 이미 받은/준 현금을 차기로 미루고, **발생항목(미수수익·미지급비용)**은 아직 안 받은/안 준 것을 당기에 인식하며, **추정항목(감가상각비·대손상각비)**은 합리적 추정으로 비용을 배분한다.

### ❹ 마감(決算 마감)

#### 1. 마감의 의의

**마감(closing)**은 한 회계기간이 끝난 후, 총계정원장의 각 계정을 정리하여 장부를 닫고 다음 기간을 준비하는 절차다. 핵심은 **수익·비용 계정(명목계정)의 잔액을 없애 순손익을 산출하고, 이를 자본에 반영**하는 것이다.

계정은 마감 방식에 따라 두 가지로 나뉜다.
- **임시계정(명목계정)**: 수익·비용 계정 → 매기 마감하여 **잔액을 0으로** 만든다.
- **영구계정(실질계정)**: 자산·부채·자본 계정 → 잔액을 **차기로 이월**한다.

#### 2. 수익·비용 → 집합손익 → 자본 대체

마감의 핵심 절차는 **집합손익(集合損益, income summary)** 계정을 이용한다.

**① 수익 계정 마감**: 수익은 대변 잔액이므로, 차변에 대체하여 잔액을 0으로 만들고 집합손익 대변으로 옮긴다.
```
(차) 매    출   500,000   (대) 집합손익   500,000
    (기타 수익도 동일하게 대체)
```

**② 비용 계정 마감**: 비용은 차변 잔액이므로, 대변에 대체하여 잔액을 0으로 만들고 집합손익 차변으로 옮긴다.
```
(차) 집합손익   400,000   (대) 매    입   300,000
                            급    여   100,000
    (기타 비용도 동일하게 대체)
```

**③ 집합손익 → 자본 대체**: 집합손익 계정의 대변(총수익) − 차변(총비용) = 당기순손익이다. 이 순손익을 자본(개인기업은 자본금, 법인은 이익잉여금)으로 대체한다.

- 순이익이 난 경우 (수익 500,000 > 비용 400,000, 순이익 100,000):
```
(차) 집합손익   100,000   (대) 이익잉여금   100,000
```
- 순손실이 난 경우에는 반대로 분개한다:
```
(차) 이익잉여금   ×××   (대) 집합손익   ×××
```

**집합손익 T계정**
```
              집합손익
 ──────────────┬──────────────
  비용 400,000  │ 수익 500,000
  이익잉여금 100,000│
 ──────────────┴──────────────
     500,000   │   500,000
```
차변·대변이 일치하며 잔액이 0이 되어 마감이 완료된다.

#### 3. 장부 마감

- **수익·비용 계정**: 위 대체로 잔액이 0이 되어 마감된다.
- **자산·부채·자본 계정**: 잔액을 "차기이월"로 기입하여 마감하고, 다음 기 첫날 "전기이월"로 다시 개시한다.
- 마감이 끝나면 마감 후 잔액이 맞는지 **이월시산표(마감후시산표)**로 확인할 수 있다.

#### 4. 정산표(精算表, work sheet)

**정산표**는 결산 절차(수정전시산표 → 기말수정분개 → 손익계산서 → 재무상태표)를 하나의 표에 정리한 **결산 보조표**다. 정식 장부는 아니지만, 결산의 흐름을 한눈에 보여주고 오류를 줄여준다.

가장 널리 쓰이는 형식이 **10위식(10-column) 정산표**로, 각 계정마다 아래 5개 구획(각각 차변·대변 2칸씩 = 10칸)을 가진다.

| 구획 | 내용 |
|---|---|
| ① 수정전시산표 | 수정 전 잔액 (차변·대변) |
| ② 수정분개 | 기말수정분개 (차변·대변) |
| ③ 수정후시산표 | ①±② 반영 잔액 (차변·대변) |
| ④ 손익계산서 | 수익·비용 계정을 옮김 (차변·대변) |
| ⑤ 재무상태표 | 자산·부채·자본 계정을 옮김 (차변·대변) |

**정산표의 원리**
- 수정후시산표의 **수익·비용**은 손익계산서란으로, **자산·부채·자본**은 재무상태표란으로 이동한다.
- 손익계산서란에서 대변(수익) − 차변(비용) = **당기순이익**이며, 이 금액은 손익계산서란 차변과 재무상태표란 대변(자본 증가)에 각각 더해져 양쪽 구획의 차·대변이 모두 일치하게 된다.

**정산표 개념 예시 (일부)**

| 계정 | 수정후 차 | 수정후 대 | 손익 차 | 손익 대 | 재무상태 차 | 재무상태 대 |
|---|---:|---:|---:|---:|---:|---:|
| 현금 | 4,300,000 | | | | 4,300,000 | |
| 외상매입금 | | 800,000 | | | | 800,000 |
| 자본금 | | 5,000,000 | | | | 5,000,000 |
| 매출 | | 500,000 | | 500,000 | | |
| 매입 | 300,000 | | 300,000 | | | |
| 급여 | 100,000 | | 100,000 | | | |
| **당기순이익** | | | **100,000** | | | **100,000** |
| 합계 | | | 500,000 | 500,000 | ... | ... |

손익계산서란: 수익 500,000 − 비용 400,000 = 순이익 100,000 → 이 100,000이 재무상태표란 대변(자본)으로 옮겨져 자본이 그만큼 증가한다.

> **핵심:** 마감은 수익·비용(명목계정)을 **집합손익**으로 대체하여 당기순손익을 산출하고, 이를 **자본(이익잉여금)**으로 대체하는 절차다. 자산·부채·자본(실질계정)은 차기이월로 마감한다. 정산표(10위식)는 수정전시산표·수정분개·손익계산서·재무상태표를 한 표에 정리한 결산 보조표로, 손익계산서란의 순이익이 재무상태표란 자본으로 연결된다.

## 제6장 상기업의 회계(상품매매)

기업은 활동에 따라 서비스업·상기업·제조업 등으로 나뉜다. 이 장에서는 상품을 사고파는 **상기업(상품매매업)**의 회계처리를 다룬다. 서비스업과 달리 **상품(재고자산)의 매입·매출·매출원가**가 회계처리의 중심이 된다.

### ❶ 상기업은 뭐하는 기업인가

#### 1. 상기업 vs 서비스업

| 구분 | 서비스업 | 상기업(상품매매업) |
|---|---|---|
| 주요 활동 | 용역(서비스) 제공 | 상품을 매입하여 그대로 판매 |
| 대표 수익 | 용역수익(수수료수익 등) | **매출** |
| 대표 비용 | 급여·임차료 등 | **매출원가** + 판매관리비 |
| 재고자산 | 원칙적으로 없음 | **상품(재고자산)** 존재 |
| 예시 | 병원·회계법인·학원 | 도소매업·유통업 |

서비스업은 재고자산이 없어 매출원가 개념이 없지만, 상기업은 팔린 상품의 원가인 **매출원가**를 별도로 산정해야 한다.

#### 2. 매출원가(賣出原價) 개념

**매출원가(cost of goods sold)**는 당기에 판매된 상품의 **취득원가(원가)**를 말한다. 상기업의 손익 구조는 다음과 같다.

```
    매출액(순매출액)
  − 매출원가
  ─────────────
  = 매출총이익(gross profit)
  − 판매비와관리비
  ─────────────
  = 영업이익
```

즉 상기업은 서비스업과 달리 **매출총이익** 단계를 거쳐 손익을 계산한다는 점이 특징이다.

> **핵심:** 상기업은 상품을 매입하여 그대로 파는 상품매매업으로, 대표 수익은 **매출**, 핵심 비용은 판매된 상품의 원가인 **매출원가**다. 「매출 − 매출원가 = 매출총이익」이라는 손익구조가 서비스업과의 가장 큰 차이다.

---

### ❷ 상기업의 회계처리 방법

상품매매 거래를 어떤 계정으로, 어떤 방식으로 기록하는가에 대해 여러 방법이 있다.

#### 1. 상품 계정의 처리 방법: 3분법·2분법·분기법

| 방법 | 사용 계정 | 특징 |
|---|---|---|
| **3분법** | 이월상품 · 매입 · 매출 | 가장 널리 사용. 매입·매출을 별도 계정으로 기록 |
| **2분법** | 상품 · 상품매매익 | 상품 계정 하나로 원가 관리, 이익만 별도 |
| **분기법** | 상품 · (매출 시 원가·이익 구분) | 매출 때마다 원가·이익을 분리 기록 (실무 부담 큼) |

**3분법(가장 중요)**에서는 상품 관련 거래를 세 계정으로 나눈다.
- **매입 계정**(비용성): 상품을 사올 때의 원가 기록
- **매출 계정**(수익성): 상품을 팔 때의 매출액 기록
- **이월상품 계정**(자산): 기초·기말 재고를 기록

**3분법 분개 예시**
- 매입 시: `(차) 매입 ××× (대) 현금(또는 외상매입금) ×××`
- 매출 시: `(차) 현금(또는 외상매출금) ××× (대) 매출 ×××`
- 기말: 이월상품·매입 계정을 정리하여 매출원가를 산정(결산정리)

#### 2. 재고자산 수량 파악 방법: 계속기록법·실지재고조사법

상품의 매출원가와 기말재고를 산정하기 위해 재고 수량을 어떻게 파악하는가에 따라 나뉜다.

| 방법 | 내용 | 특징 |
|---|---|---|
| **계속기록법** (permanent) | 상품의 입·출고를 그때그때 계속 기록 | 장부상 재고·매출원가를 상시 파악. 감모수량 파악 곤란(장부 기준) |
| **실지재고조사법** (periodic) | 기말에 실사(재고조사)로 재고 확정 | 기중 기록 간편. 매출원가는 기말에 일괄 산정. 감모가 매출원가에 포함됨 |

실무·시험에서는 두 방법을 **병행**하여, 장부재고(계속기록법)와 실제재고(실지조사)를 비교해 **재고자산감모손실**을 파악하기도 한다.

#### 3. 매출원가의 계산

3분법·실지재고조사법에서 **매출원가**는 다음 공식으로 산정한다.

```
매출원가 = 기초상품재고액 + 당기순매입액 − 기말상품재고액
```

여기서 **당기순매입액**은 총매입에서 매입에누리·환출·할인을 빼고 매입운임 등을 더한 금액이다(❸ 참조).

**[예제] 매출원가 계산**
- 기초상품재고액: 200,000
- 당기순매입액: 1,500,000
- 기말상품재고액: 300,000

매출원가 = 200,000 + 1,500,000 − 300,000 = **1,400,000**

**결산 시 매출원가 산정 분개(3분법)**
① 기초재고를 매입 계정으로 대체:
```
(차) 매    입   200,000   (대) 이월상품   200,000
```
② 기말재고를 매입 계정에서 이월상품으로 대체:
```
(차) 이월상품   300,000   (대) 매    입   300,000
```
이 두 분개 후 매입 계정 잔액이 곧 **매출원가(1,400,000)**가 된다.

**T계정으로 본 매입 계정**
```
              매 입 (→ 매출원가)
 ──────────────┬──────────────
  당기매입 1,500,000│기말재고 300,000
  기초재고   200,000│
              │  잔액(매출원가) 1,400,000
 ──────────────┴──────────────
```

> **핵심:** 상품 계정 처리는 **3분법(매입·매출·이월상품)**이 대표적이며, 재고 파악은 **계속기록법**(상시 기록)과 **실지재고조사법**(기말 실사)으로 나뉜다. 매출원가는 「**기초재고 + 당기순매입 − 기말재고**」로 계산한다.

---

### ❸ 순매출액과 순매입액

총매출·총매입 금액 그대로가 아니라, 에누리·환입·할인 등을 조정한 **순액**으로 손익을 계산한다.

#### 1. 용어 정리

| 용어 | 의미 (매출 측) | 의미 (매입 측) |
|---|---|---|
| **에누리** | 매출에누리: 하자·불량으로 판매가를 깎아줌 | 매입에누리: 하자로 매입가를 깎아 받음 |
| **환입/환출** | 매출환입: 판 상품이 반품되어 돌아옴 | 매입환출: 산 상품을 반품해 되돌려보냄 |
| **할인** | 매출할인: 외상대금 조기회수로 깎아줌 | 매입할인: 외상대금 조기지급으로 깎아 받음 |
| **운임** | (판매운임은 판매비) | 매입운임: 상품 매입 시 운반비 → 매입원가 가산 |

※ **매입운임(운반비)**은 상품을 취득하는 데 든 부대비용이므로 **매입원가에 가산**한다. 반면 판매 시 부담하는 운반비(판매운임)는 매출원가가 아니라 **판매비**로 처리한다.

#### 2. 순매출액 계산

```
순매출액 = 총매출액 − 매출에누리 − 매출환입 − 매출할인
```

**[예제] 순매출액**
- 총매출액: 3,000,000
- 매출에누리: 50,000
- 매출환입: 100,000
- 매출할인: 30,000

순매출액 = 3,000,000 − 50,000 − 100,000 − 30,000 = **2,820,000**

#### 3. 순매입액 계산

```
순매입액 = 총매입액 + 매입운임 − 매입에누리 − 매입환출 − 매입할인
```

**[예제] 순매입액**
- 총매입액: 1,600,000
- 매입운임: 40,000
- 매입에누리: 30,000
- 매입환출: 60,000
- 매입할인: 20,000

순매입액 = 1,600,000 + 40,000 − 30,000 − 60,000 − 20,000 = **1,530,000**

#### 4. 관련 분개 예시

**매출환입(반품받음, 3분법)**
"외상으로 판매한 상품 중 80,000원이 반품되어 왔다."
```
(차) 매출환입(또는 매출)   80,000   (대) 외상매출금   80,000
```

**매입환출(반품보냄, 3분법)**
"외상으로 매입한 상품 중 50,000원을 반품하였다."
```
(차) 외상매입금   50,000   (대) 매입환출(또는 매입)   50,000
```

**매입운임 지급**
"상품 매입 시 운반비 40,000원을 현금 지급하였다."
```
(차) 매    입   40,000   (대) 현    금   40,000
```

#### 5. 종합 예시 — 순매출액·순매입액·매출원가·매출총이익

**자료**
- 기초상품재고: 200,000
- 총매입액 1,600,000, 매입운임 40,000, 매입에누리·환출·할인 합계 110,000
- 총매출액 3,000,000, 매출에누리·환입·할인 합계 180,000
- 기말상품재고: 330,000

**계산**
1. 순매입액 = 1,600,000 + 40,000 − 110,000 = **1,530,000**
2. 순매출액 = 3,000,000 − 180,000 = **2,820,000**
3. 매출원가 = 기초재고 200,000 + 순매입 1,530,000 − 기말재고 330,000 = **1,400,000**
4. 매출총이익 = 순매출액 2,820,000 − 매출원가 1,400,000 = **1,420,000**

| 항목 | 금액 |
|---|---:|
| 순매출액 | 2,820,000 |
| (−) 매출원가 | 1,400,000 |
| **매출총이익** | **1,420,000** |

> **핵심:** 손익 계산에는 총액이 아니라 순액을 쓴다. **순매출액 = 총매출 − 매출에누리·환입·할인**, **순매입액 = 총매입 + 매입운임 − 매입에누리·환출·할인**이다. 매입운임은 매입원가에 가산되고, 순매입액은 매출원가 계산(기초 + 순매입 − 기말)에 그대로 반영된다.

## 제7장 재무제표 표시

재무제표는 기업의 재무상태, 재무성과, 현금흐름을 정해진 틀에 따라 체계적으로 나타낸 것이다. K-IFRS(기업회계기준서 제1001호 '재무제표 표시')는 재무제표가 갖추어야 할 일반원칙과 구성요소, 최소한의 표시항목을 규정한다. 감정평가사 시험에서는 각 원칙의 정의와 예외, 유동·비유동 분류기준이 자주 출제된다.

전체 재무제표(a complete set of financial statements)는 다음으로 구성된다.

| 구성요소 | 내용 |
|---|---|
| 기말 재무상태표 | 특정 시점의 자산·부채·자본 |
| 기간 포괄손익계산서 | 일정 기간의 수익·비용, 총포괄손익 |
| 기간 자본변동표 | 자본 항목의 기중 증감 내역 |
| 기간 현금흐름표 | 영업·투자·재무활동 현금흐름 |
| 주석 | 유의적 회계정책·측정근거 및 기타 설명정보 |

---

### ❶ 재무제표 표시의 일반원칙

K-IFRS는 재무제표가 신뢰할 수 있는 정보를 제공하도록 다음의 일반원칙을 요구한다.

**(1) 공정한 표시와 K-IFRS 준수**

재무제표는 기업의 재무상태, 재무성과 및 현금흐름을 공정하게 표시(fair presentation)해야 한다. K-IFRS에 따라 작성된 재무제표는 공정하게 표시된 것으로 본다. K-IFRS를 준수하여 작성한 기업은 그러한 사실을 주석에 명시적이고 제한 없이 기재한다. 부적절한 회계정책은 이에 대한 공시, 주석 또는 보충자료를 통해 설명하더라도 정당화될 수 없다.

**(2) 계속기업 가정(going concern)**

경영진은 재무제표를 작성할 때 계속기업으로서의 존속가능성을 평가한다. 기업이 예측가능한 미래(보고기간 말로부터 적어도 12개월)에 영업을 계속할 것이라는 가정 하에 재무제표를 작성한다. 계속기업으로서의 존속능력에 유의적인 의문이 제기될 수 있는 불확실성을 알게 된 경우 그러한 불확실성을 공시한다. 계속기업을 전제로 하지 않고 작성하는 경우 그 사실과 근거, 작성기준을 공시한다.

**(3) 발생기준 회계(accrual basis)**

기업은 현금흐름 정보를 제외하고는 발생기준 회계를 사용하여 재무제표를 작성한다. 발생기준에서는 거래나 사건의 영향을 현금 수취·지급 시점이 아니라 그것이 발생한 기간에 인식한다. 즉 수익은 실현되었을 때, 비용은 발생하였을 때 인식하며, 이때 수익·비용 대응의 원칙이 적용된다.

**(4) 중요성과 통합표시(materiality and aggregation)**

유사한 항목은 중요성 분류에 따라 재무제표에 구분하여 표시한다. 상이한 성격이나 기능을 가진 항목은 구분하여 표시하되, 중요하지 않은 항목은 성격·기능이 유사한 항목과 통합하여 표시할 수 있다. 어떤 정보를 누락하거나 잘못 기재하여 재무제표에 기초한 이용자의 의사결정에 영향을 줄 수 있으면 그 정보는 중요하다.

**(5) 상계 금지(offsetting)**

K-IFRS에서 요구하거나 허용하지 않는 한 자산과 부채, 수익과 비용은 상계하지 않는다. 상계는 발생한 거래·사건의 실질을 반영하지 못하게 하여 이용자의 이해를 저해할 수 있기 때문이다.

- 다만 다음은 상계가 아니다: 재고자산의 재고자산평가충당금, 매출채권의 대손충당금과 같은 평가충당금을 차감하여 순액으로 표시하는 것.
- 동일 거래에서 발생하는 차익과 차손은 순액으로 표시할 수 있다(예: 외환손익, 단기매매금융자산의 처분손익).

**(6) 보고빈도(frequency of reporting)**

전체 재무제표(비교정보 포함)는 적어도 1년마다 작성한다. 보고기간 종료일을 변경하여 재무제표의 보고기간이 1년을 초과하거나 미달하는 경우, 그 이유와 재무제표에 표시된 금액이 완전하게 비교가능하지 않다는 사실을 추가로 공시한다.

**(7) 비교정보(comparative information)**

K-IFRS가 달리 허용하거나 요구하지 않는 한, 당기 재무제표에 보고되는 모든 금액에 대해 전기 비교정보를 표시한다. 서술형 정보도 당기 재무제표를 이해하는 데 목적적합하다면 비교정보를 포함한다. 회계정책을 소급하여 적용하거나 재무제표 항목을 소급하여 재작성·재분류하는 경우에는 적어도 세 개의 재무상태표(당기말, 전기말, 전전기초)를 표시한다.

**(8) 표시의 계속성(consistency of presentation)**

재무제표 항목의 표시와 분류는 다음의 경우를 제외하고는 매기 동일하게 유지한다.
- 사업내용의 유의적 변화나 재무제표를 검토한 결과 다른 표시·분류가 더 적절한 것이 명백한 경우
- K-IFRS에서 표시방법의 변경을 요구하는 경우

> 핵심: 공정한 표시=K-IFRS 준수, 계속기업·발생기준을 전제로 하며, 상계 금지·표시의 계속성·매기 비교정보 제공이 재무제표 표시의 핵심 원칙이다.

---

### ❷ 재무상태표

재무상태표(statement of financial position)는 특정 시점의 자산·부채·자본을 나타내는 재무제표이다. K-IFRS는 재무상태표의 정형화된 양식을 강제하지 않으나, 최소한 표시해야 할 항목과 유동·비유동 분류방법을 규정한다.

**(1) 유동/비유동 구분표시 vs 유동성 순서 배열**

기업은 다음 중 하나의 방법으로 자산과 부채를 표시한다.

| 표시방법 | 내용 | 적용 |
|---|---|---|
| 유동·비유동 구분법 | 자산·부채를 유동/비유동으로 구분하여 표시 | 일반적인 제조·상기업 |
| 유동성 순서 배열법 | 유동·비유동 구분 없이 유동성이 큰 순서(또는 작은 순서)로 배열 | 금융회사 등 명확한 영업주기가 없는 경우 |

유동성 순서에 따른 표시방법이 신뢰성 있고 더욱 목적적합한 정보를 제공하는 경우(예: 금융회사)에는 유동성 순서 배열법을 적용한다. 두 방법을 혼합하여, 일부 자산·부채는 유동·비유동 구분법으로 나머지는 유동성 순서 배열법으로 표시하는 것도 허용된다(신뢰성 있고 목적적합한 정보를 제공하는 경우).

어느 방법을 적용하든, 자산과 부채의 각 항목이 보고기간 후 12개월 이내와 12개월 후에 회수·결제될 것으로 기대되는 금액이 통합하여 표시되는 경우 12개월 후에 회수·결제될 것으로 기대되는 금액을 공시한다.

**(2) 유동자산의 분류기준**

자산은 다음 중 하나를 충족하면 유동자산(current assets)으로 분류하고, 그 밖의 모든 자산은 비유동자산으로 분류한다.

| 조건 | 설명 |
|---|---|
| ① 정상영업주기 내 실현·판매·소비 | 기업의 정상영업주기 내에 실현될 것으로 예상하거나 정상영업주기 내에 판매하거나 소비할 의도가 있다 |
| ② 주로 단기매매 목적으로 보유 | 매매 목적으로 보유하고 있다 |
| ③ 보고기간 후 12개월 이내 실현 예상 | 보고기간 후 12개월 이내에 실현될 것으로 예상한다 |
| ④ 현금이나 현금성자산 | 교환·부채상환 목적으로의 사용에 대한 제한이 보고기간 후 12개월 이상이 아니다 |

**정상영업주기(normal operating cycle)**: 영업활동을 위한 자산의 취득시점부터 그 자산이 현금이나 현금성자산으로 실현되는 시점까지의 기간이다. 정상영업주기를 명확하게 식별할 수 없는 경우 그 기간은 12개월인 것으로 가정한다. 재고자산과 매출채권처럼 정상영업주기의 일부로서 판매·소비·실현되는 자산은 보고기간 후 12개월 후에 실현되더라도 유동자산으로 분류한다.

**(3) 유동부채의 분류기준**

부채는 다음 중 하나를 충족하면 유동부채(current liabilities)로 분류하고, 그 밖의 모든 부채는 비유동부채로 분류한다.

| 조건 | 설명 |
|---|---|
| ① 정상영업주기 내 결제 예상 | 정상영업주기 내에 결제될 것으로 예상한다 |
| ② 주로 단기매매 목적으로 보유 | 주로 단기매매 목적으로 보유하고 있다 |
| ③ 보고기간 후 12개월 이내 결제 | 보고기간 후 12개월 이내에 결제하기로 되어 있다 |
| ④ 결제 연기 무조건적 권리 없음 | 보고기간 후 적어도 12개월 이상 결제를 연기할 수 있는 무조건적인 권리를 가지고 있지 않다 |

매입채무, 종업원 및 그 밖의 영업원가에 대한 미지급비용 등은 정상영업주기 내에 사용되는 운전자본의 일부이므로, 보고기간 후 12개월 후에 결제일이 도래하더라도 유동부채로 분류한다.

**보고기간 후 차환·연기 관련 유의사항**
- 기존 대출계약에 따라 보고기간 후 적어도 12개월 이상 부채의 차환·연장을 기대하고 있고 그런 재량권이 있다면 비유동부채로 분류한다.
- 보고기간 말 이전에 장기차입약정을 위반했으나 채권자가 보고기간 후에 상환을 요구하지 않기로 합의하였더라도, 보고기간 말 현재 상환을 요구할 수 있으면 유동부채로 분류한다.
- 보고기간 말 이전에 채권자가 적어도 12개월 이상의 유예기간을 부여하기로 합의한 경우에는 비유동부채로 분류한다.

**(4) 재무상태표에 표시되는 최소 표시항목**

K-IFRS는 다음 항목의 금액을 재무상태표에 표시하도록 요구한다(순서·양식은 강제하지 않음).

| 구분 | 최소 표시항목(예시) |
|---|---|
| 자산 | 유형자산, 투자부동산, 무형자산, 금융자산, 지분법 적용 투자자산, 생물자산, 재고자산, 매출채권 및 기타 채권, 현금및현금성자산, 매각예정으로 분류된 자산 |
| 부채 | 매입채무 및 기타 채무, 충당부채, 금융부채, 당기법인세 관련 부채·자산, 이연법인세부채·자산, 매각예정처분자산집단에 포함된 부채 |
| 자본 | 비지배지분(자본에 별도 표시), 지배기업의 소유주에게 귀속되는 납입자본과 적립금 |

기업의 재무상태를 이해하는 데 목적적합한 경우 추가 항목, 제목 및 소계를 재무상태표에 포함한다. 이연법인세자산(부채)은 유동자산(부채)으로 분류하지 아니한다.

**재무상태표 표시 예시(유동·비유동 구분법)**

| 자산 | 금액(예시) | 부채와 자본 | 금액(예시) |
|---|---|---|---|
| **유동자산** | | **유동부채** | |
| 현금및현금성자산 | 100 | 매입채무 | 80 |

## 제8장 재고자산

재고자산(inventories)은 정상적인 영업과정에서 판매를 위하여 보유하거나 생산 중에 있는 자산 및 생산·용역 제공에 사용될 원재료나 소모품을 말한다(K-IFRS 제1002호). 상기업의 상품, 제조기업의 제품·재공품·원재료 등이 이에 해당한다. 재고자산은 취득원가로 인식한 뒤, 기말에 취득원가와 순실현가능가치 중 낮은 금액(저가법)으로 측정한다.

---

### ❶ 재고자산의 취득원가

재고자산의 취득원가는 매입원가, 전환원가 및 재고자산을 현재의 장소에 현재의 상태로 이르게 하는 데 발생한 기타 원가를 모두 포함한다. 상기업에서는 주로 매입원가가 문제된다.

**매입원가의 구성**

```
매입원가 = 매입가격 + 매입부대비용 − 매입할인·에누리·환출
```

| 구분 | 항목 | 처리 |
|---|---|---|
| 가산(+) | 매입가격 | 송장가격 |
| 가산(+) | 매입부대비용 | 매입운임, 하역료, 보험료, 관세, 수입제비용 등 |
| 차감(−) | 매입할인 | 외상매입금을 조기 결제하여 받은 할인 |
| 차감(−) | 매입에누리 | 하자·수량부족으로 매입가격을 깎은 금액 |
| 차감(−) | 매입환출 | 매입한 상품을 반품한 금액 |

관세납부 후 환급받는 관세환급금과 매입할인·에누리·환출은 매입원가에서 차감한다. 후속 생산단계에 투입하기 전에 보관이 필요한 경우 외의 보관비용, 판매비용, 재고자산의 취득에 기여하지 않은 일반관리비, 비정상적으로 낭비된 원가는 취득원가에 포함하지 않고 발생기간의 비용으로 인식한다.

**매입 시 분개 예시**

상품 1,000원을 외상매입하고, 매입운임 50원을 현금 지급한 경우(계속기록법):

| 구분 | 차변 | 대변 |
|---|---|---|
| 매입 | (차) 상품(재고자산) 1,050 | (대) 매입채무 1,000 |
| | | (대) 현금 50 |

매입한 상품 중 100원을 하자로 반품(매입환출)한 경우:

| 차변 | 대변 |
|---|---|
| (차) 매입채무 100 | (대) 상품(재고자산) 100 |

> 핵심: 재고자산 취득원가 = 매입가격 + 매입부대비용(운임·관세·보험료 등) − 매입할인·에누리·환출. 비정상 낭비원가·판매비용·일반관리비는 취득원가에 포함하지 않는다.

---

### ❷ 재고자산의 단위원가 결정(원가흐름의 가정)

동일한 재고자산이라도 매입시점에 따라 단가가 다르기 때문에, 기말재고와 매출원가에 어떤 단가를 적용할지 정하는 원가흐름의 가정이 필요하다. K-IFRS는 통상적으로 상호 교환될 수 없는 재고자산과 특정 프로젝트별로 생산·분리되는 재화·용역의 원가는 개별법을 사용하고, 그 외에는 선입선출법 또는 가중평균법을 사용하도록 한다. **후입선출법(LIFO)은 K-IFRS에서 인정하지 않는다.**

**(1) 개별법(specific identification)**

식별되는 재고자산별로 개별 원가를 부과하는 방법이다. 통상 상호 교환될 수 없는 재고항목이나 특정 프로젝트별로 생산·분리되는 재화·용역(예: 귀금속, 부동산, 주문제작품)에 적용한다. 원가흐름과 실제 물량흐름이 일치하여 가장 정확하나, 종류가 많고 거래가 빈번한 경우 적용이 어렵다.

**(2) 선입선출법(FIFO, first-in first-out)**

먼저 매입한 재고자산이 먼저 판매·사용된다고 가정한다. 따라서 기말재고는 가장 최근에 매입한 재고의 단가로 구성된다. 실제 물량흐름과 유사하며, 기말재고가 시가에 가깝게 표시된다.

**(3) 가중평균법(weighted-average)**

기초재고와 기중 매입한 재고의 원가를 가중평균하여 단위원가를 산정한다. 실무 적용방식에 따라 두 가지로 나뉜다.

| 구분 | 방법 | 적용 시점 |
|---|---|---|
| 총평균법 | 기간 전체의 총원가 ÷ 총수량으로 단일 평균단가 산정 | 실지재고조사법(기말 일괄) |
| 이동평균법 | 매입할 때마다 그 시점의 평균단가를 다시 계산 | 계속기록법(매입 시마다) |

**계산 예시 (공통 자료)**

| 일자 | 구분 | 수량 | 단가 | 금액 |
|---|---|---|---|---|
| 1/1 | 기초재고 | 100개 | 10원 | 1,000원 |
| 4/1 | 매입 | 100개 | 12원 | 1,200원 |
| 8/1 | 매입 | 100개 | 14원 | 1,400원 |
| | 판매가능재고 계 | 300개 | | 3,600원 |
| 12/31 | 기말재고 | 100개 | | ? |

(기중 200개 판매, 기말 100개 남음)

**① 선입선출법(FIFO)**
- 기말재고: 가장 최근 매입분 100개 × 14원 = **1,400원**
- 매출원가: 3,600 − 1,400 = **2,200원** (100개×10 + 100개×12)

**② 총평균법**
- 평균단가: 3,600원 ÷ 300개 = 12원
- 기말재고: 100개 × 12원 = **1,200원**
- 매출원가: 3,600 − 1,200 = **2,400원** (200개 × 12원)

**③ 이동평균법(예시)**
- 매입·판매 순서에 따라 매입 시마다 단가를 재계산하므로 결과는 거래 순서에 의존한다. 매입만 순차 발생한 위 자료에서 판매 직전 평균단가를 적용하여 기말재고를 산정한다.

**물가 상승(인플레이션) 시 방법별 크기 비교**

물가가 지속적으로 상승하는 경우, 각 방법이 재무제표에 미치는 영향은 다음과 같다.

| 항목 | 선입선출법(FIFO) | 가중평균법 | (후입선출법·불인정) |
|---|---|---|---|
| 기말재고자산 | 크다(최근 높은 단가) | 중간 | 작다 |
| 매출원가 | 작다(과거 낮은 단가) | 중간 | 크다 |
| 매출총이익·당기순이익 | 크다 | 중간 | 작다 |
| 법인세부담 | 크다 | 중간 | 작다 |

정리하면 물가 상승 시:
- **기말재고**: 선입선출법 > 이동평균법 ≥ 총평균법 (후입선출법이 가장 작음)
- **매출원가**: 후입선출법 > 총평균법 ≥ 이동평균법 > 선입선출법
- **당기순이익**: 선입선출법이 가장 크다(기말재고가 크므로 매출원가가 작고 이익이 큼).

수량 변동이 없다면 판매가능재고(기초재고+당기매입)는 동일하므로, 기말재고가 크면 매출원가가 작아지고 이익이 커진다는 관계(기말재고 ↑ → 매출원가 ↓ → 이익 ↑)를 이해하는 것이 핵심이다.

```
매출원가 = 기초재고 + 당기매입 − 기말재고
```

> 핵심: K-IFRS는 개별법·FIFO·가중평균법만 인정(LIFO 불인정)한다. 물가 상승 시 FIFO는 기말재고·이익이 가장 크고 매출원가가 가장 작다.

### ❸ 감모손실과 평가손실

기말 재고자산은 장부상 수량·단가와 실제가 다를 수 있다. 수량이 줄어든 것은 감모손실, 가치가 하락한 것은 평가손실로 구분한다.

**(1) 재고자산감모손실 — 수량 감소**

장부상 재고수량보다 실제 재고수량이 적을 때 발생한다(도난·파손·증발 등).

```
재고자산감모손실 = (장부수량 − 실제수량) × 단위원가
```

- **정상감모손실**: 정상적인 영업활동에서 불가피하게 발생하는 감모 → 매출원가에 가산
- **비정상감모손실**: 비정상적·우발적 원인에 의한 감모 → 기타비용(영업외비용)으로 처리

**(2) 재고자산평가손실 — 가치 하락(저가법)**

재고자산은 취득원가와 순실현가능가치(NRV, net realizable value) 중 낮은 금액으로 측정한다(저가법, lower of cost or NRV). 순실현가능가치가 취득원가보다 하락한 경우 그 차액을 평가손실로 인식한다.

```
순실현가능가치(NRV) = 예상 판매가격 − 예상되는 추가 완성원가 − 예상 판매비용
재고자산평가손실 = (단위원가 − 단위당 NRV) × 실제수량
```

저가법을 적용하는 사유(원가 회수 불가능):
- 물리적으로 손상된 경우
- 완전히 또는 부분적으로 진부화된 경우
- 판매가격이 하락한 경우
- 완성·판매에 필요한 원가가 상승한 경우

저가법은 원칙적으로 **항목별로** 적용한다. 다만 서로 유사하거나 관련 있는 항목들은 조별로 적용할 수 있으며, 완제품 또는 특정 영업부문에 속하는 모든 재고자산을 통합하여 적용하는 것은 적절하지 않다.

**저가법 계산 예시**

| 항목 | 수량 | 단위원가 | 단위당 NRV | 저가(낮은 금액) | 평가손실 |
|---|---|---|---|---|---|
| A상품 | 100개 | 100원 | 90원 | 90원 | (100−90)×100 = 1,000원 |
| B상품 | 50개 | 80원 | 85원 | 80원 | 0 (원가<NRV, 손실 없음) |

- A상품: NRV 90 < 원가 100 → 평가손실 1,000원 인식, 기말재고 100개×90 = 9,000원
- B상품: NRV 85 > 원가 80 → 평가손실 없음(가치 상승은 인식하지 않음), 기말재고 50개×80 = 4,000원

**분개 예시(재고자산평가충당금 사용)**

| 차변 | 대변 |
|---|---|
| (차) 재고자산평가손실 1,000 | (대) 재고자산평가충당금 1,000 |

재고자산평가손실은 매출원가에 가산하고, 재고자산평가충당금은 재무상태표에서 재고자산의 차감계정으로 표시한다.

**(3) 평가손실의 환입**

매 후속기간에 순실현가능가치를 재평가한다. 재고자산의 감액을 초래했던 상황이 해소되어 순실현가능가치가 회복된 경우, 최초의 취득원가를 한도로 하여 평가손실을 환입한다. 환입액은 환입이 발생한 기간의 매출원가(비용)에서 차감한다. 즉 취득원가를 초과하여 장부금액을 늘릴 수는 없다.

| 차변 | 대변 |
|---|---|
| (차) 재고자산평가충당금 ×× | (대) 재고자산평가충당금환입(매출원가 차감) ×× |

**(4) 감모손실·평가손실의 순서**

일반적으로 수량 부족(감모손실)을 먼저 인식하여 실제수량을 확정한 후, 그 실제수량에 대해 단가 하락(평가손실, 저가법)을 인식한다.

> 핵심: 수량 감소=감모손실(정상분은 매출원가, 비정상분은 기타비용), 가치 하락=평가손실(저가법, 취득원가와 NRV 중 낮은 금액). 회복 시 취득원가를 한도로 환입한다.

### ❹ 재고자산의 추정

화재·도난 등으로 실지재고조사가 불가능하거나, 중간결산에서 기말재고를 신속히 파악해야 할 때 기말재고를 추정한다. 대표적으로 매출총이익법과 소매재고법이 있다.

**(1) 매출총이익법(gross profit method)**

과거의 매출총이익률이 당기에도 유지된다고 가정하여 매출원가를 추정하고, 이를 통해 기말재고를 역산한다. K-IFRS에서 정규 결산목적으로는 인정되지 않으나, 화재손실 추정 등 비상시 추정에 사용한다.

```
매출원가 = 매출액 × (1 − 매출총이익률)
        = 매출액 × 매출원가율
기말재고(추정) = (기초재고 + 당기매입) − 매출원가
```

**계산 예시**
- 기초재고 2,000원, 당기매입 8,000원, 당기매출 10,000원, 매출총이익률 30%인 경우
- 매출원가 = 10,000 × (1 − 0.3) = 7,000원
- 기말재고(추정) = (2,000 + 8,000) − 7,000 = **3,000원**

원가에 이익을 가산하는 방식(매출원가에 대한 이익률, 즉 원가가산율)으로 제시되면 매출원가율 계산에 주의한다. 예컨대 "원가의 25% 이익"이면 매출원가율 = 1 ÷ 1.25 = 0.8이다.

**(2) 소매재고법(retail inventory method, 매출가격환원법)**

판매가격(소매가)으로 파악한 기말재고에 원가율을 곱하여 원가기준 기말재고를 추정하는 방법이다. 백화점·대형 유통업 등 품목이 많고 회전이 빠른 유통업에서 실무적으로 사용하며, 원가율이 유사한 항목을 통합하여 적용할 수 있는 경우 K-IFRS도 편의상 허용한다.

```
원가율 = 원가기준 판매가능재고 ÷ 매가기준 판매가능재고
기말재고(매가) = 매가기준 판매가능재고 − 당기 매출액
기말재고(원가) = 기말재고(매가) × 원가율
```

**계산 예시**

| 구분 | 원가 | 매가(소매가) |
|---|---|---|
| 기초재고 | 1,000원 | 1,500원 |
| 당기매입 | 5,000원 | 6,500원 |
| 판매가능재고 계 | 6,000원 | 8,000원 |
| 당기매출 | | 6,000원 |

- 원가율 = 6,000 ÷ 8,000 = 0.75(75%)
- 기말재고(매가) = 8,000 − 6,000 = 2,000원
- 기말재고(원가) = 2,000 × 0.75 = **1,500원**

원가율 산정 시 순인상액·순인하액을 어떻게 반영하는지에 따라 평균원가소매재고법, 저가기준소매재고법(전통적 소매재고법) 등으로 세분된다. 저가기준에서는 원가율 계산 시 순인하액을 분모에서 제외하여 원가율을 낮게 산정한다.

> 핵심: 매출총이익법은 매출총이익률로 매출원가를 추정해 기말재고를 역산하고, 소매재고법은 매가기준 기말재고에 원가율을 곱해 원가기준 기말재고를 추정한다.

### ❺ 외상매출·외상매입

상거래에서 대금을 즉시 현금으로 주고받지 않고 후일에 결제하기로 하면 채권·채무가 발생한다. 상품 판매로 인한 채권은 매출채권, 상품 매입으로 인한 채무는 매입채무로 처리한다.

| 구분 | 계정 | 성격 |
|---|---|---|
| 상품을 외상으로 판매 | 매출채권(외상매출금·받을어음) | 자산 |
| 상품을 외상으로 매입 | 매입채무(외상매입금·지급어음) | 부채 |

일반적 상거래(주된 영업활동인 상품·제품 매매)에서 발생하면 매출채권·매입채무, 그 외의 거래(예: 유형자산 처분 대금 미수)에서 발생하면 미수금·미지급금으로 구분한다.

**(1) 외상매출 시 분개 예시**

상품을 2,000원에 외상으로 판매한 경우(수익 인식, 3분법·계속기록법 가정):

| 구분 | 차변 | 대변 |
|---|---|---|
| 매출 인식 | (차) 매출채권 2,000 | (대) 매출 2,000 |

이후 외상대금 2,000원을 현금으로 회수한 경우:

| 차변 | 대변 |
|---|---|
| (차) 현금 2,000 | (대) 매출채권 2,000 |

매출할인(조기 회수를 위해 깎아준 금액)을 100원 적용하고 1,900원을 회수한 경우:

| 차변 | 대변 |
|---|---|
| (차) 현금 1,900 | (대) 매출채권 2,000 |
| (차) 매출할인(매출 차감) 100 | |

매출할인·매출에누리·매출환입은 총매출액에서 차감하여 순매출액을 산정한다.

```
순매출액 = 총매출액 − 매출환입 − 매출에누리 − 매출할인
```

**(2) 외상매입 시 분개 예시**

상품을 1,500원에 외상으로 매입한 경우(계속기록법):

| 구분 | 차변 | 대변 |
|---|---|---|
| 매입 인식 | (차) 상품(재고자산) 1,500 | (대) 매입채무 1,500 |

이후 외상대금 1,500원을 현금으로 지급한 경우:

| 차변 | 대변 |
|---|---|
| (차) 매입채무 1,500 | (대) 현금 1,500 |

매입할인 75원을 받고 1,425원을 지급한 경우(계속기록법에서는 재고자산에서 직접 차감):

| 차변 | 대변 |
|---|---|
| (차) 매입채무 1,500 | (대) 현금 1,425 |
| | (대) 상품(재고자산) 75 |

**(3) 매출채권과 대손**

매출채권 중 회수가 불확실한 금액은 대손충당금(손실충당금)을 설정하여 순액으로 표시한다. 기대신용손실을 추정하여 대손상각비를 인식하고, 매출채권의 차감계정으로 대손충당금을 표시한다. 이는 재무상태표상 상계가 아니라 평가충당금 차감표시에 해당한다.

| 차변 | 대변 |
|---|---|
| (차) 대손상각비 ×× | (대) 대손충당금(매출채권 차감) ×× |

> 핵심: 주된 영업의 외상거래는 매출채권·매입채무로 처리하고, 매출 시 (차)매출채권/(대)매출, 매입 시 (차)재고자산/(대)매입채무로 분개한다. 할인·에누리·환입(환출)은 각각 매출·매입에서 차감한다.

## 제9장 유형자산

### ❶ 유형자산의 정의 및 종류

**유형자산(Property, Plant and Equipment)** 이란 재화의 생산이나 용역의 제공, 타인에 대한 임대 또는 자체적으로 사용할 목적(영업활동)으로 보유하는 **물리적 실체가 있는 자산**으로서, **한 회계기간(1년)을 초과하여 사용할 것이 예상되는 자산**을 말한다.

**3가지 요건(모두 충족)**

| 요건 | 내용 |
|---|---|
| 물리적 실체 | 눈에 보이고 만질 수 있는 형체가 있음 (무형자산과 구별) |
| 사용 목적 보유 | 영업활동에 사용·임대 목적 (판매목적이면 재고자산, 투자목적이면 투자부동산) |
| 1년 초과 사용 | 한 회계기간을 초과하여 계속 사용 예상 |

> 같은 건물이라도 **사용 목적**에 따라 계정이 달라진다. 자가 사용 → 유형자산, 판매용(부동산매매업) → 재고자산, 시세차익·임대수익 목적 → 투자부동산.

**유형자산의 종류**

| 계정과목 | 내용 | 감가상각 |
|---|---|---|
| 토지 | 영업용 대지·임야 등 | **비상각** (내용연수 무한) |
| 건물 | 사무실·공장·창고 등 | 상각 |
| 구축물 | 교량·굴뚝·도로·저수지 등 | 상각 |
| 기계장치 | 제조용 기계·설비 | 상각 |
| 차량운반구 | 승용차·트럭·지게차 등 | 상각 |
| 비품 | 컴퓨터·책상·에어컨 등 | 상각 |
| 건설중인자산 | 건설 진행 중인 자산의 원가 집계 계정 | **비상각** (완성 전) |

> **핵심:** 유형자산 = 물리적 실체 + 영업목적 보유 + 1년 초과 사용. **토지와 건설중인자산은 감가상각하지 않는다.**

---

### ❷ 유형자산의 최초 측정: 원가

유형자산은 최초 인식 시점에 **원가(cost)** 로 측정한다. 원가는 자산을 취득하여 **경영진이 의도하는 방식으로 가동될 수 있는 장소와 상태에 이르게 하는 데 직접 관련되는 지출**을 모두 포함한다.

**원가의 구성**

```
원가 = 구입가격(관세·환급불가 취득세 포함, 매입할인·리베이트 차감)
     + 직접관련원가
     + 복구원가(해체·제거·복구 의무의 현재가치 추정치)
```

| 구분 | 원가 포함 O | 원가 포함 X (당기비용) |
|---|---|---|
| 예시 | 운반비, 설치비, 시운전비, 취득세, 전문가 수수료, 부지 정지비용 | 새로운 시설 개설 원가, 광고·판촉비, 관리비·기타 일반경비, 초기 가동손실 |

**직접관련원가**: 운반비, 설치 및 조립원가, 설치장소 준비원가, 정상 작동 여부를 확인하는 **시운전원가**, 전문가에게 지급하는 수수료 등. 단, 시운전 과정에서 생산된 시제품의 순매각금액은 원가에서 차감(또는 당기손익)한다.

**복구원가**: 유형자산의 사용 종료 후 해체·제거·복구할 의무가 있는 경우, 그 예상 지출액의 **현재가치**를 취득원가에 가산하고 동액을 **복구충당부채**로 인식한다.

**취득 유형별 원가 결정**

| 취득 유형 | 원가 결정 방법 |
|---|---|
| 일괄구입 | 여러 자산을 일괄 취득 시 총원가를 각 자산의 **상대적 공정가치 비율**로 안분. 단, 토지+건물 취득 후 건물 철거 목적이면 철거비·총액을 **토지 원가**로 처리 |
| 자가건설 | 직접재료·직접노무·제조간접원가 등 건설에 소요된 원가 집계 (내부이익·비정상 원가 제외) |
| 교환 | **상업적 실질이 있으면** 제공한 자산의 **공정가치**로 측정(현금수수 반영). 상업적 실질이 없거나 공정가치를 신뢰성 있게 측정 불가 시 **제공한 자산의 장부금액**으로 측정 |
| 정부보조 | 자산 취득 관련 정부보조금은 자산의 장부금액에서 차감(자산차감법)하거나 이연수익으로 인식 |

**[분개 예시]** 기계장치를 현금 ₩1,000,000에 구입하고, 운반비 ₩30,000과 설치·시운전비 ₩70,000을 현금 지급하였다.

```
(차) 기계장치   1,100,000    (대) 현금   1,100,000
```

**[일괄구입 예시]** 토지와 건물을 일괄하여 ₩900,000에 취득. 토지 공정가치 ₩700,000, 건물 공정가치 ₩300,000.

- 토지 = 900,000 × 700,000/1,000,000 = **₩630,000**
- 건물 = 900,000 × 300,000/1,000,000 = **₩270,000**

> **핵심:** 유형자산 원가 = 구입가격 + 직접관련원가(운반·설치·시운전) + 복구원가 현재가치. 광고비·관리비·초기 가동손실은 원가에 포함하지 않는다.

### ❸ 유형자산의 후속 지출

취득 후 사용 과정에서 발생하는 지출은 그 성격에 따라 **자본적 지출**과 **수익적 지출**로 구분한다.

| 구분 | 자본적 지출 (자산화) | 수익적 지출 (당기비용) |
|---|---|---|
| 성격 | 자산의 **미래경제적효익 증가** | 원상회복·능률유지 |
| 효과 | 내용연수 연장, 생산능력 증대, 원가 절감, 품질 향상 | 정상 성능 유지 |
| 예시 | 증·개축, 엘리베이터 설치, 냉난방장치 설치, 주요 부품 대체 | 건물 도색, 소모품 교체, 일상적 수선·유지, 파손 유리 교체 |
| 회계처리 | 해당 자산 계정에 가산 → 이후 감가상각 | 수선비 등 **비용** 처리 |
| 재무제표 효과 | 자산 증가 → 이후 상각통해 비용화 | 당기 비용 즉시 인식 |

**[분개 예시]** 건물의 엘리베이터를 ₩500,000에 설치(자본적 지출)하고, 건물 외벽 도색비 ₩80,000(수익적 지출)을 현금 지급하였다.

```
(차) 건물     500,000    (대) 현금   580,000
    수선비    80,000
```

> **오류의 영향**: 자본적 지출을 수익적 지출로 잘못 처리하면 → 당기 **비용 과대**, 이익·자산 과소. 반대로 수익적 지출을 자본적 지출로 처리하면 → 비용 과소, 이익·자산 과대.

> **핵심:** 미래효익을 **증가**시키면 자본적 지출(자산), 현상을 **유지**시키면 수익적 지출(비용). 판단이 재무제표 전체에 영향을 준다.

### ❹ 감가상각

**감가상각(depreciation)** 이란 유형자산의 **감가상각대상금액(취득원가 − 잔존가치)** 을 자산의 내용연수에 걸쳐 **체계적이고 합리적인 방법**으로 배분하여 비용으로 인식하는 절차이다. 감가상각은 자산의 **평가(가치 측정)** 가 아니라 **원가의 배분** 과정이라는 점이 핵심이다.

**감가상각의 3요소**

| 요소 | 내용 |
|---|---|
| 취득원가 | ❷에서 결정한 원가 |
| 잔존가치 | 내용연수 종료 시점의 처분 예상액(처분부대원가 차감) |
| 내용연수 | 자산을 사용할 것으로 예상되는 기간(또는 생산량) |

- **감가상각대상금액(상각기준액) = 취득원가 − 잔존가치**
- **장부금액(book value) = 취득원가 − 감가상각누계액**
- 감가상각비는 **손익계산서 비용**, 감가상각누계액은 자산의 **차감계정**(재무상태표)

**공통 예제 (❹ 모든 방법에 동일 적용)**
- 취득원가 ₩1,000,000, 잔존가치 ₩100,000, 내용연수 5년
- 상각대상금액 = 1,000,000 − 100,000 = **₩900,000**

#### (1) 정액법 (Straight-line method)

$$\text{연 감가상각비} = \frac{\text{취득원가} - \text{잔존가치}}{\text{내용연수}} = \frac{1,000,000 - 100,000}{5} = 180,000$$

| 연도 | 감가상각비 | 감가상각누계액 | 장부금액 |
|---|---|---|---|
| 취득 | — | — | 1,000,000 |
| 1년 | 180,000 | 180,000 | 820,000 |
| 2년 | 180,000 | 360,000 | 640,000 |
| 3년 | 180,000 | 540,000 | 460,000 |

매년 동일한 금액을 상각. 사용 기간 동안 효익이 균등하다고 볼 때 적합.

#### (2) 정률법 (Declining-balance method)

**기초 장부금액(미상각잔액)에 일정한 상각률을 곱한다.** 잔존가치는 계산식에 직접 넣지 않고, 장부금액이 잔존가치에 수렴하도록 상각률을 정한다.

$$\text{연 감가상각비} = \text{기초 장부금액} \times \text{상각률}, \qquad \text{상각률} = 1 - \sqrt[n]{\frac{\text{잔존가치}}{\text{취득원가}}}$$

$$\text{상각률} = 1 - \sqrt[5]{\frac{100,000}{1,000,000}} = 1 - 0.1^{0.2} \approx 1 - 0.631 = 0.369 \;(\text{약 } 36.9\%)$$

| 연도 | 기초 장부금액 | ×상각률(0.369) | 감가상각누계액 | 기말 장부금액 |
|---|---|---|---|---|
| 1년 | 1,000,000 | 369,000 | 369,000 | 631,000 |
| 2년 | 631,000 | 232,839 | 601,839 | 398,161 |
| 3년 | 398,161 | 146,921 | 748,760 | 251,240 |

초기에 상각비가 크고 후기로 갈수록 작아지는 **가속상각법**. 초기 효익이 크거나 진부화가 빠른 자산에 적합. (단, 마지막 해에는 장부금액이 잔존가치가 되도록 조정한다.)

#### (3) 연수합계법 (Sum-of-the-years'-digits method)

상각대상금액에 **잔여 내용연수 / 내용연수 합계**를 곱한다. 내용연수 합계 = 5+4+3+2+1 = **15**.

$$\text{연 감가상각비} = (\text{취득원가}-\text{잔존가치}) \times \frac{\text{잔여내용연수}}{\text{내용연수 합계}}$$

| 연도 | 상각대상금액 | ×상각비율 | 감가상각비 | 감가상각누계액 | 장부금액 |
|---|---|---|---|---|---|
| 1년 | 900,000 | 5/15 | 300,000 | 300,000 | 700,000 |
| 2년 | 900,000 | 4/15 | 240,000 | 540,000 | 460,000 |
| 3년 | 900,000 | 3/15 | 180,000 | 720,000 | 280,000 |

정률법처럼 초기 상각비가 크지만 계산이 단순한 가속상각법.

#### (4) 생산량비례법 (Units-of-production method)

시간이 아니라 **실제 생산량(사용량)** 에 비례하여 상각. 총 추정생산량 90,000단위 가정.

$$\text{단위당 상각비} = \frac{900,000}{90,000} = @10 /\text{단위}$$

| 연도 | 실제생산량 | ×단위당(@10) | 감가상각비 | 감가상각누계액 | 장부금액 |
|---|---|---|---|---|---|
| 1년 | 20,000단위 | 10 | 200,000 | 200,000 | 800,000 |
| 2년 | 25,000단위 | 10 | 250,000 | 450,000 | 550,000 |
| 3년 | 15,000단위 | 10 | 150,000 | 600,000 | 400,000 |

광산·유전·생산설비처럼 사용량과 소모가 직접 비례하는 자산에 적합.

**[감가상각 분개]** (방법 불문 동일한 형식) 1차연도 정액법 상각.

```
(차) 감가상각비   180,000    (대) 감가상각누계액   180,000
```

> **핵심:** 감가상각 = 원가의 배분(평가 아님). 3요소는 취득원가·잔존가치·내용연수. 정액법은 균등, 정률법·연수합계법은 초기 집중(가속), 생산량비례법은 사용량 비례. 4가지 방법의 **총 상각액(=상각대상금액)은 동일**하고 기간별 배분만 다르다.

---

### ❺ 손상

**손상(impairment)** 이란 자산의 **회수가능액이 장부금액에 미달**하는 상태를 말한다. 매 보고기간 말 **손상 징후**를 검토하고, 징후가 있으면 회수가능액을 추정한다.

**손상 징후(예시)**: 시장가치의 현저한 하락, 기술·시장·경제·법률 환경의 불리한 변화, 시장이자율 상승, 자산의 진부화·물리적 손상, 사용 중단 계획, 자산의 경제적 성과 저하 등.

**회수가능액(recoverable amount)**

$$\text{회수가능액} = \text{Max}(\text{순공정가치},\; \text{사용가치})$$

| 개념 | 내용 |
|---|---|
| 순공정가치 | 공정가치 − 처분부대원가 (지금 팔면 받는 순액) |
| 사용가치 | 자산을 계속 사용·처분하여 얻을 미래현금흐름의 **현재가치** |

**손상차손 = 장부금액 − 회수가능액** (회수가능액이 장부금액보다 클 때는 손상 없음)

**[손상 계산 예시]**
- 기계장치 장부금액 ₩800,000
- 순공정가치 ₩500,000, 사용가치 ₩550,000
- 회수가능액 = Max(500,000, 550,000) = **₩550,000**
- 손상차손 = 800,000 − 550,000 = **₩250,000**

```
(차) 유형자산손상차손   250,000    (대) 손상차손누계액   250,000
```

손상차손누계액은 자산의 차감계정으로, 손상 후 장부금액(₩550,000)을 남은 내용연수에 걸쳐 다시 감가상각한다.

**손상차손 환입(reversal)**

손상 인식 후 회수가능액이 회복되면 **손상차손환입**(수익)을 인식한다. 단, 환입 후 장부금액은 **과거에 손상을 인식하지 않았다면 계상되었을 장부금액(감가상각 후)** 을 **초과할 수 없다**.

**[환입 예시]** 위 자산의 회수가능액이 이후 ₩700,000으로 회복. 손상을 인식하지 않았다면 장부금액이 ₩600,000이었다고 가정.

- 환입 한도 = Min(회수가능액 700,000, 손상 없었을 경우 장부금액 600,000) = **₩600,000**
- 현재 장부금액 ₩550,000 → 환입액 = 600,000 − 550,000 = **₩50,000**

```
(차) 손상차손누계액   50,000    (대) 유형자산손상차손환입   50,000
```

> **핵심:** 회수가능액 = Max(순공정가치, 사용가치). 손상차손 = 장부금액 − 회수가능액. 환입 시 **손상이 없었을 경우의 장부금액을 초과할 수 없다**(영업권 손상은 환입 불가).

## 제10장 무형자산

### ❶ 무형자산 정의를 위한 요건(모두 충족)

**무형자산(Intangible Assets)** 이란 **물리적 실체는 없지만 식별가능한 비화폐성 자산**을 말한다. 무형자산으로 **정의**되기 위해서는 다음 3가지를 **모두 충족**해야 한다.

| 요건 | 내용 |
|---|---|
| ① 식별가능성 | 자산이 **분리가능**(매각·이전·라이선스 가능)하거나, **계약상·법적 권리**로부터 발생 |
| ② 통제 | 자원에서 나오는 미래경제적효익을 **기업이 통제**(제3자의 접근 제한) — 통상 법적 권리로 뒷받침 |
| ③ 미래경제적효익 | 재화·용역의 매출, 원가절감, 기타 효익의 형태로 미래에 유입 |

- **식별가능성**: 영업권과 구별하는 핵심 기준. 분리가능하거나 계약·법적 권리에서 발생해야 한다.
- **통제**: 숙련된 종업원·고객충성도 등은 통상 통제 요건을 충족하지 못해 자산으로 인식하지 못한다.

> **핵심:** 무형자산 정의 3요건 = 식별가능성 + 통제 + 미래경제적효익. 물리적 실체가 없으며, 셋을 모두 충족해야 무형자산으로 **정의**된다.

---

### ❷ 무형자산 인식요건(모두 충족)

정의를 충족하더라도 재무제표에 **인식(장부 계상)** 하려면 다음 2가지를 **모두 충족**해야 한다.

| 인식요건 | 내용 |
|---|---|
| ① 효익 유입 가능성 | 자산에서 발생하는 미래경제적효익이 기업에 유입될 가능성이 **높다(probable)** |
| ② 원가의 신뢰성 있는 측정 | 자산의 **원가를 신뢰성 있게 측정**할 수 있다 |

**무형자산의 종류(예시)**: 영업권, 특허권, 실용신안권, 상표권, 디자인권(의장권), 저작권, 라이선스, 프랜차이즈, 컴퓨터소프트웨어, 개발비, 광업권, 어업권 등.

> **핵심:** 인식 = 정의(3요건) + 인식요건(효익 유입 가능성 높음 + 원가 신뢰성 측정). 정의를 만족해도 두 인식요건을 못 갖추면 장부에 올리지 않는다.

---

### ❸ 무형자산의 최초측정

무형자산도 최초 인식 시 **원가**로 측정한다. 취득 형태에 따라 원가 결정이 달라진다.

| 취득 형태 | 원가 결정 |
|---|---|
| 개별 취득 | 구입가격 + 직접관련원가(전문가 수수료, 자산이 의도된 대로 사용되게 하는 데 드는 원가). 매입할인·리베이트는 차감 |
| 사업결합으로 취득 | 취득일의 **공정가치**로 측정. 피취득기업의 식별가능한 무형자산은 영업권과 분리하여 인식 |
| 내부창출 | 원칙적으로 엄격히 제한. 개발단계 요건 충족분(개발비)만 자산화 (❹ 참조) |
| 정부보조 | 공정가치 또는 명목금액으로 인식 가능 |

**영업권(Goodwill)**

- **사업결합** 시 이전대가가 피취득기업의 **식별가능한 순자산 공정가치**를 초과하는 금액. (초과분 = 영업권)
- **매수(외부구입) 영업권만 인식**한다. **내부창출 영업권은 자산으로 인식할 수 없다**(원가를 신뢰성 있게 측정 불가, 식별불가).
- 영업권은 내용연수가 **비한정**으로 보아 **상각하지 않고**, 매년 **손상검사**만 수행한다. 영업권 손상차손은 **환입할 수 없다**.

$$\text{영업권} = \text{이전대가} - \text{식별가능한 순자산의 공정가치}$$

> **핵심:** 개별취득은 구입가+직접원가, 사업결합은 공정가치, 내부창출은 원칙적으로 자산화 불가(개발비만 예외). **내부창출 영업권은 인식 불가**, 매수영업권만 인식하고 상각하지 않으며 손상검사만 한다.

---

### ❹ 연구활동·개발활동

내부적으로 창출한 무형자산은 자산 창출 과정을 **연구단계**와 **개발단계**로 구분한다. 둘을 구분할 수 없으면 **모두 연구단계**로 본다.

| 구분 | 연구단계(Research) | 개발단계(Development) |
|---|---|---|
| 성격 | 새로운 지식을 얻고자 하는 **탐구적** 활동 | 연구 결과를 상업적 생산·사용에 적용하는 **구체화** 활동 |
| 예시 | 새로운 지식 탐색, 대체안 탐색·평가·최종 선택 | 시제품·모형 설계/제작/시험, 시험공장 설계·건설, 신기술 관련 공구·금형 설계 |
| 회계처리 | **전액 당기비용**(연구비) | 6가지 요건 **모두 충족 시 자산화(개발비)**, 미충족 시 당기비용(경상개발비) |

**개발비 자산화 6요건(모두 충족)**

1. 무형자산을 사용·판매하기 위해 **완성할 수 있는 기술적 실현가능성**
2. 무형자산을 완성하여 사용·판매하려는 기업의 **의도**
3. 무형자산을 사용·판매할 수 있는 **능력**
4. 무형자산이 **미래경제적효익을 창출하는 방법**(시장의 존재 등)
5. 개발 완료 및 사용·판매에 필요한 **기술적·재정적 자원의 입수가능성**
6. 개발 과정의 **지출을 신뢰성 있게 측정**할 수 있는 능력

**[분개 예시]** 신제품 연구비 ₩300,000, 자산화 요건을 충족한 개발지출 ₩500,000을 현금 지출하였다.

```
(차) 연구비(비용)   300,000    (대) 현금   800,000
    개발비(무형자산) 500,000
```

> **주의**: 자산화 요건 충족 **이전**에 이미 비용으로 인식한 지출은 이후 소급하여 자산으로 인식할 수 없다. 또한 내부창출 브랜드·고객목록·출판표제 등은 자산으로 인식하지 않는다.

> **핵심:** 연구단계 지출은 **전액 당기비용**, 개발단계 지출은 **6요건을 모두 충족할 때만 자산화(개발비)**. 구분 불가 시 연구단계로 간주하여 비용 처리한다.

---

### ❺ 무형자산의 상각

무형자산은 **내용연수가 유한한지 비한정인지**에 따라 회계처리가 달라진다.

| 구분 | 내용연수 유한 | 내용연수 비한정 |
|---|---|---|
| 상각 | **상각함**(체계적 배분) | **상각하지 않음** |
| 손상검토 | 손상징후 있을 때 검토 | 매년(그리고 징후 있을 때) **손상검사** |
| 예시 | 특허권, 개발비, 라이선스(기간 제한) | 영업권, 일부 상표권(갱신 무한) |

**상각의 방법·요소**

- **상각방법**: 미래경제적효익의 소비 형태를 반영(정액법·정률법·생산량비례법 등). 소비 형태를 신뢰성 있게 결정할 수 없으면 **정액법**을 사용한다.
- **상각기간**: 자산이 사용가능한 시점부터 시작. 내용연수는 경제적·법적 내용연수 중 **짧은 기간**.
- **잔존가치**: **원칙적으로 ₩0(영)** 으로 본다. (활성시장이 있거나 제3자 구입 약정이 있는 예외적 경우에만 잔존가치 인정)
- **상각비 표시**: 통상 당기비용. 상각액은 무형자산에서 직접 차감하거나 상각누계액으로 표시.

**[상각 계산 예시]** 특허권 취득원가 ₩500,000, 내용연수 10년, 잔존가치 ₩0, 정액법.

$$\text{연 상각비} = \frac{500,000 - 0}{10} = 50,000$$

| 연도 | 상각비 | 상각누계액 | 장부금액 |
|---|---|---|---|
| 1년 | 50,000 | 50,000 | 450,000 |
| 2년 | 50,000 | 100,000 | 400,000 |
| 3년 | 50,000 | 150,000 | 350,000 |

```
(차) 무형자산상각비   50,000    (대) 특허권(또는 상각누계액)   50,000
```

**내용연수 비한정 자산**은 상각하지 않는 대신, 매 보고기간 말 **비한정이라는 평가가 여전히 타당한지 재검토**하고 **손상검사**를 수행한다. 비한정 판단이 유한으로 변경되면 그때부터 상각한다.

> **핵심:** 내용연수 **유한 → 상각(잔존가치 원칙 0, 방법 불분명 시 정액법)**, **비한정 → 상각하지 않고 매년 손상검사**. 영업권은 대표적 비한정 자산으로 상각하지 않는다.

## 제11장 금융상품

### ❶ 금융상품의 정의

금융상품(financial instrument)이란 **거래당사자 일방에게는 금융자산을, 상대방에게는 금융부채나 지분상품을 발생시키는 계약**을 말한다. 즉 금융상품은 언제나 두 당사자 사이의 **계약(contract)**을 전제로 하며, 한쪽의 금융자산은 반드시 다른 쪽의 금융부채 또는 지분상품과 짝을 이룬다.

이 정의에서 핵심은 세 가지다.

- **계약에 근거할 것**: 법령이나 정부의 규제에 따라 강제로 부과되는 조세(법인세, 재산세 등)나 의제의무는 당사자 간의 계약이 아니므로 금융상품이 아니다. 예컨대 미지급법인세는 금융부채가 아니다.
- **거래당사자가 존재할 것**: 계약에는 언제나 권리를 가지는 자와 의무를 지는 자가 있다. 한쪽에 현금 등을 받을 **권리**(금융자산)가 생기면, 상대방에는 현금 등을 지급할 **의무**(금융부채)가 생긴다.
- **결과가 금융자산·금융부채·지분상품일 것**: 계약의 결과가 재화나 용역의 수수로 귀결되면 금융상품이 아니다.

| 계약 당사자 | 발생 항목 | 성격 |
|---|---|---|
| 일방(권리자) | 금융자산 | 현금 등을 받을 계약상 권리 |
| 상대방(의무자) | 금융부채 | 현금 등을 지급할 계약상 의무 |
| 상대방(발행자) | 지분상품 | 잔여지분에 대한 계약 |

예를 들어 A가 B에게 상품을 외상으로 판매하면, A에게는 대금을 받을 권리인 **매출채권(금융자산)**이, B에게는 대금을 지급할 의무인 **매입채무(금융부채)**가 동시에 발생한다. 하나의 계약이 양쪽에 대칭적으로 금융자산과 금융부채를 만들어 내는 것이다.

> 핵심: 금융상품은 한쪽에 금융자산, 상대방에 금융부채나 지분상품을 발생시키는 **계약**이며, 조세처럼 계약에 근거하지 않는 의무는 금융상품이 아니다.

### ❷ 금융상품의 종류

금융상품은 발생시키는 항목에 따라 **금융자산, 금융부채, 지분상품**으로 구분한다.

**(1) 금융자산**

금융자산은 다음의 것을 말한다.

- **현금**: 그 자체가 교환의 수단이므로 금융자산의 기본이 된다.
- **다른 기업의 지분상품**: 다른 회사의 주식(투자지분상품) 등.
- **현금 등 금융자산을 수취할 계약상 권리**: 매출채권, 대여금, 미수금, 받을어음, 투자채무상품(다른 회사가 발행한 사채 등).
- **잠재적으로 유리한 조건으로 금융자산·금융부채를 교환하기로 한 계약상 권리** 등.

| 구분 | 대표 계정 |
|---|---|
| 현금 | 현금및현금성자산 |
| 지분상품 투자 | 다른 회사 주식(FVPL·FVOCI 금융자산) |
| 채권(수취 권리) | 매출채권, 받을어음, 대여금, 미수금, 투자채무상품(사채 투자) |

**(2) 금융부채**

금융부채는 다음의 계약상 의무를 말한다.

- **현금 등 금융자산을 인도할 계약상 의무**: 매입채무, 지급어음, 차입금, 사채, 미지급금 등.
- **잠재적으로 불리한 조건으로 금융자산·금융부채를 교환하기로 한 계약상 의무** 등.

| 구분 | 대표 계정 |
|---|---|
| 채무(인도 의무) | 매입채무, 지급어음, 차입금, 사채, 미지급금 |

**(3) 지분상품**

지분상품(equity instrument)은 기업의 자산에서 모든 부채를 차감한 후의 **잔여지분(residual interest)**을 나타내는 계약을 말한다. 발행회사 입장에서 보통주·우선주 등 자기가 발행한 주식이 지분상품에 해당하며, 이는 자본으로 분류한다.

다음 분개는 상품을 외상으로 판매한 A사(매출채권=금융자산 발생)와 이를 매입한 B사(매입채무=금융부채 발생)의 대응 관계를 보여 준다.

```
[A사] (차) 매출채권   100,000  (대) 매    출   100,000
[B사] (차) 상    품   100,000  (대) 매입채무   100,000
```

> 핵심: 금융자산은 현금·지분상품 투자·수취 권리(매출채권·대여금·투자채무상품)이고, 금융부채는 인도 의무(매입채무·차입금·사채)이며, 발행자 자신의 주식은 잔여지분인 지분상품(자본)이다.

### ❸ 금융상품에 해당하지 않는 사례

계약이라 하더라도 그 결과가 금융자산·금융부채·지분상품이 아니면 금융상품이 아니다. 특히 **결과가 재화나 용역의 수수인 경우**나 **계약에 근거하지 않은 항목**이 대표적이다.

**(1) 재화·용역의 수수로 결제되는 항목**

- **선급금·선수금**: 선급금은 미래에 **재화나 용역을 제공받을 권리**이고, 선수금은 재화·용역을 **제공할 의무**이다. 현금을 받거나 줄 권리·의무가 아니므로 금융자산·금융부채가 아니다.
- **선급비용·선수수익**: 마찬가지로 용역의 수수와 관련되므로 금융상품이 아니다.

**(2) 실물자산·무형자산**

- **재고자산, 유형자산, 무형자산**: 이는 물리적 실체나 권리를 지배하는 자산일 뿐, 현금 등 금융자산을 수취할 계약상 권리가 아니다. 예컨대 건물은 그 자체로 가치가 있으나 누군가로부터 현금을 받을 권리가 아니므로 금융자산이 아니다.
- **사용권자산**: 리스이용자가 인식하는 사용권자산도 자산의 사용 권리이므로 금융자산이 아니다(다만 리스부채는 금융부채에 해당).

**(3) 계약상 권리·의무가 아닌 항목**

- **미지급법인세·미수환급법인세**: 조세는 법령에 따른 것으로 계약에서 발생한 것이 아니므로 금융상품이 아니다.
- **의제의무(충당부채 등)**: 계약이 아니라 과거 관행 등에서 생기는 의무는 금융부채가 아니다.

| 항목 | 금융상품 여부 | 이유 |
|---|---|---|
| 선급금·선수금 | ✕ | 재화·용역 수수 권리·의무 |
| 선급비용·선수수익 | ✕ | 용역 관련, 현금 수수 아님 |
| 재고자산·유형자산·무형자산 | ✕ | 실물·권리 지배 자산 |
| 미지급법인세 | ✕ | 계약이 아닌 법령상 의무 |
| 매출채권·매입채무 | ○ | 현금 수수 계약상 권리·의무 |
| 차입금·사채·대여금 | ○ | 현금 인도·수취 계약 |

주의할 점은, 같은 "채권처럼 보이는" 계정이라도 무엇으로 결제되는가에 따라 결론이 달라진다는 것이다. 선급금은 나중에 **재화**로 회수되므로 금융자산이 아니지만, 매출채권은 나중에 **현금**으로 회수되므로 금융자산이다.

> 핵심: 선급금·선수금(재화·용역), 재고·유형·무형자산(실물·권리), 미지급법인세(법령상 의무)는 현금 수수의 계약상 권리·의무가 아니므로 금융상품이 아니다.

## 제12장 현금및현금성자산

### ❶ 현금

재무상태표에 표시되는 **현금및현금성자산**은 가장 유동성이 높은 자산으로 유동자산 최상단에 배열된다. 이 중 **현금(cash)**은 다시 통화와 통화대용증권으로 나뉜다.

**(1) 통화**

통화(通貨)는 한국은행이 발행한 **지폐와 주화**를 말한다. 그 자체가 법정 지급수단이다.

**(2) 통화대용증권**

통화대용증권은 통화는 아니지만 **은행 등에서 즉시 통화로 교환할 수 있는 증권**으로, 회계상 현금으로 분류한다. 대표적인 예는 다음과 같다.

- **타인발행수표**(당좌수표, 가계수표)
- **자기앞수표**
- **송금수표, 우편환증서(우편환)**
- **배당금지급통지표**(배당금영수증)
- **만기가 된 공사채 이자표**(국공채 만기이자표)
- **일람출급어음, 만기도래 약속어음**

| 구분 | 예시 |
|---|---|
| 통화 | 지폐, 주화 |
| 통화대용증권 | 타인발행수표, 자기앞수표, 송금수표, 우편환증서, 배당금지급통지표, 만기도래 공사채이자표 |

통화대용증권은 "즉시·확정적으로 현금화 가능한가"가 판단 기준이다. 예컨대 배당금지급통지표는 은행에 제시하면 곧바로 현금을 받을 수 있으므로 현금으로 본다. 반면 뒤에서 보듯 **선일자수표**는 형식은 수표이나 실질은 아직 만기가 오지 않은 어음과 같으므로 현금으로 보지 않는다.

거래 예시로, 상품을 판매하고 대금을 자기앞수표로 받은 경우 분개는 다음과 같다.

```
(차) 현    금   500,000  (대) 매    출   500,000
```

> 핵심: 현금은 통화(지폐·주화)와, 즉시 통화로 교환 가능한 통화대용증권(타인발행수표·자기앞수표·우편환·배당금지급통지표 등)을 포함한다.

### ❷ 현금성자산

현금성자산(cash equivalents)은 **큰 거래비용 없이 현금으로 전환이 용이하고, 이자율 변동에 따른 가치변동 위험이 경미한 금융상품** 중, **취득 당시 만기(또는 상환일)가 3개월 이내에 도래하는 것**을 말한다.

세 가지 요건을 모두 충족해야 한다.

- **유동성**: 현금으로 전환이 쉬울 것.
- **가치변동 위험이 낮을 것**: 이자율 변동에 가치가 크게 흔들리지 않을 것.
- **취득 당시 만기 3개월 이내**: 판단 기준일은 **결산일이 아니라 취득일**이다.

특히 세 번째 요건이 자주 함정으로 출제된다. 만기 3개월 이내는 **취득한 시점을 기준**으로 판단하며, 보고기간 말까지 남은 잔여만기로 판단하지 않는다.

| 구분 | 예시 |
|---|---|
| 현금성자산 ○ | 취득일로부터 만기 3개월 이내 양도성예금증서(CD), 취득일로부터 만기 3개월 이내 환매조건부채권(RP), 취득일로부터 상환일 3개월 이내 상환우선주, 3개월 이내 만기 국공채 |
| 현금성자산 ✕ | 취득일 기준 만기 3개월 초과 정기예금·정기적금, 만기 3개월 초과 채권(취득 시점 기준) |

예를 들어, 만기가 5년인 국공채라도 **취득일 현재 만기가 2개월 남은 상태에서 취득**했다면 현금성자산이다. 반대로 취득일에 만기가 4개월 남아 있었다면, 보고기간 말에 잔여만기가 2개월로 줄었더라도 현금성자산이 아니다.

지분상품(주식)은 만기가 없고 가치변동 위험이 크므로 원칙적으로 현금성자산이 될 수 없다. 다만 위 표의 **상환우선주**처럼 상환일이 정해져 있고 취득일로부터 상환일이 3개월 이내인 경우는 예외적으로 현금성자산으로 본다.

> 핵심: 현금성자산은 유동성이 높고 가치변동 위험이 적으며 **취득 당시(취득일 기준)** 만기가 3개월 이내인 금융상품으로, 결산일 잔여만기가 아니라 취득 시점으로 판단한다.

### ❸ 현금및현금성자산에서 제외되는 항목

형태상 현금처럼 보이지만 실제로는 다른 계정으로 분류해야 하는 항목들이 있다. 시험에서 가장 빈번하게 다루어지는 부분이다.

- **우표·수입인지**: 통신·납부 목적의 소모품 또는 선급비용으로, 현금이 아니다.
- **선일자수표(先日字手票)**: 발행일을 미래로 적어 만기 전에는 지급받을 수 없는 수표로, 실질은 어음과 같다. 영업 관련이면 **매출채권(받을어음)**, 그 외이면 **미수금**으로 분류한다.
- **당좌개설보증금**: 당좌예금 개설을 위해 담보로 예치한 금액으로 인출이 제한되므로 **장기금융상품(비유동자산)**으로 분류한다.
- **사용이 제한된 예금**: 부채의 담보로 제공되어 인출이 제한된 예금은, 제한 기간에 따라 단기금융상품 또는 장기금융상품으로 분류한다.
- **가불금·차용증서**: 종업원 등에 대한 **단기대여금** 또는 미수금이다.
- **부도수표·부도어음**: 회수가 불확실하므로 현금이 아니라 별도의 채권(부도어음, 매출채권 등)으로 분류한다.

| 항목 | 올바른 분류 | 이유 |
|---|---|---|
| 우표·수입인지 | 소모품·선급비용 | 현금 아닌 사용 목적 자산 |
| 선일자수표 | 매출채권(받을어음)·미수금 | 실질이 어음과 동일 |
| 당좌개설보증금 | 장기금융상품 | 인출 제한 |
| 사용제한예금 | 단기·장기금융상품 | 담보 등으로 인출 제한 |
| 가불금·차용증서 | 단기대여금·미수금 | 회수해야 할 채권 |
| 부도수표·부도어음 | 매출채권 등 채권 | 즉시 현금화 불가 |

핵심 판단 기준은 **"보고기간 말 현재 즉시·자유롭게 현금화할 수 있는가"**이다. 인출이 제한되어 있거나(당좌개설보증금·사용제한예금), 만기가 도래하지 않았거나(선일자수표), 회수가 불확실하면(부도수표) 현금및현금성자산이 아니다.

선일자수표를 받은 경우의 분개 예시는 다음과 같다(상품 매출 대가).

```
(차) 매출채권(받을어음)   300,000  (대) 매    출   300,000
```

> 핵심: 우표·수입인지(선급비용), 선일자수표(매출채권/미수금), 당좌개설보증금·사용제한예금(장기금융상품 등)은 즉시 자유롭게 현금화할 수 없으므로 현금및현금성자산에서 제외한다.

## 제13장 금융자산

### ❶ 금융자산의 분류

K-IFRS는 **투자한 금융자산(채무상품·지분상품)**을 두 가지 기준으로 분류한다.

- **사업모형(business model)**: 금융자산을 보유하는 목적. ① 계약상 현금흐름 수취, ② 수취와 매도 둘 다, ③ 매도(단기매매) 중 무엇인가.
- **계약상 현금흐름 특성(SPPI)**: 계약상 현금흐름이 **원금과 원금에 대한 이자(Solely Payments of Principal and Interest)**만으로 구성되는가.

이 두 기준을 결합하여 채무상품은 세 가지 범주로 분류한다.

| 분류 | 사업모형 | 현금흐름(SPPI) | 후속측정 | 평가손익 처리 |
|---|---|---|---|---|
| **AC**(상각후원가) | 현금흐름 수취 | 충족 | 상각후원가 | 유효이자율 상각(평가손익 없음) |
| **FVOCI**(기타포괄손익-공정가치) | 수취+매도 | 충족 | 공정가치 | 평가손익 → **기타포괄손익(OCI)** |
| **FVPL**(당기손익-공정가치) | 그 외(매도 등) | 불충족 포함 | 공정가치 | 평가손익 → **당기손익(PL)** |

- **AC**(Amortized Cost, 상각후원가측정 금융자산): 원리금 수취 목적으로 보유하고 현금흐름이 원리금만으로 구성될 때. 공정가치로 평가하지 않고 유효이자율법에 따른 상각후원가로 측정한다.
- **FVOCI**(Fair Value through Other Comprehensive Income, 기타포괄손익-공정가치측정 금융자산): 원리금 수취와 매도를 모두 목적으로 하고 SPPI를 충족할 때. 공정가치로 평가하되 평가손익은 기타포괄손익에 반영한다.
- **FVPL**(Fair Value through Profit or Loss, 당기손익-공정가치측정 금융자산): 위 두 조건에 해당하지 않는 경우(예: 단기매매목적, SPPI 불충족). 공정가치로 평가하고 평가손익을 당기손익에 반영한다.

> 핵심: 금융자산은 **사업모형+계약상 현금흐름 특성(SPPI)**에 따라 AC(상각후원가)·FVOCI(기타포괄손익-공정가치)·FVPL(당기손익-공정가치)로 분류하며, 평가손익을 어디에 반영하는지가 범주별로 다르다.

### ❷ 투자지분상품

다른 회사의 주식과 같은 **투자지분상품**은 원리금 개념이 없어 SPPI 조건을 충족할 수 없다. 따라서 지분상품 투자는 **원칙적으로 FVPL로 분류**한다.

다만 단기매매목적이 아닌 지분상품에 대해서는, **최초 인식 시점에 FVOCI로 지정(선택)**할 수 있다. 이 지정은 다음 특징을 가진다.

- **취소 불가(irrevocable)**: 한 번 FVOCI로 지정하면 이후 취소할 수 없다.
- **재분류 불가**: 지분상품은 FVPL과 FVOCI 사이에서 재분류하지 않는다.
- **평가손익은 기타포괄손익(OCI)**: FVOCI로 지정하면 공정가치 변동을 OCI에 반영한다.
- **처분손익도 당기손익 아님**: FVOCI 지정 지분상품은 처분 시에도 평가손익 누계액을 당기손익으로 재순환(recycling)하지 않는다.

| 구분 | 분류 | 평가손익 |
|---|---|---|
| 지분상품(원칙) | FVPL | 당기손익 |
| 단기매매목적 아닌 지분상품(선택 지정) | FVOCI(지정) | 기타포괄손익, 재분류·재순환 불가 |

FVPL 지분상품의 기말 평가 예시로, 공정가치가 취득원가보다 상승한 경우 분개는 다음과 같다.

```
(차) FVPL금융자산   50,000  (대) 금융자산평가이익(당기손익)   50,000
```

반면 FVOCI로 지정한 지분상품이라면 상대 계정이 당기손익이 아니라 기타포괄손익이 된다.

```
(차) FVOCI금융자산   50,000  (대) 금융자산평가이익(기타포괄손익)   50,000
```

> 핵심: 투자지분상품은 SPPI를 충족할 수 없어 원칙적으로 FVPL이며, 단기매매목적이 아니면 최초 인식 시 **취소 불가능하게 FVOCI로 지정**할 수 있다(이후 재분류·재순환 불가).

### ❸ 투자채무상품

다른 회사가 발행한 사채와 같은 **투자채무상품**은 원리금(원금과 이자)이라는 현금흐름이 있어 SPPI 조건 충족 여부를 판단할 수 있다. 따라서 세 범주 모두로 분류될 수 있으며, 사업모형과 SPPI 조건의 조합으로 결정된다.

| 사업모형 | SPPI 충족 | 분류 |
|---|---|---|
| 계약상 현금흐름 수취 | 충족 | **AC**(상각후원가) |
| 현금흐름 수취 + 매도 | 충족 | **FVOCI**(기타포괄손익-공정가치) |
| 매도(단기매매) 등 | 충족·불충족 무관 | **FVPL**(당기손익-공정가치) |
| 위 어느 경우든 | SPPI 불충족 | **FVPL** |

- **AC 조건**: 원리금 수취만을 목적으로 보유(사업모형①)하고 현금흐름이 원리금만으로 구성(SPPI 충족)될 것.
- **FVOCI 조건**: 원리금 수취와 매도를 모두 목적(사업모형②)으로 하고 SPPI를 충족할 것.
- **FVPL 조건**: 위 두 조건에 해당하지 않을 때(단기매매목적이거나 SPPI 불충족). 또한 회계불일치를 제거하기 위해 최초 인식 시 FVPL로 지정할 수도 있다.

투자채무상품의 FVOCI는 지분상품의 FVOCI와 결정적으로 다르다. **채무상품 FVOCI는 처분(또는 재분류) 시 그동안 OCI에 쌓인 평가손익 누계액을 당기손익으로 재순환(recycling)**한다. 반면 지분상품 FVOCI(지정)는 재순환하지 않는다.

| 구분 | 지분상품 FVOCI | 채무상품 FVOCI |
|---|---|---|
| 성격 | 선택적 지정 | 사업모형·SPPI로 결정 |
| 취소·재분류 | 불가 | 사업모형 변경 시 재분류 가능 |
| 처분 시 재순환 | 불가 | **가능(당기손익 재순환)** |

또한 AC와 FVOCI로 분류된 채무상품은 뒤에서 볼 **손실충당금(기대신용손실)**의 적용 대상이 된다는 점도 특징이다.

> 핵심: 투자채무상품은 원리금 현금흐름이 있어 AC(수취+SPPI충족)·FVOCI(수취+매도+SPPI충족)·FVPL(그 외)로 모두 분류될 수 있으며, 채무상품 FVOCI는 지분상품과 달리 처분 시 평가손익을 당기손익으로 재순환한다.

### ❹ 손실충당금

K-IFRS는 금융자산의 신용위험(채무불이행 위험)을 손상으로 인식하는데, 손실이 이미 발생했을 때가 아니라 **미래에 예상되는 손실을 미리 인식하는 기대신용손실(Expected Credit Loss, ECL) 모형**을 사용한다.

**(1) 기대신용손실 모형의 개념**

- **발생손실 → 기대손실**: 과거에는 부도 등 손상 사건이 실제로 발생한 후에 손실을 인식했으나, 현재는 손상 징후가 없어도 미래에 예상되는 신용손실을 추정하여 미리 인식한다.
- **적용 대상**: AC(상각후원가) 금융자산과 채무상품 FVOCI, 매출채권 등이 대상이다. **FVPL 금융자산과 지분상품은 대상이 아니다**(FVPL은 이미 공정가치로 평가하여 손실이 당기손익에 반영되므로, 지분상품은 원리금 개념이 없으므로).

**(2) 손실충당금의 성격**

손실충당금(loss allowance)은 이름에 "충당금"이 들어가지만 **부채가 아니다**. 이는 **금융자산(채권)의 장부금액을 줄이는 자산의 차감적 평가계정(contra-asset)**이다. 재무상태표에는 채권 총액에서 손실충당금을 차감한 순액(회수가능액)이 표시된다.

| 구분 | 내용 |
|---|---|
| 계정 성격 | 자산의 차감적 평가계정(부채 아님) |
| 표시 | 채권 총액 − 손실충당금 = 순장부금액 |
| 상대 계정(손익) | 손상차손(당기비용) |
| 적용 대상 | AC 금융자산, 채무상품 FVOCI, 매출채권 등 |
| 적용 제외 | FVPL 금융자산, 지분상품 |

**(3) 회계처리**

기대신용손실을 인식할 때는 **손상차손(비용)**을 계상하고 상대 계정으로 **손실충당금**을 설정한다.

```
(차) 금융자산손상차손   20,000  (대) 손실충당금   20,000
```

이후 신용위험이 개선되어 손실충당금을 줄여야 하면 **손상차손환입(수익)**으로 처리한다.

```
(차) 손실충당금   5,000  (대) 손상차손환입   5,000
```

이처럼 손실충당금은 매출채권에 대한 대손충당금과 같은 구조로, 자산 차감 계정으로 표시되어 채권의 순 회수가능액을 보여 준다.

> 핵심: 손실충당금은 **기대신용손실(ECL) 모형**에 따라 미리 인식하는 금액이며, 부채가 아니라 금융자산의 장부금액을 줄이는 **자산의 차감적 평가계정**이다(FVPL·지분상품은 적용 제외).

## 제14장 금융부채와 사채

기업이 자금을 조달하는 방법은 크게 **부채(타인자본)** 와 **자본(자기자본)** 으로 나뉜다. 이 중 계약에 따라 거래상대방에게 현금 등 금융자산을 인도할 의무를 지는 부채를 **금융부채**라 하며, 대표적인 장기 금융부채가 **사채(社債, bonds)** 이다. 사채는 회사가 다수의 투자자로부터 거액의 자금을 장기간 빌리기 위해 발행하는 채무증권으로, 만기까지 정기적으로 이자를 지급하고 만기에 액면금액을 상환한다.

### ❶ 금융부채의 분류

**금융부채(financial liability)** 란 다음 중 하나에 해당하는 계약상 의무이다.

- 거래상대방에게 **현금 등 금융자산을 인도**하기로 한 계약상 의무
- 잠재적으로 불리한 조건으로 금융자산·금융부채를 교환하기로 한 계약상 의무

매입채무, 미지급금, 차입금, 사채 등이 금융부채에 해당한다. 반면 **선수금·선수수익**은 재화·용역을 제공할 의무이고, **미지급법인세**는 법령에 따른 의무이므로 금융부채가 아니다.

K-IFRS는 금융부채를 후속측정 방법에 따라 두 가지로 분류한다.

| 구분 | 상각후원가측정 금융부채 | 당기손익-공정가치측정(FVPL) 금융부채 |
|---|---|---|
| 영문 약칭 | AC(Amortized Cost) | FVPL(Fair Value through P/L) |
| 후속측정 | **상각후원가**(유효이자율법) | **공정가치**, 변동분 당기손익 |
| 해당 예시 | 일반 사채, 차입금, 매입채무 | 단기매매목적 부채, 파생상품부채 |
| 거래원가 | 최초 장부금액에서 **차감** | 당기비용 처리 |

- **상각후원가측정 금융부채**: 대부분의 금융부채가 여기에 속한다. 최초에 **공정가치(발행금액)에서 거래원가를 차감**한 금액으로 인식하고, 이후 **유효이자율법**을 적용한 상각후원가로 측정한다.
- **FVPL 금융부채**: 단기매매목적이거나 최초 인식 시 이 범주로 지정한 금융부채로, 매 보고기간 말 **공정가치로 재측정**하고 변동분을 당기손익에 반영한다. 거래원가는 발생 즉시 비용으로 처리한다.

일반적인 사채는 상각후원가측정 금융부채로 분류되며, 본 장의 논의는 이를 중심으로 한다.

> 핵심: 금융부채는 현금 등 금융자산을 인도할 계약상 의무이며, 대부분은 상각후원가로(유효이자율법), 단기매매·지정분은 FVPL로 측정한다.

### ❷ 사채의 발행

사채에는 세 가지 이자율 개념이 있다.

- **액면이자율(표시이자율, coupon rate)**: 사채권면에 표시된 이자율. 매기 지급할 액면이자(현금이자)를 계산하는 기준이다. → **액면이자 = 액면금액 × 액면이자율**
- **시장이자율(유효이자율, market rate)**: 발행 당시 시장에서 요구하는 이자율. 사채의 발행금액(현재가치)을 결정한다.

**사채의 발행금액은 사채로부터 발생하는 미래현금흐름(만기 액면금액 + 매기 액면이자)을 시장이자율로 할인한 현재가치**로 결정된다.

발행금액 = (매기 액면이자 × 연금현가계수) + (만기 액면금액 × 현가계수)

액면이자율과 시장이자율의 관계에 따라 발행 형태가 달라진다.

| 발행 형태 | 이자율 관계 | 발행금액 vs 액면금액 | 발행차금 |
|---|---|---|---|
| **액면발행** | 액면이자율 = 시장이자율 | 발행금액 = 액면금액 | 없음 |
| **할인발행** | 액면이자율 < 시장이자율 | 발행금액 < 액면금액 | 사채할인발행차금 |
| **할증발행** | 액면이자율 > 시장이자율 | 발행금액 > 액면금액 | 사채할증발행차금 |

직관: 시장이 더 높은 이자(시장이자율)를 요구하는데 사채가 낮은 이자(액면이자율)만 준다면, 투자자는 그만큼 **싸게** 사려 하므로 **할인발행**된다. 반대로 사채가 시장보다 후한 이자를 주면 **비싸게** 팔려 **할증발행**된다.

**(1) 액면발행** — 액면 1,000,000원, 액면이자율 = 시장이자율 10%

```
(차) 현금        1,000,000   (대) 사채   1,000,000
```

**(2) 할인발행** — 액면 1,000,000원, 액면이자율 8%, 만기 3년, 시장이자율 10%, 이자 매년 말 지급

- 액면이자 = 1,000,000 × 8% = 80,000원
- 연금현가계수(10%, 3년) = 2.48685, 현가계수(10%, 3년) = 0.75131
- 발행금액 = 80,000 × 2.48685 + 1,000,000 × 0.75131 = 198,948 + 751,310 = **950,258원**
- 사채할인발행차금 = 1,000,000 − 950,258 = 49,742원

```
(차) 현금            950,258   (대) 사채   1,000,000
    사채할인발행차금   49,742
```

**사채할인발행차금**은 사채의 **차감계정(평가계정)** 으로, 재무상태표에 사채 액면금액에서 차감하는 형식으로 표시된다. 따라서 발행 시 장부금액(순액) = 1,000,000 − 49,742 = 950,258원이다.

**(3) 할증발행** — 액면 1,000,000원, 액면이자율 10%, 만기 3년, 시장이자율 8%, 이자 매년 말 지급

- 액면이자 = 1,000,000 × 10% = 100,000원
- 연금현가계수(8%, 3년) = 2.57710, 현가계수(8%, 3년) = 0.79383
- 발행금액 = 100,000 × 2.57710 + 1,000,000 × 0.79383 = 257,710 + 793,830 = **1,051,540원**
- 사채할증발행차금 = 1,051,540 − 1,000,000 = 51,540원

```
(차) 현금   1,051,540   (대) 사채            1,000,000
                            사채할증발행차금     51,540
```

**사채할증발행차금**은 사채의 **가산계정**으로, 사채 액면금액에 가산하여 표시된다. 발행 시 장부금액(순액) = 1,000,000 + 51,540 = 1,051,540원이다.

> 핵심: 발행금액은 미래현금흐름을 시장이자율로 할인한 현재가치이며, 액면이자율<시장이자율이면 할인발행, 액면이자율>시장이자율이면 할증발행된다.

### ❸ 사채이자와 상각

사채의 이자비용은 **유효이자율법(effective interest method)** 으로 인식한다. 핵심 산식은 다음과 같다.

- **유효이자(이자비용) = 기초 장부금액 × 유효이자율**
- **액면이자(현금지급액) = 액면금액 × 액면이자율**
- **상각액 = 유효이자 − 액면이자** (절대값)

상각액만큼 사채할인·할증발행차금이 상각되어, 사채의 장부금액이 매기 **액면금액을 향해 수렴**한다.

- **할인발행**: 장부금액 < 액면 → 장부금액이 매기 **증가**(할인차금 상각). 이자비용(유효이자) > 현금이자(액면이자).
- **할증발행**: 장부금액 > 액면 → 장부금액이 매기 **감소**(할증차금 상각). 이자비용(유효이자) < 현금이자(액면이자).

두 경우 모두 매기 상각액은 점점 **커진다**.

**(1) 할인발행 상각표** — 발행금액 950,258원, 유효이자율 10%, 액면이자 80,000원

| 연도 | 기초 장부금액 | 유효이자(10%) | 액면이자(8%) | 상각액 | 기말 장부금액 |
|---|---|---|---|---|---|
| 1 | 950,258 | 95,026 | 80,000 | 15,026 | 965,284 |
| 2 | 965,284 | 96,528 | 80,000 | 16,528 | 981,812 |
| 3 | 981,812 | 98,188* | 80,000 | 18,188 | 1,000,000 |

\* 3차연도 유효이자는 단수차이를 조정한 금액(98,188 = 80,000 + 18,188)이다. 상각액 합계 15,026 + 16,528 + 18,188 = 49,742원으로 사채할인발행차금 총액과 일치한다.

1차연도 이자지급 분개:

```
(차) 이자비용   95,026   (대) 현금             80,000
                             사채할인발행차금    15,026
```

이자비용 95,026원은 현금 지급이자 80,000원과 상각액 15,026원의 합이다. 상각액만큼 사채할인발행차금(차감계정)이 감소하므로 사채 장부금액이 950,258 → 965,284원으로 증가한다.

**(2) 할증발행 상각표** — 발행금액 1,051,540원, 유효이자율 8%, 액면이자 100,000원

| 연도 | 기초 장부금액 | 유효이자(8%) | 액면이자(10%) | 상각액 | 기말 장부금액 |
|---|---|---|---|---|---|
| 1 | 1,051,540 | 84,123 | 100,000 | 15,877 | 1,035,663 |
| 2 | 1,035,663 | 82,853 | 100,000 | 17,147 | 1,018,516 |
| 3 | 1,018,516 | 81,484* | 100,000 | 18,516 | 1,000,000 |

\* 3차연도 유효이자는 단수차이를 조정한 금액(81,484 = 100,000 − 18,516)이다. 상각액 합계 15,877 + 17,147 + 18,516 = 51,540원으로 사채할증발행차금 총액과 일치한다.

1차연도 이자지급 분개:

```
(차) 이자비용        84,123   (대) 현금   100,000
    사채할증발행차금   15,877
```

이자비용 84,123원은 현금 지급이자 100,000원에서 상각액 15,877원을 차감한 금액이다. 상각액만큼 사채할증발행차금(가산계정)이 감소하므로 사채 장부금액이 1,051,540 → 1,035,663원으로 감소한다.

**정액법과의 비교**: K-IFRS는 정액법을 인정하지 않고 **유효이자율법만** 허용한다. 정액법은 매기 상각액이 일정하나, 유효이자율법은 장부금액에 유효이자율을 곱하므로 매기 이자비용이 장부금액 변화에 따라 달라진다(할인발행 시 이자비용 점증, 할증발행 시 점감).

> 핵심: 유효이자율법에서 이자비용=기초 장부금액×유효이자율, 상각액=유효이자−액면이자이며, 상각으로 장부금액은 매기 액면금액을 향해 수렴한다.

### ❹ 사채의 조기상환(만기 전 상환)

기업은 만기 전에 사채를 매입하여 상환(조기상환)할 수 있다. 이때 **상환일의 장부금액(상각후원가)** 과 **상환금액(지급 현금)** 을 비교하여 손익을 인식한다.

**사채상환손익 = 상환일의 장부금액 − 상환금액**

- 장부금액 > 상환금액 → **사채상환이익**(싸게 갚음)
- 장부금액 < 상환금액 → **사채상환손실**(비싸게 갚음)

상환일의 장부금액은 상환 직전까지 유효이자율법으로 상각을 반영한 값을 사용한다. 조기상환 시 미상각 발행차금(할인·할증차금 잔액)도 함께 제거한다.

**계산 예시** — 앞의 할인발행 사채(액면 1,000,000원)를 2차연도 말 장부금액 981,812원인 시점에 현금 990,000원을 지급하고 상환

- 2차연도 말 장부금액 = 981,812원
- 미상각 사채할인발행차금 = 1,000,000 − 981,812 = 18,188원
- 사채상환손익 = 981,812 − 990,000 = **−8,188원(사채상환손실)**

```
(차) 사채          1,000,000   (대) 현금             990,000
    사채상환손실       8,188        사채할인발행차금    18,188
```

차변 합계(1,000,000 + 8,188 = 1,008,188)와 대변 합계(990,000 + 18,188 = 1,008,188)가 일치한다. 액면 1,000,000원과 미상각 할인차금 18,188원을 모두 제거하여 장부금액 981,812원을 소멸시키고, 이보다 큰 현금 990,000원을 지급하였으므로 8,188원의 상환손실이 발생한다.

**할증발행 사채의 조기상환 예시** — 할증발행 사채(액면 1,000,000원)를 2차연도 말 장부금액 1,018,516원인 시점에 현금 1,010,000원을 지급하고 상환

- 미상각 사채할증발행차금 = 1,018,516 − 1,000,000 = 18,516원
- 사채상환손익 = 1,018,516 − 1,010,000 = **+8,516원(사채상환이익)**

```
(차) 사채            1,000,000   (대) 현금        1,010,000
    사채할증발행차금     18,516        사채상환이익      8,516
```

사채상환손익은 당기손익(영업외손익 성격)으로 처리한다. 시장이자율이 발행 시점보다 상승하면 사채의 공정가치가 하락하므로 낮은 금액으로 상환할 수 있어 상환이익이 발생하기 쉽고, 반대로 시장이자율이 하락하면 상환손실이 발생하기 쉽다.

> 핵심: 조기상환손익=상환일 장부금액−상환금액이며, 미상각 발행차금을 함께 제거한다. 장부금액이 상환금액보다 크면 상환이익, 작으면 상환손실이다.


## 제15장 충당부채·우발부채

부채는 과거사건의 결과로 현재 부담하는 의무로서, 그 이행에 경제적효익이 유출될 것으로 예상되는 것을 말한다. 지급 금액과 시기가 확정된 **확정부채**(매입채무, 차입금 등)와 달리, 지출의 **시기 또는 금액이 불확실한** 부채가 존재한다. K-IFRS 제1037호는 이러한 불확실한 부채를 **충당부채·우발부채·우발자산**으로 구분하여 인식·공시 기준을 규정한다.

### ❶ 충당부채

**충당부채(provision)** 란 **지출의 시기 또는 금액이 불확실한 부채**를 말한다. 충당부채는 다음 **세 가지 인식요건을 모두 충족**할 때 부채로 인식한다.

1. **과거사건의 결과로 현재의무(법적의무 또는 의제의무)가 존재**한다.
2. 그 의무를 이행하기 위하여 **경제적효익이 있는 자원의 유출가능성이 높다(probable)**. 여기서 '높다'는 발생확률이 발생하지 않을 확률보다 큰 경우, 즉 **50% 초과**를 의미한다.
3. 그 의무의 이행에 소요되는 **금액을 신뢰성 있게 추정**할 수 있다.

세 요건 중 하나라도 충족하지 못하면 충당부채로 인식하지 않는다.

**현재의무의 종류**

- **법적의무**: 법률, 계약(명시적·묵시적) 등에 의해 발생하는 의무
- **의제의무(constructive obligation)**: 과거의 실무관행, 공표된 정책 등으로 기업이 특정 책임을 이행할 것이라는 정당한 기대를 상대방에게 갖게 하여 발생하는 의무 (예: 법적 의무는 없으나 관행적으로 환불해 온 정책)

**측정 — 최선의 추정치(best estimate)**

충당부채는 보고기간 말 현재 의무 이행에 필요한 지출에 대한 **최선의 추정치**로 측정한다.

- 다수의 항목이 관련되면 **기댓값(가능한 결과에 확률을 가중)** 으로 추정한다.
- 단일 의무는 **가장 발생가능성이 높은 단일 금액**을 사용한다.
- 화폐의 시간가치 영향이 중요하면 **현재가치**로 할인하여 측정한다.
- 매 보고기간 말 잔액을 검토하여 최선의 추정치를 반영하도록 조정한다.

**충당부채의 예시**

| 유형 | 내용 |
|---|---|
| **제품보증충당부채** | 판매한 제품의 무상수리·교환 의무에 대비하여 설정 |
| **소송충당부채** | 진행 중인 소송에서 패소 가능성이 높고 배상액 추정 가능 시 |
| **복구충당부채** | 유형자산 사용 후 원상복구 의무 |
| **경품·마일리지충당부채** | 판매촉진 제도에 따른 미래 지출 의무 |

**제품보증충당부채 예시** — 당기 매출액 10,000,000원, 과거 경험상 매출액의 2%가 보증비용으로 지출될 것으로 추정

```
(설정)
(차) 제품보증비        200,000   (대) 제품보증충당부채   200,000

(실제 보증비 50,000원 지출 시)
(차) 제품보증충당부채   50,000   (대) 현금              50,000
```

수익-비용 대응 원칙에 따라, 매출이 발생한 기간에 관련 보증비용을 추정하여 비용과 충당부채로 인식한다.

> 핵심: 충당부채는 ①과거사건에 의한 현재의무, ②유출가능성 높음(50% 초과), ③금액의 신뢰성 있는 추정 — 세 요건을 모두 충족할 때 최선의 추정치로 인식한다.

### ❷ 우발부채

**우발부채(contingent liability)** 는 다음 중 하나에 해당하며, 부채로 **인식하지 않고 주석으로 공시**한다.

- **잠재적 의무**: 과거사건으로 발생하였으나, 기업이 전적으로 통제할 수 없는 **미래의 불확실한 사건**의 발생 여부로만 그 존재가 확인되는 잠재적 의무
- **현재의무이나 요건 미충족**: 현재의무가 존재하지만, ⓐ 경제적효익의 유출가능성이 높지 않거나(50% 이하), ⓑ 금액을 신뢰성 있게 추정할 수 없어 충당부채의 인식요건을 충족하지 못하는 경우

**충당부채와 우발부채의 판단 기준**

우발부채는 재무제표 본문에 부채로 계상하지 않는다. 다만 유출가능성이 **아주 낮은 경우(remote)** 를 제외하고는 주석으로 공시한다.

| 자원 유출가능성 | 금액 추정 가능 | 금액 추정 불가능 |
|---|---|---|
| **높음(probable, 50% 초과)** | **충당부채**로 인식 | **우발부채** 주석공시 |
| **높지 않으나 아주 낮지는 않음** | **우발부채** 주석공시 | **우발부채** 주석공시 |
| **아주 낮음(remote)** | 공시하지 않음 | 공시하지 않음 |

핵심은 두 축이다. ① 유출가능성이 '높은지'와 ② 금액을 '신뢰성 있게 추정'할 수 있는지. **둘 다 충족하면 충당부채**, 그렇지 않으면 우발부채(또는 공시 배제)이다.

**주석 공시 내용**: 우발부채의 성격, 재무적 영향의 추정금액, 유출 시기·금액의 불확실성, 제3자에 의한 변제 가능성 등을 주석에 기재한다.

> 핵심: 우발부채는 부채로 인식하지 않고 주석에 공시하며, 잠재적 의무이거나 유출가능성이 높지 않거나 금액 추정이 불가능한 현재의무이다(단, remote는 공시 제외).

### ❸ 우발자산

**우발자산(contingent asset)** 은 과거사건으로 발생하였으나 기업이 전적으로 통제할 수 없는 **미래의 불확실한 사건**의 발생 여부로만 그 존재가 확인되는 **잠재적 자산**이다. (예: 기업이 제기하여 진행 중인 소송에서 승소하여 받을 것으로 기대되는 배상금)

- 우발자산은 **자산으로 인식하지 않는다**. 미실현이익을 인식하지 않기 위한 보수주의의 결과이다.
- 경제적효익의 **유입가능성이 높은(probable)** 경우에는 **주석으로 공시**한다.
- 상황 변화로 수익의 실현이 **거의 확실(virtually certain)** 해지면, 그때 관련 자산을 재무제표에 **인식**한다(이 경우 더 이상 우발자산이 아님).

**충당부채·우발부채·우발자산 비교표**

| 구분 | 충당부채 | 우발부채 | 우발자산 |
|---|---|---|---|
| 성격 | 불확실한 **부채** | 잠재적 **부채**·요건 미충족 부채 | 잠재적 **자산** |
| 재무제표 인식 | **인식(부채로 계상)** | 인식 안 함 | 인식 안 함 |
| 유출·유입가능성 높음 | 인식 요건 | 주석공시 | 주석공시 |
| 가능성 높지 않음 | 우발부채로 | 주석공시(remote 제외) | 공시 안 함 |
| 거의 확실 | — | — | **자산 인식** |
| 처리 원칙 | 비용·부채 인식 | 주석공시 | 주석공시(보수주의) |

우발부채와 우발자산의 처리는 **비대칭적**이다. 부채(우발부채)는 유출가능성이 높지 않아도 주석으로 공시하나, 자산(우발자산)은 유입가능성이 높을 때만 공시한다. 이는 손실·부채는 적극적으로, 이익·자산은 신중하게 반영하는 **보수주의**를 반영한다.

> 핵심: 우발자산은 자산으로 인식하지 않고 유입가능성이 높을 때만 주석 공시하며, 실현이 거의 확실해지면 자산으로 인식한다. 부채는 넓게, 자산은 좁게 다루는 보수주의가 적용된다.


## 제16장 자본

**자본(equity)** 은 기업의 자산에서 부채를 차감한 **잔여지분(residual interest)** 으로, 주주(소유주)에게 귀속되는 몫이다. 자본은 크게 소유주가 납입한 **납입자본**과 기업활동으로 창출·유보한 **이익잉여금**, 그리고 미실현손익 등을 반영하는 **기타자본요소**로 구성된다. 자본거래(소유주와의 거래)에서는 손익이 발생하지 않고, 손익거래(영업활동)에서만 손익이 발생한다는 점이 자본 회계의 기본 원리이다.

### ❶ 자본의 분류

일반기업회계기준에 따른 자본의 5가지 분류는 다음과 같다.

| 분류 | 성격 | 주요 항목 |
|---|---|---|
| **자본금** | 발행주식의 액면총액 | 보통주자본금, 우선주자본금 |
| **자본잉여금** | 자본거래에서 생긴 잉여금 | 주식발행초과금, 감자차익, 자기주식처분이익 |
| **자본조정** | 자본 가감 성격의 임시항목 | 자기주식(−), 주식할인발행차금(−), 감자차손(−), 자기주식처분손실(−), 미교부주식배당금(+) |
| **기타포괄손익누계액** | 미실현손익 누계 | FVOCI금융자산평가손익, 재평가잉여금, 해외사업환산손익 |
| **이익잉여금** | 손익거래에서 유보한 이익 | 이익준비금, 임의적립금, 미처분이익잉여금 |

- **자본금**: 발행주식수 × 1주당 액면금액. 상법상 자본충실의 기준이 되는 법정자본이다.
- **자본잉여금**: 증자·감자·자기주식 등 **자본거래**에서 발생한 잉여금. 주식발행 시 액면 초과액이 **주식발행초과금**이다. 자본잉여금은 자본거래 이익이므로 배당재원이 아니며, 자본금 전입(무상증자)이나 결손보전에 사용된다.
- **자본조정**: 자본에 가감하는 성격이나 자본금·잉여금 어디에도 속하지 않는 임시항목. 자기주식은 자본의 차감(−)으로 표시한다.
- **기타포괄손익누계액**: 당기손익에 반영하지 않고 자본에 직접 누적되는 미실현손익.
- **이익잉여금**: **손익거래**에서 벌어들여 사외 유출(배당)하지 않고 사내 유보한 이익.

> 핵심: 자본은 자본금·자본잉여금·자본조정·기타포괄손익누계액·이익잉여금으로 분류되며, 자본거래 잉여금은 자본잉여금, 손익거래 유보이익은 이익잉여금이다.

### ❷ 자본금의 변화

**자본금 = 발행주식수 × 1주당 액면금액**

자본금은 액면금액에 발행주식수를 곱한 금액이며, 주식의 시가나 발행금액과는 무관하다. 액면금액을 초과하여 발행하면 초과액은 **주식발행초과금**(자본잉여금)으로, 액면금액 미만으로 발행하면 미달액은 **주식할인발행차금**(자본조정, 차감)으로 처리한다.

**유상증자(액면 초과발행) 예시** — 액면 5,000원 주식 1,000주를 주당 8,000원에 발행

```
(차) 현금   8,000,000   (대) 자본금          5,000,000
                            주식발행초과금     3,000,000
```

자본금은 액면총액 5,000,000원(= 5,000 × 1,000주)만 증가하고, 초과분 3,000,000원은 주식발행초과금으로 계상된다.

자본금이 변동하는 대표적 거래는 **증자**(자본금 증가)와 **감자**(자본금 감소)이며, 무상증자·주식배당 등으로도 자본금(발행주식수)이 변한다.

> 핵심: 자본금은 발행주식수×액면금액으로 결정되며, 발행금액 중 액면 초과분은 주식발행초과금, 미달분은 주식할인발행차금으로 자본금과 분리하여 처리한다.

### ❸ 증자

**증자(增資)** 는 자본금을 증가시키는 것으로, 실질에 따라 유상증자와 무상증자로 나뉜다.

| 구분 | 유상증자(실질적 증자) | 무상증자(형식적 증자) |
|---|---|---|
| 방법 | 신주를 발행하여 현금 등 자산 납입 | 잉여금을 자본금으로 전입 |
| 자산 | **증가** | 불변 |
| 자본 총액 | **증가** | **불변** |
| 자본금 | 증가 | 증가 |
| 발행주식수 | 증가 | 증가 |

**유상증자(실질적 증자)**: 신주를 발행하고 그 대가로 현금 등 자산이 유입되어 **자산과 자본이 실질적으로 증가**한다.

```
(차) 현금   8,000,000   (대) 자본금          5,000,000
                            주식발행초과금     3,000,000
```

**무상증자(형식적 증자)**: 자본잉여금(주식발행초과금 등)이나 법정적립금을 **자본금으로 전입**하여 신주를 무상 교부한다. 자본 내부 계정 간 대체일 뿐이므로 **자본 총액은 불변**이고 자산 유입도 없다.

주식발행초과금 5,000,000원을 자본금으로 전입(무상증자):

```
(차) 주식발행초과금   5,000,000   (대) 자본금   5,000,000
```

자본금은 증가하나 자본잉여금이 동액 감소하므로 자본 총액은 변하지 않는다. 무상증자로 주주는 추가 납입 없이 주식을 받지만, 주식 수 증가로 1주당 가치는 희석되어 실질적인 부의 증가는 없다.

> 핵심: 유상증자는 자산·자본이 실질적으로 증가하는 실질적 증자이고, 무상증자는 잉여금을 자본금으로 대체할 뿐이어서 자본 총액이 불변인 형식적 증자이다.

### ❹ 자본이 불변하는 다양한 사례

발행주식수나 자본금 구성은 변하지만 **자본 총액(총자본)은 변하지 않는** 거래들이 있다. 무상증자·주식배당·주식분할·주식병합이 대표적이다. 이들은 모두 자산 유입·유출이 없는 자본 내부의 변화 또는 주식 수량 조정이다.

| 구분 | 자본금 | 잉여금 | 발행주식수 | 1주당 액면 | 총자본 |
|---|---|---|---|---|---|
| **무상증자** | 증가 | (자본·이익잉여금) 감소 | **증가** | 불변 | **불변** |
| **주식배당** | 증가 | 이익잉여금 감소 | **증가** | 불변 | **불변** |
| **주식분할** | 불변 | 불변 | **증가** | **감소** | **불변** |
| **주식병합** | 불변 | 불변 | **감소** | **증가** | **불변** |

- **무상증자**: 잉여금 → 자본금 전입. 자본금 증가, 주식수 증가, 총자본 불변.
- **주식배당**: 이익잉여금 → 자본금 전입, 주식으로 배당. 자본금 증가, 주식수 증가, 총자본 불변. (현금 유출이 없어 사내 자금 유보 효과)
- **주식분할(액면분할)**: 1주를 여러 주로 분할(예: 액면 5,000원 1주 → 액면 1,000원 5주). **자본금·잉여금 모두 불변**, 주식수만 증가하고 1주당 액면이 감소한다. 회계처리(분개)가 없다.
- **주식병합**: 여러 주를 1주로 병합(주식분할의 반대). 자본금·잉여금 불변, 주식수 감소·1주당 액면 증가.

**핵심 비교** — 무상증자·주식배당은 **자본금이 증가**(잉여금 감소)하나, 주식분할·주식병합은 **자본금이 불변**(액면만 조정)이라는 점이 결정적 차이다. 그러나 네 가지 모두 **총자본은 변하지 않으며** 회사에 자산이 유입되지도 유출되지도 않는다.

> 핵심: 무상증자·주식배당·주식분할·주식병합은 모두 총자본이 불변이며, 무상증자·주식배당은 자본금이 증가(잉여금 감소)하고 주식분할·주식병합은 자본금이 불변인 채 액면만 조정된다.

### ❺ 자기주식

**자기주식(treasury stock)** 은 회사가 이미 발행한 자기 회사 주식을 재취득한 것이다. 자기주식은 미발행주식과 유사한 성격이므로 자산이 아니라 **자본의 차감항목(자본조정)** 으로 처리한다. 자기주식 거래는 자본거래이므로 취득·처분에서 **당기손익이 발생하지 않는다**.

**(1) 취득** — 액면 5,000원 주식 100주를 주당 8,000원에 취득

```
(차) 자기주식   800,000   (대) 현금   800,000
```

자기주식 800,000원은 자본에서 차감(−)하여 표시한다. 취득원가법에 따라 매입가액 전액을 자기주식으로 계상한다.

**(2) 처분(처분이익)** — 취득한 자기주식 중 50주(취득원가 주당 8,000원)를 주당 10,000원에 처분

```
(차) 현금   500,000   (대) 자기주식          400,000
                          자기주식처분이익    100,000
```

처분가액(500,000)이 취득원가(400,000)를 초과한 100,000원은 **자기주식처분이익**으로, **자본잉여금**에 계상한다(당기손익 아님).

**(3) 처분(처분손실)** — 나머지 50주(취득원가 주당 8,000원)를 주당 6,000원에 처분

```
(차) 현금            300,000   (대) 자기주식   400,000
    자기주식처분이익   100,000
```

처분가액(300,000)이 취득원가(400,000)에 미달한 100,000원은 **자기주식처분손실**이다. 다만 이전에 계상한 자기주식처분이익(100,000원, 자본잉여금) 잔액이 있으면 **먼저 상계**하고, 부족분만 **자기주식처분손실(자본조정)** 로 처리한다. 위 예시는 처분이익 잔액 100,000원과 전액 상계되어 처분손실 계정이 남지 않는다.

**(4) 소각** — 취득한 자기주식(액면 5,000원 100주, 취득원가 800,000원)을 소각

```
(차) 자본금   500,000   (대) 자기주식   800,000
    감자차손   300,000
```

소각 시 액면금액(500,000원 = 5,000 × 100주)만큼 자본금을 감소시키고, 취득원가가 액면을 초과한 300,000원은 **감자차손(자본조정)** 으로 처리한다. 반대로 취득원가가 액면보다 작으면 그 차액은 **감자차익(자본잉여금)** 이 된다.

> 핵심: 자기주식은 자산이 아닌 자본의 차감항목이며, 처분손익은 당기손익이 아닌 자본잉여금(처분이익)·자본조정(처분손실)으로 처리하고, 소각 시 액면 초과분은 감자차손으로 인식한다.

### ❻ 이익잉여금

**이익잉여금(retained earnings)** 은 손익거래에서 벌어들인 이익 중 배당 등으로 사외 유출하지 않고 사내에 유보한 금액이다. 처분·적립 여부에 따라 다음과 같이 구분한다.

| 구분 | 성격 | 내용 |
|---|---|---|
| **이익준비금** | 법정적립금 | 상법상 강제 적립. 자본금의 1/2에 달할 때까지 매 결산기 **현금배당액의 1/10 이상** 적립 |
| **임의적립금** | 임의적립금 | 정관·주주총회 결의로 특정 목적을 위해 적립(사업확장적립금, 감채적립금 등) |
| **미처분이익잉여금** | 미처분 | 아직 처분되지 않은 이익잉여금. 배당·적립의 재원 |

**이익준비금**: 상법 제458조에 따라 회사는 자본금의 1/2에 달할 때까지 매 결산기 **금전(현금)에 의한 이익배당액의 10분의 1 이상**을 이익준비금으로 적립해야 한다. 주식배당은 대상에서 제외된다.

**배당의 회계처리**

배당은 배당기준일·배당결의일(주주총회)·배당지급일의 순서로 진행되며, 배당결의일에 부채(미지급배당금) 또는 자본금 전입 의무가 확정된다.

**① 현금배당** — 미처분이익잉여금에서 현금배당 1,000,000원 결의(이익준비금은 배당액의 1/10 적립)

```
(배당 결의 시)
(차) 미처분이익잉여금   1,100,000   (대) 미지급배당금   1,000,000
                                        이익준비금        100,000

(배당 지급 시)
(차) 미지급배당금   1,000,000   (대) 현금   1,000,000
```

현금배당은 자산(현금)과 자본(이익잉여금)을 모두 감소시키는 **실질적 유출**이다. 배당결의 시점에 미지급배당금(부채)이 계상되고, 동시에 배당액의 1/10인 100,000원을 이익준비금으로 적립한다.

**② 주식배당** — 미처분이익잉여금에서 주식배당 1,000,000원(액면 발행) 결의

```
(배당 결의 시)
(차) 미처분이익잉여금   1,000,000   (대) 미교부주식배당금   1,000,000

(주식 교부 시)
(차) 미교부주식배당금   1,000,000   (대) 자본금            1,000,000
```

주식배당은 이익잉여금을 자본금으로 대체하는 것으로, **현금 유출이 없고 자본 총액도 불변**이다. 결의 시 미교부주식배당금(자본조정)을 계상하고, 교부 시 자본금으로 대체한다. 주식배당은 이익준비금 적립 대상이 아니다.

**현금배당과 주식배당의 비교**

| 구분 | 현금배당 | 주식배당 |
|---|---|---|
| 자산 | 감소(현금 유출) | 불변 |
| 이익잉여금 | 감소 | 감소 |
| 자본금 | 불변 | 증가 |
| 총자본 | **감소** | **불변** |
| 이익준비금 적립 | 대상(1/10 이상) | 제외 |

> 핵심: 이익잉여금은 이익준비금(법정)·임의적립금·미처분이익잉여금으로 구성되며, 현금배당은 총자본을 감소시키고(배당액의 1/10 이익준비금 적립), 주식배당은 이익잉여금을 자본금으로 대체하여 총자본이 불변이다.
